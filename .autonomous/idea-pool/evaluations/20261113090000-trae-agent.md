## 入选清单（5 个，均通过全部硬约束）

### 1. 20261113080544 C99 十六进制浮点 hexfloat 双向转换器 → `hexfloat-converter`

- **可行性确认**：手写扫描器解析符号/`0x`/十六进制尾数/`p` 指数，按 `(-1)^s × mantissa × 2^exp` 求值；生成方向用 DataView 取 binary64 位还原规范化 `0x1.xxxp±n`，覆盖 ±0/Infinity/NaN/subnormal。零新增依赖（仅用 DataView/Number 内置能力）。
- **查重**：`ieee754-float-converter` 仅展示内存位级 hex（`3FF0...`）、`number-base-converter` 仅处理整数进制，均不解析带 `p` 指数的 hexfloat 字符串；registry/loaders 无同名 slug。
- **复杂度**：S，纯函数。
- **测试向量**：`0x1.8p+1`→3、`0x1p-4`→0.0625、`-0x1.f4p+3`→-15.625；`3.0`→`0x1.8p+1`、`0.1`→`0x1.999999999999ap-4`；往返严格相等。
- **类目**：DEV_CODE，icon `Binary`。

### 2. 20261113080545 RFC 3986 相对引用解析器 → `relative-url-resolver`

- **可行性确认**：自实现 §5.2–§5.3 组件判定、merge 与 §5.2.4 输入缓冲/输出栈 `remove_dotSegments`，不调用 `new URL` 以保证可解释、跨环境一致。零依赖。
- **查重**：`url-parser` 仅拆分单个完整 URL，不接受 base+relative 双输入、不实现合并与点段移除；无同名 slug。
- **复杂度**：M，纯函数。
- **测试向量**：RFC 3986 §5.4.1 正常示例与 §5.4.2 异常示例（`../../../g`、`/./g`、`g/./h`、`g/../h`、`//g`、`g?y` 等）逐字符断言。
- **类目**：DEV_CODE，icon `Globe`。

### 3. 20261113080546 HTTP 日期头解析与格式化器 → `http-date-codec`

- **可行性确认**：手写 IMF-fixdate / RFC 850（两位年份世纪规则）/ asctime 三个确定性解析器，UTC 处理，输出 epoch 与格式类型，回写标准 IMF-fixdate，星期/日期交叉校验。零依赖。
- **查重**：`http-headers-reference` 仅参考表不解析、`timestamp-converter` 仅数字时间戳，均不识别三种 HTTP-date 语法；无同名 slug。
- **复杂度**：M，纯函数。
- **测试向量**：RFC 9110 §5.6.7 三个官方示例归一到同一 epoch；IMF 生成逐字符一致；缺 GMT/非法日期报错。
- **类目**：TIME_MATH，icon `Clock`。

### 4. 20261113080547 Content-Disposition 解析与构造器 → `content-disposition-codec`

- **可行性确认**：词法切分 disposition-type 与参数，引号感知；`filename*` 按 RFC 8187 `charset'lang'pct-encoded` 三段拆分并 UTF-8 百分号解码（TextEncoder/TextDecoder 内置）；§4.2 文件名优先级；构造生成 `filename*` + ASCII 降级 `filename`。零依赖。
- **查重**：`multipart-form-data-builder` 仅请求体间接生成、`url-encoder-decoder` 仅通用百分号编码，均不覆盖响应头语义与 ext-value 三段结构；无同名 slug。
- **复杂度**：M，纯函数。
- **测试向量**：`报告.pdf` 的 `%E6%8A%A5%E5%91%8A` 编解码往返、优先级决策、inline/回退/畸形 ext-value 报错。
- **类目**：DEV_CODE，icon `FileText`。

### 5. 20261113080548 RFC 8288 HTTP Link 头解析与构造器 → `link-header-codec`

- **可行性确认**：尖括号 `<...>` 与引号感知的逗号/分号两级词法切分，提取 URI-Reference 与 rel/rev/anchor/hreflang/type/media/title/扩展参数，rel 空白拆分小写归一，构造方向按 ABNF 反向生成并往返。零依赖。
- **查重**：`url-parser` 仅单 URL、`http-headers-reference` 仅文档，均不实现 link-value 列表语法；无同名 slug。
- **复杂度**：M，纯函数。
- **测试向量**：两条目示例头（含引号内逗号/分号不误切）、`rel="next preload"` 多值归一、构造往返、畸形输入可读报错。
- **类目**：DEV_CODE，icon `Link2`。
