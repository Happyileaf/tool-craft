## 入选清单（5 个，均通过全部硬约束）

### 1. 20261028081033 以太坊地址 EIP-55 校验和编码与校验器 → `eip55-address-checksum`

- **可行性确认**：Keccak-256（注意非 NIST SHA3-256，padding/domain separator 不同）以零依赖纯 TS 实现（约 80 行，参考 keccak 官方填充 0x01 与 24 轮 Keccak-f[1600]），不新增 npm 依赖。
- **查重**：现有 base58/bech32/base62/base64 等编码工具均不覆盖 EVM 地址校验和；无 web3/ethereum/keccak 相关 slug。
- **复杂度**：M（哈希置换 + 校验和规则），纯本地确定性运算。
- **测试向量**：EIP-55 官方向量（全小写输入 → 混合大小写输出，含 `0x5aAeb6053F3E94C9b9A09f33669435E7Ef1BeAed` 等）+ 篡改大小写检测断言。
- **类目**：CRYPTO_ENCODING，icon `ShieldCheck`。

### 2. 20261031080656 MRZ 机读旅行证件校验器 → `mrz-checksum-validator`

- **可行性确认**：纯字符串 + 模 10 加权（7,3,1）整数运算，零依赖；TD1（3×30）/TD2（2×36）/TD3（2×44）三种格式分支解析。
- **查重**：现有身份证 GB11643、Luhn、EAN-13、ISBN、IBAN、ISIN、VIN、统一社会信用代码等校验器均无 MRZ/ICAO 9303 条目，算法域不同。
- **复杂度**：M（多格式字段解析 + 多校验位），无外部依赖。
- **测试向量**：ICAO 9303 官方示例护照 MRZ（TD3 `L898902C3` / `6908061` / `9406236` / 复合位）固定断言。
- **类目**：DEV_CODE，icon `ScanLine`（映射表无此名则用 `Barcode`，最终选用已注册的 `Barcode`）。

### 3. 20261101140216 TypeID 标识符生成与解析器 → `typeid-codec`

- **可行性确认**：Crockford Base32 编解码 + UUIDv7 组装，纯 TS 零依赖；随机源复用 `crypto.getRandomValues`（与 ulid-generator 同一浏览器原生能力，非 npm 依赖）。
- **查重**：ulid-generator 生成裸 ULID、uuid-v7-generator 生成裸 UUID、base32-codec 是通用 Base32、uuid-inspector 只解析裸 UUID；「类型前缀 + `_` + Base32(UUID)」组合编解码无重复。
- **复杂度**：M，确定性输出。
- **测试向量**：TypeID 官方规范向量 `user_01h455vb4pex5vsknk084sn02q`（固定 UUID 编码/解码往返、前缀规则、非法字符/版本变体校验断言）。
- **类目**：DEV_CODE，icon `Fingerprint`。

### 4. 20261031201039 定点数 Qm.n 转换与运算可视化器 → `fixed-point-q-converter`

- **可行性确认**：纯整数/二进制补码运算，BigInt 处理 32/64 位，零依赖；Q 格式定标、范围/精度、饱和与舍入均为确定性公式。
- **查重**：ieee754-float-converter 解析 IEEE 浮点、number-base-converter/varint-codec/gray-code-converter 处理进制与整数编码，均不涉及定点小数位定标与运算语义。
- **复杂度**：M，纯函数。
- **测试向量**：Q15/Q1.15 已知向量（如 0.5→0x4000、-1→0x8000）、补码范围边界、乘法结果 Q 格式定标断言。
- **类目**：TIME_MATH（计算类），icon `Binary`。

### 5. 20261109020214 APR 实际年利率计算器 → `apr-ear-calculator`

- **可行性确认**：EAR=(1+r/n)^n−1、连续复利 e^r、手续费摊薄均为纯数学函数，零依赖；多方案对比为数组 map。
- **查重**：loan-calculator 只算月供/总利息、compound-interest-calculator 算终值、npv-irr-calculator 算现金流 NPV/IRR，均无名义 APR↔实际 EAR 换算与手续费年化。
- **复杂度**：S，纯函数。
- **测试向量**：12% 月复利 → 12.6825%、连续复利 10% → 10.5171%、反求名义利率往返断言。
- **类目**：TIME_MATH，icon `Percent`。
