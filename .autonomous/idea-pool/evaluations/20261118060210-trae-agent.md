## 入选理由（逐条）

1. **20261118040102 DNS CAA 记录生成与校验器（S）**：RFC 8659/8658 规则确定（issue/issuewild/iodef 标签、0 issuewes、flag 0/128、255 字符分段），与既有 dmarc-record-generator 同家族但标签语法完全不同；registry 无 CAA 工具（dmarc/spf/dkim/acme 均不覆盖），SWITCH 测试环境有真实 CAA 记录可作交叉向量。
2. **20261117200504 ISO 9362 BIC/SWIFT 代码结构校验器（S）**：8/11 位结构、4 银行码+2 国家码（ISO 3166-1 alpha-2）+2 地区码+可选 3 位分行码，纯字符串规则零依赖；registry 中 container-code-checksum 的 "BIC" 指 ISO 6346 集装箱代码，非 ISO 9362，不构成重复。
3. **20261105080303 DICOM UID 生成器与校验器（S）**：PS3.5 Ch.9 UID 规则确定（数字与句点、≤64 字符、每段非零开头、单字符段允许 0），校验为纯字符串规则、生成走时间戳+计数器确定性后缀（另有 Web Crypto 随机模式），固定向量可断言；registry 全文检索 dicom/medical-uid 无同类，与 ULID/UUID 等通用 ID 工具语法完全不同，零依赖。
4. **20261106160207 GS1 SSCC/EAN-14 条码校验位计算器（S）**：GS1 通用 Mod 10 加权 3/1 算法，SSCC(18)/GTIN-14(14)/GTIN-13/GTIN-12/GTIN-8 长度族 + AI(00)/(01) 包装，官方示例向量公开；registry 仅有面向 ISBN/银行卡/身份证的 Luhn 工具，无 GS1 应用标识符工具。
5. **20261107140226 iCalendar VTODO/VJOURNAL 组件生成器（M）**：RFC 5545 行折叠（75 字符 CRLF+空格）、属性参数转义、STATUS/PRIORITY/DUE/RELATED-TO 等字段确定；既有 ics-generator 经 grep 确认仅产 VEVENT，全仓无 VTODO/VJOURNAL 字符串，增量明确不重复。
