## 描述

对文本执行 ROT13 变换或自定义位移量（0–25）的凯撒密码加解密，仅变换英文字母，保留数字、符号与大小写，提供实时双向结果。现有 `symmetric-crypto`、`hash-generator` 等均为真实密码学算法，经典简单替换密码（常用于 CTF、谜题与轻度文本混淆）尚无覆盖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：英文字母的凯撒位移（含 ROT13 特例），工具 slug 拟为 `caesar-cipher`。
- **核心逻辑**：纯函数按位移量（0–25，自动按 26 取模）对 A–Z / a–z 做循环位移；非字母字符（数字、标点、空格、CJK 等）原样保留，保留原大小写。
- **加密 / 解密**：加密为正向位移，解密为反向（26 - shift）位移；ROT13 为 shift=13，加解密同一变换，对结果再施加一次应还原原文。
- **核心交互**：文本输入区 + 位移量选择（0–25，ROT13 快捷按钮）+ 加密 / 解密结果展示，实时联动。
- **输入输出**：纯函数，不触碰 DOM / React。
- **边界情况**：位移量超范围按模 26 归一化；空文本返回空字符串。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] ROT13：`Hello, World!` → `Uryyb, Jbeyq!`，再变换一次还原原文。
- [ ] 自定义位移：shift=3 时 `abcXYZ` → `defABC`；解密还原。
- [ ] 仅英文字母参与位移，数字、符号、空格、中文原样保留，大小写保持。
- [ ] shift=0 输出与输入一致；shift=26 与 shift=0 等价。
- [ ] 纯浏览器本地运算，无任何网络请求。
