## 描述

在服务等级协议（SLA）可用性百分比与允许停机时长之间双向换算：输入可用性目标（如 99.9%、99.95%、99.99%，支持自定义「几个 9」）输出每天/每周/每月（30 天）/每年对应的最大停机时间（自动换算为天/时/分/秒）；反向输入已发生故障时长与统计周期，算出实际可用性百分比与对应的「9 个数」等级，并对照常见 SLA 等级（99.0%–99.999%）给出服务积分（service credit）参考区间。面向 SRE、运维与售前技术方案编写。现有 `survey-sample-size-calculator` 等统计工具、`percentage-calculator` 通用百分比均不做时间预算换算；时间类工具（timestamp/duration 等）面向时刻与时长计算而非可用性建模。纯本地数值计算，零依赖，S 复杂度。

## 设计内容（进入 Claimed 前补全）

- slug：`sla-uptime-calculator`，目录 `apps/web/src/tools/sla-uptime-calculator/`，含 `index.tsx` / `constants.ts` / `index.module.css` / `utils/sla.ts` + `utils/sla.test.ts`。
- 纯函数层 `utils/sla.ts`：
  - `downtimeBudget(availabilityPct)`：由可用性百分比计算停机比例（1−pct/100），输出日（86400s）、周（604800s）、月（30 天 = 2592000s）、年（365 天 = 31536000s）四个周期允许停机秒数；
  - `formatDuration(seconds)`：把秒数自适应换算为「d/h/m/s」组合字符串（如 43m 12s），不足 1 秒显示毫秒；
  - `actualAvailability(downtimeSeconds, periodSeconds)`：由实际故障时长与统计周期反推可用性百分比（保留 4 位小数）与「9 的个数」`-log10(1−a)`；
  - `ninesToPercent(nines)` / `percentToNines(pct)`：n 个 9 与百分比互转；
  - 常见等级表（99.0 / 99.5 / 99.9 / 99.95 / 99.99 / 99.999）常量与参考 service credit 区间（定性档位：无 / 5% / 10% / 25% 等常见合同档位，UI 标注「参考」）。
- 组件：上半区可用性 → 停机预算（InputNumber 输入百分比或选择「几个 9」预设按钮，四周期结果卡片/表格）；下半区反向计算（故障时长 + 周期选择 → 实际可用性、9 个数、所达等级 Tag）；非法输入（<0、≥100、周期为 0）抛错并由 Alert 展示，不产出 NaN。
- 零新增依赖，全部数值计算在主线程瞬时完成。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 「3 个 9」与 99.9% 互转一致；99.999% 年预算 = 315.36 秒（5m 15.36s）
