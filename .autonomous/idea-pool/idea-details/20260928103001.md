## 描述

双向转换 CSV 和 JSON 格式数据。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：CSV → JSON（对象数组）与 JSON（对象数组）→ CSV 双向转换。
- **核心交互**：选择转换方向、分隔符（逗号 / 制表符 / 分号）与「首行作为表头」开关；输入即时转换，输出可复制、可清空、可载入示例。
- **输入输出**：CSV 文本 ↔ JSON 文本（对象数组）。
- **边界情况**：遵循 RFC 4180 处理引号包裹字段——字段内的分隔符、换行与双引号（`""` 转义）需正确解析与生成；字段数不齐时按表头补齐；空行跳过；兼容 CRLF 与 UTF-8 BOM；JSON → CSV 时按键并集生成表头；非法输入给出明确错误。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] CSV → JSON：首行表头映射为对象键，输出对象数组。
- [ ] 引号包裹字段内的分隔符、换行、双引号正确解析。
- [ ] JSON → CSV：对象数组按键生成表头与数据行，值含分隔符/引号/换行时正确转义。
- [ ] 支持切换分隔符与「首行作为表头」开关。
- [ ] 非法输入（如 JSON 非数组对象）给出明确错误信息。
- [ ] 纯浏览器本地运算，无任何网络请求。
