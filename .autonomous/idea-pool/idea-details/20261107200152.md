## 描述

面向 CTF 解谜、密码学教学与密室逃脱场景的古典（前现代）密码合集，一个工具内提供四种独立算法的加 / 解密：Bacon 培根密码（A/B 与 0/1 两种字母表变体，含隐藏文本的大小写隐写模式）、Rail Fence 栅栏密码（可调栏数 2–10，含偏移变体）、Playfair 普莱费尔方阵（5×5 方阵、I/J 合并、自动补 X 与重复字母拆分）、Atbash 埃特巴什字母反转。现有 `caesar-cipher`（凯撒 / ROT13）与 `vigenere-cipher`（维吉尼亚）只覆盖位移类与多表替换类古典密码，本合集四种算法与其原理互不重叠，且在 registry、活动池、completed、rejected 中以 Bacon / 培根 / Rail Fence / 栅栏 / Playfair / Atbash / 埃特巴什 全库检索均零命中。明确标注「仅用于教学解谜、不提供任何现代安全性」，非字母字符按各算法标准规则处理或原样保留。纯浏览器本地确定性运算、零新增依赖，可用教材标准密文向量做固定验收。
