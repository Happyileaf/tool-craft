## 描述

输入 FEN（Forsyth–Edwards Notation）字符串，解析为 8×8 棋盘并以 Unicode 棋子字符可视化，支持白方 / 黑方视角与 a–h / 1–8 坐标标注；校验字段结构与基本合法性（每方一个王、兵不得位于首末横线、易位权利与王车位置一致、吃过路兵目标格与走子方匹配），输出各字段明细、警告列表与规范化 FEN，并可复制 ASCII 棋盘。用于棋谱调试、引擎与教学工具对接；纯本地解析，零依赖。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 解析 FEN：棋子布局（8 个横线，以 `/` 分隔，数字 1–8 表示连续空格）、走子方（w / b）、易位权利（`-` 或 K / Q / k / q 子集）、吃过路兵目标格（`-` 或 a–h 加 3 / 6 横线）、半回合计数、回合数；允许 4–6 个字段，缺省半回合为 0、回合数为 1 并提示补全；② 结构校验（阻断性错误）：字段数不在 4–6、横线数不为 8、某横线合计格数不为 8、非法棋子字符、数字 0 / 9 或连续数字、走子方非 w / b、易位权利重复或含非法字符、吃过路兵目标格非法、计数非整数 / 负数 / 回合数为 0；③ 合法性警告（不阻断渲染）：白王 / 黑王数量不为 1、兵位于第 1 或第 8 横线、易位权利缺少对应王或车、吃过路兵目标格与走子方横线不匹配（w→第 6 横线、b→第 3 横线）、目标格非空或对应兵不在预期横线；④ 可视化：Unicode 棋子（`♔♕♖♗♘♙` / `♚♛♜♝♞♟`），白方视角（第 8 横线在上）或黑方视角（第 1 横线在上、文件 h→a），附坐标；⑤ 输出：棋子数量、走子方、易位权利、吃过路兵、半回合 / 回合数、警告代码与文案、规范化 FEN（易位按 KQkq 排序）、ASCII 棋盘（`PNBRQK` / `pnbrqk` / `.`）。

**核心交互**：FEN 输入框、示例按钮（初始局面）、视角切换、Unicode / ASCII 棋盘切换、复制规范化 FEN 与 ASCII 棋盘、错误 / 警告分区展示；非法结构时不高亮棋盘，仅显示错误定位。

**输入输出**：输入为 FEN 文本；输出为棋盘矩阵、Unicode / ASCII 渲染、字段明细、错误（阻断）与警告（非阻断）列表、规范化 FEN、棋子总数。

**边界情况**：输入首尾与字段间多余空格自动裁剪；全空棋盘 `8/8/8/8/8/8/8/8 w - - 0 1` 合法渲染并给出缺王警告；FEN 中的 `-` 与大小写严格校验；半回合 / 回合数上限 100000，超出报错；吃路过路兵目标格必须为小写文件名 + 横线；不推断走子合法性（将军、王车易位是否被阻挡等）并明确说明；Unicode 棋盘在非等宽字体下可能错位，提供 ASCII 作为稳定回退。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 初始局面 `rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1`：解析成功，棋子总数 32，无错误与警告，规范化 FEN 与输入一致
- [ ] 末横线少一格 `.../RNBQKBN w KQkq - 0 1`：返回结构错误并指明第 8 横线合计 7 格
- [ ] 非法棋子字符 `.../RNBQKBNX w KQkq - 0 1`：返回结构错误并指明字符 X 的位置
- [ ] 全空棋盘 `8/8/8/8/8/8/8/8 w - - 0 1`：可渲染空棋盘，给出「缺少白王」「缺少黑王」两条警告
- [ ] `P7/8/8/8/8/8/8/8 w - - 0 1`：给出「兵位于第 8 横线」警告（同时允许缺王警告）
- [ ] 易位权利乱序 `rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w qkQK - 0 1`：规范化 FEN 中易位字段为 `KQkq`；`KK` 重复则返回结构错误
- [ ] `4k3/8/8/8/8/8/8/4K3 w KQ - 0 1`：给出易位权利缺少对应车的警告；`4k3/8/8/8/8/8/8/4K3 w - e6 0 1` 给出吃过路兵目标格无对应兵的警告
- [ ] 4 字段 FEN `rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq -`：补全为 `0 1` 并提示；黑方视角首行显示第 1 横线且文件顺序为 h→a
