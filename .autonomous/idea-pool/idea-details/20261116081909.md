## 描述

按电器的额定功率（W / kW）、每日使用时长、每月使用天数与数量，结合单一电价或峰谷电价，计算每台电器及合计的日 / 月 / 年用电量（kWh）与电费，并展示各电器占月度用电的比例；另可将能效标签上的「年耗电量 kWh」反推为平均功率。用于家庭电费预估、电器耗电对比与节能决策；纯本地估算，结果不受阶梯电价、基本电费与待机功耗影响。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 多电器表格：名称、功率（W 或 kW 输入，内部统一换算为 W）、每日使用小时、每月使用天数、数量，逐行计算日耗电、月耗电、月电费、年耗电、年电费与占总量比例；② 合计面板：月度总 kWh、月度总电费、年度总 kWh / 总电费、平均每日电费与平均功率；③ 电价模式：单一电价（元/kWh）或峰谷电价（峰价、谷价、峰段用电占比 0–100%），峰谷模式下按合计电量分摊；④ 能效反推：输入年耗电量 kWh，输出 365×24 小时平均功率（W）；⑤ 电器耗电排行（按月电费或月 kWh 排序）。

**核心交互**：可增删的电器行、功率单位切换（W / kW）、每日时长与天数输入、数量输入、电价模式切换与费率输入、结果统计卡片与排行条形列表、一键复制汇总；非法输入即时标红提示。

**输入输出**：输入为电器清单（功率、时长、天数、数量）、电价模式与费率、可选年耗电量；输出为每行 kWh / 电费 / 占比与合计月度、年度用电量及费用、能效反推平均功率。

**边界情况**：功率 0–100000 W；每日时长 0–24 小时；每月天数 0–31 天；数量 1–100；电价 0–10 元/kWh；峰段占比 0–100%；kWh 保留 3 位小数、金额保留 2 位小数（四舍五入）；年度值按「月度 ×12」计算并注明假设；零时长或零功率输出 0；电价允许为 0（输出费用 0 并提示）；时长 >24、天数 >31、负数或非数字返回明确错误；空电器表提示至少添加一台；结果标注为估算值，不含阶梯加价、基本电费、税费与待机功耗。
