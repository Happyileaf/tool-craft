## 描述

生成 Nano ID 风格的 URL-safe 随机字符串标识符：支持自定义长度、自定义字母表（默认 `A-Za-z0-9_-`）、批量生成与一键复制；随机源使用 Web Crypto `getRandomValues`（密码学安全），并通过拒绝采样（rejection sampling）消除取模偏置。解决 UUID 之外更短、对 URL / HTML id 友好、可定制字符集与长度的标识需求。纯本地确定性运算、零新增依赖；核心生成函数允许注入随机源，可用固定随机字节向量做可验证验收。与已实现的 uuid-generator（RFC 4122 固定结构）、totp-generator / pkce-generator（特定协议产物）以及池中已有的「ULID generator」（时间可排序的 Crockford Base32）、「Snowflake ID 解析器」（时间戳+机器位结构 ID）、「Random data generator」（面向通用 mock 数据）原理与产物均不同：Nano ID 属于紧凑、字母表与长度可定制的随机 ID 独立类别，不构成重复。
