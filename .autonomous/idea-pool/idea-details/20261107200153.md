## 描述

在 sRGB / HEX 与 HSL、HSV（HSB）、HWB、CIE Lab、LCH（圆柱 Lab）之间做全双向互转的色彩工程工具，一次输入同步输出全部空间的数值与 CSS 可用字符串（hsl() / hwb() / lab() / lch()），并给出 sRGB 色域越界标记与钳制（clamp）提示。现有颜色工具中 `color-harmony` 仅内部使用 HSL 做调和、`oklch-workbench` 只做 OKLab/OKLCH 感知色阶、`rgb-cmyk-converter` 只做印刷 CMYK、`color-temperature-converter` 做色温、`color-mixer` / `color-blind-simulator` 均不暴露通用多空间坐标互转；活动池中的「CIE Lab 色差计算器 ΔE」聚焦色差评分而非空间坐标互转。本工具定位为开发者 / 设计师在 CSS Color Module Level 4 新语法与传统取色器之间换算的基础坐标工具。纯浏览器本地确定性矩阵 / 圆柱坐标运算、零新增依赖，可用 CSS 规范与已知色卡（如纯红、#2563EB）固定向量验收。
