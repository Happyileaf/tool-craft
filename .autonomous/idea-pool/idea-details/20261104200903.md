## 描述

实现 RFC 4226 HOTP（HMAC-Based One-Time Password）的纯前端生成与校验工具：输入共享密钥（Base32 / hex / 原始文本）、计数器 counter（0 起，十进制可步进）、位数（6–8 位，默认 6）与可选算法（SHA-1 默认 / SHA-256 / SHA-512），输出当前 HOTP 值，并支持「服务端视角」校验——给定用户提交的密码与窗口大小（look-ahead window），返回是否通过、计数器应前进多少步（resync），演示重放后计数器失效的行为；附 RFC 4226 附录 D 官方测试向量（secret `12345678901234567890`、counter 0–9 对应 `755224`…）逐条对照。

池中已完成 `totp-generator`（RFC 6238 时间型），其内部虽复用 HOTP 的动态截断，但 UI 只暴露时间步参数、不接受任意计数器输入，也不提供窗口重同步校验；HOTP 是独立的计数器型 OTP（硬件令牌、恢复码场景常用），无法由 TOTP 界面等价完成。全部使用 Web Crypto（HMAC）本地计算、零依赖，官方向量可确定性验收，复杂度 S。

## 设计内容（进入 Claimed 前补全）

- 纯函数核心使用 Web Crypto（HMAC，SHA-1 / SHA-256 / SHA-512）实现动态截断 HOTP。
- 密钥输入支持 Base32 / hex / 原始文本三种格式；counter 为非负整数（BigInt 解析，可步进）；位数 6–8，默认 6。
- 服务端视角校验：给定提交码与 look-ahead 窗口，返回是否命中、计数器前进步数（resync）；同一计数器重放不通过。
- 内置 RFC 4226 附录 D 官方向量（counter 0–9）一键载入逐条对照。
- 主线程、零新依赖（复用现有 base32 解码模式）；复杂度 S。
