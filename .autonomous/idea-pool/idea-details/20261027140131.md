## 描述

提供通用的 PBKDF2（Password-Based Key Derivation Function 2，RFC 8018 / PKCS#5）密钥派生计算器：输入密码、salt、迭代次数、派生密钥长度与底层哈希（SHA-1 / SHA-256 / SHA-384 / SHA-512），输出十六进制与 Base64 格式的派生密钥（DK），支持自定义 salt（文本或 hex），可用于生成测试向量、校验后端配置、学习迭代参数。与已有 `symmetric-crypto` 不同：其内部 `deriveKey` 是绑定 AES-GCM、SHA-256、固定 600000 次迭代的私有流程，不暴露通用派生结果；本工具是面向任意参数组合、可对比标准测试向量的通用 PBKDF2 计算器，全部基于 Web Crypto 本地运算，不上传密码。
