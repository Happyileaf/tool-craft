## 描述

在文本与摩尔斯电码（点 `.` / 划 `-`）之间双向转换，支持可调字符间隔与单词间隔、可选的音频播放，覆盖字母、数字与常用标点。可用于业余无线电、谜题与教学场景，现有工具集无任何摩尔斯电码相关能力。

## 设计内容（进入 Claimed 前补全）

- **slug**：`morse-codec`，路径 `/tools/morse-codec`，分类 CRYPTO_ENCODING，主线程本地处理，图标 Sparkles（lucide 白名单内）。
- **纯函数层** `src/tools/morse-codec/utils/morse.ts`：
  - `MORSE_MAP` 覆盖 A–Z、0–9 与 18 个常用标点/业务符号（`. , ? ' ! / ( ) & : ; = + - _ " $ @`），`REVERSE_MAP` 由其派生。
  - `encodeMorse(text, {charGapUnits, wordGapUnits})`：大写归一化、空白折叠；间隔经 `normalizeGap` 夹到 1–20；单词间隔必须大于字符间隔，否则返回错误；非法字符返回带字符的错误。
  - `decodeMorse(morse)`：仅允许点、划、空白、斜杠；1–4 空格为字符间隔（手写容错），斜杠或 ≥5 空格为单词间隔；非法码组返回错误。
  - `buildMorseTiming(morse, charGapUnits, wordGapUnits)`：输出 `{units, on}[]` 时序（点 1、划 3、码元间隔 1、字符间隔、单词间隔 7），供 UI 层 Web Audio 调度，音频 API 不进入纯函数。
- **UI 层**：antd + CSS Modules，编码/解码 Radio 双向切换，文本域实时转换，InputNumber 调字符/单词间隔（仅编码方向），Select 三档点长速度（120/80/50ms），600Hz 正弦波播放/停止，复制结果，错误 Alert；卸载时关闭 AudioContext。
- **测试**：Vitest 23 个用例（编码 10、解码 6、时序 7），含标准向量 `SOS`、7 空格/斜杠分词、4 空格容错、全字符集 pangram 往返、自定义间隔与非法输入。

### 向量核对（实现时已核对）

- 标准向量：`SOS` → `...   ---   ...`（3 空格字符间隔）；`HI THERE` → `....   ..       -   ....   .   .-.   .`（7 空格单词间隔）。
- 码表遵循 ITU-R M.1677-1：A `.-` … Z `--..`、0 `-----` … 9 `----.`、标点如 `@ .--.-.`、`! -.-.--`。
- 时序：单点 `{1,on}`、单划 `{3,on}`、`.-` 为 1/1静默/3；斜杠与 7 空格等价为 7 单位静默。
