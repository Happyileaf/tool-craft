## 描述

堆叠 rotate / scale / skew / translate 变换并实时预览，输出等价的 CSS matrix() 值，支持调整变换应用顺序与反向解析（matrix → 分解变换参数）。手写动画与合成层性能优化场景常用。现有 css-filter-generator、box-shadow-generator 分别面向滤镜与阴影；池内 CSS Grid 布局（20261023040530）、Flexbox（20261021221304）、CSS 形状（20261023020510）、@keyframes 动画（20261023040532）均为布局与关键帧方向，无 transform 矩阵换算能力。矩阵乘法与矩阵分解为纯函数，零依赖、纯本地。
