## 描述

面向中学数学与工程制图的平面解析几何工具：输入两个点 P1(x1,y1)、P2(x2,y2)，计算斜率、截距、斜截式 / 点斜式 / 一般式 Ax+By+C=0 三种直线方程、两点距离、中点坐标；再输入第二条直线（两点式或一般式系数），求两线交点并判定平行 / 垂直 / 重合关系，给出点到直线距离与垂足。对竖直线（斜率不存在）、两点重合、平行线无交点等边界给出明确提示而非除零错误；分数结果同时输出精确分数与小数。现有 `line-operations` 是文本行（log line）排序过滤工具、与几何无关；`vector-calculator` 面向向量代数、`triangle-solver` 面向三角形边角、`polygon-area-calculator` 面向面积、`polynomial-root-calculator` 面向多项式求根，均不提供直线方程与交点判定。纯浏览器本地确定性运算、零新增依赖，用教材例题固定向量验收。

## 设计内容（进入 Claimed 前补全）

纯客户端单页工具，零网络、零新增依赖；几何计算收敛为可单测纯函数 `utils/geometry.ts`，统一采用直线一般式 Ax+By+C=0。

- **模块一（两点）**：斜率、倾斜角、距离、中点、一般式方程；竖直直线斜率返回 null 而非除零。
- **模块二（两直线）**：平行、重合、相交、垂直判定并求交点（含垂足）。
- **模块三（点线距离）**：点到一般式直线距离，竖直/水平线均适用。
- **边界**：两点重合报错；方程系数为 ±1 时省略数字输出；联合类型收窄保证类型安全。
