## 描述

根据光圈值（f/N）、快门速度与 ISO 计算曝光值 EV（EV100 与当前 ISO 下的 EV），并在三者之间做等效曝光组合换算，输出 1/3 与 1/2 档的标准光圈 / 快门序列。同时支持 ND 滤镜档数换算（ND2/ND4/ND8… 与 ND0.3/0.6/0.9… 双标法）：由原快门时间与滤镜减光档数求新的快门时间，或反推所需滤镜档数，并给出长曝光计时参考。用于风光长曝光与滤镜配档。

## 设计内容（进入 Claimed 前补全）

### 功能范围

- 曝光参数输入：光圈 f/N（1/3 与 1/2 档预设 + 自定义）、快门（1/8000–30s 预设与文本输入）、ISO（常用预设 + 自定义）。
- 曝光值计算：EV100 = log2(N² / t)，EV_ISO = EV100 + log2(ISO / 100)。
- 等效曝光组合：固定 EV 下枚举光圈与快门组合，过滤超出快门范围的项。
- ND 换算：由原快门 + ND 档数求新快门；由原 / 新快门反推所需档数；ND 编号与光学密度双向换算。

### 核心交互

- 顶部参数区实时输出 EV 与结果卡；点击快门预设直接写入快门输入。
- ND 面板可切换「按档数求时间」与「按时间求档数」。
- 等效曝光表格展示 1/3 档与 1/2 档两组组合。

### 输入输出与边界

- 输出：EV100、EV_ISO、等效组合表、ND 换算结果、长曝光时间文本。
- 边界：光圈或快门 ≤ 0 时报错；快门文本支持 `1/125`、`2s`、`0.5`；ND 缺少匹配预设时回退到最近档位并提示；长时间曝光以秒 / 分 / 时格式化。
