## 描述

上传浏览器 DevTools 导出的 HAR（HTTP Archive，JSON 格式）文件，解析 `log.entries`，以列表展示每个请求的方法、URL、状态码、MIME 类型、请求/响应大小、耗时、开始时间，可按方法/状态码/关键字过滤、按域名分组统计请求数与流量；选中某条请求后，将其请求行与请求头（可选是否带 Cookie/Authorization、是否解压/解码 body）重放片段导出为 cURL 命令与 JavaScript `fetch`（含 headers/body/method）代码，支持复制。解决排查线上请求、把抓到的 HAR 快速转成可复现命令、定位慢请求/大响应的调试需求；解析纯本地进行，不上传文件、不发起任何网络请求。零新增依赖（HAR 即 JSON），可用固定的脱敏 HAR 样例断言解析条数、字段提取与生成命令包含的关键片段。查重：registry 已有 curl-to-code（把 cURL 转成多语言代码，输入方向相反且不解析 HAR）、原始 HTTP 报文解析器（pending `20261026200350`，解析单条裸报文而非 HAR 归档）、cookie-parser、url-parser，但没有任何 HAR 归档解析 / 批量请求浏览 / HAR→cURL 导出条目，能力方向不同，不构成重复。
