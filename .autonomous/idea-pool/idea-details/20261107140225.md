## 描述

面向音乐播放器与字幕制作场景，在结构化歌词条目（`mm:ss.cc` 时间戳 + 歌词文本）与标准 LRC 文本之间双向转换：粘贴纯歌词逐行打时间戳生成 LRC；粘贴 LRC 文件解析回可编辑表格并校验时间戳合法性，支持增强格式行内多时间戳（一行歌词对应多个时间点，合唱 / 重复段落常用）与 ID 标签（`ti`/`ar`/`al`/`by`/`offset`）。本地纯文本处理，零依赖、不上传音频或歌词文件。

## 设计内容（进入 Claimed 前补全）

- 工具 slug：`lrc-lyrics-codec`，分类 TEXT（文本与字符），主线程零依赖纯文本处理。
- 核心纯函数（utils/lrc.ts）：
  - `parseLrc(text)`：解析为 `{ meta: Record<string,string>, lines: { time: number(秒), text: string }[] }`；识别 ID 标签 `[ar:歌手]`/`[ti:标题]`/`[al]`/`[offset:+250]` 等（去首尾空格，保留原值字符串）；时间标签 `[mm:ss.xx]` 与 `[mm:ss.xxx]`，一行多时间标签（跟唱/合唱）展开为多行；无时间标签的纯文本行进 plain 列表。
  - `stringifyLrc(parsed, options)`：反向序列化，时间格式 `[mm:ss.xx]`（两位数毫秒，四舍五入），meta 在前、歌词按时间升序；可选项处理 offset 正负号与进位（如 59.999s 进位到 1:00.00）。
  - `shiftOffset(parsed, deltaMs)`：整体平移时间（秒数浮点相加后统一在 stringify 量化），支持正负。
  - `validateLrc(text)`：报告非法时间标签、时间乱序、空歌词等带行号问题。
- 边界：CRLF 归一化、BOM 剥离、空白行跳过、同一行时间标签+文本混合、时间标签后无文本（纯伴奏行）、毫秒 2/3 位兼容、乱序不报错仅告警。
- 组件：左右双栏（LRC 原文 / 结构化表格：时间点可编辑+歌词）、meta 信息编辑表单、整体平移毫秒输入、校验告警、示例与复制下载。
