# 预产期与孕周计算器（末次月经 / 排卵日双模式 + 孕周时间线）

- **Idea ID**：20261108200233
- **类型**：Web Tool
- **来源**：Exploration
- **类别**：Daily Life
- **状态**：Claimed

## 问题陈述

孕期管理中，孕妇与家属需要反复回答几个问题：预产期（EDD）是哪天、当前处于第几周第几天、距预产期还有多久、各次产检对应的孕周节点。市面上的同类工具大多嵌在带登录、广告与账号体系的母婴 App 中，输入月经日期即被索取手机号；而 Naegele 规则（末次月经 +280 天）、排卵日 +266 天两种推算口径、孕周按末次月经起算的惯例，完全可以在本地浏览器用纯日期运算完成。

Tool-Craft 的 Daily Life 类别目前集中在 BMI、体脂、热量、贷款、个税、汇率等场景，全文检索预产期/孕周/月经/怀孕/EDD 在活动池、completed.md、rejected.md 均无命中；现有 `timestamp-converter`、`date-difference-calculator` 只做通用时间戳与日期间隔，不包含孕期专用的 40 周时间线与产检节点语义。

## 方案概述

构建纯本地、零输入上送的孕期计算工具，核心能力：

1. **双模式推算**：模式一输入末次月经第一天（LMP），按 Naegele 规则（+280 天，即月份 −3、日期 +7 的等价口径）算预产期；模式二输入已知排卵/受孕日，按 +266 天推算；两种模式同时给出对应孕周起点换算。
2. **当前孕周仪表盘**：选择参考日期（默认今天），输出"孕 X 周 Y 天"、已进入的三月期（trimester：1–13/14–27/28–40 周）、距预产期天数、进度百分比。
3. **40 周时间线与节点**：按周渲染时间线，标注关键医学节点的常规时间窗——NT 检查（11–13⁺⁶ 周）、早/中唐筛查、大排畸（20–24 周）、糖耐量 OGTT（24–28 周）、胎心监护起始（32 周起）等，当前周高亮，并注明具体时间以产检医院医嘱为准。
4. **周期长度修正**：月经周期非 28 天时，按 `(周期天数 − 28)` 对预产期做天数修正，并在结果中展示修正前后对照。

## 价值假设

- **真实高频刚需**：孕程 40 周内"现在几周了、下次产检什么时候"是每周甚至每天都会查的问题，目标用户规模大且查询重复度高；
- **隐私敏感场景的本地优先优势**：经期与孕产数据属于高度个人隐私，纯浏览器计算、零表单上送与 Tool-Craft local-first 红线天然契合，是对账号制母婴 App 的直接差异化；
- **填补类别空白**：Daily Life 现有工具无任何孕产健康条目，日期纯函数实现简单、可测性强。

## 目标用户

- 备孕及孕期女性与其家属；
- 需要快速核对孕周与产检窗口、不愿注册母婴 App 的用户；
- 生殖健康科普场景的内容创作者（可嵌入交互式计算模块）。

## 核心功能（MVP）

1. LMP / 排卵日双模式预产期推算；
2. 参考日期下的孕周、孕天、三月期、倒计时与进度；
3. 周期长度（21–35 天）修正及前后对照；
4. 40 周时间线 + 关键产检节点时间窗标注与当前周高亮。

## 不做什么（边界）

- 不提供任何医学诊断、用药建议或异常妊娠判断，所有结果页固定显著免责声明；
- 不做账号、云同步、历史档案存储与提醒推送（无通知权限、无后端）；
- 不做试管婴儿特殊方案（如囊胚移植日折算）的复杂分支，仅保留排卵日模式可近似覆盖；
- 不采集任何个人标识信息，不接入统计 SDK。

## 技术可行性

- 核心全部为原生 `Date` 日期加减与整除/取模运算（孕周 = floor(天数/7)，孕天 = 天数 mod 7），零依赖、纯函数，测试向量可用已知日历案例穷举；
- 时间线为静态 40 行配置数据 + CSS 高亮，无渲染压力；
- 日期输入用原生 `<input type="date">`，无需日期库；
- 复杂度评估：**S**（日期运算 + 静态时间线渲染），符合 S–M 约束，全程主线程、无网络请求。

## 验收标准

1. 标准案例：LMP 为 2026-01-01 时预产期为 2026-10-08（Naegele 规则），排卵日模式下同一受孕基准两模式孕周一致；
2. 参考日期 = LMP 时显示孕 0 周 0 天，参考日期 = LMP+280 时显示孕 40 周 0 天、倒计时 0；
3. 周期 35 天修正后预产期较 28 天基准晚 7 天，修正对照数值正确；
4. 三月期分界（13⁺⁶ / 27⁺⁶ 周边界）切换正确；
5. 全部计算纯函数单测覆盖率 ≥90%，网络面板零请求、零新依赖，页面含显著"非医疗建议"声明。

## 风险与约束

- 医学口径差异：不同医院对孕周/产检窗口的惯例略有差异，节点一律以时间窗而非绝对日期呈现并附医嘱提示；
- 时区与夏令时：按用户本地日历日计算，避免 UTC 偏移导致跨日错误；
- 免责声明合规：明确工具仅做日期算术，不替代专业医疗意见，防止被误解为诊断产品。
