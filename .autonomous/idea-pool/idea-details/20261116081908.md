## 描述

在 ISO 216 的 A / B / C 系列、北美 Letter / Legal / Tabloid / Executive 与自定义尺寸之间选择纸张，按指定 DPI 计算印刷所需的像素宽高（如 A4 @300 DPI = 2480×3508），或由像素尺寸与 DPI 反推物理尺寸并匹配最接近的标准纸张；支持横向 / 纵向、mm / cm / in / px 单位互转，输出总像素与百万像素。用于设计稿新建画布、印刷分辨率核对、扫描件与海报尺寸估算；纯本地计算，结果四舍五入到整数像素。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 正向换算：选择标准纸张（ISO A0–A10、B0–B10、C0–C10，以及 Letter 8.5×11in、Legal 8.5×14in、Tabloid 11×17in、Executive 7.25×10.5in）或输入自定义宽高，切换横向 / 纵向，选择 DPI 预设（72 / 96 / 150 / 300 / 600 / 1200）或自定义 DPI，输出物理尺寸（mm / cm / in）与像素尺寸（宽 × 高）、总像素、百万像素；② 反向换算：输入像素宽高与 DPI，输出物理尺寸，并按宽高相对误差在标准纸张（含横竖两个方向）中匹配最接近项，误差 ≤2% 时标注「近似匹配」；③ 单位互转：mm / cm / in 双向输入；④ 常用尺寸速查表（A3–A6、Letter、Legal 在 72 / 150 / 300 DPI 下的像素值）。

**核心交互**：纸张预设下拉 + 自定义尺寸输入、横竖切换、DPI 下拉与自定义、换算方向切换（「纸张 → 像素」/「像素 → 纸张」）、结果卡片（物理尺寸、像素、百万像素、匹配纸张）与一键复制；输入非法时即时提示。

**输入输出**：输入为纸张预设或自定义宽高（单位可选 mm / cm / in）、DPI、方向、换算模式、像素宽高；输出为物理尺寸（mm / cm / in，2 位小数）、像素尺寸（整数）、总像素与百万像素、最接近的标准纸张及误差。

**边界情况**：DPI 限定 1–2400；纸张边长限定 1mm–2000mm（约 0.04–78.7in）；像素边长限定 1–100000 且总像素不超过 1e10；像素取整统一使用四舍五入（Math.round，.5 向上）；1in = 25.4mm 精确换算；横向 / 纵向仅交换宽高，不改变面积；自定义尺寸可超出标准表但仍按同一公式计算；所有非法输入（0、负数、非数字、超范围）返回明确错误而非默认值；页面注明 DPI 为打印墨点密度、与屏幕 PPI 含义不同。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] A4（210×297mm）@300 DPI 输出 2480×3508 px
- [ ] A4 @72 DPI 输出 595×842 px；A4 @96 DPI 输出 794×1123 px；A4 @150 DPI 输出 1240×1754 px
- [ ] A3（297×420mm）@150 DPI 输出 1754×2480 px；A5（148×210mm）@300 DPI 输出 1748×2480 px
- [ ] Letter（8.5×11in）@300 DPI 输出 2550×3300 px
- [ ] A4 横向 @300 DPI 输出 3508×2480 px（宽高交换、面积不变）
- [ ] 反向：2480×3508 px @300 DPI 输出 209.97×297.01mm，并匹配 A4（误差 ≤2%）
- [ ] 自定义 100×100mm @300 DPI 输出 1181×1181 px；1in×1in @300 DPI 输出 300×300 px
- [ ] DPI 为 0、边长为 0 或负数、像素超过 100000 时返回明确错误
