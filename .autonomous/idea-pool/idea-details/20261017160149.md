## 描述

在 px、rem、em、pt 等 CSS 单位之间互相换算，可设置根字体大小与父级上下文字号，实时给出换算结果与常用数值对照表。现有工具集没有任何 CSS 单位换算能力（`text-case-converter`、`gradient-generator` 等均不涉及），而设计稿还原与响应式适配中高频需要 px↔rem 换算。

## 设计内容（进入 Claimed 前补全）

- 功能范围：在 px、rem、em、pt 四种长度单位间互相换算，以 px 为内部基准：`1in = 96px = 72pt`，`1rem = rootFontSize px`，`1em = parentFontSize px`（pt 与 root/parent 无关）。
- 核心交互：数值 + 源单位输入，实时展示其余三个目标单位的结果；提供「根字号（rem 基准，默认 16px）」与「父级字号（em 基准，默认 16px）」两个可编辑参数，修改后所有结果即时刷新；基准必须为 > 0 的有限数值，否则给出提示。
- 对照表：以当前基准渲染常用 px 值（如 1/2/4/8/12/14/16/18/20/24/32/48）对应的 rem/em/pt 对照表。
- 纯函数设计：`utils/css-unit.ts` 导出单位常量与 `convertUnit(value, from, to, ctx)`（返回 number）、`buildScaleTable` 等纯函数，非法输入（NaN/Infinity/非正基准/不支持单位）返回 `null`；配套 `utils/css-unit.test.ts` 覆盖四向换算、自定义基准与边界。
- 边界：只支持绝对长度换算（不含 %、vh/vw、ch 等视口/相对字号以外单位）；不做 CSS 解析，不持久化设置。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 默认 16px 基准：16px = 1rem = 1em = 12pt；12pt = 16px；32px = 2rem = 24pt
