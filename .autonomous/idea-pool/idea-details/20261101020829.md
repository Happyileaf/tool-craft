## 描述

面向接口调试，在 JSON 对象与 `application/x-www-form-urlencoded` HTTP 请求体之间双向转换：JSON→表单时按 RFC 3986 / application/x-www-form-urlencoded 规则做百分号编码（空格为 `+` 或 `%20` 可切换），对象值支持标量与数组（数组按 `a=1&a=2` 重复键输出，可选 PHP 风格 `a[]=1`），嵌套对象用点路径或括号风格展开（可配置），布尔/数字/null 有明确序列化策略并在非法值（对象内嵌套深层类型冲突）时报错；表单→JSON 时解析重复键为数组、做百分号解码（含 `+`→空格）并输出合法 JSON。纯确定性字符串处理，零新增依赖。
