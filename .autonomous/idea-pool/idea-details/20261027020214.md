## 描述

通过策略（none / quarantine / reject）、聚合与取证报告邮箱（rua / ruf）、报告聚合选项、子域策略（sp）、策略百分比（pct）、对齐模式（adkim / aspf）等选项拼装发信域的 `_dmarc` DNS TXT 记录，并可对粘贴的现有记录做标签语法校验、未知标签提示与冲突检查（如 `fo` 取值非法、`pct` 越界）。DMARC 配错会让 SPF / DKIM 的仿冒防护无法生效，运维在配置邮件域时高频需要从零生成或核对记录。池内已有 SPF 记录生成与校验器（20261023020512）只覆盖 SPF 单一机制，不含 DMARC 策略标签与 rua/ruf 报告配置；HTTP 安全响应头生成器（20261017220048）面向 HTTP 响应头，领域完全不同。DMARC 记录是「标签=值; 」组成的小型有限词法（v / p / sp / rua / ruf / adkim / aspf / fo / pct / rf / ri），纯函数即可完成解析、校验与规范化输出，零新依赖、纯本地、确定性结果，可用固定向量验收（最小记录、全标签记录、非法标签与越界值报错、去空格规范化往返一致）。
