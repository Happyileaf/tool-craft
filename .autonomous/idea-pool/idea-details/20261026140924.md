## 描述

实现 [MessagePack](https://msgpack.org/) 二进制序列化格式与 JSON 文本的双向转换：JSON 对象/数组 → MessagePack 二进制（支持 nil / bool / int / uint / float / str / bin / array / map / ext 类型，整数自动选择最紧凑的 fixint / 8/16/32/64 位编码），MessagePack 二进制 → JSON（支持 hex 或 Base64 粘贴输入、逐字节错误定位、显示字节长度与十六进制转储预览）。典型场景是调试使用 msgpack 的后端 / Redis 缓存 / RPC 消息，无需安装语言运行时即可在浏览器查看二进制负载。纯本地确定性编解码、零新增依赖（依据公开的 msgpack 规范实现固定类型表），可用官方规范示例向量（如 `{"compact":true,"schema":0}` 的固定字节序列 `82 a7 63 6f 6d 70 61 63 74 c3 a6 73 63 68 65 6d 61 00`、fixint 边界、字符串、嵌套数组）做固定验收。与已实现的 JSON/YAML/CSV/NDJSON 转换器及在池的 Bencode、INI、.env、Quoted-Printable 等格式工具均不同：MessagePack 是带类型标注、长度前缀的紧凑二进制格式（区分 int/uint/float/str/bin/ext），不是文本格式也不与上述任一格式语义重合；rejected.md 中无相关淘汰记录，不构成重复。

## 设计内容（进入 Claimed 前补全）

纯客户端单页工具，零网络、零新增依赖；编解码收敛为可单测纯函数 `utils/messagepack.ts`，UI 负责 JSON 编辑、hex/Base64 输入切换与字节转储渲染。

- **编码方向（JSON → MessagePack）**：解析 JSON 文本为 JS 值，按规范输出 Uint8Array。支持 nil、true/false、fixint/uint/int 8/16/32/64（用 DataView 处理，64 位用 BigInt 路径但常规安全整数自动选最紧凑宽度）、float64、fixstr/str8/16、bin8/16、fixarray/array16、fixmap/map16；整数按非负走 uint、负数走 int 并选最小宽度；map 键统一按字符串编码。ext 类型本轮不开放输入（JS/JSON 无对应类型），解码器遇到 ext 保留 type 与 data。
- **解码方向（MessagePack → JSON）**：接受 hex（允许空格/0x）或 Base64 输入，转为字节后递归解析，输出格式化 JSON；非法首字节、长度越界、截断输入返回带字节偏移的错误；展示总字节数与十六进制转储（每行 16 字节）。
- **核心交互**：方向切换（JSON→MsgPack / MsgPack→JSON）、二进制输入格式切换（HEX/Base64）、结果区显示 JSON 或 hex/Base64、复制按钮、字节长度统计。
- **边界**：空输入提示；JSON 语法错误透传统计；嵌套深度与长度前缀不一致报错并定位；不处理循环引用（JSON.parse 本身不产生）。
