## 描述

输入 IPFS 内容标识符，解析并展示其完整结构：CIDv0（Base58btc、隐含 dag-pb + sha2-256）与 CIDv1（multibase 前缀 + version + multicodec codec + multihash：hash 算法代码 / 摘要长度 / 摘要 hex），支持 CIDv0 ↔ CIDv1 互转以及同一 CIDv1 在常见 multibase 表示间切换（base58btc `z`、base32 `b`、base32upper `B`、base16 `f`）。现有 `base58-codec` 只做裸 Base58 文本编解码（不含 multihash/CID 结构解析），`bech32-codec`、`base32-codec` 等均为单一编码层；分布式存储 / Web3 开发中 CID 版本与编码互转是高频需求。解码与重组全部为确定性字节运算，可在既有 Base58/Base32 实现基础上零新增依赖完成，用官方文档标准向量验收。
