## 描述

输入两段文本，计算并展示常用相似度指标：Levenshtein 编辑距离与相似度百分比、最长公共子序列（LCS）长度、Jaro-Winkler 相似度与 Dice 系数，可选附带编辑操作对齐视图。现有 text-diff 只输出行级增删视图、无法给出量化指标，而模糊去重、输入纠错、日志聚类前估算等场景需要的是数值化结果；池内 JSON 结构化差异对比仅针对 JSON 数据。全部为经典动态规划 / 双指针算法，纯函数实现，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- slug：`text-similarity`，分类 TEXT_CONTENT，主线程纯浏览器运算，零新增依赖。
- `utils/similarity.ts` 纯函数：
  - `levenshtein(a,b)` 两行 DP 编辑距离；`levenshteinAlignment` 全矩阵回溯输出 equal/replace/delete/insert 对齐序列；
  - `lcsLength(a,b)` 两行 DP 最长公共子序列；
  - `jaroWinkler(a,b)`（匹配窗口 ⌊max/2⌋−1、换位按错位配对/2、前缀加成最多 4 字符、p=0.1）；
  - `diceCoefficient(a,b)` 字符 bigram 多重集合交集，2·∩/(|A|+|B|)；
  - `compareTexts(a,b,{ignoreCase})` 汇总四指标、归一化比率（Levenshtein 1−d/max、LCS 2L/(|A|+|B|)）与对齐序列；空串对视为完全相同。
- UI：双文本框（带字符数 Tag）、忽略大小写 / 对齐视图两个开关、四个指标 Progress 百分比行（附距离/LCS 原始值）、字符级四色对齐 chips（空格显示为 ␣）、示例与清空，错误 Alert 中文提示。
- 中文按 JavaScript 字符码元计数，FAQ 说明与 text-diff 的差异及各指标选型建议。
