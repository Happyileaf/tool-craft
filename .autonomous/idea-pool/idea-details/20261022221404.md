## 描述

输入两段文本，计算并展示常用相似度指标：Levenshtein 编辑距离与相似度百分比、最长公共子序列（LCS）长度、Jaro-Winkler 相似度与 Dice 系数，可选附带编辑操作对齐视图。现有 text-diff 只输出行级增删视图、无法给出量化指标，而模糊去重、输入纠错、日志聚类前估算等场景需要的是数值化结果；池内 JSON 结构化差异对比仅针对 JSON 数据。全部为经典动态规划 / 双指针算法，纯函数实现，零新依赖、纯本地。
