## 描述

基于 OpenCC 风格词库的简繁双向转换，支持「简体 → 繁体（通用 / 台湾 / 香港）」与「繁体 → 简体」六个方向，按最长词组优先做词组级转换而非逐字替换，并可选地区用词归一（如「软件 ↔ 軟體」「鼠标 ↔ 滑鼠」）。用于文案本地化、跨地区发布、港台资料阅读与多语言站点的中文变体产出；纯本地计算，非中文字符与标点原样保留。

## 设计内容（进入 Claimed 前补全）

功能范围：转换方向单选（s2t / s2tw / s2hk / t2s / tw2s / hk2s）；词库分字符表与词组表，按最长匹配优先替换，避免「干」→「乾」这类逐字误转；可选「地区用词转换」与「仅转换选中片段」；输出区展示转换结果、变更字符数与逐条命中词组明细，便于核对。

核心交互：左右双栏输入 / 输出、方向切换与一键互换、示例文本预置、复制结果、转换明细折叠面板；超大文本分块处理并给出版本/词库来源说明。

输入输出：输入任意中文文本（含中英混排、Emoji、URL）；输出目标变体文本、命中词组列表（原词 → 替换词）与统计信息。

边界情况：空输入返回空；非汉字符号、数字、英文与代码片段不转换；词库未收录的字保持原样；同形异义需按最长词组优先；转换不改变文本长度以外的排版（保留原有空白与换行）。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] s2t：`发展` → `發展`，`后台` → `後台`，`头发` → `頭髮`（词组级而非逐字）
- [ ] s2tw：`软件` → `軟體`，`鼠标` → `滑鼠`，`这里` → `這裡`
- [ ] t2s：`鬱鬱蔥蔥` → `郁郁葱葱`，`後來` → `后来`

- [ ] 空输入与仅含英文/数字/Emoji 的输入不报错且输出等同输入
