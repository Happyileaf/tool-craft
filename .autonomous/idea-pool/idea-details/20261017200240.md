## 描述

输入文件扩展名（如 `.webp`、`.docx`）或 MIME 类型（如 `image/webp`）双向互查，展示标准 MIME 类型、常见扩展名、所属主类型（text / image / audio / video / application 等）、字符集参数示例与是否属于可安全内联展示的类型，并支持按关键词模糊搜索。现有工具集中无 MIME 类型参考能力，而配置 `Content-Type`、排查文件上传与下载问题时频繁需要查阅；基于内置静态映射表的纯函数查询实现，零新增依赖。

## 设计内容（进入 Claimed 前补全）

- 内置静态映射表（`utils/mime.ts`，零依赖）：收录约 50 个长期稳定的常用条目，每条含 MIME 类型（如 `application/json`）、扩展名列表（如 `json`，多个别名如 `jpg/jpeg`）、主类型（text/image/audio/video/application/font/model/multipart/message）、中文名称、关键词、charset 示例（文本类默认 `UTF-8`）、是否可安全内联展示（image/png、image/jpeg、image/gif、image/webp、image/svg+xml、text/plain、application/pdf 等）。
- 纯函数核心：扩展名→MIME（大小写不敏感、自动去前导点，未知扩展名返回 null）；MIME→扩展名列表（主 MIME 首个为推荐扩展名）；关键词模糊搜索（同时匹配 MIME 字符串、中文名、英文名/关键词，大小写不敏感）；按主类型分组与过滤。
- UI：搜索框 + 主类型 Radio 过滤；命中条目以可折叠列表展示（MIME 大字、推荐扩展名、别名、charset 示例、内联安全 Tag）；空结果 Empty；纯展示、零状态副作用，主线程。
