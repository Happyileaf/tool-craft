## 描述

输入若干个整数，计算其最大公约数（GCD）与最小公倍数（LCM）；并可对单个整数执行质因数分解、列出全部因数、判断质数 / 合数。面向算法学习、分数化简与数论验证场景。现有 number-base-converter 仅处理进制转换，工具集中无整数数论类工具；基于欧几里得算法与试除法自研纯函数实现，零新增依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：整数 GCD / LCM / 质因数分解 / 因数枚举 / 质数判定，工具 slug 拟为 `number-theory-calculator`。
- **GCD / LCM**：欧几里得算法求两两 GCD 再归约；LCM(a,b)=|a*b|/GCD（先除后乘防溢出），支持 2–10 个整数。
- **质因数分解**：试除法（先除 2，再奇数到 √n），输出 `n = p1^e1 × p2^e2 …` 形式与因数个数。
- **因数枚举**：成对枚举至 √n 收集全部正因数并排序。
- **质数判定**：试除到 √n；0、1 既非质数也非合数，负数取绝对值处理。
- **输入输出**：纯函数，不触碰 DOM / React。
- **边界情况**：非整数 / 空输入 / 含 0 的 LCM 给出明确提示；大整数限制在 Number.MAX_SAFE_INTEGER 内。
