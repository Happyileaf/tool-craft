## 描述

在可视化预览框上通过拖拽控制点编辑 `clip-path` 形状（polygon / circle / ellipse / inset），实时生成可复制的 CSS `clip-path: polygon(...)` 代码，并提供预设形状（三角形、平行四边形、切角、箭头、星形、对话气泡等）、坐标单位切换（% / px）、边界吸附与控制点数值微调。典型场景：制作头像异形裁剪、卡片切角、横幅造型，手写多边形坐标极易出错。设计类已实现工具中，box-shadow-generator、gradient-generator、css-filter-generator、CSS Grid / Flexbox 生成器（20261023040530 / 20261021221304）均不覆盖裁剪路径；「CSS 形状生成器」（20261023020510）面向通用装饰形状输出，本工具专注 `clip-path` 属性的坐标级双向编辑（拖拽 ↔ 代码同步），不构成重复。输出是确定的 CSS 函数字符串，坐标到代码为纯映射，零新依赖、纯本地，可用固定向量验收（各预设生成已知坐标串、拖拽控制点后代码同步、非法坐标不生成越界值）。
