## 描述

设置宽高、前景 / 背景色与自定义文字后即时生成 SVG 占位图，提供复制 SVG 代码、下载 .svg / .png（Canvas 转换）与 data URI 三种输出，参考 placeholder.com 等外部服务的常用参数。前端开发与设计稿 Mock 需要指定尺寸的占位图，依赖外部占位图服务存在网络可用性与隐私顾虑；现有 image-resizer 处理已有图片的压缩裁剪、qr-generator 生成二维码，均不覆盖「按参数生成占位图」，池内「图片与 Base64 Data URI 互转」（20261017183438）是既有图片的格式转换而非生成。SVG 由模板字符串确定生成、PNG 导出走浏览器 Canvas，零新依赖、纯本地。
