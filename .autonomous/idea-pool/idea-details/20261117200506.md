## 描述

输入一组实数或复数采样序列（逗号 / 空白分隔，支持 `a+bi` 复数写法），计算其离散傅里叶变换，输出各频率 bin 的复数分量、幅度谱（含单边谱选项）、相位谱（弧度 / 角度）与归一化频率；支持逆变换 IDFT 还原原始序列以验证往返一致性，并对 2 的幂长度自动走 radix-2 Cooley–Tukey FFT、非 2 的幂长度回退朴素 DFT（实现上用 Bluestein 或 O(N²)，UI 标注算法与复杂度）。全部数值计算在本地主线程完成（默认限制 N ≤ 4096，超限提示），零依赖，可用固定正弦向量验收。

## 设计内容（进入 Claimed 前补全）

功能范围：单页工具。① 正变换 DFT/FFT：实数序列或复数序列输入，输出 N 个 bin 的 Re/Im、|X[k]|、∠X[k]、归一化频率 k/N；② 单边谱开关（实数输入时仅展示前 N/2+1 个 bin，幅度按 2/N 缩放，DC 与 Nyquist 不翻倍）；③ 逆变换 IDFT：粘贴频域复数序列还原时域；④ 往返自检：对当前输入自动 IDFT 并展示最大重构误差；⑤ 算法标注：显示本次使用 radix-2 FFT 还是 naive DFT 及理论复杂度。

核心交互：序列输入框、复数语法开关、相位单位切换（rad/deg）、单边 / 双边谱切换、变换方向切换（正向 / 逆向）、结果表格与轻量 SVG 幅度谱条形图、复制 CSV；非法 token、超长序列、空序列即时错误提示。

输入输出：输入为数值序列文本；输出为 `{ bins: [{ k, re, im, magnitude, phase, normalizedFreq }], algorithm, reconstructionError }`。

边界情况：N=1 时 DFT 等于自身且单边 / 双边一致；N 非 2 的幂走 naive DFT 并在 UI 标注 O(N²)；实数序列虚部按 0 处理；相位对幅度接近 0 的 bin（|X| < 1e-12）标记为未定义而非输出随机角度；逆变换虚部残差 < 1e-10 的实数序列结果自动取实；输入长度超过 4096 拒绝计算并提示。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 脉冲序列 `[1,0,0,0]`（N=4）的 DFT 四个 bin 幅度均为 1、相位均为 0
- [ ] `[1,0,-1,0]`（N=4）仅在 k=1 与 k=3 处有非零分量，幅度均为 2，相位分别为 −π/2 与 +π/2（容差 1e-10）
- [ ] N=8 的 `cos(2π·n/8)` 序列能量集中在 k=1 与 k=7，单边谱 k=1 幅度为 1
- [ ] radix-2 FFT 与 naive DFT 对同一 N=16 随机固定向量结果最大误差 < 1e-9
- [ ] 任意合法输入经 FFT → IFFT 往返后与原序列最大绝对误差 < 1e-9
- [ ] 非 2 的幂长度（N=6）正确走 naive DFT 且 UI 标注算法；N>4096 被拒绝
