## 描述

依据最小/最大字号与最小/最大视口宽度（或容器宽度），计算斜率与截距并生成对应的 CSS `clamp()` 表达式（`clamp(min, 斜率 * 视口单位 + 截距, max)`），用于流式响应式字号与间距，并提供缩放预览与一键复制。现有 CSS 单位换算工具只做静态单位换算，不生成随视口变化的响应式表达式。
