## 描述

在 JSON 数组与 JSON Lines（NDJSON，每行一个独立 JSON 对象、无外层数组、无行尾逗号）之间做双向转换，并支持把多行 NDJSON 流式解析为对象数组；对非法行给出所在行号与错误信息。JSON Lines 是日志采集（如结构化日志）、数据管道、批处理导入导出（BigQuery/Elasticsearch Bulk 风格）中的常用格式。纯本地解析/序列化、零依赖、可固定样例验收。与已有 csv-json-converter、json-flatten、json-to-yaml 解决的格式与结构问题不同（CSV 为表格、flatten 为点路径展平），本工具专注 JSON 数组与逐行 JSON 记录流之间的转换，不构成重复。
