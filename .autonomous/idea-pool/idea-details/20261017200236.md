## 描述

可视化拖拽编辑 cubic-bezier 控制点，实时预览缓动曲线与一段动画示例；内置 ease / ease-in / ease-out / ease-in-out / linear 等预设以及常见弹性、回弹曲线，并导出可直接用于 transition-timing-function / animation-timing-function 的 cubic-bezier(...) 代码。现有 gradient-generator、box-shadow-generator、css-filter-generator 已覆盖同类「可视化生成 CSS」需求，但缓动曲线生成能力缺失；基于贝塞尔曲线数值求解自研纯函数实现，零新增依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：可视化编辑 CSS `cubic-bezier(x1,y1,x2,y2)` 缓动函数并导出代码，工具 slug 为 `cubic-bezier-generator`。
- **核心交互**：
  - SVG 曲线图：绘制单位方框、(0,0)→(1,1) 曲线、两个可拖拽控制点（P1/P2，x 轴限制 0–1，y 轴可超出）；拖拽时数值输入联动。
  - 四个数值输入框（x1 y1 x2 y2，0–1 的 x 校验，非法值提示）；实时生成 `cubic-bezier(...)` 与 CSS 预览代码，一键复制。
  - 预设：linear、ease、ease-in、ease-out、ease-in-out 及 easeInBack（过冲 y>1）等常用曲线；动画演示：一个小方块以当前曲线在 1s 内位移，可重播。
- **输入输出**：贝塞尔求值（给定 t 求点）、由 x 反解 t（牛顿迭代 + 二分回退）再求 y 的 `solveCubicBezierY(x, ...)` 纯函数放 `utils/bezier.ts`，供曲线采样与单测使用，不触碰 DOM。
- **边界情况**：x1/x2 越界（<0 或 >1）给出错误态并禁用复制/预览；预设切换即更新；动画在减少动态效果偏好（prefers-reduced-motion）下仍可手动步进或直接不自动播放。
