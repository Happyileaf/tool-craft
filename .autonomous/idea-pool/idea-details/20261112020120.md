## 描述

在浏览器内把上传图片转换为 ASCII 字符画：通过 Canvas API 本地读取像素、按可调输出宽度（字符列数）等比缩放并补偿字符长宽比（约 0.5），将亮度映射到可自定义的字符梯度表（如 ` .:-=+*#%@`），支持对比度/亮度调节、反相、可选 ANSI 彩色或 HTML 彩色输出，结果可复制为纯文本或导出 `.txt`；全程不上传、不引入第三方图像处理库。与 rejected.md 中被拒的「Emoji 表情检索」不同：本工具不依赖任何随版本更新的大型静态数据集，字符表仅为一条可内联的短字符串，像素处理全部走浏览器原生 Canvas。现有 `image-resizer` 只缩放位图、`image-color-extractor` 只提取主色、`image-data-uri-converter` 只做 Data URI 转换，均不输出字符画。零新增依赖（Canvas 为浏览器原生能力），S–M 复杂度。
