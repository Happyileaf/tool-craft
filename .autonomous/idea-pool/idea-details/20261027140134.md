## 描述

输入起始与结束两个 IP 地址（IPv4 或 IPv6），输出覆盖该连续范围、数量最少的 CIDR 前缀列表（range → CIDR aggregation / range2cidrs），并显示每个 CIDR 的地址数与总块数；反向支持把一组可能重叠或相邻的 CIDR 合并为超网（CIDR summarize / supernet）。用于编写防火墙白名单、路由汇总、ACL 规则与云安全组配置时把零散 IP 段压缩为最小前缀集合。与已有 `cidr-subnet-calculator` 不同：后者仅对单个「地址 + 前缀」计算网络 / 广播 / 主机范围（IPv4 与 IPv6 拆解齐全），不支持起止范围到最小 CIDR 列表的聚合，也无 CIDR 合并 / 超网；本工具是其反方向的独立能力。
