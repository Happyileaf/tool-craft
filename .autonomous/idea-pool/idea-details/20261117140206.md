## 描述

在浏览器本地对输入颜色（HEX / RGB，支持逐个输入或粘贴调色板色值列表）做色觉缺陷模拟：按 Brettel–Viénot 1997（或 Machado 2009 矩阵族）的 LMS 色空间变换矩阵，输出红色盲（Protanopia）、绿色盲（Deuteranopia）、蓝色盲（Tritanopia）及对应色弱（异常三色，可选强度）下的模拟色，并对调色板两两组合给出"模拟后是否可区分（ΔE 阈值）"的冲突矩阵与替代色建议方向。现有颜色工具中 `color-palette` 只做 WCAG 2.1 亮度对比度（且一条同主题 idea 已在 Rejected 记录中），活动池 APCA idea（20261104081012）只做感知对比度 Lc，CIE Lab 色差 idea（20261101080346）只做正常色觉下 ΔE——均不含色觉缺陷模拟变换，能力不重叠。全部为矩阵乘法与 ΔE 纯函数，零依赖，主线程即可完成。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：①单色/多色调色板输入（HEX、rgb()、逗号或换行分隔，去重与非法值提示）；②三类二色视觉（Protanopia/Deuteranopia/Tritanopia）模拟色输出，含色弱（anomalous trichromacy，强度 0–100% 可调，默认给典型值）；③调色板内任意两色在每种模拟条件下的可区分性检查（CIEDE2000 ΔE，阈值可配，默认 ΔE≥10 判可区分）；④冲突对高亮与逐色预览卡片（原色块 + 三种模拟色块并排）；⑤一键复制模拟后的调色板（HEX 列表）。
- **核心交互**：左侧色值列表输入（实时解析），右侧按模拟类型分 Tab/分栏展示模拟色块与冲突矩阵；强度滑块仅作用于色弱模式。
- **输入输出**：输入色值数组 + 模拟类型 + 色弱强度 + ΔE 阈值；输出每色在各模拟下的 sRGB 结果、冲突对列表（含 ΔE 数值）、可区分性矩阵。
- **边界情况**：非法色值整行报错并跳过；空列表禁用计算；模拟结果做 sRGB gamut clamp 并标注被裁剪的通道；色值数量上限（如 32 色）防止矩阵组合爆炸并给出提示。
- **核心算法**（纯函数，零依赖，放 `utils/color-vision.ts`）：sRGB→线性 RGB→LMS（Hunt-Pointer-Estevez 或 Viénot 矩阵）→缺陷投影矩阵→回变换链；ΔE2000 可与现有色差工具的常量/实现风格保持一致但本工具内独立维护，不跨工具引用。
- **测试覆盖**（`utils/color-vision.test.ts`）：矩阵与公开参考值（如 Brettel–Viénot 论文/常用在线模拟器示例向量）误差在约定容差内；灰色（r=g=b）在任何模拟下保持中性色；强度 0% 时模拟色等于原色；冲突矩阵对角线无冲突；非法输入抛错。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 三种二色视觉模拟结果与公开参考实现（Brettel–Viénot/Machado 矩阵族）对同一输入的 ΔE76 差异 <1.0
- [ ] 色弱强度 0% 恒等、100% 收敛到对应二色视觉结果；中性灰在全部模拟下不变
- [ ] 调色板冲突矩阵正确标出不可区分色对，ΔE 数值与独立手算/参考实现误差 <0.5
- [ ] 非法色值、空输入、超色数上限等边界有明确错误提示；纯函数核心具备单元测试且全部通过
- [ ] lint / typecheck / build 全绿；注册表无重复，与 `color-palette`、APCA、CIE Lab 色差工具无能力重叠
