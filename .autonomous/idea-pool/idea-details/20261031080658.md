## 描述

录入一笔项目/投资按时间排列的现金流（第 0 期初始支出通常为负、后续各期净流入）与贴现率，计算净现值 NPV（按给定年/期贴现率折现求和）、内部收益率 IRR（使 NPV=0 的折现率，二分/割线数值求解，支持无解或多解情形的提示）、以及净现值随贴现率变化的关系；可选支持非等间隔日期现金流（按实际天数/年折现）。结果给出 NPV 金额、IRR 百分比、是否值得投资（NPV>0 且 IRR 高于门槛率）。解决项目可行性评估、理财与设备采购决策时需要快速估算资金时间价值的问题。纯本地数值计算、零新增依赖，NPV 可用手工可验证的固定现金流断言、IRR 可用已知收敛结果断言（含全为同号、首项非负等边界提示）。查重：registry 与池中已有贷款月供、复利定投、个税、增值税、百分比、描述性统计、线性回归等，但没有 NPV / IRR / 净现值 / 内部收益率 / 现金流折现（DCF）条目，不构成重复。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：按期排列现金流的净现值 NPV 与内部收益率 IRR 计算，工具 slug 拟为 `npv-irr-calculator`。
- **输入模型**：可增删的现金流行（期次 t=0,1,2…、金额，第 0 期通常为初始负支出）、每期贴现率（年化 / 期贴现率，百分比输入）、可选门槛率（hurdle rate）用于投资判定。
- **NPV 计算**：`NPV = Σ CF_t / (1+r)^t`，t 从 0 开始（第 0 期不折现）；同时展示各期折现值明细。
- **IRR 计算**：求解使 NPV=0 的 r；先用有界二分（区间 [-0.9999, 10] 或更宽，检查端点异号）保证稳健，辅以割线 / Newton 加速提升收敛速度，最大迭代与容差固定；无符号变化时提示「全同号现金流，IRR 不存在」，多解情形给出首次找到的解并提示可能存在多解。
- **投资判定**：NPV > 0 且（若填写门槛率）IRR > 门槛率 → 值得投资；否则不值得；展示 NPV 金额、IRR 百分比、判定结论与各期折现明细表。
- **核心交互**：现金流表格（期次 / 金额，可增删）、贴现率与门槛率输入、计算结果卡片（NPV、IRR、判定 Tag）、折现值明细 Table；输入变化实时计算，错误以 Alert 展示不抛异常。
- **输入输出**：核心计算为零依赖纯函数（`utils/npvIrr.ts`），不触碰 DOM / React，Vitest 固定数值断言。
- **边界情况**：空现金流 / 仅一行、全为同号（IRR 无解）、首项非负（无典型投资形态，提示但仍计算 NPV）、贴现率 ≤ -100% 非法、不收敛时提示、金额非数字 / NaN / Infinity 拦截、NPV 在区间端点仍同号时提示无解而非返回误导数值。非等间隔日期折现本轮不做（保持范围收敛）。
