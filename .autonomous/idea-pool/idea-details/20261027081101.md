## 描述

粘贴文件头部字节的 Hex dump（或拖拽文件读取前若干字节），依据常见文件格式的魔数签名（如 `%PDF`、`\x89PNG`、`PK\x03\x04`、`GIF8`、`fLaC` 等）识别文件的真实类型，解决扩展名被篡改或缺失时无法判断文件真实格式的问题。全部计算在浏览器本地完成，文件不上传。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：粘贴 Hex dump（自动剥离偏移前缀、空格、冒号、换行）或拖拽/选择本地文件（FileReader 仅读前 64 字节），按内置魔数签名表识别真实文件类型，输出类型名、MIME、扩展名、命中偏移与签名 hex；多签名命中（如 Office 复合文档）全部列出；未命中给出明确提示而非静默误判。
- **核心交互**：Tabs 切换「Hex 输入」与「文件读取」；结果卡片展示匹配签名与原始前 16 字节规范化 hex；一键清空。
- **输入输出**：hex 文本 / File → 签名匹配结果数组（type、mimeType、extensions、offset、signatureHex、description）。
- **边界情况**：奇数长度/非 hex 字符报错；字节数不足任何签名最小长度时提示数据过短；同名多签名（DOC/XLS/PPT 均为 D0 CF 11 E0）以候选列表返回并注明需进一步内容判断。
- **核心算法**（纯函数，零依赖，放 `utils/magic.ts`）：hex 归一化 → Uint8Array → 签名表逐条 offset 前缀比对，按特异性排序。
- **测试覆盖**（`utils/magic.test.ts`）：PDF/PNG/JPEG/GIF87a/GIF89a/ZIP/PK/ELF/class/FLAC/OGG/RIFF 等典型向量、hex 噪声剥离、未命中与过短输入、多候选排序。
