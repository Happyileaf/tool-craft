## 描述

解析、校验并比较语义化版本号（SemVer 2.0.0）：输入两个版本判断大小与兼容关系，校验版本字符串是否合法，并解析 npm 风格的范围表达式（如 `^1.2.3`、`>=1.0.0 <2.0.0`）对指定版本的命中情况。依赖排障与发版校验中高频使用，现有工具集无此能力。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：SemVer 2.0.0 解析、校验、比较与范围匹配，工具 slug 拟为 `semver-parser`。
- **解析与校验**：解析 `major.minor.patch` 及可选的预发布 `-prerelease` 与构建元数据 `+build`，容忍前导 `v` 与首尾空白；按规范校验合法性（如数字段不得有前导零，缺段视为非法）。
- **比较**：按主版本、次版本、修订号逐级比较；相等时按预发布优先级规则比较（有预发布 < 无预发布，预发布逐段比较：数字段按数值、字母数字段按字典序、数字段小于字母数字段）。
- **范围匹配**：解析 npm 风格范围表达式并判断给定版本是否命中，支持 `^`、`~`、`>=`、`<=`、`>`、`<`、`=`、`x` / `*` 通配、空格表示 AND、`||` 表示 OR、连字符区间 `1.2.3 - 2.0.0`。
- **核心交互**：区块一为版本校验与解析（展示分解后的 major/minor/patch/prerelease/build）；区块二为两版本比较（输出大小与关系）；区块三为范围命中判断（输入范围与版本，输出命中结果）。
- **输入输出**：纯函数，不触碰 DOM / React。
- **边界情况**：非法版本与非法范围给出明确错误信息并定位原因；预发布版本参与范围匹配时按 npm 语义处理。
