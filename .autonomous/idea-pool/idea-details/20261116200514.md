## 描述

前端与 Node.js 排障时，`Error.stack` 是一坨非结构化文本，且 V8（Chrome/Node/Electron）、SpiderMonkey（Firefox）、JavaScriptCore（Safari）三家格式互不相同：V8 用 `at func (file:line:col)`、Firefox 用 `func@file:line:col`、Safari 行内还可能带 `eval code`/`native code`。本工具在浏览器本地把粘贴的堆栈文本解析为统一的帧结构（函数名、文件 URL、行号、列号、是否 eval/native/async、是否 node: 内置模块），自动识别引擎方言，输出可排序/过滤的帧表格与可读的模块/路径拆分，纯字符串规则解析、零依赖、不上报错文。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 方言自动识别：依据首行错误消息与帧特征（`at ` 前缀 → V8；`@` 分隔 → Firefox；`_*`/`eval code`/无列号风格 → JSC）判定引擎，允许手动覆盖；② 帧解析：提取函数名（含匿名 `<anonymous>`、`new Func`、`Object.<anonymous>`）、文件/URL、行号、列号，识别 eval 嵌套（`eval at ... (eval at ...)`）、native code、node: 内置模块与异步钩子（`async`、`processTicksAndRejections`）；③ 结构化展示：帧表格（序号 / 函数 / 文件 / 行 / 列 / 标签），支持按 node_modules、node:、native、帧函数名关键字过滤与高亮首帧（最接近用户代码的一帧）；④ 路径拆分：把 file URL 拆成协议、宿主、路径、查询/锚点，Windows 路径与 `file:///` 归一展示；⑤ 错误头提取：单独给出错误名（如 `TypeError`）与 message。

**核心交互**：堆栈 TextArea（多行粘贴）+ 示例（三种引擎各一）一键填充；引擎 Radio（自动 / V8 / Firefox / Safari）；帧 Table 与过滤开关（隐藏 node_modules、隐藏 node: 内置、仅看用户代码）；错误头卡片；首帧高亮；解析为 JSON 可复制。

**输入输出**：输入为原始 `Error.stack` 多行文本；输出为引擎判定、错误名与 message、统一帧对象数组（function/file/line/column/flags）、过滤后表格与 JSON。

**边界情况**：空输入 → 提示；无法识别的行归入 `raw` 字段并标记 `unparsed` 而不丢弃；缺列号/缺行号 → 对应字段为 null 且不报错；native code / eval code 帧无位置信息时 flags 标注；多行 message（含原因 `Caused by` / Node `cause` 链）保留并分段；行号列号保证为非负整数，非法时为 null；文件列含 `)`、URL 带查询串与括号时按最后一个 `:` 与最外层括号贪婪/回溯正确切分；超大堆栈（如 >10000 帧）只做线性解析不卡顿并给帧数统计。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] V8 示例 `TypeError: Cannot read properties of undefined\n    at foo (/app/src/a.js:10:20)\n    at Object.<anonymous> (/app/src/b.js:3:5)\n    at node:internal/process/task_queues:96:5`：识别为 V8，错误名 TypeError，解析出 3 帧，第 1 帧 function=foo、file=/app/src/a.js、line=10、column=20，第 3 帧带 node: 内置标签
- [ ] Firefox 示例 `foo@/app/src/a.js:10:20\nbar@/app/src/b.js:3:5`：识别为 Firefox，帧字段与 V8 示例等价（function/file/line/column 一致）
- [ ] Safari/JSC 风格含 `eval code` 与 `native code` 的帧：正确打上 eval / native flag 且不要求行号列号
- [ ] 过滤开关：隐藏 node: 内置后上例仅剩 2 帧；「仅看用户代码」排除 node_modules 与 node: 帧；首帧高亮指向第一个非内置帧
- [ ] 匿名函数（`at /app/x.js:1:1` 无函数名）→ function 为 `<anonymous>`；缺列号帧 column=null 且不报错；无法解析的怪行保留在 raw 并标记 unparsed，不丢失
- [ ] 输出的结构化 JSON 可被 `JSON.parse` 还原且帧字段固定；空输入给出明确提示而非异常
