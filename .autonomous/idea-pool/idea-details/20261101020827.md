## 描述

基于 Shamir 门限方案将一段秘密（文本或十六进制字节，如密钥 / 助记词）拆分为 `n` 个分片、任意 `k` 个（k ≤ n）即可恢复：在 GF(2⁸) 上逐字节构造 k−1 次随机多项式（随机系数使用 Web Crypto CSPRNG），输出可复制的分片文本（编号 + Base64/十六进制载荷，自描述门限参数）；恢复端粘贴 ≥ k 个分片，用拉格朗日插值在 GF(2⁸) 上还原秘密，并对分片数量不足、编号重复、分片不一致给出明确错误。纯确定性算法 + CSPRNG，全部本地运算，零新增依赖。与已实现的对称/非对称加密工具互补——那些工具做单密钥加解密，本工具解决「秘密分散保管、单人不持有全部」的门限保管问题。
