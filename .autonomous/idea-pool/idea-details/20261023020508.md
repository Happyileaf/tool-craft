## 描述

填写标题、起止时间、全天 / 时区、地点、描述与提醒偏移后，生成单事件的标准 iCalendar (.ics) 文件，可直接导入 Google / Outlook / Apple 日历。为线上活动、发版排期、会议邀请等场景提供「一键加日历」文件是高频需求，而手写 ICS 极易在 TEXT 转义（逗号 / 分号 / 换行）、UTC 时间格式、UID / DTSTAMP 必填字段与折行规则上出错；池内 vCard 生成器（20261017220045）面向联系人名片（.vcf），与本条面向日程（.ics）的格式与用途均不重叠。单事件 VEVENT 为固定结构的纯文本生成，纯函数实现，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- 工具目录：`apps/web/src/tools/ics-generator/`（index.tsx + index.module.css + constants.ts + utils/ics.ts + utils/ics.test.ts）。
- 核心纯函数（utils/ics.ts）：
  - `escapeIcsText(value)`：按 RFC 5545 Section 3.3.11 转义反斜杠、分号、逗号与换行。
  - `foldLine(line)`：按 RFC 5545 Section 3.1 做 75 八位组折行，按 UTF-8 字节计数避免截断多字节字符，续行以单个空格开头。
  - `buildIcsEvent(data)`：校验标题必填、时间格式与起止顺序、提醒正整数；输出 VCALENDAR/VEVENT，自动生成 UID 与 DTSTAMP，CRLF 行尾。
  - 三种时间形式：UTC `DTSTART:…Z`、带 TZID 的 IANA 时区本地时间、全天 `DTSTART;VALUE=DATE`（DTEND 自动取排他性次日）。
  - 提醒输出 VALARM（ACTION:DISPLAY + TRIGGER:-PTnM），分钟/小时/天统一换算为分钟。
- UI（Ant Design）：左表单右预览双栏；全天 Switch 切换 date/datetime-local 输入；时区 Select（常用 IANA 时区，留空即 UTC）；提醒 Switch + InputNumber/Select + 快捷预设 Tag；复制与下载 event.ics。
- 注册：loaders.ts 懒加载 + registry.ts 双语 doc，category=DEV_CODE，iconName=Clock，processing=MAINTHREAD，零新依赖。
