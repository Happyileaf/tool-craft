## 描述

输入气温与相对湿度，计算露点温度（Magnus 公式）、湿球温度（Stull 经验式或热力学迭代）；结合气压由压高公式估算海拔，或由海拔反推标准气压。气象计算类现有工具仅 `apparent-temperature`（体感 / 风寒 / 湿热），不含露点 / 湿球 / 压高换算，能力互补；全部为闭式公式，纯函数零依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：①露点 Td（Magnus 公式）；②湿球温度 Tw（Stull 2011 经验式）；③气压 P → 海拔 h（国际标准大气压高公式，含对流层 L=0.0065 K/m 分层）；④海拔 → 标准气压反算；⑤由 T、Td、P 反推相对湿度作为交叉验证。
- **核心交互**：气温（°C）+ 相对湿度（%）实时出露点 / 湿球；气压（hPa）↔ 海拔（m）双向换算（气压输入时以当前气温作海平面基准修正）；结果卡片显示结露温差（T−Td）与结露 / 结霜风险提示。
- **输入输出**：
  - 露点：γ = ln(RH/100) + α·T/(b+T)，Td = b·γ/(α−γ)（α=7.5，b=237.1 °C）；
  - 湿球（Stull）：Tw = T·atan(0.151977·√(RH+8.313659)) + atan(T+RH) − atan(RH−4.686035) + 0.00391838·RH^1.5·atan(0.023101·RH) − 4.686035；
  - 压高：P = P0·(1 − L·h/T0K)^(g·M/(R·L))，逆变换 h = (T0K/L)·(1 − (P/P0)^(R·L/(g·M)))，T0K = T + 273.15（以输入气温作基准），P0=1013.25 hPa。
- **边界情况**：RH 限定 0–100%（越界报错）；RH=0 露点无定义（报错提示）；Magnus 适用范围外（T<−45 °C 或 >60 °C）给出精度警告；气压 ≤0 或 >1100 hPa 警告；Stull 式适用 RH 5–99%、T −20–50 °C，越界标注“精度下降”。
- **核心算法**（纯函数，零依赖，放 `utils/psychrometrics.ts`）：dewPoint / wetBulb / pressureToAltitude / altitudeToPressure 均为独立纯函数，常量集中管理。
- **测试覆盖**（`utils/psychrometrics.test.ts`）：经典向量（20 °C/50% → Td≈9.27 °C；30 °C/80% → Td≈26.2 °C；20 °C/50% → Tw≈13.7 °C Stull）；海拔↔气压往返（0 m↔1013.25 hPa、1500 m↔约 845 hPa、5500 m 珠峰大本营量级）；100% RH 时 Td≈T；非法 RH / 气压抛错。
