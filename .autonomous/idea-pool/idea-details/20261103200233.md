## 描述

批量解析 Apache/Nginx 默认 combined（及 common）访问日志行，逐行拆出客户端 IP（含 X-Forwarded-For 首跳可选项）、ident、远程用户、请求时间、HTTP 方法、路径、协议版本、状态码、响应字节数、Referer、User-Agent 与请求耗时（若日志模板含 `$request_time`/`$upstream_response_time` 扩展字段），输出结构化字段表与解析失败行标记，并给出状态码分布、Top 路径/IP/UA 等汇总统计。日志可能含敏感信息，纯浏览器本地解析、不上传数据。现有 `20261103140204` syslog 解析器面向 RFC 3164/5424 系统日志、`20261026200350` 原始 HTTP 报文解析器面向单条 HTTP 请求/响应报文，均不覆盖 Web 服务器访问日志的批量行格式与统计场景，是独立工具。
