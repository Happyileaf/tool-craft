## 描述

解析 NCSA Combined / Common Log Format 访问日志，逐行提取 IP、时间、方法、路径、状态码、字节数、Referer、UA、响应耗时，对畸形行给出精确错误定位，并汇总状态码分布、Top IP / 路径 / UA、流量与时间跨度。现有解析类工具覆盖 nginx-conf、access-log-to-curl、user-agent-parser 等单方向转换，无日志批量解析 + 统计能力；正则 / 字符串纯函数可完整实现。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：①Common（8 字段）与 Combined（+Referer+UA）两种格式自动识别；②可选尾部响应时间字段（`request_time`，数值）；③逐行解析结果表格（时间转 ISO 8601，保留原始时区偏移）；④无法匹配行标注错误与原因（括号不闭合 / 时间格式错 / 字段缺失）；⑤汇总：总行数 / 成功率 / 2xx/3xx/4xx/5xx 计数、字节总量、Top 5 IP/路径/UA/状态码、时间范围与 QPS。
- **核心交互**：多行文本框粘贴日志；上方统计卡片 + 分布图（纯 CSS/SVG 条形），下方逐行表格；畸形行红色高亮并可只看错误；空字节字段 `-` 识别为 null（不计入流量但单独计数）。
- **输入输出**：标准行 `host ident authuser [10/Oct/2026:13:55:36 -0700] "GET /a HTTP/1.1" 200 2326 "http://ref/" "Mozilla/5.0 ..."`；输出结构化字段对象 + 全局 summary；方法 / 路径 / 协议拆分为独立字段，路径保留 query string。
- **边界情况**：请求内含引号转义 / 畸形请求行（无 HTTP 版本）；方括号缺失；多行空行跳过不计错误；UA / Referer 为 `-`；超大批量（≥1 万行）统计不卡顿（单次遍历聚合，O(n)）；混合格式行按各自格式解析。
- **核心算法**（纯函数，零依赖，放 `utils/accessLog.ts`）：单条正则 + tokenizer 兜底（处理引号内空格）；`parseLine` 返回 `{ok, data|error}`；`summarize(rows)` 单次遍历用 Map 聚合；CLF 月份缩写映射手写。
- **测试覆盖**（`utils/accessLog.test.ts`）：标准 Combined / Common 行往返；含转义引号 UA；`-` 字节 / Referer；带响应时间扩展；畸形行（缺引号、坏时间、截断）错误定位；汇总 Top-N 与状态码分类、时间跨度、字节 null 统计。
