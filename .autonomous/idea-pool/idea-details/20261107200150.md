## 描述

在任意 2–36 进制整数之间双向转换，并支持自定义字母表（如 Crockford Base32、自定义混淆字母表），基于 BigInt 保证超出 2^53 的大整数不丢精度。现有 `number-base-converter` 仅提供 2/8/10/16 四个固定进制且字母表不可定制；base32 / base45 / base58 / base62 / base64 / base85 / base91 等编解码工具面向字节流与 RFC 固定字母表，不提供通用整数 radix 互转与自定义字母表能力，本工具补的是「整数数值在任意 radix 下的表示」这一独立空白。支持输入前缀（0x/0o/0b）、下划线分隔、大小写归一、负号，并输出二/八/十/十六进制一览与位宽分组视图；自定义字母表时校验字符唯一性与长度（须 ≥2 且与 radix 等长），对字母表外字符按位置报错。纯浏览器本地确定性运算、零新增依赖，可用固定数值向量（如 255、2^64−1、负数）做可验证验收。
