## 描述

提供 CSS Color Module Level 4 定义的 148 个命名颜色（含 `rebeccapurple`）的双向查询表：按名称查 HEX/RGB/HSL 值并展示色块，按 HEX/RGB 反查最接近的命名颜色，支持搜索过滤与一键复制，补齐现有颜色工具偏重转换/取色而缺少标准命名色表的空白。

## 设计内容（进入 Claimed 前补全）

- 单页纯前端工具，静态内置 148 条命名颜色数据（数据来自 W3C 标准，构建时常量，无外部请求）。
- 主视图：网格卡片列表，每张卡片含色块、名称、HEX、RGB、HSL；点击色块或值即复制对应文本。
- 搜索：支持按名称（前缀/包含，不区分大小写）与按 HEX/RGB 值过滤；输入合法颜色值时高亮最接近的命名色。
- 反查：用户输入任意 HEX/RGB/HSL，计算与全部命名色在 RGB 空间的欧氏距离，给出最接近的 3 个命名色及差值。
- 分组展示：基础 16 色（Basic CSS colors）与扩展色分区；支持按色相排序或字母排序切换。
- 边界情况：非法颜色输入提示格式错误；`transparent`、`currentcolor` 等关键字单独列出并说明非命名色值；3 位 HEX 自动扩展为 6 位。
- 不在范围：取色器/吸管、调色板生成、对比度计算（现有 contrast-checker 已覆盖）、颜色格式互转主流程（现有 color-converter 已覆盖）。
