## 描述

在整数与其变长字节编码之间双向转换，覆盖 Protocol Buffers 使用的无符号 VarInt（Base-128 LEB128，每字节低 7 位载荷、最高位为续位）、有符号整数的 ZigZag 编码（(n<<1)^(n>>63)，将负数映射为小的无符号值后再走 VarInt），并直观展示逐字节拆分、续位标记与十六进制 / 二进制结果；同时支持直接的 LEB128 无符号 / 有符号解读，可用于调试 protobuf 报文、逆向二进制协议与理解序列化格式。处理边界值（0、-1、Int32/Int64 上下限）、非规范（过长）编码与截断 / 非法续位输入的报错。与现有进制转换（定长 hex/dec/bin 互换）、IEEE 754 浮点表示、Base-N / URL 编码等工具不重叠：那些针对定长数值或文本字节，本工具针对 Base-128 变长且续位相关的协议级整数编码。纯位运算实现，纯函数，零新增依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：VarInt（Base-128 LEB128 无符号）+ ZigZag 有符号映射 + 逐字节可视化，工具 slug 拟为 `varint-codec`。
- **无符号 VarInt**：BigInt → 每字节低 7 位载荷、最高位续位；解码截断输入（无续位结束）报错；非规范过长编码（超出 BigInt 可处理范围或末字节全 0 的冗余）给出错误。
- **ZigZag**：`(n<<1) ^ (n>>63)` 语义，用 BigInt 任意精度实现，支持 sint32/sint64 语义选择（按位宽做往返范围校验）。
- **可视化**：列出每字节的续位标记、低 7 位分组、合成偏移，输出 hex（如 300 → `AC 02`）与二进制串。
- **核心交互**：输入整数或字节串（hex），选择模式，实时双向转换；非法输入明确报错。
- **输入输出**：纯 BigInt / 位运算纯函数，不触碰 DOM / React，零新增依赖。
- **边界情况**：0、-1、Int32/Int64 上下限、截断 / 非法续位、过长编码、空输入。

## 验收标准（进入 Claimed 前补全，必须可验证）
