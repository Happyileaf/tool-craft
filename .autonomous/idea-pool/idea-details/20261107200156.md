## 描述

按 RFC 791 在浏览器本地构建与解析 IPv4 首部（不含载荷）：可视化编辑版本 / IHL、DSCP+ECN、总长度、标识、标志位（DF/MF）与片偏移、TTL、协议号（内置 IANA 常用协议名对照）、源 / 目的地址、可选 Options（NOP / EOL / Loose/Strict Source Route / Record Route / Timestamp），实时输出 20–60 字节首部的十六进制转储与逐字段 bit 级偏移图；反向粘贴 hex 即可拆解全部字段并校验首部校验和（RFC 1071）、IHL 与总长度一致性、选项长度合法性。现有 `cidr-subnet-calculator` 做子网划分、`ip-address-converter` 做地址表示互转、`tcpip-checksum` 只算校验和、活动池 DNS / HTTP / ICMP 工具均不覆盖 IPv4 首部线格式，四源查重以 IPv4 首部、IP header、分片、IHL、Options 检索无同类。纯本地 DataView 位运算、零新增依赖，用 RFC 791 示例首部与公开抓包向量验收。
