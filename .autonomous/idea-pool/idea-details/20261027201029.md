## 描述

输入电压 V、电流 I、电阻 R、功率 P 中任意两个已知量，自动求解其余两个量（V=I·R、P=V·I=I²R=V²/R），并展示所用公式、单位换算（V/mV、A/mA、Ω/kΩ/MΩ、W/mW/kW）；对 P、R 这类可能多解 / 需开方的组合给出全部合法解（如给定 V、P 求 I、R），并对零电阻、负输入等非法或物理无意义情形给出提示。用于硬件 / 电子调试中估算限流电阻、器件功耗与电流。与池中已有的「电阻器色环计算器」不同：后者只做色环 ↔ 阻值 / 公差的标识解读，本工具做欧姆定律与功率方程的联立求解，能力不重叠。纯数学公式计算，纯函数实现，零新增依赖，可用固定电路向量验收。

## 设计内容（进入 Claimed 前补全）

工具 slug：`ohms-law-calculator`。四个输入字段 V（电压）、I（电流）、R（电阻）、P（功率），每个字段带单位下拉（V：V/mV；I：A/mA；R：Ω/kΩ/MΩ；P：W/mW/kW），统一换算为基准单位（V/A/Ω/W）。恰好填写两个字段时求解：

- V,I → R=V/I, P=V·I
- V,R → I=V/R, P=V²/R（R>0）
- V,P → I=P/V, R=V²/P（V≠0、P>0；给定 V、P 为唯一解，开方出现在 I,R 与 P,R 组合）
- I,R → V=I·R, P=I²·R
- I,P → V=P/I, R=P/I²（I≠0）
- R,P → V=±√(P·R), I=±√(P/R)（R>0、P≥0；P>0 时正负双解，物理场景取正极性并同时呈现数学双解）

结果卡片显示每个量的值（自动选择合适单位）与所用公式。校验：已填字段数 ≠ 2 时提示「请恰好填写两个量」；负数（功率/电阻）、零除、非有限数给出明确错误。纯函数 `solveOhmsLaw(inputs)` 放 `utils/ohms.ts`，固定电路向量（如 5V/1kΩ → 5mA/25mW）做 Vitest，零依赖。
