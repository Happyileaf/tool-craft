## 描述

对两段列表（每行一项）执行集合运算：交集、并集、仅左侧独有（A−B）、仅右侧独有（B−A）与对称差集，并可开关「忽略大小写」「忽略首尾空白」「结果去重」，同时统计各结果集的条目数量。用于账号 / 权限 / ID / 标签等清单的差异比对。现有 line-operations 仅对单段列表做排序、去重、反转与过滤，text-diff 展示逐行字符差异，均不提供双列表之间的集合运算。基于 Set 的纯函数实现，零新增运行时依赖。

## 设计内容（进入 Claimed 前补全）

- 功能范围：对两段文本列表（A / B，每行一项，支持空输入）执行五种集合运算——交集 A∩B、并集 A∪B、仅左侧 A−B、仅右侧 B−A、对称差集 (A−B)∪(B−A)，同屏展示五个结果区与各自条目数。
- 输入预处理选项（开关）：「忽略首尾空白」（默认开，对每行 trim）、「忽略大小写」（默认关，比较前两侧统一小写）；另有「结果去重」（默认开）。
- 输出顺序与重复项语义：结果一律按首次出现顺序排列（交集/并集/A−B 以 A 中顺序为准，B−A 以 B 为准，对称差 = A−B 后接 B−A）。去重开启时每值出现一次；关闭时交集与并集以 A 为基准保留 A 中重复出现的次数，A−B 保留 A 中被减后的重复，B−A 对称保留 B 侧重。空行经 trim 后若为空字符串则不作为条目（两侧皆空时结果为空列表）。
- 核心交互：两个多行输入框 + 三个开关，输入即算（无按钮）；每区展示条目数与一行一项的结果，附一键复制。
- 纯函数设计：`utils/set-ops.ts` 导出 `parseList(text, { trim, lowercase })` 与 `setOperations(a, b, { dedupe })`（返回五组字符串数组）纯函数；配套 `utils/set-ops.test.ts` 覆盖五种运算、顺序、重复计数、trim/小写开关、空列表与空串。
- 边界：仅做逐行精确匹配（不做模糊/分词）；不处理超大文件（主线程，常规清单规模）；不持久化输入。
