## 描述

批量校验 CAS 化学物质登记号（CAS Registry Number / CAS RN，形如 `7732-18-5`，水）的合法性：从右向左对连字符前的数字（不含校验位）依次乘以权重 1,2,3,…，求和后对 10 取模，结果须等于末位校验数字。支持每行一个的批量输入、容忍空格与全角连字符的规范化、逐行给出"合法 / 非法 + 实际算出的校验位"、统计合法数；额外做结构规则检查（当前 CAS 号为 2–7 位 + 2 位 + 1 位三段、首位非 0 的通用规则，未来 10 位起始号段也兼容）。典型场景：化工/制药/环境/学术数据录入时核对 SDS、文献、数据库中的 CAS 号是否抄写错误，实验室数据治理。纯本地确定性算法，零依赖，可用 CAS 官方公开示例号（水 7732-18-5、乙醇 64-17-5、咖啡因 58-08-2、阿司匹林 50-78-2、氯化钠 7647-14-5）及故意改坏校验位的反例固定向量验收。边界：校验只证明**格式与校验位自洽**，不能证明该号真实分配给某物质（不内置任何 CAS 号数据库，不做号→物质名反查，CAS 数据库为付费版权数据）；与现有 ISBN / EAN / IBAN / ISIN / 银行卡 / 统一社会信用代码等校验位工具算法不同（权重方向与模均不同），是独立的校验体系，池内无同类条目。
