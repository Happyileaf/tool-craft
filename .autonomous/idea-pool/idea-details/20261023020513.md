## 描述

输入或粘贴 URL 列表（可选 lastmod / changefreq / priority），批量生成符合 sitemaps.org 协议的 sitemap.xml，自动处理 XML 转义（& < > 等）并在接近单文件 5 万 URL 上限时提示拆分。站点向搜索引擎提交收录前需要站点地图，手写 XML 与批量转义繁琐且易错；池内 robots.txt 生成器（20261017200239）面向爬取规则（robots.txt 纯文本），本条面向 URL 清单的 XML 站点地图，格式与用途均不同。输出为固定模板的 XML 字符串生成（只生成不解析，无 XML 解析复杂度），纯函数实现，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：由 URL 清单生成符合 sitemaps.org 协议的 sitemap.xml，工具 slug 为 `sitemap-generator`；只生成不解析。
- **输入**：每行一条 URL，支持全局默认 lastmod / changefreq / priority，应用于全部条目。
- **XML 转义**：对 URL 文本节点转义 `&` `<` `>` 及引号，保证输出合法 XML。
- **上限提示**：URL 数超过 50000 条时提示超出单文件上限；URL 非 http(s) / 非法时给出错误计数与样例行号。
- **输出**：`<?xml ...?>` + `<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">` 包裹的 `<url>` 条目，空值字段省略；一键复制。
- **输入输出**：纯函数 `generateSitemap(urls, options)` 与校验函数，不触碰 DOM / React。
- **边界情况**：空输入输出空态；首尾空白裁剪、空行跳过；重复 URL 不去重（保持输入语义）。
