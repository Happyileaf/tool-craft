## 描述

面向摄影取景与镜头选型的纯前端光学计算器：给定焦距（mm）、光圈 f 值、对焦距离与弥散圆直径 CoC（mm，内置全画幅 0.03 / APS-C 0.02 / M4/3 0.015 等常见画幅预设，也可自定义），按标准薄透镜公式计算超焦距 H = f²/(N·c) + f、近景深边界 Dn = s·(H−f)/(H+s−2f)、远景深边界 Df = s·(H−f)/(H−s)（s 超过 H 时 Df 为无穷远并明确标注）、总景深 DoF = Df−Dn 与前后景深占比；反向支持「给定目标景深求所需光圈」；结果在 m/cm/ft 间换算，并给出无穷远对焦、微距（对焦距离接近焦距）等边界情形的提示。

现有工具集覆盖电子学（`ohms-law-calculator`、`rc-filter-calculator` 等）、通用单位换算（`unit-converter`，仅长度/面积等 11 类物理单位，无光学成像公式）与数学计算，但没有任何摄影光学工具；景深公式以 CoC、焦距、光圈为输入，与通用单位换算或欧姆定律的输入输出均不同，不构成重复。纯浮点本地计算、零依赖，可用固定参数（f=50mm、f/8、s=3m、CoC=0.03mm → H≈10.4m，DoF 可固定断言）确定性验收，复杂度 S。
