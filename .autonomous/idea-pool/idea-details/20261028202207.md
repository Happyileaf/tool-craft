## 描述

在紧凑区间表达式与离散整数列表之间双向批量转换：展开方向把 `1-5, 10, 12-14`（支持可选步长如 `0-10:2`、负数）解析为完整数列；压缩方向把一串（可能乱序、重复的）数字排序去重后合并成最小区间表示。基于 BigInt 支持大整数，可配置分隔符与是否补零对齐。纯浏览器本地处理、零新增依赖，适合端口号清单、ID 段、页码范围等批量数值整理。

## 设计内容

- 展开方向：解析 `1-5, 10, 12-14` 为完整数列；支持可选步长 `0-10:2`、负数（如 `-5--1`、`-3..3` 写法以英文逗号/连字符语法说明为准）与空白容错；元素/区间数量设安全上限防止爆量。
- 压缩方向：把离散数字列表（允许乱序、重复、换行分隔）排序去重后合并为最小区间表示；相邻数合并为 `a-b`，孤立数单列。
- 基于 BigInt 支持大整数；可配置输出分隔符；非法 token、倒置区间、非正步长返回明确错误。
- 纯函数逻辑放 `utils/range.ts`，组件仅负责交互与方向切换；零新依赖、主线程（S–M，输出规模设上限）。

## 验收标准（必须可验证）

- [ ] `1-5, 10, 12-14` 展开为 `1,2,3,4,5,10,12,13,14`。
- [ ] `0-10:2` 展开为偶数序列；步长为 0/负数与倒置区间被识别报错。
- [ ] `5,3,1,2,4,4,6,8` 压缩为 `1-6,8`；乱序与重复被正确排序去重。
- [ ] 负数与 BigInt 大整数往返一致（展开再压缩等价）。
- [ ] 单测覆盖解析、展开、压缩与错误分支；lint / typecheck / test / build 全部通过。
