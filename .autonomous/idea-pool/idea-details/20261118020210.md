## 描述

面向车载 / 工业 CAN 总线调试，解析 Vector DBC 文件的核心段落并对抓包得到的 CAN/CAN FD 数据帧做信号级解码。① DBC 解析：识别 `BO_` 报文定义（ID、名称、DLC、发送节点）与 `SG_` 信号定义（起始位、长度、字节序 Intel/Motorola、有无符号、factor、offset、min/max、单位、接收节点），兼容 `BA_` 中常用的注释类属性（忽略不支持的复杂属性而非报错）；② 帧解码：粘贴十六进制 data（0–64 字节，兼容 CAN FD）与报文 ID，按 DBC 中该报文的全部信号做位提取（Intel 小端与 Motorola 大端两种起始位约定）、有/无符号整型还原，再按 `physical = raw * factor + offset` 换算并附带单位与范围合规判定；③ 反向编码：给定物理值反算 raw 并回填到帧字节，便于构造测试报文。纯文本解析与位运算，零依赖、无网络请求，文件不离开浏览器。

## 设计内容（进入 Claimed 前补全）

功能范围：单页三区。① DBC 输入区：粘贴 DBC 文本（或拖拽 `.dbc` 文件本地读取），解析后以报文卡片列出每个 BO_ 及其信号表（名称/起始位/长度/字节序/因子/偏移/单位/范围），解析错误按行号报告；② 解码区：选择报文 ID（或自动按帧 ID 匹配）、输入帧 data 十六进制（容忍空格分隔），逐信号输出 raw 值、二进制位高亮（在 8×N 位网格中标出每个信号占用位）、physical 值、单位、是否超出 min/max；③ 编码区：按信号表单输入 physical 值，实时生成完整 data 十六进制并显示未使用位（填充位）；④ 字节序示意：静态说明 Intel（LSB 起始位）与 Motorola（MSB 起始位、锯齿跨字节）两种布局规则。

核心交互：DBC 解析结果卡片化、位网格实时高亮、报文 ID 下拉联动信号表、十六进制输入自动归一化、字段级错误提示（DLC 不足、信号越界、ID 无定义）、一键复制解码结果与编码帧；同一份 DBC 在会话内缓存，切换报文不丢失。

输入输出：输入为 DBC 文本/文件与帧 ID + data 十六进制；输出为报文/信号结构表、逐信号 raw/physical 解码、位网格可视化、编码后的 data 十六进制。

边界情况：DBC 中未识别的段落（`BA_DEF_`、`VAL_TABLE`、`BS_` 等）整体跳过不报错，仅统计跳过行数；Motorola 信号跨字节边界时按标准 sawtooth 规则映射并给出中间位序；有符号信号做正确的符号扩展；factor 为小数时用浮点换算并按 DBC 精度合理展示（避免浮点尾差，末尾零裁剪）；帧 data 短于信号所需字节时缺失位按 0 处理并明确警告；同一报文内信号位重叠时给出冲突警告；扩展帧 ID（29 位）与标准帧（11 位）均支持，ID 匹配时忽略高位填充差异；空 DBC 或零个 BO_ 时提示而非白屏。
