## 描述

识别并分离 Markdown 文件顶部的 frontmatter 元数据块（支持 `---` YAML 与 `+++` TOML 两种定界），将正文与元数据分区展示：以表单 / 键值表格编辑字段（增删改、嵌套键、数组值），实时回写为合法 frontmatter 并保持正文原样不动，同时给出 YAML/TOML 两种输出对照与语法错误定位，面向静态站点（Hugo / Hexo / Astro / Jekyll）作者批量维护文章元数据。

## 设计内容（进入 Claimed 前补全）

- 工具 slug：`markdown-frontmatter-editor`，分类 TEXT（文本与字符），主线程零依赖。
- 核心纯函数（utils/frontmatter.ts）：
  - `splitFrontmatter(markdown)`：识别文档开头 `---`/`+++` 围栏（必须从首行开始，允许首行 BOM），返回 `{ format: 'yaml'|'toml'|null, raw: string, body: string, startLine, endLine }`，无围栏时 format=null、raw=''、body=原文。
  - `parseYamlSimple(raw)`：覆盖 Frontmatter 常见子集——标量（字符串/整数/浮点/布尔/null）、不带引号与单双引号字符串、`#` 注释、两级嵌套 map（2 空格缩进）、`- ` 序列（标量序列）；不引入 yaml 依赖，超出子集（流式 [] {}、锚点等）返回 unsupported 告警而非错误解析。
  - `parseTomlSimple(raw)`：覆盖 `key = "value"`、整数/浮点/布尔、`[section]` 表、section 下标量与简单数组；同样零依赖、超子集告警。
  - `stringifyYaml(obj)` / `stringifyToml(obj)`：把结构化对象写回规范文本（字符串含 `: #` 等特殊字符时自动加双引号并转义）。
  - `buildDocument(format, raw, body)`：重组完整 Markdown。
- 边界：CRLF 归一化、围栏内空值、重复键告警、数组/对象与正文边界（首个 `---` 后换行）、正文内出现 `---` 分隔线不被误判（仅认文档开头围栏）。
- 组件：双栏——左侧 Markdown 原文，右侧 Frontmatter 结构化键值表格（增删改行、类型标识）+ 正文编辑区；YAML/TOML 切换时双向转换；不支持语法高亮告警 Alert；示例与复制。
