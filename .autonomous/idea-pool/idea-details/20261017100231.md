## 描述

根据 JSON 样例数据自动生成等价的 TypeScript 接口 / 类型定义，供前端开发直接复用。现有 `json-formatter` 仅做格式化与校验，缺少「从数据反推类型」的能力，本条补齐该缺口。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：解析 JSON 文本，递归推断类型并生成 TypeScript `interface` / `type` 定义；覆盖对象、数组、字符串、数字、布尔与 null 的任意嵌套。
- **核心交互**：左侧输入 JSON，右侧实时输出 TypeScript 类型定义；提供根类型名可编辑、是否导出（`export`）、缩进宽度、可选 / 只读修饰、数组元素类型合并等选项；解析失败时展示可读错误且不产出结果。
- **输入输出**：输入 JSON 字符串，输出 TypeScript 声明文本；非法 JSON 抛出可读错误并由界面捕获展示。
- **边界情况**：空输入返回空输出；同一数组内元素类型不一致时取联合类型（如 `(string | number)[]`）；空数组推断为 `unknown[]`；`null` 值推断为 `null` 并提示可空；键名不是合法 TS 标识符时加引号；嵌套对象生成独立命名接口，命名需去重且稳定；数字需区分整数与浮点（整数推断为 `number`）。
