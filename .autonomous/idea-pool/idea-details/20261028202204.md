## 描述

输入含 2–8 个变量的布尔表达式（支持 AND / OR / NOT / XOR / 蕴含 / 等价及括号，兼容 `&&`、`||`、`!`、`^`、`->`、`<->` 等常见写法），自动生成完整真值表，并判定表达式性质（重言式 / 矛盾式 / 可满足式），支持多个表达式同表对比中间子表达式结果。纯浏览器本地计算，自实现轻量词法/语法分析，零新增依赖，适合数字逻辑、离散数学学习与条件逻辑核对。

## 设计内容

- 输入含 2–8 个变量的布尔表达式，运算符：AND（`&`/`&&`/`AND`/`·`）、OR（`|`/`||`/`OR`/`+`）、NOT（`!`/`~`/`NOT`）、XOR（`^`/`XOR`）、蕴含（`->`）、等价（`<->`/`<=>`），支持括号与大小写不敏感关键字。
- 自实现轻量词法分析 + 递归下降解析为 AST，按 2^n 枚举变量取值生成完整真值表（表格按变量列 + 结果列）。
- 判定表达式性质：重言式（永真）/ 矛盾式（永假）/ 可满足式；支持多个表达式同表对比（每行多结果列）。
- 语法错误给出明确错误位置信息；变量超 8 个或为 0 个时提示。
- 纯函数逻辑放 `utils/boolean.ts`（tokenize/parse/evaluate），组件渲染表格；零新依赖、主线程（2^8=256 行，S–M）。

## 验收标准（必须可验证）

- [ ] `A AND B` 生成 4 行真值表，结果与标准与运算一致。
- [ ] `A OR NOT A` 判定为重言式；`A AND NOT A` 判定为矛盾式；`A XOR B` 判定为可满足式。
- [ ] 括号、`->`、`<->`、`&&`、`||`、`!`、`^` 各写法解析正确（以已知真值向量验证）。
- [ ] 语法错误（如未闭合括号、空表达式）返回明确错误信息而非抛异常；变量数超 8 被拒绝。
- [ ] 单测覆盖词法、解析优先级、求值与性质判定；lint / typecheck / test / build 全部通过。
