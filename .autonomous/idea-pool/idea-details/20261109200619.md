## 描述

输入一个可见光波长（约 380–750nm），按经典光谱 → sRGB 近似算法（分段线性插值 + 边缘衰减因子 gamma 校正）输出对应的 RGB 与 HEX 值、色卡预览及所在光谱区间（紫 / 蓝 / 青 / 绿 / 黄 / 橙 / 红）；对落在可见光谱外（<380nm 近紫外、>750nm 近红外）的输入给出明确越界提示而非伪造颜色，并支持批量输入与波长—色卡对照带。面向光学教学、LED / 激光选型与科普场景。现有 `color-temperature-converter` 处理的是黑体色温（开尔文 K）→ 颜色，与「单色光波长（纳米 nm）→ 光谱色」是两套完全不同的物理模型；`oklch-workbench` / `color-palette` 等做色彩空间互转与调色，不涉及波长。本工具补齐光谱波长方向空白，纯函数、零依赖。

## 设计内容（进入 Claimed 前补全）

- slug：`wavelength-rgb-converter`，目录 `apps/web/src/tools/wavelength-rgb-converter/`，含 `index.tsx` / `constants.ts` / `index.module.css` / `utils/spectrum.ts` + `utils/spectrum.test.ts`。
- 纯函数层 `utils/spectrum.ts`（采用 Dan Bruton 经典近似算法的工程化移植，固定参数保证可断言）：
  - `wavelengthToRgb(wavelengthNm, gamma = 0.8)`：380–440 / 440–490 / 490–510 / 510–580 / 580–645 / 645–750 六段线性插值得到线性 R/G/B（0–1），边缘衰减因子 `factor`（380–420 与 645–750 段按 0.3+0.7×比例衰减），gamma 校正后映射到 0–255 整数并四舍五入；
  - `rgbToHex([r,g,b])`：输出 `#RRGGBB`；
  - `getSpectralBand(wavelengthNm)`：返回紫/蓝/青/绿/黄/橙/红区间名；
  - 越界判定：<380 或 >750 返回 `outOfRange: true` 与近紫外/近红外提示，不伪造 RGB（RGB 字段为 null）。
- 组件：波长 InputNumber + 滑块（300–850nm 便于演示越界）、色卡预览、RGB/HEX 展示与复制、区间 Tag、越界 Alert；批量模式（多行波长或逗号分隔）输出对照表；页面底部渲染 380–750nm 渐变色带（CSS linear-gradient 由离散采样点生成）。
- 零新增依赖，纯函数计算。
