## 描述

输入化学分子式（如 `H2O`、`H2SO4`、`Ca(OH)2`、`CuSO4·5H2O`、`C2H5OH`、`Fe2(SO4)3`），解析元素符号、下标与嵌套括号、结晶水（`·nH2O`），按内置的标准原子量（IUPAC 常规原子量，零依赖静态表）计算摩尔质量（g/mol），并展开各元素的原子个数、质量贡献与质量百分比（mass fraction %）；支持一次输入多个化学式批量计算、点击复制结果。典型场景：化学实验配液、教学作业、实验记录换算。纯本地确定性计算、零网络请求，可用固定向量验收（H₂O = 18.015、NaCl = 58.44、Ca(OH)₂ 括号嵌套、CuSO₄·5H₂O 结晶水加成、未知元素符号 / 括号不匹配 / 非法下标的明确报错）；原子量数值固定来源版本以保证验收用例不随时间漂移。已实现工具集无任何化学计算工具，在池 Idea 与 completed / rejected 归档中检索「化学 / 分子式 / 摩尔 / molar」均无相关条目（检索命中的「摩尔」均为「摩尔斯电码」子串，无关），不构成重复。
