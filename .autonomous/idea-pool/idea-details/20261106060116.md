## 描述

支持桌面角色扮演/桌游常见骰子表达式（如 `3d6+2`、`2d20kh1` 优势骰取高、`4d6dl1` 弃低、`d100`），用 Web Crypto 安全随机源模拟投掷并给出每次明细与总计；同时对给定骰子组合精确计算点数和的概率分布（动态规划枚举全部组合，输出每个总和的概率、P(X≤k) 累积概率与直方图），帮助玩家与设计者评估命中概率与期望值。

## 设计内容（进入 Claimed 前补全）

**实现载体**：`apps/web/src/tools/dice-roll-probability/`（`index.tsx` + `dice.ts` 纯函数（表达式解析/分布 DP）+ `__tests__/dice.test.ts`），分类 `Math`，零第三方依赖；随机数用 `crypto.getRandomValues`，纯函数 `rollDice(expr, rng?)` 支持注入确定性 rng 以便测试。

**功能范围**：
1. 表达式解析（手写小型 parser，正则+递归即可，不引依赖）：支持 `NdS`（N 个 S 面骰，N 可省略默认 1，如 `d6`）、常量修正 `+m`/`-m`、多个骰子项相加（`2d6+1d4`）、保留/丢弃规则 `kh<n>` keep highest、`kl<n>` keep lowest、`dh<n>`/`dl<n>` drop highest/lowest（n 省略默认 1）。白名单字符 `0-9dDkhld+-` 与空白，非法表达式抛出可展示的中文错误。
2. 模拟投掷：点击「投掷」用 Web Crypto 生成每次每粒骰子点数，展示逐粒明细、保留/丢弃标记、最终总和；支持连续投掷并保留最近若干次历史。
3. 精确概率分布：对基础 `NdS`（不含 kh/dl 的组合）用动态规划枚举点数和的全部组合计数，输出每个总和的组合数、概率（计数/S^N）、累积概率 P(X≤k)、期望值、最小/最大值；含修正值时整体平移。含 keep/drop 的表达式按同样 DP 思路对排序后选取的结果做计数（在合理骰数上限内，如总骰子 ≤20、面数 ≤100）。
4. 界面：表达式输入 + 示例 chips（`d20`、`3d6+2`、`2d20kh1`、`4d6dl1`、`d100`）；分布表 + 纯 CSS/div 直方图；期望与区间概率（P(X≥目标值)，可输入目标值）。

**输入输出**：输入表达式字符串；解析输出 `{ dice: {count,sides}[], modifier, keep?, drop? }`；分布输出 `{ sum, count, probability, cumulative }[]` 与 `expected, min, max`。

**边界情况**：空/非法字符、N 或面数为 0 或超上限（count≤20、sides 2–100）、keep 数 ≥ 骰子数（等同全保留）、drop 数 ≥ 骰子数（报错或归零，定义为报错提示）、仅常量无骰子（报错）、超大组合数用 `number` 计数在安全整数范围内（上限内 S^N ≤ 100^20 超出——改用概率 DP 归一化而非原始计数，避免 BigInt 渲染麻烦；测试向量选小组合用精确分数核对）。
