## 描述

将 CSV（首行作为列名）转换为 SQL `INSERT` 语句，支持自定义表名与列名、每条语句批量插入的行数、标识符引号风格（反引号 / 双引号 / 方括号）以及 NULL / 空值处理与字符串转义。现有 csv-json-converter 只做 CSV ↔ JSON 转换，缺少面向数据库导入的 SQL 生成能力。

## 设计内容（进入 Claimed 前补全）

- slug：`csv-to-sql`，分类 DATA_JSON，主线程处理，零新依赖。
- 纯函数模块 `utils/csv-sql.ts`：`detectDelimiter` / `parseCsv`（RFC 4180 字符级状态机，BOM、CRLF、引号转义）/ `quoteIdentifier`（反引号 / 双引号 / 方括号）/ `toSqlValue`（NULL 策略、裸数字、单引号双写）/ `buildSqlInserts`（自定义列截取、分批行数）。
- UI：Ant Design 双 Card（输入 + 选项 / SQL 输出），Radio.Group 切换分隔符、引号风格、空值策略，Switch 控制 NULL 字样识别，Tag 显示列数 / 行数，一键复制。
- 边界：空文本 / 未闭合引号 / 表名或列名为空 / 行列数不匹配均抛错并由 Alert 展示；只有表头时提示无数据行。
