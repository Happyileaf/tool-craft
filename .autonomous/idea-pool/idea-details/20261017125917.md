## 描述

对多行文本进行排序（升/降序、自然排序）、去重、反转行序、过滤空行/重复行等行级操作，常用于清洗日志、提取唯一值与整理列表。`text-case-converter` 只处理字符大小写，`word-count` 只统计，没有行级变换工具。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：面向多行文本的行级变换工具，工具 slug 拟为 `line-operations`。
- **排序**：支持升序 / 降序；比较方式支持字典序、自然序（数字段按数值比大小）、按行长、按数值（整行可解析为数字时）；排序稳定（相等行保持原相对顺序）。
- **去重**：去除重复行并保留首次出现的行；提供「区分大小写」开关。
- **反转**：按行反转顺序。
- **过滤**：去除空行（含仅空白行）；按关键字包含过滤（保留命中 / 排除命中）；按正则过滤（保留命中 / 排除命中）。
- **其它选项**：去除每行首尾空白、统计处理前后行数。
- **核心交互**：左侧输入多行文本，选择操作与选项后右侧实时输出；提供复制、清空、载入示例。
- **输入输出**：纯函数 `string -> string`，不触碰 DOM / React。
- **边界情况**：空输入返回空；兼容 LF 与 CRLF 换行；正则在非法时给出错误提示而非抛异常；空行判断包含仅含空白字符的行。
