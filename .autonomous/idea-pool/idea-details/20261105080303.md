## 描述

在浏览器本地按 DICOM 标准（PS3.5 Chapter 9 / PS3.7 B.2）生成与校验 UID：UID 仅由数字 `0-9` 与句点 `.` 组成、总长不超过 64 字符、每段以非零数字开头（单字符段允许 `0`）、首段为组织根 UID（Organization Root，如 `1.2.840.10008` 这类 ISO 分支号）。工具支持输入组织根 UID 后以密码学安全随机数（`crypto.getRandomValues`）或时间戳+计数器方式批量生成后缀并拼接出 Study / Series / SOP Instance UID；对粘贴的 UID 做逐段校验并指出违反规则的位置；同时区分标准里保留的 Well-known UID 与自定义 UID。

与现有各类 ID 生成器（ULID / KSUID / Nano ID / TypeID / Snowflake / ObjectId）面向通用分布式系统不同，DICOM UID 有独立的点分数字语法与医疗行业合规约束，规则确定且可固定断言；零依赖纯函数 + Web Crypto 即可实现，复杂度 S。
