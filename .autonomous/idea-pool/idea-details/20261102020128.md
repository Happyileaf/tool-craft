## 描述

在 Apple 平台本地化资源文件 `Localizable.strings`（旧式 NextStep 文本 plist 格式，语法 `"key" = "value";`）与 JSON 键值对象之间双向转换。解析侧正确处理：单行/多行 C 风格注释（`//` 与 `/* … */`，保留/剥离可切换）、空行、字符串内转义（`\n \t \r \" \\ \0` 以及 `\Uxxxx` 四位数与 `\Uxxxxxxxx` 八位代理对形式）、未转义 Unicode 字符、键或值跨行、缺分号/未闭合引号的错误定位（行号）、重复键检测；生成侧输出 `"key" = "value";`、按键排序可选、自动转义特殊字符。典型场景：iOS/macOS 应用多语言本地化交付时与翻译平台（多收 JSON / XLIFF）互转、批量审查译文、把服务端下发的 JSON 文案生成为 .strings。纯本地确定性转换，零依赖，可用固定 .strings↔JSON 向量（含注释、转义、中文/emoji、重复键反例）验收。边界：不处理二进制 plist（.bplist）、.stringsdict 复数规则、.xcstrings（Xcode 15 字符串目录，JSON 结构不同）——这些是独立格式，超出本条范围；与现有 `ini-json-converter` / `properties-json-converter` 类似但格式规则不同（.strings 为带引号键值 + 分号 + C 转义/`\U` 编码，INI 有 section、Java .properties 用反斜杠续行与 `\uXXXX` 但键无引号且无 C 注释），不构成重复；池内无 .strings / iOS 本地化条目。
