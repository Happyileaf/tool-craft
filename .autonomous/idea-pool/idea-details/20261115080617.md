## 描述

给定工作频率计算自由空间波长与常用天线物理长度：半波偶极子（含端效应缩短系数与 468/f(MHz) 英尺、143/f 米经验式）、四分之一波长垂直 / 接地平面天线（234/f 英尺、71.5/f 米）、全波环形与 5/8 波长垂直天线；并支持由天线长度反向求谐振频率、导线 / 同轴速度因子修正，以及业余无线电与常见无线模块频段（HF / VHF / UHF、433 MHz、868 MHz、2.4 GHz）预设。输出米 / 英尺双向结果与增益 / 极化说明，用于业余无线电、天线裁剪与 RF 模块选型快速估算。纯本地计算、零依赖。

## 设计内容（进入 Claimed 前补全）

功能范围：单页双向换算。①「频率 → 天线长度」：输入工作频率（MHz，0.1–6000），输出自由空间波长（米 / 英尺），并给出半波偶极子、四分之一波长垂直天线、5/8 波长垂直天线与全波环形天线的物理长度（米 / 英尺双单位）；②「天线长度 → 谐振频率」：输入已知天线长度（米）与天线类型，反推谐振频率。支持速度因子（0.50–1.00，默认 1.00）修正物理长度，提供 HF / VHF / UHF 与 433.92 / 868 / 915 / 2400 MHz 等常用频段预设。

核心交互：模式单选、频率或长度数值输入、速度因子输入、天线类型下拉/卡片选择、频段预设按钮；结果区展示每类天线的长度、对应波长与增益/极化说明，输入非法即时提示。

输入输出：输入为频率 MHz 或长度 m、速度因子与天线类型；输出为波长（λ = 300 / f 米，984 / f 英尺，按速度因子缩放）以及半波偶极子（143 / f 米、468 / f 英尺）、四分之一波长（71.5 / f 米、234 / f 英尺）、5/8 波长（187.5 / f 米）与全波环形（300 / f 米）长度。

边界情况：频率必须为正数且在 0.1–6000 MHz 内；长度为 0 或负数报错；速度因子超出 0.50–1.00 报错；经验公式的端效应缩短系数已内置，速度因子仅对物理长度做额外修正；结果保留 5 位有效数字并同时给出米/英尺。
