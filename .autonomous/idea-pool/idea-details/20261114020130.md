## 描述

可视化定制网页滚动条外观并输出两套 CSS：传统 WebKit 私有属性组（`::-webkit-scrollbar` 宽高、`::-webkit-scrollbar-track` 轨道背景/圆角/阴影、`::-webkit-scrollbar-thumb` 滑块颜色/圆角/hover 态、`::-webkit-scrollbar-button` 按钮）与 Firefox/标准属性组（`scrollbar-width: auto|thin|none`、`scrollbar-color: thumb track`）。提供滑块/轨道颜色选择器、宽度滑块、圆角、边框等控件，左侧实时预览一个可滚动容器的真实滚动条效果，右侧同步输出可复制 CSS，并附浏览器兼容说明。现有 `box-shadow-generator`、`gradient-generator`、`cubic-bezier-easing` 等 CSS 生成器均不涉及滚动条；registry、活动池、completed.md、rejected.md 全文检索 scrollbar / 滚动条无任何条目。纯样式字符串拼装与 DOM 内预览（纯函数部分可在 Vitest 验收），零依赖，S–M 级。
