## 描述

输入一组有序顶点坐标（手动逐行输入 `x,y` 或粘贴 GeoJSON Polygon 坐标），用鞋带公式（shoelace formula）计算多边形面积与周长，自动判断环方向（顺时针/逆时针、signed area 正负），支持孔洞环的外环/内环分别统计，并给出自相交检测提示。面向 GIS、土地丈量与几何计算场景，与已有 great-circle（球面两点距离）互补——本工具处理平面多边形整体量算。

## 设计内容（进入 Claimed 前补全）

纯客户端单页工具，零网络、零新增依赖；量算逻辑收敛为可单测纯函数 `utils/polygon.ts`，UI 负责坐标录入 / GeoJSON 解析与结果渲染。

- **输入**：
  1. 手动模式：文本域逐行输入 `x,y` 顶点（空白与容错分隔），按顺序构成一个环；
  2. GeoJSON 模式：粘贴 Polygon / MultiPolygon JSON，解析其坐标数组（第一个为外环，其余为孔洞内环）。
- **核心处理**：鞋带公式求有符号面积（signed area），取绝对值得面积、符号判环方向（正=逆时针、负=顺时针，按右手坐标系约定）；相邻顶点欧氏距离求和（含闭合边）得周长；孔洞环分别量算并从外环面积中扣减；顶点数 < 3 报错。
- **自相交检测**：对非相邻边做线段相交（O(n²)，n 为常见小顶点数，可接受）粗检，发现相交给出警告（面积仍按鞋带公式计算但提示结果可能无几何意义）。
- **输出**：面积、周长、环方向、顶点数；GeoJSON 多环时逐环列出并给出净面积；坐标解析失败给出明确错误。
- **边界**：不足 3 个顶点报错；坐标非数字报错；GeoJSON 类型不符 / 结构损坏报错；首尾点重复（闭合写法）自动去重避免重复边。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 单位正方形顶点 (0,0)(1,0)(1,1)(0,1) 面积为 1、周长为 4。
- [ ] 直角三角形 (0,0)(3,0)(0,4) 面积为 6、周长为 12。
- [ ] 环方向判定正确：逆时针顶点 signed area 为正、顺时针为负。
- [ ] 首尾点重复的闭合写法自动去重，结果与不重复写法一致。
- [ ] GeoJSON Polygon 粘贴后正确解析外环与孔洞环，净面积 = 外环面积 − 孔洞面积。
- [ ] 自相交多边形触发相交警告；顶点数 < 3、坐标非数字、GeoJSON 结构损坏均返回明确错误。
