## 描述

粘贴顶点坐标列表（`x,y` 每行一个）或 GeoJSON Polygon 几何，自动闭合多边形，用鞋带公式计算有向面积与绝对面积、周长、边数、质心，并判定环绕方向（顺时针/逆时针）；支持带孔 GeoJSON Polygon（外环减内环）。零依赖纯函数。

## 设计内容（进入 Claimed 前补全）

- 功能范围：
  - 两种输入模式：坐标文本（每行 `x,y`，支持空格/逗号/制表符分隔）与 GeoJSON Polygon/MultiPolygon 粘贴。
  - 自动闭合：首末点不同时自动补闭合边，面积与周长不重复计算。
  - 鞋带公式输出有向面积（带符号）与绝对面积；周长逐边欧氏距离求和；边数；质心（顶点平均，标注为算术中心）。
  - 环绕方向：有向面积符号判定 CCW/CW（屏幕坐标与数学坐标差异给出说明）。
  - GeoJSON 孔（holes）：面积 = 外环 − 内环之和；MultiPolygon 逐多边形输出并汇总。
- 核心交互：Radio 切换输入模式；文本域 + 示例填充；结果卡片含面积/周长/边数/方向 Tag；顶点表格。
- 边界：少于 3 个顶点报错；重复相邻点去重提示；坐标非数字带行号报错；GeoJSON 类型不符/环不闭合按 RFC 7946 处理（自动闭合）。
- 不做：不做地图渲染、不做坐标系投影转换（输入即平面笛卡尔坐标，GeoJSON 经纬度面积标注为「平面近似，未做球面修正」）。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 单位正方形 (0,0)(1,0)(1,1)(0,1) 面积 = 1、周长 = 4，未闭合输入自动闭合结果一致

- [ ] 环绕方向：CCW 有向面积为正、CW 为负
- [ ] GeoJSON Polygon 带孔时面积 = 外环 − 内环；MultiPolygon 汇总正确
