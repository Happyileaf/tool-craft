## 描述

Erlang B 公式是电信容量规划的经典模型（M/M/c/c 损失制，呼损即阻塞、无排队），用于在已知忙时话务量 A（Erlang）与中继线/信道数 N 时求呼叫阻塞概率 B，并支持两个反向工程问题：给定目标服务等级 GoS（如 B=1%）与话务量求最少中继线数，给定中继线数与目标阻塞率反算可承载的最大话务量；再附 N±1、GoS 0.1%/1%/5% 的灵敏度对照表与阻塞率随 N 变化的曲线，辅助扩容决策。计算采用递归形式 `B(0)=0`、`B(n) = A·B(n-1) / (n + A·B(n-1))`，数值稳定、无需阶乘/幂级数大值运算，反向问题用二分查找收敛。现有工具家族中电信/网络类工具偏协议编解码与解析（`sip-message-parser`、`rtp-header-codec`、`sms-segment-calculator` 等），无容量规划/排队论模型；`probability-distribution-calculator` 提供通用泊松 PMF/CDF，但 Erlang B 是带条件归一化的多服务器损失模型（递归阻塞公式），并非通用分布函数，且本工具面向工程上的 GoS 查表与反算工作流。四源查重全文检索「Erlang / 爱尔兰 / 话务 / 中继线 / M/M/1 / 排队」无相同或高度相似 Idea（唯一 Erlang 命中为 CUSIP 文档中的无关词）；纯数值递归与二分、零依赖，符合红线。
