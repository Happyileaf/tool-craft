## 描述

以面粉重量为 100% 计算各配料的烘焙百分比、含水量与配方总重，并按目标面粉量、目标面团总重或模具尺寸缩放每种配料的克数；支持圆模 / 方模 / 吐司盒在同高度下的体积换算与常见比例提示。用于面包、吐司与甜点配方换算、模具改尺寸和批量生产备料；纯本地计算。

## 设计内容（进入 Claimed 前补全）

功能范围：①「百分比」：输入面粉重量与配料行（名称、重量或百分比），输出每种配料的烘焙百分比、含水量（水 / 面粉）、盐与酵母相对面粉的比例、配方总重与总百分比；②「缩放」：按目标面粉量、缩放倍数或目标面团总重反算全部配料克数；③「模具换算」：圆模按 (新直径 / 原直径)²、方模按 (新边长 / 原边长)²、同底面积改高度按高度比，输出缩放系数；④ 常见烘焙比例对照（吐司 65%–75% 含水量等）仅作提示，不干预计算。

核心交互：配料行可增删、重量 / 百分比双输入联动、目标缩放方式切换、模具形状与尺寸输入、结果表（原配方 / 缩放后并列）与复制；非法输入即时提示。

输入输出：输入为面粉重量、配料列表、缩放目标、模具尺寸；输出为各配料百分比与缩放后重量、总重、含水量、缩放系数与结果表。

边界情况：面粉重量必须大于 0；配料百分比行允许 0 但不允许负数；总百分比不等于 100% 属正常（以面粉为基准），需明确说明；缩放目标必须大于 0；模具尺寸必须为正且形状参数齐全；结果按 0.1g 取整并给出取整误差说明。
