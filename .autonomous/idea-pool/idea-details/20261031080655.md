## 描述

上传或粘贴 ZIP/JAR/APK/Office（docx/xlsx 等均为 ZIP 容器）文件（或其 hex/Base64 表示），按 ZIP 规范（PKWARE APPNOTE）解析中央目录（End of Central Directory、Central Directory Header、Local Header），列出归档内全部条目：文件名、大小、压缩后大小、压缩方式（Store / Deflate / Deflate64 等常量）、CRC-32、修改时间、标志位（是否加密、是否 UTF-8 文件名、数据描述符），并展示总条目数、未压缩/压缩总大小与压缩率、ZIP64 标记等汇总信息；对截断、魔数不符、声明偏移越界、名称编码异常给出错误定位。解决拿到归档但不想/不能解压时，快速查看其中包含哪些文件与元数据的问题。解析限定为只读结构解析（不解压、不重打包），纯本地字节运算（DataView / TextDecoder）、零新增依赖（Deflate 不展开内容，仅读头部与 CRC），可用本地构造的固定 ZIP 字节样本做字段级断言验收。查重：registry 中 hex-dump-viewer 仅做十六进制转储展示，ELF 文件头解析器（pending `20261031020752`）解析的是 ELF 而非 ZIP；GZip/Deflate 压缩解压（pending `20261030200907`）面向单一流的压缩/解压而非 ZIP 中央目录结构；池内无 ZIP/归档解析条目，不构成重复。
