## 描述

在原始文本与 Quoted-Printable 编码（MIME 传输编码）之间双向转换：编码时将非 ASCII 字节转义为 `=XX` 十六进制形式、按 76 字符行宽插入软换行（行尾 `=`），解码时还原转义并去除软换行，支持指定源字符集。邮件开发与调试（SMTP/IMAP 抓包、multipart 正文解析）中 QP 编码正文十分常见，现有 base64 / base32 工具与池内 Base58、字符集解码条目均不覆盖 QP——它是与 Base64 并列的另一种 MIME 传输编码，算法与场景均不同。编码解码均为纯函数，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- **工具 slug**：`quoted-printable-codec`
- **分类 / 图标**：`ToolCategoryEnum.CRYPTO_ENCODING`（与 base45 / base32 等传输编码同分类）；图标 `Binary`
- **查重结论**：registry 中 base64-codec / base32-codec / base45-codec / base58-codec / ascii85-codec 均为定长字母表分块编码，无 QP 这种「可打印字符直出 + `=XX` 字节转义 + 76 列软换行」机制；rejected.md 无同类归档，池内无其他 QP 条目。不构成重复。
- **文件结构**（三件套，零新依赖）：
  - `constants.ts`：`CodecModeEnum`（encode/decode）、`MODE_OPTIONS`、`DEFAULT_TEXT`（含中文与特殊符号）、`DEFAULT_QP`（其 QP 编码）、`MAX_LINE_LENGTH=76`
  - `utils/quotedPrintable.ts`：纯函数 `encodeQuotedPrintable(text)`（UTF-8 编码后，可打印 ASCII 33–126 除 `=` 外直出，空格/制表符按规则处理，其余字节转 `=XX`，超 76 列在行尾插入软换行 `=\r\n`）、`decodeQuotedPrintable(input)`（去除软换行、还原 `=XX`、非法转义报错，字节经 UTF-8 解码并校验）
  - `index.tsx`：Radio 双向切换、TextArea 输入、只读结果 TextArea、错误 Alert、复制结果、载入示例 / 清空；hint 说明 QP 是 MIME 邮件传输编码
  - `index.module.css`：container/toolbar/label/hint
- **注册**：`registry.ts` 追加双语 ToolMeta（CRYPTO_ENCODING / Binary / isNew / MAINTHREAD / defaultSampleInput）；`loaders.ts` 追加懒加载条目
- **边界**：仅按 UTF-8 处理字节；解码遇到非法 `=XX`（非两位十六进制）或非法 UTF-8 序列明确报错；空输入返回空输出；不处理邮件头 `=?charset?Q?...?=` 包裹格式（仅正文传输编码）
