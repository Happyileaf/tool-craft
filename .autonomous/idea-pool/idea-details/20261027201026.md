## 描述

提供一张可搜索、可按类别筛选的标准 ASCII（US-ASCII，0–127）码表：逐字符展示十进制码位、十六进制、八进制、二进制、可打印字符、控制字符缩写（NUL / SOH / CR / LF / ESC / DEL 等）及其说明，并支持由字符查码位、由码位反查字符，以及常用控制键（Ctrl+字母）组合速查。用于调试协议、终端控制符、嵌入式串口数据与字符编码问题。工具集现有编码类工具（base16/32/45/58/64/85、HTML 实体、Quoted-Printable、Unicode 规范化、全半角等）均为「数据 ↔ 编码」转换器，没有任何一个提供按码位检索的静态字符码表，能力不重叠。数据为固定的 128 项公开标准表，纯本地渲染与查表，零新增运行时依赖，可用固定向量验收。

## 设计内容（进入 Claimed 前补全）

工具 slug：`ascii-table`。静态数据 0–127 共 128 行（码位、缩写、分类：控制字符/可打印/DEL、中英文说明、可打印字符或控制符名）：

1. 码表区：表格列 Dec / Hex / Oct / Bin / Char / 缩写 / 说明，支持类别筛选（全部 / 控制字符 0–31 / 可打印 32–126 / DEL 127）与关键字搜索（匹配缩写、说明、字符、码位的十进制与 0x 十六进制写法）。
2. 双向检索：输入单个字符（如 `A`、空格）显示其完整码位信息；输入十进制（65）或十六进制（0x41 / 41h）反查字符；超出 0–127 提示非 US-ASCII 范围。
3. Ctrl 组合速查：0x01–0x1A 对应 Ctrl+A…Ctrl+Z（65–90 与 0x40–0x5A 掩码关系），展示组合键 ↔ 码位；另列常用 ESC（0x1B）、CR（0x0D）、LF（0x0A）、Tab（0x09）、空格（0x20）、DEL（0x7F）。
4. 空格（0x20）以可见占位 `␠` 呈现并注明；点击行可复制码位 / 字符。

核心纯函数放 `utils/ascii.ts`（ASCII 表常量、lookupByCode、lookupByChar、ctrlCombo 列表、筛选/搜索谓词），Vitest 断言 128 行完整性与抽样向量（'A'=65=0x41、'0'=48、LF=10、DEL=127、Ctrl+M=CR），零依赖。
