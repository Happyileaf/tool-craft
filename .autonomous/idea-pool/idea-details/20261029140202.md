## 描述

按 RFC 5869 对输入密钥材料（IKM，支持文本/Hex/Base64）执行 HKDF-Extract 与 HKDF-Expand，可选 salt 与 info，选择 SHA-256/SHA-384/SHA-512 与输出长度，展示 PRK 与 OKM 中间结果，并支持官方测试向量反向验证。解决协议开发、JWT/加密联调中需要对照实现派生结果却只能临时写脚本的问题；使用 Web Crypto 纯本地计算，零新增依赖。
