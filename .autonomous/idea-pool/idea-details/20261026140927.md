## 描述

提供一份可检索、可反向查询的知名端口（well-known / registered ports）速查工具：支持按端口号（如 `443`）或服务名 / 协议关键字（如 `https`、`ssh`、`postgresql`）模糊搜索，列出端口号、传输协议（TCP / UDP / SCTP）、官方服务名、简要用途与是否属于 0–1023 系统端口区间；支持一次粘贴多行端口号批量解析、点击复制，以及「端口属于哪个端口段」的判定（well-known 0–1023 / registered 1024–49151 / dynamic 49152–65535）。数据基于 IANA 官方 Service Name and Port Number Registry 中稳定的知名条目（sshd、HTTP/HTTPS、DNS、SMTP、MySQL、PostgreSQL、Redis 等长期不变条目），以零依赖静态数据集内置。典型场景：读 nginx / 防火墙配置、排查端口占用、填写安全组规则时快速确认端口归属。纯本地确定性查询、无网络请求，可用固定向量（22/53/80/443/3306/5432/6379 的精确匹配、未知端口 65000 的区间判定、非法端口 70000/-1 的报错）固定验收；数据集陈旧风险通过只收录 IANA 长期稳定条目、标注数据来源日期来控制（与 rejected.md 中「依赖持续更新数据」被拒的 CSS prefixer 不同，知名端口一经分配极少回收，属稳定参考数据）。与已实现的 HTTP 状态码速查、MIME 类型速查（在池）、User-Agent parser（在池）同属开发参考类但对象不同；已实现工具与在池/Rejected 历史中均无端口查询工具，不构成重复。

## 设计内容（进入 Claimed 前补全）

- 内置静态表（`utils/ports.ts`，零依赖）：约 30 条 IANA 长期稳定条目（20/21/22/23/25/53/67/68/69/80/110/123/143/161/443/465/587/993/995/3306/3389/5432/5601/5672/6379/8080/8443/9200/27017 等），每条含端口号、传输协议（TCP/UDP/两者）、官方服务名、中文用途说明、关键词；页面标注「数据基于 IANA 长期稳定条目，截至 2026-10」。
- 纯函数核心：`lookupPort(n)` 精确匹配；`searchPorts(keyword)` 按服务名/关键词/端口字符串模糊匹配；`getPortRange(n)` 返回 well-known(0–1023)/registered(1024–49151)/dynamic(49152–65535)；`validatePort(input)` 对非整数、越界（<0、>65535，如 70000、-1）返回明确错误。
- UI：搜索框（输入数字时同时给出精确条目与端口段判定；未知端口如 65000 仅显示端口段）、协议 Radio 过滤、命中条目折叠列表（端口、TCP/UDP Tag、服务名、用途）；非法输入行内错误提示。零依赖、主线程。
