## 描述

电池续航估算计算器：输入电池容量（mAh / Ah / Wh）、负载电流或功率、转换效率与允许放电深度（DoD），计算预计续航时间与消耗能量；支持多节电池串并联组包后的电压 / 容量 / 总能量合成、Peukert 指数修正，并给出不同负载电流下的续航对比表。用于电子项目选电、功耗预算与移动设备续航评估。纯本地计算、零依赖。

## 设计内容（进入 Claimed 前补全）

### 功能范围

- 容量输入：支持 mAh / Ah / Wh 三种单位，并在给定电压下互相换算。
- 电池组：单节容量与电压 + 串联数 / 并联数，输出组包后的电压、容量与总能量。
- 续航计算：负载输入支持电流（A）与功率（W）两种方式；考虑转换效率与允许放电深度。
- Peukert 修正：可选开启，按 t = t_base × (I_rated / I)^(k-1) 修正高倍率放电。
- 倍率对比：0.1C / 0.25C / 0.5C / 1C / 2C 下的续航对比表。

### 核心交互

- 单体 / 串并联模式切换；容量单位随输入自动复合换算。
- 结果卡展示可用能量、续航时间与额定负载；倍率表按倍率升序。
- 非法容量、电压、负载或串并联数量时给出校验提示。

### 输入输出与边界

- 输出：可用能量 Wh、续航时长、组包规格、倍率续航表。
- 边界：容量与电压必须为正；串联 / 并联数为正整数；负载为 0 或负值报错；效率与放电深度限制在 0–100%；Peukert 指数小于等于 1 时按理想容量处理。
