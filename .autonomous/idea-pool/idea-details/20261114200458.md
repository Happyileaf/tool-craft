## 描述

基于 BigInt 的任意精度整数计算器，支持加、减、乘、除（整除与余数）、幂、阶乘、最大公约数 / 最小公倍数、模逆与模幂等运算，并展示结果的十进制位数以及十进制 / 十六进制 / 二进制表示。解决普通 Number 在加密参数、长 ID、组合数等大整数运算时精度丢失的问题。纯本地计算、零依赖。

## 设计内容（进入 Claimed 前补全）

功能范围：基于 JavaScript BigInt 的任意精度整数计算器。支持二元运算加（+）、减（−）、乘（×）、整除（/，同时给出商与余数）、取模（%）、幂（^，快速幂）、最大公约数（GCD）、最小公倍数（LCM）、模幂（A^B mod M）与模逆元（A⁻¹ mod M）；支持一元运算阶乘（n!）。每个结果同时展示十进制（带千位分隔）、十六进制与二进制表示，以及十进制位数、二进制位数与符号。

核心交互：操作数 A、B 与可选模数 M 的大整数文本输入，运算选择下拉；一元阶乘使用 A 输入；结果卡片展示主结果、商/余数（整除时）、进制表示与位数统计，支持一键复制各表示；非法输入即时提示。

输入输出：输入为任意长度的十进制整数文本（可带正负号与千位逗号）、运算类型与可选模数；输出为 BigInt 精确结果及 hex / bin / 十进制分组文本，并给出位长与位数。

边界情况：空输入或非整数文本（含小数点、字母）报错；除数为 0 报错；阶乘要求 0 ≤ n ≤ 10000，幂指数要求 0 ≤ B ≤ 10000 且底数位数 × 指数不超过安全规模；模数必须为正整数；负数阶乘、负模数或模逆不存在（gcd ≠ 1）给出明确错误；所有计算使用内置 BigInt，零新增依赖。
