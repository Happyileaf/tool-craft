## 描述

BibTeX（.bib）是 LaTeX 学术写作中标准的参考文献数据格式，由 `@article{…}`、`@inproceedings{…}` 等条目及大括号包裹的字段组成。研究者常需检查 .bib 文件、在条目与结构化数据之间互转，或快速生成格式化引用。本工具在浏览器本地解析 .bib 文本为条目列表（JSON 视图，含 entry key / entry type / 字段表），支持字段缺失与重复检测，并可把结构化条目序列化回合法 BibTeX；纯文本解析、零新增依赖、不上传文献数据。
