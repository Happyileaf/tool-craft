## 描述

在 Windows 与 POSIX 路径之间做双向转换：把 `C:\Users\me\project` 转成 `/mnt/c/Users/me/project`（或 WSL 新版 `/c/Users/me/project`），把 `/home/me/src` 转成 `C:\Users\me\src` 的指定盘符形式，并处理 UNC 路径（`\\server\share\x` ↔ `//server/share/x`）、混合分隔符归一、尾随分隔符与 `.` / `..` 段折叠。用于 WSL / Git Bash / Cygwin 与 Windows 工具之间复制路径、编写跨平台脚本和排查「路径找不到」问题；纯本地字符串处理，不访问任何文件系统。

## 设计内容（进入 Claimed 前补全）

功能范围：方向单选（Windows → POSIX / POSIX → Windows）；目标风格选项（WSL `/mnt/<盘符>` 与 WSL2 挂载 `/ <盘符>`、纯 POSIX 无盘符映射）；UNC 前缀识别与双向映射；分隔符归一（反斜杠与正斜杠混用自动识别）；可选段归一（折叠 `.`、处理 `..`、去除重复与尾随分隔符，遇越界 `..` 给出提示）；批量模式按行转换。

核心交互：单行 / 多行输入、方向与目标风格切换、一键互换、示例路径预置、逐行结果与告警标注、复制结果。

输入输出：输入一条或多条路径字符串；输出转换后的路径、识别到的路径类型（盘符绝对 / UNC / POSIX 绝对 / 相对）与告警（非法盘符、无法映射的根、越界 `..`）。

边界情况：空行忽略并计数；相对路径按规则仅做分隔符转换并提示无法确定盘符；`/mnt/c` 之外的 WSL 挂载（如 `/mnt/wsl`）原样保留并告警；URL（含 `://`）不当作路径处理；大小写不做强制转换。
