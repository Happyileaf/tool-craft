## 描述

给定一个基准时间和多个参会者所在时区，并排展示每个时区对应的本地日期时间与星期，标注各地工作时间（如 09:00–18:00）内 / 外状态，并对一段候选时间区间给出「全员都在工作时间」的重叠时段排序推荐；支持选择某个日期整体滑动查看、夏令时自动处理（依赖浏览器 Intl 时区数据）、结果可复制为带各地时间的会议邀请文本。典型场景：跨国团队排会、找海外窗口。已实现的 timestamp-converter 做的是单个 Unix 时间戳与单一目标时区的双向换算，不含多城市并排对比与跨时区工作时间重叠求解；「日期时间差计算与日期加减计算器」（20261026140925）处理的是同一时标下的时长与日期偏移，不涉及时区。核心计算基于浏览器内置 `Intl.DateTimeFormat` / IANA 时区数据库，无需任何外部 API 与时区数据包，确定性输出，可用固定向量验收（如 UTC 12:00 对上海 / 伦敦 / 纽约的已知时刻、跨 DST 边界日期、无重叠工作时间时给出提示）。
