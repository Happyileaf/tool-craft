## 描述

通过表单配置行列数量、轨道尺寸（fr / px / auto / minmax）、间距（gap）与命名区域（grid-template-areas），在预览区实时呈现网格布局并生成完整的 `grid-template-*` CSS 代码。前端日常布局开发中 Grid 是与 Flexbox 并列的核心体系，现有已注册的 CSS 类工具（阴影、渐变、滤镜、单位换算）均不涉及布局生成，池内仅有 Flexbox 生成器条目，而两者输出属性（`grid-template-columns/rows/areas` 与 flex 系属性）完全不同，属能力缺口。表单状态到 CSS 文本的映射为纯函数，预览用纯 CSS 渲染，零新依赖、纯本地。
