## 描述

拖拽或粘贴一个 `.mid` / `.midi` 标准 MIDI 文件（或其字节），在浏览器本地只读解析 Standard MIDI File 结构：校验 `MThd` 头块并读取 format（0/1/2）、track 数、division（每四分音符 tick 数或 SMPTE 时基）；遍历每个 `MTrk` 轨道块，按可变长度 delta-time 解码事件序列，展开 MIDI 通道事件（Note On/Off、Control Change、Program Change 等）、Meta 事件（速度、拍号、调号、曲名、文本）与 SysEx，并正确处理 running status（省略状态字节）的还原；以时间线 / 表格呈现各轨道事件，不做音频合成与任何写回。现有 `midi-note-frequency-converter` 只做「音名 ↔ 频率」换算、不解析文件；Tool-Craft 已有多个只读二进制结构解析器（WAV/MP4/ELF 等）但无 SMF 覆盖。本工具延续只读解析器家族，纯函数、零依赖、可固定向量单测。
