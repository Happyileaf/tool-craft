## 描述

输入 Glob 模式（支持 `*`、`**`、`?`、`{a,b}`、`[abc]` 与路径段规则）与一组测试路径，实时显示每个路径是否匹配，并输出等价的 JavaScript RegExp 字面量。文件选择、构建工具的 include/exclude、CI 忽略规则大量使用 Glob 语法，而现有 regex-tester 仅支持标准正则，开发者常需在两种语法间手工转换并反复验证。Glob → Regex 是确定性翻译算法（处理 `**` 跨段匹配、`{}` 组展开与正则元字符转义），纯函数实现，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- slug：`glob-tester`，分类 DEV_CODE，主线程处理，零新依赖。
- 纯函数模块 `utils/glob.ts`：`translateSegment`（字符级扫描）+ `scanBracket`（`[abc]`/`[!abc]` 字符类，未闭合按字面 `[`）+ `findBraceEnd`/`splitAlternatives`（`{}` 组按顶层逗号展开、可嵌套，未闭合按字面 `{`）；导出 `globToRegExp`（`^(?:...)$` 整串锚定，可选大小写不敏感）、`globToRegExpLiteral`、`matchGlob`、`matchPaths`。
- 语义：`*` → `[^/]*` 不跨段；`?` → `[^/]`；`**` 按相邻 `/` 识别为跨段匹配（`**/` 前缀可匹配零段，`a/**` 匹配任意层级，段中 `a**b` 退化为 `.*`）；正则元字符统一转义。
- UI：Ant Design 双 Card（模式 + 等价正则 / 测试路径列表），Switch 控制区分大小写，每行绿/灰展示匹配结论与汇总 Tag，一键复制正则字面量，空列表显示 Empty 提示。
- 边界：空模式只匹配空串；路径文本按行拆分、trim 并忽略空行；翻译异常由 Alert 展示。
