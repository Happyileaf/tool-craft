## 描述

通过表单生成移动端深链（Deep Link / Universal Links / App Links）所需的两份站点关联文件：iOS 的 `apple-app-site-association`（AASA，含 appIDs、components、paths、appIDs 与 webCredentials 段）与 Android 的 `assetlinks.json`（含 package_name、sha256_cert_fingerprints 数组、relation）。支持同时编辑双平台、多 Team ID / 多签名指纹条目、通配 path 与 component 级 query/fragment 匹配规则，实时预览格式化 JSON、校验必填字段与 SHA-256 指纹格式（冒号分隔 32 字节），并给出两份文件的正确部署路径（`/.well-known/`）与 `Content-Type` 检查清单。纯本地 JSON 拼装与格式校验，零依赖、无网络请求。

## 设计内容（进入 Claimed 前补全）

功能范围：单页双 Tab。① iOS AASA：输入 Team ID + Bundle ID 自动拼 `TEAMID.com.example.app` 形式 appID（支持多条），编辑 `applinks.details[].components`（`/` path、`?` query、`#` fragment、`comment`、`exclude` 开关），可选 `webcredentials` 与 `appclips` 段开关；输出符合现代 components 语法的 AASA JSON（无 `.well-known` 外层包裹）。② Android assetlinks：输入 package_name、一条或多条 SHA-256 指纹，relation 固定 `delegate_permission/common.handle_all_urls`（含可选 `get_login_credentials`），输出标准 `assetlinks.json`。③ 部署清单：静态展示两文件 URL 路径、`application/json` Content-Type、HTTPS 与无重定向要求、Android 指纹获取命令示例（keytool 文本，不执行）。

核心交互：平台 Tab 切换、动态增删 appID / 指纹 / component 行、实时 JSON 预览与语法高亮（纯文本 pre 即可）、一键复制与下载（Blob 本地下载）、字段级校验错误提示；空 appID、错误指纹长度、非法 Bundle 字符即时标红。

输入输出：输入为表单字段；输出为两份可直接部署的 JSON 文本与部署检查清单。

边界情况：SHA-256 指纹统一转大写并校验 95 字符（32 组两位十六进制 + 31 冒号），非法字符 / 组数错误明确报错；AASA components 为空时回退提示使用 `paths` 旧语法的兼容开关；数组类字段去空白条目、去重；输出 JSON 固定 2 空格缩进、键序稳定以利 diff；未选择任何平台时禁用复制按钮并提示。
