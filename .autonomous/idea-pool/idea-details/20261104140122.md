## 描述

实现 RFC 6455 WebSocket 数据帧（frame）的纯本地编解码器：解码方向解析 FIN / RSV1-3 / opcode（continuation / text / binary / close / ping / pong）、MASK 位、7/16/64 位 payload length、masking key 与掩码还原后的 payload（文本帧按 UTF-8 显示，close 帧解析 16 位状态码与原因，控制帧超 125 字节等非法情况报错）；编码方向支持输入文本/hex payload 构造客户端帧（自动加掩码）或服务端帧（不掩码），并展示逐字节 hex dump 与字段对照。

已有工具 `websocket-accept` 只覆盖握手阶段的 `Sec-WebSocket-Accept` 计算，不涉及帧层协议；本工具与池中 DNS 报文、IPv4 数据报头、Redis RESP 等「协议线格式解析」家族同类，是 Web 开发抓包排障（wss 帧调试、代理与网关开发）中常见而尚未覆盖的能力。零新增依赖、固定算法可用 RFC 6455 §5 示例字节做确定性验收。
