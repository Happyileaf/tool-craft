## 描述

输入两个 2D 或 3D 向量，计算模长、点积、叉积（3D；2D 输出标量叉积）、夹角（度/弧度）、向量投影与标量投影、加法/减法/数乘，并给出正交/平行/同向判定。零依赖纯函数，浮点结果做合理精度截断。

## 设计内容（进入 Claimed 前补全）

- 功能范围：
  - 2D/3D 维度切换；分量输入支持负数与小数。
  - 模长 |a|、|b|；点积 a·b；叉积 a×b（3D 向量 / 2D 标量 z 分量）。
  - 夹角 cosθ 与 θ（弧度+度），基于 atan2(|a×b|, a·b) 提升数值稳定性。
  - 投影：向量投影 proj_b(a) 与标量投影 comp_b(a)。
  - 和、差、数乘；关系判定：正交（点积≈0）、平行（叉积≈0）、同向/反向。
- 核心交互：两组分量输入框 + 维度切换；结果 Descriptions 分区展示；公式说明。
- 输入输出：数值分量；输出各运算结果向量/标量与判定 Tag。
- 边界：零向量参与夹角/投影时明确报错（除零）；分量非法输入报错；浮点容差 1e-10 判定正交平行。
- 不做：不做 N 维泛化（UI 聚焦 2D/3D），不做矩阵运算（仓库已有 matrix 类方向另立条目）。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 正交向量点积为 0 并判定正交；平行向量叉积为 0 并判定平行
- [ ] 3D 标准基向量 e1×e2 = e3；2D (1,0)×(0,1) = 1
- [ ] 夹角：同向 0°、反向 180°、垂直 90°，弧度与度一致
- [ ] 投影满足 proj_b(a) 与 b 共线，零向量 b 触发明确报错
- [ ] 纯函数 utils 具备 vitest 固定向量测试，typecheck / lint / test 全通过
