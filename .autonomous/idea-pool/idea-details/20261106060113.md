## 描述

输入两个二维或三维向量，计算模长、单位化、加减法、数乘、点积、叉积（三维）、夹角（角度/弧度）、一个向量在另一个上的标量与向量投影，并展示关键中间量。面向图形学、物理与工程学习者，补齐现有 matrix-calculator（矩阵运算）与 complex-number-calculator 未覆盖的几何向量运算缺口。

## 设计内容（进入 Claimed 前补全）

纯客户端单页工具，零网络、零新增依赖；全部运算收敛为可单测纯函数 `utils/vector.ts`，UI 仅采集向量并渲染结果。

- **输入**：维度切换 2D / 3D；向量 A、向量 B 的分量（数字输入）；数乘标量 k；角度单位切换（度 / 弧度）。
- **核心运算**：模长、单位化向量、A±B、数乘 k·A、点积 A·B、叉积 A×B（仅 3D）、夹角（由点积公式反余弦，支持度/弧度）、A 在 B 上的标量投影与向量投影。
- **输出**：各运算结果分量 / 标量，保留合理精度；零向量参与单位化、夹角、投影等非法情形给出明确错误而非 NaN。
- **边界**：两向量维度必须一致；叉积仅 3D 可用，2D 下禁用并提示；含零向量的点积合法（结果为 0），但单位化 / 夹角 / 投影遇零向量报错；输入非数字给出校验提示。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] A=(1,2,3)、B=(4,5,6) 点积为 32；叉积 A×B=(-3,6,-3)。
- [ ] A=(3,4) 模长为 5，单位化结果为 (0.6,0.8)。
- [ ] 互相垂直向量（如 (1,0) 与 (0,1)）夹角为 90°（π/2 弧度）；平行同向向量夹角为 0°。
- [ ] A=(3,4) 在 B=(1,0) 上标量投影为 3、向量投影为 (3,0)。
- [ ] 加减法与数乘结果分量正确；零向量单位化 / 求夹角返回明确错误而非 NaN。
- [ ] 2D 模式下叉积被禁用并提示；3D 模式下叉积可用。
