## 描述

由 IP 地址与 CIDR 前缀（或子网掩码）计算网络地址、广播地址、可用主机范围、主机数量与掩码信息，支持 IPv4（并尽量覆盖 IPv6），用于网络规划与排障。当前工具集无任何网络地址计算能力。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：输入 IPv4 地址 + CIDR 前缀或子网掩码，输出网络地址、广播地址、地址范围、可用主机数、掩码（点分与 CIDR）、网络类别与是否为私有地址等；支持 IPv6 前缀长度计算。
- **核心交互**：地址与掩码 / 前缀输入，实时展示计算结果与二进制位视图；支持前缀滑块或下拉选择；提供私有网段等常用示例。
- **输入输出**：输入地址字符串（`192.168.1.10/24` 或地址 + 掩码），输出结构化结果；非法地址 / 前缀给出可读错误。
- **边界情况**：`/31`、`/32` 的可用主机数需按 RFC 3021 特殊处理；前缀越界（<0 或 >32）报错；掩码非连续（非 CIDR 合法掩码）报错；IPv6 支持前缀长度与网络地址、地址数量级展示。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 输入 `192.168.1.10/24`，网络地址为 `192.168.1.0`、广播地址为 `192.168.1.255`、可用主机范围为 `192.168.1.1 - 192.168.1.254`、可用主机数为 254。
- [ ] 支持以子网掩码（如 `255.255.255.0`）等价输入并得到相同结果。
- [ ] `/31` 与 `/32` 的可用主机数按 RFC 3021 正确处理。
- [ ] 非法地址或越界前缀给出明确错误，且不产出错误结果。
- [ ] 支持 IPv6 前缀长度的网络地址计算。
- [ ] 纯浏览器本地运算，无任何网络请求。
