## 描述

输入物理焦距与传感器尺寸（或画幅预设 / 裁切系数），计算水平、垂直与对角视角以及 35mm 等效焦距和等效光圈（景深等效）提示；支持全画幅、APS-C、APS-H、M4/3、1 英寸、中画幅等预设与自定义传感器宽高，并支持由目标视角反推所需焦距。用于镜头选型、跨画幅构图对照与转接环裁切效果预估；纯本地计算。

## 设计内容（进入 Claimed 前补全）

功能范围：① 正向：由焦距 + 传感器宽高（或预设画幅 + 裁切系数）计算水平 / 垂直 / 对角 FOV（公式 2·atan(尺寸 / (2·焦距)））、35mm 等效焦距（焦距 × 裁切系数，裁切系数 = 43.27mm / 传感器对角）与等效光圈（光圈 × 裁切系数）；② 反向：由目标水平（或对角）FOV 与传感器尺寸反推物理焦距；③ 画幅对照表：同一焦距在常见画幅下的等效焦距与对角视角一览。

核心交互：画幅预设下拉 + 自定义宽高输入、焦距与光圈输入、视角维度单选（水平 / 垂直 / 对角）、正反向模式切换、结果卡片与常见画幅对照表；非法输入即时提示。

输入输出：输入为焦距（mm）、传感器宽高（mm）或裁切系数、光圈值、目标视角；输出为三种 FOV、等效焦距、等效光圈、裁切系数与反推焦距。

边界情况：焦距与传感器边长必须大于 0；自定义传感器需同时给出宽与高；FOV 结果限定在 (0°, 180°)；反向模式目标视角必须小于 180° 且大于 0°；中画幅等非 3:2 画幅按实际宽高计算，不假设固定比例。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 全画幅（36 × 24mm）50mm：对角视角 ≈ 46.8°（2·atan(43.27 / 100)）
- [ ] 全画幅 24mm：对角视角 ≈ 84.0°，水平视角 ≈ 73.7°
- [ ] APS-C（裁切系数 1.5）50mm：35mm 等效焦距 75mm，等效光圈 f/2 → f/3
- [ ] M4/3（17.3 × 13mm，裁切系数 2.0）25mm：等效焦距 50mm
- [ ] 反向：全画幅目标对角视角 46.8° → 焦距 ≈ 50mm
- [ ] 焦距 0、传感器边长为 0 或目标视角 180° 均返回明确错误
