## 描述

将 URL 拆解为协议、主机、端口、路径、查询参数、哈希等组件并可视化编辑，支持增删改查询参数后重新拼回 URL，便于排查复杂链接与接口参数。`base64-codec` 只做 URL 的百分号编解码，不具备结构化解析与编辑能力。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：URL 结构化解析 + 查询参数可视化编辑 + 重新拼接，工具 slug 拟为 `url-parser`。
- **解析**：将 URL 拆解为协议（scheme）、用户名、密码、主机（host）、端口（port）、路径（pathname）、查询参数列表（有序键值对，区分重复键）、哈希（hash）；同时给出每个键值的原始（raw）与解码后（percent-decoded）形式。
- **编辑**：以表格形式增删改查询参数（键 / 值编辑、启用停用开关、删除行），实时按编辑结果重新拼接出完整 URL。
- **重新拼接**：按 `encodeURIComponent` 规则正确编码键值并保留原始编码形式可切换；保留哈希片段。
- **核心交互**：顶部输入 URL，中部展示解析出的各组件，下部为查询参数编辑表格与实时拼接结果；提供复制、清空、载入示例。
- **输入输出**：纯函数解析与拼接，不触碰 DOM / React（仅产出数据与字符串）。
- **边界情况**：相对路径（无协议）与仅含路径的输入；非法 URL 给出错误提示而非抛异常；同名参数多次出现时按顺序保留；值中已编码字符的显示与还原。
