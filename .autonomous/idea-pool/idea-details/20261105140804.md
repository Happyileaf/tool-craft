## 描述

一个面向教学的确定性表达式解析可视化工具：输入含 `+ - * / ^`、括号、一元负号与函数调用（如 `sin`、`max`）及浮点数字面量的中缀表达式，基于 Dijkstra 调度场算法（Shunting-yard）输出后缀表达式（RPN，逆波兰记号），并以可单步回放的方式展示每一步的运算符栈、输出队列与决策原因（压栈 / 因优先级或结合性弹出 / 括号匹配 / 函数入栈）；随后对 RPN 执行基于值栈的逐步求值，每步展示压入操作数或弹出操作数计算的过程，最终给出数值结果；对括号不匹配、未知标识符、函数参数个数错误、除零等情况在对应步骤给出明确报错。

池中 `math-expression-evaluator` 只返回求值结果（黑盒），`matrix-calculator` 面向矩阵运算，均不暴露 token 流、运算符栈状态与 RPN 中间表示；本工具的核心交付物是可回放的算法过程与中间数据结构，而非计算结果本身，输入输出形态不同，不构成重复。调度场与栈式求值是确定性状态机，对固定表达式（如 `3 + 4 * 2 / ( 1 - 5 ) ^ 2`）每一步的栈/队列快照都可固定断言，纯前端零依赖实现，复杂度 M（交互步骤回放与状态渲染略高，但无算法风险）。

## 设计内容（进入 Claimed 前补全）

纯客户端教学可视化工具，零网络、零新增依赖；算法收敛为可单测纯函数 `utils/shuntingYard.ts`（tokenize、toRPN、evalRPN 均返回带快照的步骤序列），UI 负责步骤回放与栈/队列渲染。

- **词法分析 tokenize**：识别浮点数字面量（含小数）、运算符 `+ - * / ^`、括号、逗号与标识符（函数/常量）；`-` 根据位置（表达式起始或左括号/运算符之后）识别为一元负号；空白忽略；非法字符报错并定位。
- **运算符表**：`+/-` 优先级 1 左结合，`*//` 优先级 2 左结合，`^` 优先级 4 右结合，一元 `u-` 优先级 3 右结合；内置函数 `sin/cos/sqrt/abs/max/min` 与常量 `pi/e`；`max/min` 为变长参数函数。
- **调度场 toRPN**：逐 token 记录每一步快照（输入剩余、运算符栈、输出队列、决策原因：读入操作数/函数压栈/运算符因优先级或结合性弹栈/左括号压栈/右括号弹到匹配左括号/逗号弹到左括号）；括号不匹配、未知标识符、逗号出现在函数外等在对应步骤报错。
- **RPN 求值 evalRPN**：值栈逐步快照（压入操作数、弹出 n 个操作数计算、函数应用），`^` 用 Math.pow，除零报错，函数参数个数错误报错；一元负号对栈顶取负。
- **核心交互**：表达式输入 + 预置示例；阶段切换（转 RPN / RPN 求值）；上一步/下一步/自动播放/重置；每步高亮当前 token、栈与队列内容及决策说明；最终展示 RPN 字符串与数值结果。
