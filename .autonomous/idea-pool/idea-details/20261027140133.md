## 描述

在多种系统纪元时间戳与人类可读时间之间双向转换：Unix epoch（秒 / 毫秒 / 微秒 / 纳秒）、Windows FILETIME（自 1601-01-01 起的 100 纳秒间隔）、.NET DateTimeOffset Ticks（自 0001-01-01 起的 100 纳秒间隔）、Google Chrome / WebKit 时间戳（自 1601-01-01 起的微秒）、Apple Cocoa Core Data（2001-01-01 起秒）。输入一个时间戳即可同时给出各纪元的等价值与 UTC / 本地时间，亦可由日期时间反推所有纪元值。与已有 `timestamp-converter` 不同：后者仅支持 Unix 秒（≤10 位按秒）/毫秒两种输入，不含 FILETIME / Ticks / Chrome 等纪元；本工具面向排查日志、文件元数据、浏览器与 Windows / .NET 数据时的多纪元换算需求。
