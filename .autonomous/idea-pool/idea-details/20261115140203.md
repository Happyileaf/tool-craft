## 描述

输入性别、身高、体重、颈围、腰围与臀围，按美国海军（US Navy）围度公式估算体脂率、脂肪重量与瘦体重，并给出 BMI 交叉校验、腰臀比（WHR）风险区间与 ACE 体脂分级；无围度数据时可退回 Deurenberg 由 BMI 与年龄推导体脂率。用于健身进度跟踪、体成分粗估与健康风险自查；纯本地计算，并明确标注为估算值而非医学诊断。

## 设计内容（进入 Claimed 前补全）

功能范围：①「围度法」：男性 BF% = 495 / (1.0324 − 0.19077·log10(腰 − 颈) + 0.15456·log10(身高)) − 450（厘米制），女性 BF% = 495 / (1.29579 − 0.35004·log10(腰 + 臀 − 颈) + 0.22100·log10(身高)) − 450，英制输入先换算；②「BMI 法」：Deurenberg 公式 BF% = 1.20·BMI + 0.23·年龄 − 10.8·性别 − 5.4（男 = 1，女 = 0）；③ 输出体脂率、脂肪重量、瘦体重、BMI、WHR（腰 / 臀）及男女不同风险阈值，并按 ACE 五档（必需脂肪 / 运动员 / 健身 / 平均 / 肥胖）分档；④ 单位切换（cm / in、kg / lb）。

核心交互：性别切换、单位切换、数字输入、方法单选（围度法 / BMI 法 / 两者对比）、结果卡片与分级带；缺失或矛盾输入即时提示。

输入输出：输入为性别、年龄、身高、体重、颈围、腰围、臀围；输出为体脂率（两种方法并列，可对比差值）、脂肪 / 瘦体重、BMI、WHR、体脂分级与风险说明。

边界情况：围度法要求腰 > 颈（女性还需腰 + 臀 > 颈），否则对数无意义并提示；身高 / 体重必须为正；年龄限定 15–100；所有数值保留一位小数；结果为估算，附「不构成医学建议」说明；BMI 法对运动员可能高估，页面给出提示。
