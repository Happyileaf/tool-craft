## 描述

拖拽或粘贴本地 GIF 文件（读取 ArrayBuffer，不上传），按 GIF87a/GIF89a 规范解析并以只读树/表格展示其内部结构：Header 签名与版本、Logical Screen Descriptor（宽高、全局色表标志、色分辨率、排序标志、全局色表大小与背景色索引、像素宽高比）、Global Color Table 色板（逐项 RGB）、各 Graphic Control Extension（ disposal 处理方式 0–3、用户输入标志、透明色标志与透明索引、延迟时间 cs→ms）、Comment / Plain Text / Application Extension（识别 NETSCAPE2.0 循环次数块）、每帧 Image Descriptor（左右/上下偏移、宽高、局部色表与 interlace 标志）、LZW 最小代码尺寸与 image data 子块字节统计、Trailer `0x3B`；汇总帧数、总播放时长（无限循环时标注）、动画/静态判定，并对截断块、非法 introducer、子块长度越界等给出错误定位。

池中「文件结构只读解析」系列已有 PNG（IHDR/IDAT/IEND）、WAV、ZIP、TAR、MP4、BMP、PE、ELF、Mach-O、Java .class 等，尚无 GIF；`magic-number` 工具只用 `GIF8` 魔数识别类型，不解析任何内部块。GIF 为定长头 + introducer 引导的子块序列，解析规则明确、无需 LZW 解压（只读跳过 image data），零依赖纯函数可对内置样本 GIF 做确定性断言，复杂度 M。
