## 描述

实现以太坊递归长度前缀（Recursive Length Prefix，黄密码附录 B）的纯函数编码 / 解码器：将字符串与嵌套列表结构序列化为最小化字节串并可逆解码，以树形视图展示前缀类型与长度解析。RLP 是区块 / 交易 / Trie 节点的底层序列化格式；现有工具仅有 base 系列编码与 `bencode-codec`（BitTorrent 的字典/整数字典式编码，规则完全不同），无任何以太坊最小序列化能力，存在明确能力缺口。编码规则为确定性结构遍历，零依赖、纯函数可完整覆盖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：RLP 编码 + 解码双向；单值与任意嵌套列表；UTF-8 文本、十六进制（`0x` 可选）两种字节输入；解码以树形视图展示每项的前缀类型（单字节 / 短字符串 / 长字符串 / 短列表 / 长列表）、长度字节与 payload。
- **核心交互**：左侧输入结构（类 JSON 语法：字符串与嵌套数组，如 `["cat", ["dog", "0x7067"]]`）；右侧输出编码结果（hex 分色标注前缀，附字节数）；反向 tab 粘贴 hex RLP 解码为树。
- **输入输出**：编码输入为 JSON 兼容表达式（JSON 字符串/数组，字符串按 UTF-8 编码；`0x` 前缀字符串按 hex 字节处理）；解码输入为 hex 或 raw 文本；输出 hex 大写可选、默认小写 `0x` 前缀；树节点标注类型与长度。
- **边界情况**：空字符串 `""`→`0x80`、空列表 `[]`→`0xc0`、单字节 `<0x80` 原样；长前缀 55 字节分界；长度字段多字节大端、含前导零（`0xb800…`）判错；解码时长度越界 / 截断 / 消费后有剩余字节 / 短格式可用却用长格式（非规范）报错并给出偏移；嵌套深度限制 64。
- **核心算法**（纯函数，零依赖，放 `utils/rlp.ts`）：
  - 编码：`encode(value)`；字节 0–55 直接放；长度 1–55 → `0x80+len`；>55 → `0xb7+lenOfLen || lenBytes || data`；列表同理基址 `0xc0` / `0xf7`。
  - 解码：读首字节判定类型与 payload 长度，校验总长，递归切分；返回带类型的树节点。
- **测试覆盖**（`utils/rlp.test.ts`）：官方文档经典向量（`"dog"`→`0x83646f67`、`["cat","dog"]`、`"Lorem ipsum..."` 长字符串）、空串 / 空数组 / 单字节 / 0 字节整数表示、嵌套列表往返、非规范编码 / 截断 / 多余尾字节 / 非法 hex 报错。
