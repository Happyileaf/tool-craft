## 描述

基于浏览器 `crypto.getRandomValues`（CSPRNG）提供无偏的区间随机整数生成，并在此之上支持抽签/抽奖（从名单中不放回抽取 N 个）、随机分组（将名单均分为指定组数）与列表洗牌（Fisher–Yates，拒绝采样消除取模偏置）。解决 `Math.random()` 不安全且对非 2 次幂区间存在取模偏置的问题，面向抽签、随机分组、随机排序等日常场景。纯本地计算、零依赖。与已有 strong-password-generator（生成密码字符串）、uuid-generator（生成 UUID）、random-data-generator（生成模拟数据字段）目标不同，本工具聚焦「给定区间/名单上的无偏随机选择与排列」，不构成重复。

## 设计内容（进入 Claimed 前补全）

工具 slug：`secure-random-picker`，单页四个模式（Tab / Radio 切换），全部纯本地计算：

1. 随机整数：输入最小值 min、最大值 max（含端点）与生成数量 n，基于 `crypto.getRandomValues` 拒绝采样（对 `2^32` 取区间上限倍数后拒绝越界值）生成无偏整数；可选「允许重复 / 不重复」，不重复时校验 n ≤ 区间大小。
2. 抽签：每行一个候选项的文本框，输入抽取数量 k，不放回抽取 k 个；k ≤ 名单非空行数，否则报错。
3. 随机分组：候选项名单 + 组数 g（或每组人数，二选一），Fisher–Yates 洗牌后尽量均分（允许 1 人的组大小差），输出各组。
4. 列表洗牌：对名单做完整 Fisher–Yates（无偏：用拒绝采样在 0..i 取随机下标），输出打乱后的顺序。

核心纯函数放在 `utils/random.ts`（安全随机整数、shuffle、sample、splitGroups），UI 仅做输入解析与结果展示；不引入任何新依赖。边界：空名单、重复行保留（按条目实例参与抽取）、数量非法、超大 n（设上限避免页面卡顿，如单次 ≤ 10000）。
