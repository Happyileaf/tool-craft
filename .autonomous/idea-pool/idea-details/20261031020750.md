## 描述

粘贴一段已有的 unified diff / git patch 文本，解析其结构并给出可读视图：按文件（`diff --git` / `---` / `+++` 头，含重命名 `rename from/to`、新文件、删除文件识别）与每个 hunk（`@@ -a,b +c,d @@`）分组展示，统计总变更文件数、新增行数（`+`）、删除行数（`-`）、每个文件的增删行汇总，并对格式不合法的 patch（缺 hunk 头、行数声明与实际内容不符、坏行前缀）给出定位提示。解决代码评审、CI 补丁排查时面对裸 patch 文本难以快速掌握改动范围与定位错误的问题。纯文本逐行确定性解析、零新增依赖、纯本地运算，可用 git 真实产出的 patch 与手工构造的畸形样本做固定用例验收。查重：已注册的 `text-diff` 是对两段文本「生成并展示」差异，本工具反向——消费已存在的 diff/patch 文本并解析统计，不做两段文本比对；池内 json-patch / json-merge-patch 是 JSON 补丁模型，与 unified diff 文本格式无关；completed/rejected 归档无同类条目，不构成重复。
