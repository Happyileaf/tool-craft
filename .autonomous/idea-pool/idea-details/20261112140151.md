## 描述

在 Clojure EDN（extensible data notation）与 JSON 之间双向转换：EDN→JSON 时解析 nil/true/false、字符串、数字（含有理数比例 `1/3`）、keyword（`:foo/bar`）、symbol、字符 `\c`、list/vector/map/set、`#inst` 与 `#uuid` 标签值，并按可配置策略把 keyword/symbol/set/比例等 JSON 无对应类型映射为带标记的兼容表示；JSON→EDN 时按 EDN 语法规则合法输出（集合用 `#{}`、映射用 `{}`、keyword 加冒号），对字符串做正确转义。手写递归下降解析器、零新增依赖，S–M 复杂度，纯函数可用固定 EDN 样例做双向往返与边界用例验收。

## 设计内容（进入 Claimed 前补全）

- 工具目录：`apps/web/src/tools/edn-json-converter/`（index.tsx + index.module.css + constants.ts + utils/edn.ts + utils/edn.test.ts）。
- 核心纯函数（utils/edn.ts）：
  - `tokenize(input)`：词法分析，处理字符串转义（`\t \n \r \\ \" \uXXXX`）、分隔符、`#{` 集合前缀、`#inst/#uuid` 标签、分号注释与逗号空白。
  - `EdnParser` 递归下降：`readValue/readSequence/readMap/readTagged`，支持 nil/布尔/字符串/数字、keyword（含命名空间）、symbol、list/vector/set/map、`#inst`/`#uuid`。
  - 类型映射：keyword/symbol/set/list/inst/uuid 统一以 `{ "___edn_type": ... }` 标记表示；map 的 keyword 键存为 `":name"` 字符串。
  - `ednToJson(input, indent)` / `jsonToEdn(input, indent)`：双向转换，序列化侧识别标记还原 `#{}`、`()`、`:kw`、`#inst/#uuid`，字符串做反斜杠/引号/控制字符转义，支持缩进与紧凑两种输出。
  - `EdnError` 携带字符位置，UI 分别格式化 EdnError 与 JSON SyntaxError。
  - 范围说明：本期实现 EDN 内置数据形式的常用子集，不包含有理数比例 `1/3` 与字符 `\c`（遇到时按普通 symbol 处理，不报错丢数据）。
- UI（Ant Design）：双栏卡片 + 方向 Radio（EDN→JSON / JSON→EDN）、「换向并载入输出」、紧凑/缩进 Switch、示例/清空按钮，useMemo 实时转换与错误提示。
