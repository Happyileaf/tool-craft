## 描述

输入两到多个以换行 / 逗号 / 空格分隔的元素列表（如标签、关键词、用户 ID、去重词表），自动去重为集合后计算两两 Jaccard 指数（|A∩B|/|A∪B|）、Sørensen–Dice 系数（2|A∩B|/(|A|+|B|)）与重叠系数（Overlap Coefficient），以矩阵热力表呈现并可导出 CSV，用于标签体系比对、去重评估、推荐特征分析与论文文献集合对比。

## 设计内容（进入 Claimed 前补全）

**实现载体**：`apps/web/src/tools/set-similarity-calculator/`（`index.tsx` + `similarity.ts` 纯函数 + `__tests__/similarity.test.ts`），分类 `Data`，零依赖、零网络、主线程。

**功能范围**：
1. 输入 2–6 个命名集合（每行一个集合，首词为集合名，其余为元素；或提供多个文本框，元素按换行/逗号/空白分隔），自动 trim、去重为 `Set<string>`，数字与字母大小写按原样区分（提供「忽略大小写」开关，默认关闭）。
2. 对每对集合计算三个系数：
   - Jaccard = |A∩B| / |A∪B|
   - Sørensen–Dice = 2|A∩B| / (|A|+|B|)
   - Overlap = |A∩B| / min(|A|,|B|)
   空集合（两者皆空）定义为 Jaccard=1、Dice=1、Overlap=1；仅一方为空时全部为 0，且不抛错。
3. 输出：每个集合去重后的元素数；两两系数表格（行=集合对，列=三系数，百分比 + 4 位小数）；Jaccard 对称矩阵热力表（0–1 色阶）；交集/并集元素明细。
4. 导出 CSV（矩阵 + 系数表），使用现有下载工具模式；提供 2 组示例（标签集合、用户 ID 集合）。

**输入输出**：输入多组分隔文本；输出 `{ sets: {name, size, elements}[], pairs: {a,b,intersection,union,jaccard,dice,overlap}[], matrix: number[][] }`。

**边界情况**：空输入、单集合（提示至少 2 个）、重复元素去重、完全相同集合（系数=1）、互不相交（系数=0）、包含关系（Overlap=1）、空集合与除零保护、元素含逗号时以换行分隔为准。
