## 描述

实现固定列宽文本（Fixed-width Format，常见于主机报表、银行账单、遗留系统导出）与 CSV 的双向转换。CSV → FWF：按配置的列宽/列名对字段做左对齐或右对齐填充（空格或指定填充字符）、超长字段给出截断/报错策略；FWF → CSV：按列起止位置（或列宽列表）逐行切片、去除两侧/单侧填充空白，首行可配置为表头。支持多列定义的可视化增删、引号转义（CSV 侧复用标准 CSV 规则）、LF/CRLF 换行选择与批量粘贴。纯字符串确定性处理，纯函数可单测、固定样例可验收，零新增依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：固定列宽文本（FWF）与 CSV 的双向转换，工具 slug 拟为 `fwf-csv-converter`。
- **列定义模型**：每列包含列名、宽度（正整数）、对齐方式（左 / 右，默认左对齐文本、右对齐可选）、填充字符（默认空格，限单字符）。
- **CSV → FWF**：用零依赖 RFC 4180 风格 CSV 解析器（支持引号包裹、`""` 转义、字段内逗号与换行）解析为行数组；按列定义逐字段填充——超长字段按策略处理（截断或报错，默认截断并计数提示）；短字段按对齐方式补齐到列宽；行尾拼接不保留额外分隔空格；支持 LF / CRLF 输出选择。
- **FWF → CSV**：按列宽列表推导每列起止位置（或显式起止位置），逐行切片；去除填充（支持仅 trim 单侧：左对齐列只去尾部填充、右对齐列只去头部填充）；可选首行为表头（从首行取列名）；输出标准 CSV（含逗号 / 引号 / 换行的字段自动加引号并转义）。
- **核心交互**：顶部方向切换（CSV→FWF / FWF→CSV）；列定义表格（列名、宽度、对齐，可增删行）；超长策略单选（截断 / 报错）；换行符单选（LF / CRLF）；首行表头开关；左右双栏输入输出，实时转换，错误以 Alert 展示。
- **输入输出**：核心转换逻辑为零依赖纯函数（`utils/fwfCsv.ts`），不触碰 DOM / React，随机源与环境无关，Vitest 固定样例断言。
- **边界情况**：空输入、列宽非法（0 / 负数 / 非整数）、列数与数据字段数不一致、FWF 行长度不足（按可用字符切片并在结果中保留短字段，不崩溃）、填充字符与被填充内容歧义（trim 按对齐方向单侧处理）、BOM 与首尾空白保持、超长报错时定位行号列名。
