## 描述

面向前端 / 设计工程师的色板工程工具：输入一个或多个基色（HEX/RGB），在 HSL 圆柱模型下按明度（lightness）与饱和度档位生成 50–950 共 11 级 Tailwind 风格色阶，并提供互补 / 三等分 / 分裂互补等调和模式自动派生多色相色板；结果可一键导出为 CSS 自定义属性（`:root { --color-primary-500: ... }`）、Tailwind config 片段、JSON 设计令牌（Design Tokens W3C 草稿风格）与 SCSS 变量四种格式。与 `oklch-workbench`（仅 OKLCH 单模型色阶）、`color-harmony`（只给 HSL 调和关系、不生成完整色阶与令牌）、`color-shade-generator` 类工具的区别在于：本工具以 HSL/HSV 工程化档位 + 多格式设计令牌导出为核心，且四源查重以 调色板导出、设计令牌、Design Token、Tailwind 色阶、CSS 变量 检索无同类。所有换算在浏览器本地完成、零新增依赖，用固定基色（如 #2563EB）的已知色阶向量做可验证验收。
