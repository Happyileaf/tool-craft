## 描述

输入 555 定时器非稳态电路的 R1、R2、C 参数，计算高电平时间 t1、低电平时间 t2、周期 T、频率 f 与占空比 D，并给出电容电压波形示意与引脚接线说明；支持带二极管的约 50% 占空比改进电路。现有电子工具覆盖色环电阻、欧姆定律、LC/RC 滤波器与分压，唯独缺最常用的 555 拓扑；公式极简（ln2 常数乘电阻电容），纯函数零依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：经典非稳态（充电经 R1+R2、放电经 R2）与二极管改进型（充电经 R1+二极管、放电经 R2）两种模式；输出 t1、t2、T、f、占空比；SVG 充放电波形示意（Vcc/3、2Vcc/3 阈值线标注）。
- **核心交互**：R1/R2 数值 + 单位下拉（Ω/kΩ/MΩ），C 数值 + 单位（pF/nF/µF/mF），模式切换（经典 / 二极管≈50%）；实时计算，结果卡片显示 t1/t2/T/f/D 并自动选择合适单位（ns/µs/ms/s、Hz/kHz）。
- **输入输出**：经典模式 t1=ln2·(R1+R2)·C，t2=ln2·R2·C，T=t1+t2，f=1/T，D=t1/T；二极管模式 t1=ln2·R1·C，t2=ln2·R2·C，D=R1/(R1+R2)。
- **边界情况**：R 或 C ≤ 0 报错；经典模式占空比恒 >50%（给出说明，R2≫R1 时趋近 50%）；二极管模式 R1=R2 时约 50%（标注“约”，忽略二极管压降）；f 超出 NE555 典型工作范围（>2 MHz 或周期 <1 µs）给出越界警告但仍输出理论值；极小 C（寄生效应）提示。
- **核心算法**（纯函数，零依赖，放 `utils/timer555.ts`）：单位归一化（p/n/µ/m）→ 计算 → 单位自动格式化；波形路径由 t1/t2 比例纯函数生成。
- **测试覆盖**（`utils/timer555.test.ts`）：经典教科书数值（R1=1k, R2=1k, C=1µF → t1≈1.386 ms、t2≈0.693 ms、f≈481 Hz、D≈66.7%）；二极管模式 50%；单位换算（kΩ×µF、MΩ×pF）；非法输入抛错。
