## 描述

粘贴一段 JSON（对象或数组），自动推断结构并生成对应的 Python `@dataclass` 定义代码：递归生成嵌套类、推断字段类型（`str` / `int` / `float` / `bool` / `None` / `list[...]` / `Optional[...]` 及嵌套 dataclass），处理数组中异构对象的合并、空数组退化为 `list`、类名规范化（snake_case 字段、PascalCase 类名、冲突重命名），并可选生成 `from_dict` / `asdict` 辅助方法或 `typing.TypedDict` 风格输出。解决后端/脚本开发中根据接口样例手写 Python 数据模型的重复劳动。纯客户端 JSON 遍历与字符串生成，零新增依赖、纯本地运算，可用固定 JSON 样本（嵌套对象、对象数组、空数组、null、键名含下划线/连字符）对生成代码做确定性快照验收。与已完成的 json-to-typescript（输出 TS interface）目标语言不同；历史被拒 Idea 20261021180801（多语言合一）的拒绝理由明确写明「单语言子集拆分后才可重新评估」，本条为其中 Python 单语言子集，符合重新立项条件，不构成重复。
