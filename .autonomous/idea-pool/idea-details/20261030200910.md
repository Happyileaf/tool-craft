## 描述

粘贴一段 JSON（对象或数组），自动推断结构并生成对应的 Python `@dataclass` 定义代码：递归生成嵌套类、推断字段类型（`str` / `int` / `float` / `bool` / `None` / `list[...]` / `Optional[...]` 及嵌套 dataclass），处理数组中异构对象的合并、空数组退化为 `list`、类名规范化（snake_case 字段、PascalCase 类名、冲突重命名），并可选生成 `from_dict` / `asdict` 辅助方法或 `typing.TypedDict` 风格输出。解决后端/脚本开发中根据接口样例手写 Python 数据模型的重复劳动。纯客户端 JSON 遍历与字符串生成，零新增依赖、纯本地运算，可用固定 JSON 样本（嵌套对象、对象数组、空数组、null、键名含下划线/连字符）对生成代码做确定性快照验收。与已完成的 json-to-typescript（输出 TS interface）目标语言不同；历史被拒 Idea 20261021180801（多语言合一）的拒绝理由明确写明「单语言子集拆分后才可重新评估」，本条为其中 Python 单语言子集，符合重新立项条件，不构成重复。

## 设计内容（进入 Claimed 前补全）

- slug：`json-to-python-dataclass`，分类 DEV_CODE，主线程纯浏览器运算，零新增依赖。
- `utils/python-dataclass.ts` 纯函数：
  - `toPythonFieldName`（snake_case，保留字追加下划线、数字开头前置下划线）、`toPythonClassName`（PascalCase）；
  - `mergeTypes(values, baseName, ctx)`：标量 int/float→float、其余冲突→Any；null 与单一标量共存→Optional[T]、全 null→None；数组拍平一层递归合并后包 list，空数组退化为裸 list；对象数组按键并集合并为具名类，缺失键标记 absent；类名冲突追加数字后缀；
  - `collectClass` 递归提升嵌套对象为顶层具名类；
  - 两种渲染风格：`@dataclass`（absent 字段在渲染期包 Optional 并给 = None 默认值，必填字段排序在前；可选生成 from_dict 类方法与根类 to_dict，缺失键走 dict.get）与 `TypedDict`（absent 标 NotRequired[Optional[T]]，按使用收集 TypedDict/Optional/Any/NotRequired 导入）；
  - 根为数组时生成元素类并输出 `<Root> = list[...]` 类型别名；根为标量时输出类型别名；输入空白返回空串。
- UI：JSON 输入框、根类名输入、@dataclass/TypedDict 风格切换、辅助方法开关（仅 dataclass）、三个示例（简单用户信息含下划线/连字符键、API 嵌套与异构对象数组、null 与空数组）、类数量 Tag、复制、清空，错误 Alert 中文提示。
