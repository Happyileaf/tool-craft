## 描述

输入示例 JSON（或多个样例），在浏览器本地推断并生成 TypeScript Zod v3 校验 schema 源码（`z.object` / `z.array` / `z.enum` / 联合类型 / 可选字段 / 嵌套递归），支持字符串格式提示（email/uuid/datetime）、字段命名保留与复制导出。解决拿到接口响应样例后手写运行时校验样板代码繁琐的问题。仅产出代码文本，不引入 zod 运行时依赖。与已有 `json-to-typescript`（只生成编译期 interface，无运行时校验）互补不重叠。
