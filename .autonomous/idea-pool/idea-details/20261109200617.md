## 描述

拖拽或粘贴一个 `.flac` 文件（或其文件头字节），在浏览器本地只读解析 FLAC 容器：校验 `fLaC` 魔数，按 metadata block header（last-flag / type / 长度）逐块遍历，结构化展示 STREAMINFO（采样率、声道数、位深、总样本数、MD5 签名）、VORBIS_COMMENT（标题 / 艺术家 / 专辑等标签与数量）、PADDING、APPLICATION、SEEKTABLE、PICTURE（封面 mime / 尺寸）等块类型与字节偏移，不做任何写回或重编码。Tool-Craft 已有 `wav-parser`（RIFF/WAV）等媒体容器解析器，但无 FLAC（Ogg/FLAC 原生容器）覆盖；`magic-number-identifier` 只依据 `fLaC` 魔数判定文件类型、不解析块结构。本工具延续「只读文件结构解析器」家族，纯函数、零依赖、可固定向量单测。
