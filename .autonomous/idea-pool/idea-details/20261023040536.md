## 描述

计算任意输入文本的 Shannon 信息熵（bits/字符）、唯一字符数、理论最小编码长度等指标，并展示字符频率分布，用于评估密钥 / 令牌的随机性、文本可压缩性与数据随机性。现有 word-count 只做字数统计，password-strength-checker 基于规则评分且源码中不含熵计算（已核实），池内「文本词频统计」条目面向高频词分析而非信息论度量，属现有能力缺口。熵与频率统计均为纯函数计算，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- **工具 slug**：`text-entropy-calculator`
- **分类 / 图标**：`ToolCategoryEnum.TEXT_CONTENT`（与 word-count 同属文本分析）；图标 `BarChartOutlined` 或白名单内图表图标
- **查重结论**：registry 中 word-count 仅做字数 / 词数 / 行数统计，password-strength-checker 为规则评分（长度 / 字符类 / 常见密码），均不含 Shannon 熵；non-crypto-hash / crc32-checksum 输出散列值而非熵；池内 20261021180802「文本词频统计」面向高频词分析，与信息论度量不同。不构成重复。
- **文件结构**（三件套，零新依赖）：
  - `constants.ts`：示例文本（含随机令牌样例）、展示条数上限常量
  - `utils/entropy.ts`：纯函数 `analyzeEntropy(text)` 返回 `{ length, uniqueCount, entropy, maxEntropy, normalizedEntropy, minBits, frequencies: {char,count,probability}[] }`；Shannon 熵 `H=-Σp·log2(p)`，`maxEntropy=log2(uniqueCount)`，`minBits=ceil(H·length)`；空文本返回零值结构
  - `index.tsx`：TextArea 输入、Statistic 指标卡（长度 / 唯一字符 / 信息熵 / 归一化熵 / 最小编码位）、频率分布表格（字符、计数、概率、可视化条）、按频率排序；空状态提示
- **注册**：`registry.ts` 追加双语 ToolMeta（TEXT_CONTENT / isNew / MAINTHREAD / defaultSampleInput）；`loaders.ts` 追加懒加载条目
- **边界**：字符按 JS UTF-16 code point（`Array.from` 处理代理对，emoji 按一个字符）；空白 / 换行均计入；超长文本主线程即时计算（单次远低于 100ms，无需 Worker）；空输入指标显示 0 / 空表不报错
