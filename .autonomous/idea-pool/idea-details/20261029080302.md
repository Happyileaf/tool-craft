## 描述

在 Web Mercator（EPSG:3857）下于经纬度、缩放层级、XYZ 瓦片坐标、像素坐标与瓦片包围盒之间互算：给定点返回所在瓦片 x/y、瓦片内像素、瓦片四至；列出父级与四个子瓦片路径及 OSM 切片 URL。地图方向现有 `geo-coordinate-converter`（仅 WGS84 度分秒）、`distance-bearing-calculator`（大圆距离）与 `what3words`，均不涉及 Web Mercator 投影与切片金字塔，能力独立；核心为闭式三角公式，纯函数零依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：①经纬度 + zoom → 全局像素 / 瓦片 XYZ / 瓦片内像素；②瓦片 z/x/y → 四至包围盒（N/S/E/W 经纬度）与中心点；③父瓦片与四个子瓦片坐标 + QuadKey；④OSM/Google XYZ 与 TMS y 翻转互转；⑤生成可点击的 OSM 切片 URL 与 `{z}/{x}/{y}` 路径。
- **核心交互**：lng/lat 数值输入（支持粘贴 `lng,lat`），zoom 0–22 整数（滑块 + 数字）；结果分区显示瓦片坐标、256px 内像素、包围盒、层级路径；小 zoom 下 SVG 示意瓦片在全球网格中的位置。
- **输入输出**：n=2^z；瓦片浮点坐标 X=(lng+180)/360·n，Y=(1−asinh(tan φ)/π)/2·n；tileX=floor(X)，像素=floor((X−tileX)·256)；反算 lat=atan(sinh(π·(1−2Y/n)))·180/π；TMS y′=n−1−y。
- **边界情况**：lat 钳制到 ±85.05112878（越界报错提示而非静默）；zoom 非整数 / 越界 0–22 报错；极地 / 日期变更线附近瓦片（x=0 或 n−1）正确；zoom=0 只有 0/0 瓦片；子瓦片 z+1 超 22 警告。
- **核心算法**（纯函数，零依赖，放 `utils/mercator.ts`）：lngLatToTileFraction / tileToBounds / parent / children / tileToQuadKey / tmsFlip；常量与 EPSG:3857 极限纬度集中管理。
- **测试覆盖**（`utils/mercator.test.ts`）：经典向量（z=0 全图 0/0；lng=0/lat=0 z=1 → 瓦片 1/1 左上角？标准结果 (1,0) 浮点→tile (1,0)；按 OSM wiki 向量：lat/lng 与已知 z/x/y 对照）；OSM 文档示例（131.036/−24.999@6 等）；四至往返还原中心点；父子层级关系；QuadKey 已知向量；TMS 翻转；非法 zoom / 极地纬度抛错。
