## 描述

按 RFC 792 在浏览器本地构建与解析 ICMPv4 Echo Request / Reply（Type 8 / 0）报文：输入标识符、序列号、可选 payload 文本或 hex，输出完整 ICMP 报文的十六进制转储（含 Type、Code、Checksum、Identifier、Sequence Number、Data 字段），并反向解析粘贴的 hex 报文、逐字段标注偏移与含义；校验和按 RFC 1071 反码求和实时计算并高亮，支持把校验和置零后重算以验证抓包数据。与已完成的 `tcpip-checksum`（只做 IPv4/TCP/UDP/ICMP 反码求和的单一计算）互补而非重复——本工具聚焦 ICMP 报文结构的组包 / 拆包全流程；与活动池中 DNS 报文编解码器、原始 HTTP 报文解析器同属协议线格式工具族但协议不同，四源查重以 ICMP、ping、echo、报文 检索无同类。纯本地 DataView / Uint8Array 确定性运算、零新增依赖，可用 RFC 792 文档示例与 Wireshark 抓包向量验收。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：按 RFC 792 构建 Echo Request（Type 8）/ Echo Reply（Type 0）报文：Identifier、Sequence Number、可选 payload（文本或 hex），输出含 Type/Code/Checksum/Identifier/Sequence/Data 的完整 hex dump；反向解析粘贴 hex，逐字段标注偏移（0/1/2/4/6/8）与含义；RFC 1071 反码求和校验和实时计算，支持把校验和清零后重算以核对抓包数据。
- **核心交互**：Tabs 切换「构建」与「解析」；构建侧输入标识符/序列号/payload 实时出 hex；解析侧展示字段表、校验和核对结果（匹配/不匹配）、payload 文本尝试还原；hex 输入容忍空格/冒号/换行/0x 前缀。
- **输入输出**：{type, identifier, sequence, data: Uint8Array} ↔ hex 字符串；校验和为独立纯函数。
- **边界情况**：标识符/序列号限 0–65535；奇数长度 hex、非 hex 字符报错；Code 必须为 0，非 0 给出警告；解析长度不足 8 字节报错；payload 超长（>1472 典型 MTU 限制）给出警告但仍输出。
- **核心算法**（纯函数，零依赖，放 `utils/icmp.ts`）：DataView 大端读写 + RFC 1071 一维反码求和；hex 归一化复用本地实现。
- **测试覆盖**（`utils/icmp.test.ts`）：RFC 1071 经典向量、ping 抓包已知 hex 往返、校验和清零重算一致、非法 hex/过短报文/Code 非零、文本与 hex 两种 payload。
