## 描述

按 RFC 792 在浏览器本地构建与解析 ICMPv4 Echo Request / Reply（Type 8 / 0）报文：输入标识符、序列号、可选 payload 文本或 hex，输出完整 ICMP 报文的十六进制转储（含 Type、Code、Checksum、Identifier、Sequence Number、Data 字段），并反向解析粘贴的 hex 报文、逐字段标注偏移与含义；校验和按 RFC 1071 反码求和实时计算并高亮，支持把校验和置零后重算以验证抓包数据。与已完成的 `tcpip-checksum`（只做 IPv4/TCP/UDP/ICMP 反码求和的单一计算）互补而非重复——本工具聚焦 ICMP 报文结构的组包 / 拆包全流程；与活动池中 DNS 报文编解码器、原始 HTTP 报文解析器同属协议线格式工具族但协议不同，四源查重以 ICMP、ping、echo、报文 检索无同类。纯本地 DataView / Uint8Array 确定性运算、零新增依赖，可用 RFC 792 文档示例与 Wireshark 抓包向量验收。
