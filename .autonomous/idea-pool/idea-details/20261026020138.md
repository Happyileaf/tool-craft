## 描述

提供经典维吉尼亚（Vigenère）多表替换密码的加密与解密：输入明文/密文与一个关键词，按关键词逐字符位移完成加解密，并可选择是否保留大小写、忽略非字母字符。属于编码/古典密码科普与解谜类工具。纯本地确定性字符运算、零依赖，可用固定明文+密钥的已知向量做可验证验收。与池中已有的「ROT13 与凯撒密码」（单表/固定位移）、「摩尔斯电码编解码」（电报编码）原理与用途不同，是多表替换这一独立类别，不构成重复。

## 设计内容（进入 Claimed 前补全）

- **工具 slug**：`vigenere-cipher`
- **分类 / 图标**：`ToolCategoryEnum.CRYPTO_ENCODING`（与 caesar-cipher / morse-codec 同属编码与加密）；图标 `Key`
- **查重结论**：registry 中 caesar-cipher 为固定位移单表替换（ROT13/自定义 shift，所有字母同一位移量），morse-codec 为点划电报编码，均非「按关键词循环的多表替换」；rejected.md 无同类归档，池内无其他维吉尼亚条目。不构成重复。
- **文件结构**（三件套，零新依赖）：
  - `constants.ts`：`CipherModeEnum`（encrypt/decrypt）、`MODE_OPTIONS`、`DEFAULT_TEXT='HelloWorld'`、`DEFAULT_CIPHER`（其密文）、`DEFAULT_KEY='KEY'`
  - `utils/vigenere.ts`：纯函数 `vigenere(text, key, decrypt=false)`：关键词只取 A–Z（大小写不敏感）循环复用，对每个字母按 `Ci=(Pi+Ki) mod 26`（解密为减）位移；保留原大小写；非字母字符默认原样保留（不消耗密钥位）；关键词无字母时返回错误；空输入返回空串。另导出规范化与可测试的步进函数
  - `index.tsx`：Radio 加解密切换、明文/密文 TextArea、密钥 Input（字母）、只读结果 TextArea、错误 Alert、复制结果、载入示例 / 清空；hint 说明多表替换原理与与凯撒的区别
  - `index.module.css`：container/toolbar/label/hint
- **注册**：`registry.ts` 追加双语 ToolMeta（CRYPTO_ENCODING / Key / isNew / MAINTHREAD / defaultSampleInput='HelloWorld'）；`loaders.ts` 追加懒加载条目；FAQ 至少含与凯撒密码区别、密钥为何循环复用、非字母如何处理
- **边界**：仅处理 A–Z / a–z；数字 / 标点 / 空格 / 中文原样保留且不推进密钥；密钥去除非字母后为空则报错；加密 → 解密往返一致；不实现 Autokey / Beaufort 等变体
