## 描述

将 JSON 格式数据转换为格式化的 YAML 数据，补齐现有 `yaml-to-json` 工具缺失的反向转换能力，实现 JSON 与 YAML 之间的双向互转。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：解析 JSON 文本并序列化为等效 YAML，覆盖对象、数组、字符串、数字、布尔与 null 的任意嵌套；支持块状缩进输出与可配置缩进宽度。
- **核心交互**：左侧输入 JSON，右侧实时输出 YAML；解析失败时展示可读错误信息且不产出结果；提供复制、清空与载入示例操作。
- **输入输出**：输入 JSON 字符串，输出 YAML 字符串；非法 JSON 抛出可读错误并由界面捕获展示。
- **边界情况**：空输入返回空输出；可被 YAML 误判为其他类型的字符串（如 `"123"`、`"true"`、空串、含前导/尾随空格）需加引号以保持字符串类型；含特殊字符（`: `、`#`、换行）的字符串与键名需按 YAML 规则转义或加引号；多行字符串处理；数组元素缩进。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 输入合法 JSON 对象，输出为键值对 + 缩进嵌套的等效 YAML。
- [ ] 支持嵌套对象与数组，缩进层级正确。
- [ ] 可被误解析为数字/布尔/null 的字符串输出时加引号，重新解析后类型仍为字符串。
- [ ] 非法 JSON 输入给出明确错误信息，且不产出结果。
- [ ] 空输入返回空输出。
- [ ] 纯浏览器本地运算，无任何网络请求。
