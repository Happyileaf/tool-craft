## 描述

输入 48 位 MAC 地址（支持 `aa:bb:cc:dd:ee:ff`、`aa-bb-...`、`aabb.ccdd.eeff` 等常见写法），在中间插入 `ff:fe` 并翻转第 7 位（U/L 位）生成 64 位 EUI-64 接口标识符，再拼出 `fe80::/64` 链路本地地址；逐步可视化插入字节与位翻转前后对比，并支持给定任意 /64 前缀组合 SLAAC 地址。面向网络配置与 IPv6 教学排障。零依赖、纯本地位运算与字符串格式化，可用 RFC 4291/4941 经典向量（MAC `00-1C-C0-FF-FE-80` → 接口 ID `021C:C0FF:FEFF:FE80`）验收。与现有 mac-address-converter（只做 MAC 本身格式转换与校验）、cidr-subnet-calculator、ip-address-converter（IPv4/IPv6 与整数互转）均不重叠，本工具新增 EUI-64/SLAAC 派生能力。
