## 描述

通过表单生成合法的 systemd `.service` 单元文件：分组填写 `[Unit]`（Description、After/Wants/Requires）、`[Service]`（Type=simple/forking/oneshot/notify、ExecStart/ExecStop/ExecReload、User/Group、WorkingDirectory、Environment、Restart 策略与 RestartSec、标准日志输出）、`[Install]`（WantedBy/RequiredBy），实时生成可复制的单元文件文本，并给出配套的安装启用命令提示（`systemctl daemon-reload` / `enable --now`）。解决部署服务时记忆字段、手写 ini 风格单元文件易出错的问题。纯表单到文本的确定性映射、零新增依赖、纯本地运算，可用固定表单输入与字段缺省/空值省略规则做输出快照验收（与已完成的 gitignore-generator、editorconfig-generator、web-manifest-generator 同属配置文件生成族）。与现有 .env converter、nginx 配置（待开发）目标文件不同，池内无 systemd 相关 Idea，不重复。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：表单生成 systemd `.service` 单元文件，覆盖 `[Unit]`（Description、After/Wants/Requires）、`[Service]`（Type=simple/forking/oneshot/notify/dbus/idle/exec、ExecStart/ExecStop/ExecReload、User/Group、WorkingDirectory、Environment 多行、Restart 策略与 RestartSec、StandardOutput/Error 日志）、`[Install]`（WantedBy/RequiredBy/Also）；实时输出文本并给出 daemon-reload / enable --now 命令提示。
- **核心交互**：按 section 分组的表单（Input/Select/TextArea），右侧只读输出区一键复制；空字段对应指令行整体省略；提供常见服务预设（Web 应用 / 定时脚本 / Node 守护）。
- **输入输出**：表单对象 → INI 风格单元文本（确定性快照）；单元名同步用于文件名与安装命令提示。
- **边界情况**：ExecStart 为空时给出必填错误；Environment 每行 `KEY=VALUE`，等号缺失行报错；数值字段（RestartSec）非负校验；字段值做基础转义提示（`$`、引号）但不篡改用户输入。
- **核心算法**（纯函数，零依赖，放 `utils/systemd.ts`）：section → 有序键值行映射，空值跳过，固定 section 顺序 Unit/Service/Install。
- **测试覆盖**（`utils/systemd.test.ts`）：完整表单快照、空值省略规则、Environment 多行与非法行、各 Type/Restart 枚举输出、往返可解析性（按行还原 section）。
