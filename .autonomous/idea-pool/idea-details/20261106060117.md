## 描述

录入课程成绩（百分制分数或 A+/A/B+ 等等级）与学分，按标准 4.0、改良 4.3、WES 分段、中国高校常见百分制对照表四种口径换算单课绩点，计算学分加权 GPA、算术平均分、总学分，并并排对照各算法结果。零依赖纯函数。

## 设计内容（进入 Claimed 前补全）

- 功能范围：
  - 课程行可增删：课程名（可选）、成绩、学分；成绩支持百分制数字或等级（A+ ~ F，含 +/-）。
  - 四套换算表：
    - 标准 4.0（美式分段：90+=4.0、85+=3.7… 等级直映）
    - 改良 4.3（A+=4.3、A=4.0、A-=3.7…）
    - WES 风格分段（85+=4.0、75+=3.0、60+=2.0、<60=0）
    - 中国大陆常见百分制对照（90+=4.0、85-89=3.7、82-84=3.3…60=1.0，不及格 0）
  - 输出：每算法学分加权 GPA（Σ 绩点×学分 / Σ 学分）、算术平均分（仅百分制）、总学分、课程数。
  - 等级成绩先按等级表映射为百分制中位段再参与百分制算法，链路透明展示。
- 核心交互：可编辑表格（antd Table 或动态行）；算法结果四列对照卡片；示例成绩单一键填充；复制汇总。
- 边界：学分为 0/负数/非数字报错；百分制超 0–100 报错；无法识别的等级报错；全 0 学分时加权口径报「总学分为 0」；不及格课程按各表 0 绩点处理但仍计学分。
- 不做：不做院校自定义权重上传、不做成绩单 OCR、不存储数据。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 固定成绩单（如 90/3 学分 + 80/2 学分 + 70/1 学分）四算法加权 GPA 与手算一致
- [ ] 等级 A+/A/B 在 4.0 与 4.3 口径下分别得到 4.0/4.0/3.0 与 4.3/4.0/3.0
- [ ] 不及格（<60 或 F）绩点为 0 且学分仍计入分母
- [ ] 总学分为 0、非法成绩/学分逐条报错
- [ ] 纯函数 utils 具备 vitest 固定向量测试，typecheck / lint / test 全通过
