## 描述

在 RFC 4648 标准 Base64（含 `+` `/` 与 `=` 填充）与 Base64URL（`-` `_`、无填充）两种表示之间双向规范化转换，支持自动识别输入变体、缺失填充自动补齐、非法字符定位与字节级解码验证，并可批量处理多行令牌（如 JWT 片段、OIDC nonce、PASETO 负载调试）。现有 `base64-codec` 聚焦文本 ↔ Base64 编解码本身，不做两种字母表变体之间的规范化互转与 JWT 风格无填充令牌处理。纯字符替换与确定性校验、零依赖、纯本地计算。

## 设计内容（进入 Claimed 前补全）

- 功能范围：RFC 4648 标准 Base64（字母表含 `+` `/`、`=` 填充）与 Base64URL（`-` `_`、无填充）双向规范化互转；自动识别输入变体；缺失填充自动补齐；非法字符定位与字节级解码校验；多行令牌批量处理。
- 核心交互：模式切换（自动识别 / 标准→URL / URL→标准），左侧粘贴一个或多个令牌（每行一个），右侧输出规范化结果，非法行原样保留并带行号告警；显示识别到的变体与填充情况。
- 输入输出：纯字符替换 + 长度/字符集确定性校验，不依赖 atob 处理 URL 变体（自行实现或先转标准再用 atob 校验）；空行保留。
- 边界情况：长度非法（非 4 倍数且无法补 padding）、含非法字符（如 `*`、空格策略）、标准体混入 `-`/`_`、URL 体混入 `+`/`/` 的报错；JWT 风格无填充令牌补齐；零依赖纯本地。
