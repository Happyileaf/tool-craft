## 描述

将 Markdown 文本转换为 HTML：支持标题、段落、粗体 / 斜体 / 删除线 / 行内代码、有序与无序列表（含一级嵌套）、链接与图片、引用块、围栏代码块、分隔线、硬换行与 HTML 转义；输出区提供 HTML 源码与实时渲染预览切换，并显示目录大纲。典型场景：写 README / 公告时快速得到可直接粘贴的 HTML 片段。已实现的 markdown-preview 是 Markdown 实时预览工具，但其定位是排版预览，不保证输出干净、可复制的独立 HTML 源码片段；本工具以「转换出可控 HTML 字符串」为核心交付。注意区分曾被淘汰的反向工具「HTML to Markdown」（20261017160147，Rejected，原因是 HTML DOM 解析复杂度 L 级）——Markdown→HTML 方向只需处理一个小型、规则确定的行内 + 块级语法子集，自研为 S–M 级纯函数（分两遍：块级切分 + 行内替换，先转义再注入标签），无需 DOMParser、不依赖浏览器环境、零新依赖，输出可用固定用例逐字验收（各级标题、列表嵌套、链接图片、代码块内外的转义差异）。
