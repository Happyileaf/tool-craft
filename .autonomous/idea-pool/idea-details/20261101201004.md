## 描述

粘贴或拖拽浏览器 DevTools / WebPageTest 导出的 HAR（HTTP Archive，JSON 结构，1.2 与 1.3 版本）文本，解析 `log.entries` 并展示请求摘要表：方法、URL（拆分 scheme/host/path/query）、状态码、MIME 类型、请求/响应体大小、各阶段耗时（blocked/dns/connect/send/wait/receive，来自 `timings`）、总传输量与按 host/MIME 聚合统计；支持按方法/状态码/关键字过滤，点选单条查看请求头、响应头、query/postData 与 cookies（敏感头值默认脱敏展示）。典型场景：离线分析页面加载瀑布、接口排查、生成性能报告素材。纯本地解析 JSON 结构、不上传文件，零依赖（不引入 HAR 解析库），可用手写固定 HAR 夹具验收。边界：现有 `curl-to-code` 只解析单条 cURL 命令文本，`raw-http-message`（Pending）解析裸 HTTP 报文，`json-form-urlencoded` 处理表单编码，三者都不读取 HAR 的 `log.entries` 容器结构与 timings 聚合；HAR 是独立归档格式，不构成重复。
