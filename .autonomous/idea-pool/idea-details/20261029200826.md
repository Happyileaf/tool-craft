## 描述

按 RFC 7638 计算 JSON Web Key（JWK）的标准指纹（thumbprint）：粘贴一个 JWK（RSA / EC / OKP / 对称密钥），工具先剔除规范要求之外的成员，仅保留密钥类型必需成员（如 RSA 的 `e`/`kty`/`n`，EC 的 `crv`/`kty`/`x`/`y`），按成员名做词典序排序、无空白紧凑 JSON 序列化（UTF-8），再计算 SHA-256 摘要，输出 base64url 编码的 thumbprint；可选 SHA-384 / SHA-512（RFC 9278 定义的 `x5t#S256` 同类哈希选择）。解决 DPoP、mTLS 绑定、OAuth 客户端 `jkt` 确认、密钥去重识别等场景需要对同一公钥得到唯一可复现标识的问题。全过程确定性纯函数，SHA-256 走 Web Crypto，base64url 可零依赖实现，可用 RFC 7638 §3.1 的公开 JWK 样例（thumbprint = `NzbLsXh8uDCcd-6MNwXF4W_7noWXFZAfHkxZsRGC9Xs`）做固定验收向量。
