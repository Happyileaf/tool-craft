## 描述

按 RFC 7638 计算 JSON Web Key（JWK）的标准指纹（thumbprint）：粘贴一个 JWK（RSA / EC / OKP / 对称密钥），工具先剔除规范要求之外的成员，仅保留密钥类型必需成员（如 RSA 的 `e`/`kty`/`n`，EC 的 `crv`/`kty`/`x`/`y`），按成员名做词典序排序、无空白紧凑 JSON 序列化（UTF-8），再计算 SHA-256 摘要，输出 base64url 编码的 thumbprint；可选 SHA-384 / SHA-512（RFC 9278 定义的 `x5t#S256` 同类哈希选择）。解决 DPoP、mTLS 绑定、OAuth 客户端 `jkt` 确认、密钥去重识别等场景需要对同一公钥得到唯一可复现标识的问题。全过程确定性纯函数，SHA-256 走 Web Crypto，base64url 可零依赖实现，可用 RFC 7638 §3.1 的公开 JWK 样例（thumbprint = `NzbLsXh8uDCcd-6MNwXF4W_7noWXFZAfHkxZsRGC9Xs`）做固定验收向量。

## 设计内容（进入 Claimed 前补全）

- 纯函数规范化（`utils/thumbprint.ts`）：
  - 按 `kty` 选取 RFC 7638 §3.2 规定的必需成员白名单：RSA=`e,kty,n`；EC=`crv,kty,x,y`；OKP=`crv,kty,x`；oct=`k,kty`；其余成员（alg、use、kid、x5c 等）一律剔除。
  - 成员名按词典序（Unicode 码位，即 `crv<e<k<kty<n<x<y`）排序，`JSON.stringify` 紧凑序列化（无空白、键名原样保留 JWK 中的小写成员名），UTF-8 编码。
  - 摘要用 Web Crypto `crypto.subtle.digest`，支持 SHA-256（默认）/SHA-384/SHA-512；输出 base64url（无 padding）。
  - 输入支持粘贴 JWK JSON 文本，解析失败、缺必需成员、不支持的 kty 均返回明确中文错误，不抛裸异常。
- UI：JWK 文本输入（含 RFC §3.1 样例默认值）、哈希算法单选、规范化 JSON 中间结果展示（便于核对）、thumbprint 结果一键复制；零依赖、主线程。
