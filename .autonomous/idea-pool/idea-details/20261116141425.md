## 描述

在二进制比特流与线路电平跳变序列之间双向转换，覆盖两种主流约定：IEEE 802.3（以太网，0 = 高→低跳变、1 = 低→高跳变）与 Thomas / G.E. Thomas 约定（极性相反），并支持差分曼彻斯特编码（令牌环，比特 0 在位起始处跳变、比特 1 不跳变，每位中间恒有跳变）。输出每个码元的电平序列、时钟 / 数据关系示意（SVG 波形）与位时序参数（码元速率、波特率 = 比特率，最小带宽提示）；反向支持从电平序列还原比特并检测非法跳变。面向数字电路、计算机网络与嵌入式通信教学，与现有 `gray-code-converter`、`bcd-codec`、`varint-codec` 等位级编解码工具同构；纯位映射确定性算法，零依赖。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 编码：输入二进制串（支持空格 / 换行分隔与 `0b` 前缀，自动校验仅含 0/1），选择曼彻斯特（IEEE / Thomas 二选一）或差分曼彻斯特；输出每位的双相电平对（如 IEEE：0 → HL、1 → LH）与完整电平时间序列；差分模式需指定初始电平。② 解码：粘贴电平序列（H/L 字符或 0/1 双相采样），按约定按位对齐还原比特；差分模式按「位边界是否跳变」还原；检测中间沿缺失、码元长度奇数、电平符号非法等错误并定位到第几位。③ 波形可视化：SVG 绘制 NRZ 原始数据、时钟、曼彻斯特 / 差分波形三行对照，标注每位边界与中间跳变沿。④ 时序参数：输入比特率（bps）输出码元宽度（秒 / µs）与理论最小信道带宽（曼彻斯特频谱主瓣 ≈ 比特率 Hz），仅公式换算不维护器件数据。

**核心交互**：编 / 解码模式切换、约定单选（IEEE 802.3 / Thomas / 差分）、比特串或电平序列输入、初始电平选择（差分模式）、SVG 波形区、电平序列与比特结果复制按钮、教学示例一键填充。

**输入输出**：输入为比特串或电平符号串、约定类型、可选比特率；输出为双相电平序列、还原比特、SVG 波形、码元宽度与带宽、错误位定位。

**边界情况**：空输入 → 报错；含 0/1 以外字符（规范化分隔符后）→ 报错并定位；解码输入长度为奇数（无法成对对齐）→ 报错；电平符号非 H/L（或约定的 0/1）→ 报错；差分模式未指定初始电平 → 要求选择；超长输入（如 > 4096 位）给出长度提示但仍可计算，波形只渲染前 N 位并提示。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] IEEE 802.3 编码 `1011`：输出电平序列 `LH HL LH LH`（1=LH、0=HL），每位中间恰有一次跳变
- [ ] Thomas 约定编码同一 `1011`：输出与 IEEE 完全相反 `HL LH HL HL`
- [ ] 差分曼彻斯特：初始电平 L，输入 `1011` → 位 1 起始无跳变、位 0 起始有跳变，每位中间均有跳变；解码端无需知道绝对极性即可还原 `1011`
- [ ] 闭环：三种约定分别对随机 64 位向量编码后解码，还原比特与原串完全一致
- [ ] 错误检测：奇数长度电平序列、含非法符号 `X`、码元中间沿缺失（手工构造畸形序列）→ 均报带位序号的明确错误
- [ ] 时序：比特率 10 Mbps → 码元宽度 100 ns，带宽提示 ≈ 10 MHz 量级；输入规范化：`0b10 11` 与 `1011` 等价
