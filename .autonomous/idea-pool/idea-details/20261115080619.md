## 描述

由主动轮 / 从动轮齿数计算单级传动比（i = N从 / N主）、输出转速、扭矩倍数与旋转方向；支持多级串联齿轮组逐级相乘并汇总总传动比、总输出 RPM 与总扭矩，也可由目标输出转速反推所需齿数组合。提供齿数比化简、常见减速比对照与传动效率修正。用于机械设计、机器人关节、3D 打印机与减速电机选型估算。纯本地计算、零依赖。

## 设计内容（进入 Claimed 前补全）

功能范围：单级与多级齿轮传动计算。①「单级」：输入主动轮齿数、从动轮齿数、输入转速（RPM）、输入扭矩（N·m）与传动效率（%，默认 100），输出传动比 i = N从 / N主、输出转速 = 输入转速 / i、输出扭矩 = 输入扭矩 × i × 效率、旋转方向（外啮合反转）、齿数比化简（GCD 约分）与圆周速度提示；②「多级」：可增删多级齿轮对，逐级相乘得到总传动比、总输出转速与总输出扭矩，输出方向按级数奇偶判定；③「反推」：由目标输出转速与已知主动轮齿数反推单级所需从动轮齿数。

核心交互：模式单选（单级 / 多级 / 反推）、齿数与转速扭矩数字输入、效率滑块、多级齿轮对动态增删、常见减速比预设按钮；结果区展示各级明细与汇总，非法输入即时提示。

输入输出：输入为各级主动/从动齿数、输入 RPM、输入扭矩与效率；输出为单级或多级传动比（含小数与化简分数）、输出 RPM、输出扭矩、方向、齿数比分子分母以及反推得到的从动轮齿数。

边界情况：齿数必须为正整数（1–500），输入转速必须大于 0，扭矩允许 0 但不允许负数，效率限定 50–100%；除数为 0 或反推目标转速 ≤ 0 报错；多级列表为空时提示至少一级；所有结果为确定性乘除，不做隐式取整。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 单级 12 齿主动 / 36 齿从动、输入 1200 RPM、10 N·m、效率 100%：传动比 3、输出 400 RPM、输出扭矩 30 N·m、方向反转、化简比 3:1
- [ ] 两级（12→36，10→40）：总传动比 3 × 4 = 12，输入 1200 RPM 输出 100 RPM，方向恢复为正转
- [ ] 单级 12/36、效率 90%：输出扭矩 27 N·m
- [ ] 反推：输入 1200 RPM、目标 400 RPM、主动轮 12 齿 → 从动轮 36 齿
- [ ] 齿数为 0、转速为 0 或效率 120% 均返回明确错误
- [ ] Vitest 单测覆盖单级、多级、效率修正、化简与反推固定向量
