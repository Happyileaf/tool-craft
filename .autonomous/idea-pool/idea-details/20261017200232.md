## 描述

在浏览器本地完成常见 legacy 字符集（GBK / GB18030、Big5、Shift_JIS、EUC-KR、windows-125x 等）的文本解码，并将按 legacy 编码写入的字节还原为正确的中文 / 日文 / 韩文文本；同时针对「UTF-8 被按 Latin-1 误读」「被套壳二次编码」等典型 mojibake 场景，一键给出可读的修复结果。跨系统数据对接时乱码排查是高频刚需，而现有 base64-codec 仅覆盖 Base64 / URL / 十六进制编码、html-entity-codec 仅覆盖 HTML 实体，均不涉及字符集（码页）层面的转换。基于浏览器原生 TextDecoder 支持的字符集标签与「字符串 → Latin-1 字节 → 目标编码」的纯函数重解码实现，零新增依赖。
