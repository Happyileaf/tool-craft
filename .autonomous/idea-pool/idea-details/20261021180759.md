## 描述

将深层嵌套的 JSON 对象按点分隔键（如 `user.address.city`）扁平化为单层键值结构，并支持反向还原（unflatten），可自定义分隔符与数组处理方式，用于表格化查看嵌套数据、与 CSV / KV 形态互转、对比配置层级。当前 JSON 类工具只覆盖格式化、YAML / TS / CSV 互转、结构化 diff 与 JSONPath 查询，没有「对象层级与点路径单层结构」之间的双向转换能力。

## 设计内容（进入 Claimed 前补全）

- **slug**：`json-flatten`；分类 DATA_JSON；主线程同步运算；图标 LayoutGrid。
- **纯函数层** `tools/json-flatten/utils/flatten.ts`：
  - `FlattenOptions { separator?: string; expandArrays?: boolean }`、`FlatRecord`、`FlatResult { data, error }`。
  - `flattenJson(input, options)`：递归 walk；对象键以分隔符连接，数组项以 `[index]` 标记；根数组路径从 `[0]` 开始，根标量输出空路径键；空对象 / 空数组 / null 作为叶子保留；空容器根输出 `{}`。
  - `flattenJsonText(text, options)`：空文本返回空结果，JSON.parse 失败与分隔符非法均转成 `{ error }`。
  - `unflattenJson(input, separator)`：路径 token 化（分隔符切段 + 段内 `/\[(\d+)\]/g` 扫描，方括号间文本作 key），按 token 自动建数组 / 对象赋值；叶子继续下钻、索引与对象类型不匹配、同槽位覆盖容器一律 throw「路径冲突」。
  - `unflattenJsonText(text, separator)`：解析后校验必须为非数组对象单层 KV；try/catch 把冲突抛错收口为 `{ error }`。
- **测试** `utils/flatten.test.ts`（34 个用例）：点路径扁平化、数组 / 嵌套数组 / 根数组、空对象空数组与 null 叶子、根标量、自定义分隔符、expandArrays=false、含点号的键；unflatten 还原、稀疏数组、标量根、四类路径冲突、多根值、空分隔符；复杂结构与根数组往返；Text 层解析错误 / 非对象输入 / 冲突不抛异常。
- **UI** `index.tsx` + `constants.ts` + `index.module.css`：Flatten / Unflatten 方向 Radio、分隔符 Select（`.` / `_` / `/` / `-`）、展开数组 Checkbox（仅 flatten）、双栏 TextArea 实时联动、载入示例 / 清空 / 复制结果、错误 Result 面板与路径规则提示。
