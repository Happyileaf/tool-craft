## 描述

粘贴 JSON 样本即可推断并生成 C++17 数据模型：`int32_t` / `int64_t` / `double` / `bool` / `std::string`、数组生成为 `std::vector<T>`、嵌套对象生成为独立 `struct`、缺失或 `null` 字段生成为 `std::optional<T>`，属性名按 PascalCase 生成并规避 C++ 关键字，可选输出外层 `namespace`。用于把接口返回的 JSON 快速落成 C++ 类型定义、减少手写样板代码。现有 JSON 代码生成工具覆盖 TypeScript / Go / Rust / Java / Kotlin / PHP / Python dataclass / C# / Swift / Zod / SQL DDL，唯独缺少 C++，本 Idea 补齐该语言族缺口。

## 设计内容（进入 Claimed 前补全）

功能范围：JSON 样本解析与类型推断（整数按范围区分 32/64 位、浮点、布尔、字符串、对象、数组、`null` 与空数组按 `std::any` 或可配置占位并给出提示）；数组元素类型合并（同质数组取并集，异质数组退化为可配置类型并告警）；嵌套对象递归展开为多个 struct，重名对象按结构一致性去重或后缀区分；字段名规范化（PascalCase、非法字符替换、关键字加后缀）；可选命名空间与字段注释标记来源 JSON 路径。

核心交互：JSON 输入区（实时语法错误定位）、命名空间输入、`optional` / 空数组策略选项、生成结果代码区与一键复制、嵌套 struct 顺序预览。

输入输出：输入合法 JSON 文本与可选命名空间；输出 C++17 头文件风格代码（`#include <cstdint>` / `<optional>` / `<string>` / `<vector>` 前置包含）与告警列表（异质数组、非法字段名、空数组类型未知）。

边界情况：空对象生成空 struct；顶层为数组时按元素推断并给出顶层类型别名；超深嵌套给出层级提示；数字超出 `int64_t` 范围提示转字符串；字段名仅为 C++ 关键字时自动改名并在告警中列出。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] `{"id":1,"name":"a","active":true,"score":1.5}` 生成含 `int32_t id; std::string name; bool active; double score;` 的 struct
- [ ] 可选字段缺失时生成 `std::optional<T>`，全量出现时生成裸类型（两种样本分别验证）
- [ ] 数组 `[{"x":1},{"x":2}]` 生成 `std::vector<Item>` 与嵌套 `Item` struct
- [ ] 字段名 `user-name` / `class` 分别规范化为可编译标识符并在告警中列出改名记录
- [ ] 指定命名空间时输出包裹 `namespace demo { ... }`，未指定时不输出
- [ ] 非法 JSON 返回带位置信息的错误而非崩溃，空对象与顶层数组样本均能输出合法代码
