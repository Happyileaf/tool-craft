## 描述

在十六进制字节序列与整数之间做字节序（大端 big-endian / 小端 little-endian）双向编解码：给定 16 / 32 / 64 位宽与有无符号，同一串字节同时给出大端、小端两种解释值；给定整数可分别输出大端、小端两种字节序列。支持整串字节反转（byte swap）与按 16 位半字交换（如 `CDAB` 风格），并可处理多字节数组逐元素重排。用于嵌入式寄存器读数、协议字段解码、二进制文件排查与跨端序数据交换；纯本地位运算，不上传任何数据。

## 设计内容（进入 Claimed 前补全）

功能范围：模式切换（字节 → 整数 / 整数 → 字节）；位宽 16/32/64；有符号 / 无符号；输入容错（忽略空格、`0x` 前缀、逗号/换行分隔，奇数位补零并告警）；整串反转与半字交换两种重排策略；多元素模式（按所选位宽把字节序列切分为多个元素分别解释 / 拼接）；补码表示说明与十进制 / 十六进制双输出。

核心交互：输入区——字节序列或整数；位宽与符号选择；重排策略选择；结果卡片同时展示大端值、小端值与两种字节序列；一键互换与复制；示例（如 `DE AD BE EF`、寄存器 `0x12345678`）。

输入输出：输入十六进制字节串或十进制/十六进制整数；输出两种端序的解释值、重排后的字节序列、按位宽切分的元素列表与告警。

边界情况：空输入返回空；非法字符定位报错；字节数与位宽不匹配时截断或补齐并显式告警；有符号最小负值与最大值边界正确（如 16 位 `0x8000` → -32768）；多元素切分末尾不足一个元素时提示；64 位整数超出 JavaScript 安全整数范围时用 BigInt 路径保证精度。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] `DE AD BE EF` 32 位无符号 → 大端 `3735928559`（0xDEADBEEF）、小端 `4022250974`（0xEFBEADDE）
- [ ] 十进制 `305419896`（0x12345678）32 位 → 大端 `12 34 56 78`、小端 `78 56 34 12`
- [ ] 16 位有符号 `0x8000` → 大端 `-32768`，`0xFFFF` → `-1`
- [ ] 半字交换对 `12 34 56 78` 输出 `34 12 78 56`，整串反转输出 `78 56 34 12`
- [ ] 64 位 `0xFFFFFFFFFFFFFFFF` 无符号输出 `18446744073709551615` 且不丢精度
- [ ] 输入含 `0x` 前缀、空格与换行的字节串可按同一规则解析，非法字符返回定位明确的错误
