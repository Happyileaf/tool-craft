## 描述

统一的循环冗余校验（CRC）计算器，覆盖 CRC-8（如 CRC-8/SMBus、CRC-8/MAXIM）、CRC-16（CCITT-FALSE、MODBUS、XMODEM、IBM/ARC 等）、CRC-32（IEEE 802.3、CRC-32C Castagnoli、CRC-32/BZIP2）与 CRC-64（CRC-64/XZ、CRC-64/ISO）常用参数模型，并允许自定义 width / poly / init / refin / refout / xorout / check 参数。现有 `crc16-checksum` 与 `crc32-checksum` 是各自独立、参数固定的单一模型工具，不提供 CRC-8 与 CRC-64，也不支持参数自定义与多模型并排；本工具以通用参数化驱动函数 + 预置模型表统一四类位宽，并显示 check 常量（"123456789" 标准校验值）用于自校验，支持文本（UTF-8）与十六进制字节两种输入、逐字节过程表与校验和 hex 输出。纯浏览器本地确定性运算、零新增依赖，可用 CRC catalogue 官方 check 向量逐一验收。
