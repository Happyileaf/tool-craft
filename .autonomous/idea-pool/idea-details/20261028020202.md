## 描述

在非负整数（支持单个或一组数字）与短而随机、URL 安全的字符串 ID 之间双向编解码，实现 Sqids（Hashids 的官方后继，规范见 sqids.org）算法：支持自定义字母表（默认小写字母+数字，需打乱）、最小输出长度、黑名单词过滤（自动重排避免生成指定脏词），编码结果可逆且对同一输入在固定参数下确定。典型用途是把数据库自增 ID 对外暴露为短链 / 分享码，同时支持多数字打包。工具需正确实现字母表洗牌（基于分隔符种子的迭代交换）、分隔符与规整逻辑、超长/超范围数字（超过字母表容量）的报错，并保证 decode 结果与原始数字数组一致；提供参数实时预览。全部为本地确定性算法，纯函数实现，零新增依赖（直接按公开规范实现，不引入 sqids npm 包）。与现有 uuid-generator / nano-id-generator / ulid-generator（均为生成不可读随机/有序 ID，不可逆）、Base62（无洗牌/黑名单语义的通用进制编码）不重叠：Sqids 是可逆、可配置、带黑名单的整数↔短码方案。
