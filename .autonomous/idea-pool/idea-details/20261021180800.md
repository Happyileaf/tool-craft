## 描述

在原始 Cookie 请求头字符串（`a=1; b=2`）与可编辑的名值对表格之间双向转换，并支持生成 `Set-Cookie` 形式的属性字段（Domain / Path / Expires / Max-Age / Secure / HttpOnly / SameSite），用于排查登录态、构造测试请求头。当前 URL 解析、.env 转换、HTML entity 等工具均不处理 Cookie 这一高频开发场景，与已拒绝的 URL encoder/decoder、JWT decoder 均无重叠。

## 设计内容（进入 Claimed 前补全）

工具 slug：`cookie-parser`，单页两区：

1. Cookie 请求头解析：文本框粘贴 `name1=value1; name2=value2`（兼容前后空白、无空格分号、重复名称按出现顺序保留多行），按 `;` 分段、首个 `=` 切分名称与值，名称 trim，值不做 URL 解码（提供可选 URL-decode 开关），结果以可编辑表格展示（名称、值、删除/新增行）。
2. Cookie 请求头生成：表格编辑后一键序列化为 `a=1; b=2`（值原样输出，可选 URL-encode 开关）。
3. Set-Cookie 生成器：名称、值、Expires（日期选择）/ Max-Age（秒）、Domain、Path、Secure、HttpOnly、SameSite（Lax/Strict/None；None 时提示应同时 Secure），输出标准 `Set-Cookie:` 响应头字符串，并可粘贴已有 Set-Cookie 单行回填属性（解析 Expires/Max-Age/Domain/Path/Secure/HttpOnly/SameSite 等已知属性，其余属性原样保留展示）。

核心纯函数放 `utils/cookie.ts`（parseCookieHeader、serializeCookieHeader、parseSetCookie、buildSetCookie），Vitest 固定向量（含空格、空值、重复名、大小写属性名）；零依赖、纯本地。
