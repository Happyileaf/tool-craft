## 描述

对十六进制或二进制输入的 IPv4 首部、TCP / UDP 段（含伪首部）、ICMP 报文计算互联网校验和（RFC 1071 的 16 位反码求和），并支持校验模式：填入已带校验和的报文判断是否合法（计算结果为 0），以及生成模式：将 checksum 字段清零后回填正确值；TCP / UDP 模式自动提示并允许输入伪首部（源/目的地址、协议号、长度）。解决网络协议学习与抓包调试时手工核对校验和的问题。纯函数、确定性运算、零依赖、纯本地执行，可用 RFC 1071 官方示例向量（如 `00 01 f2 03 f4 f5 f6 f7` → `220d`）、公开抓包样本与往返（回填后再校验通过）固定验收。与现有 crc16-checksum / crc32-checksum（CRC 多项式族，非反码求和）、cidr-subnet-calculator / ip-address-converter（地址运算，不做报文校验）均不重复。

## 设计内容（进入 Claimed 前补全）

- slug：`tcpip-checksum`，分类 DEV_CODE，主线程处理，零新依赖。
- 纯函数模块 `utils/checksum.ts`：`parseHexBytes` / `parseIpv4` / `buildPseudoHeader` / `onesComplementSum` / `internetChecksum` / `verifyChecksum` / `applyChecksum` / `generateChecksum` / `verifySegment` / `toHex`，导出 TCP/UDP 偏移与协议号常量。
- 三种模式：raw（IPv4 首部 / ICMP，偏移可配，默认 10）、tcp（偏移 16）、udp（偏移 6）；TCP/UDP 自动拼接 12 字节伪首部并自动清零校验和字段。
- UI：Ant Design Card + Radio 模式切换 + 十六进制 TextArea + 源/目的 IPv4 输入 + 结果卡片（0x 值、十进制、回填报文、校验结论）。
- 边界：奇数长度末字节按高字节补 0；非法十六进制 / 奇数位 / 非法 IPv4 / 缺地址 / 偏移越界均抛错并由 Alert 展示。
