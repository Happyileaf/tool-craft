## 描述

输入原始 JSON 文档与一个 JSON Patch 操作数组（`add` / `remove` / `replace` / `move` / `copy` / `test`，含 RFC 6901 JSON Pointer 路径），实时应用补丁并展示结果文档或精确的操作级错误（操作序号、失败原因），同时支持补丁合法性校验（op 未知、路径不存在、数组越界、`test` 不匹配等）。解决联调 HTTP PATCH/JSON Patch 接口时缺乏可快速试算与定位错误的本地工具的问题；纯函数实现、零依赖、可离线。
