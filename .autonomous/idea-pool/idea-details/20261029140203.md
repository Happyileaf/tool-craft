## 描述

输入原始 JSON 文档与一个 JSON Patch 操作数组（`add` / `remove` / `replace` / `move` / `copy` / `test`，含 RFC 6901 JSON Pointer 路径），实时应用补丁并展示结果文档或精确的操作级错误（操作序号、失败原因），同时支持补丁合法性校验（op 未知、路径不存在、数组越界、`test` 不匹配等）。解决联调 HTTP PATCH/JSON Patch 接口时缺乏可快速试算与定位错误的本地工具的问题；纯函数实现、零依赖、可离线。

- 2026-10-29 创建（状态 Pending）：由 Idea Generation 流程写入。四源查重通过——registry 中 `json-merge-patch`（RFC 7386）详情明确「不支持 JSON Patch（RFC 6902）的路径操作」，二者为不同 RFC、不同补丁模型；`json-flatten`、JSONC、JSON↔NDJSON 等工具均不做补丁应用；活动池 / completed.md / rejected.md 无相同或高度相似 Idea（6902、JSON Patch 关键词检索无命中，rejected 中 JSONPath 被否原因是查询语言解析复杂，与确定性应用补丁数组不同）。
- 2026-10-29 领取（Claimed）：trae-agent 六维评估通过（查重：json-merge-patch 为 RFC 7386 不同补丁模型；高频价值：HTTP PATCH 联调试算与错误定位；纯客户端、零新依赖、纯函数；主线程；复杂度 M：6 个操作 + JSON Pointer 与操作级错误），纳入本轮实现清单，工具 slug：json-patch。
- 2026-10-29 实现（In Progress）：新增 `apps/web/src/tools/json-patch/`：
  - `utils/json-patch.ts`：零依赖纯函数。RFC 6901 指针解析（/ 分段、~1→/、~0→~、非法转义/不完整波浪号校验）；完整 RFC 6902 六操作（add 含数组插入与 "-" 追加、remove、replace、move 含“禁止移入自身后代”校验、copy、test 深度相等断言）；顺序应用、任一失败即整体返回错误，错误带操作序号、op 名与中文原因（op 未知、缺字段、路径不存在、数组越界/非法下标、test 不匹配等）；深拷贝隔离，原文档不变；导出 parseJsonInput（行列定位）与 deepEqual。
  - `utils/json-patch.test.ts`：44 个用例，覆盖 RFC 6902 附录 A 官方示例（A.1/A.3–A.11/A.14–A.18）、根节点替换、深拷贝隔离、copy 脱耦及全部操作级错误分支，全部通过。
  - `constants.ts` / `index.tsx` / `index.module.css`：antd 双栏 UI（原文档 + 补丁数组 → 实时结果/错误 Alert），显示已应用操作数，一键复制，附「错误示例」按钮演示操作级定位；registry.ts（DATA_JSON，iconName Braces）与 loaders.ts 已注册。
