## 描述

面向问卷调查、民意测验、用户研究与市场调研场景，基于 Cochran（1977）经典抽样公式，在浏览器本地完成两类互逆计算，全部零依赖：

1. **正向（定误差求样本量）**：输入置信水平（90% / 95% / 99%）、允许误差范围（margin of error，百分比）、预期总体比例 p（默认 0.5 即最保守估计）、总体规模 N（可选，留空视为无限总体），输出所需最小样本量 n（向上取整）；填写有限总体时自动应用有限总体校正（FPC, Finite Population Correction），同时展示校正前基准值与 FPC 缩减比例。
2. **反向（定样本量求误差）**：输入已确定的样本量 n、置信水平、预期比例 p 与可选总体规模 N，输出在该配置下可达到的误差范围（百分比），用于评估既定样本能支撑的精度。

页面附公式说明（n₀ = Z²·p(1−p)/e²；FPC 校正 n = n₀ / (1 + (n₀−1)/N)）、Z 临界值速查（90%≈1.6449、95%≈1.9600、99%≈2.5758）与方法学提示（简单随机抽样假设、p=0.5 给出最保守最大样本量、结果为理论最小值需结合无应答率上浮）。不做抽样模拟、不做分层/整群等复杂抽样设计、不做假设检验（与活动池 `20261103140201` 假设检验计算器及已上线 `descriptive-statistics` 描述性统计工具定位区分）。

## 设计内容（进入 Claimed 前补全）

- **核心纯函数（`utils/sample-size.ts`，零运行时依赖）**
  - `zForConfidence(level: 90 | 95 | 99): number`：返回标准正态双侧临界值常量 1.644854 / 1.959964 / 2.575829，非法 level 抛错。
  - `baseSampleSize(z, p, e): number`：Cochran 无限总体公式 n₀ = Z²·p·(1−p)/e²（e 为小数，如 0.05），返回未取整理论值。
  - `adjustFinitePopulation(n0, N): number`：FPC 校正 n = n₀ / (1 + (n₀−1)/N)；N 缺省/非有限时原样返回 n₀。
  - `requiredSampleSize(input): { n0, nAdjusted, fpcRatio }`：组合上述函数，最终样本量 `Math.ceil` 向上取整；fpcRatio = nAdjusted/n₀。
  - `marginOfError(z, p, n, N?): number`：逆运算，e = Z·sqrt(p(1−p)/n_eff)，有限总体时 n_eff 按 FPC 关系反解（由 n = n₀·N/(N+n₀−1) 反解得 n_eff = n·N / (N − n + 1)），返回小数误差。
- **输入校验与边界**
  - p ∈ (0,1)，默认 0.5；e ∈ (0,1)；n 为 ≥1 整数；N 为正整数且 N ≥ n（否则报错）；置信水平仅允许 90/95/99 三档枚举。
  - 非法输入（空值、越界、NaN、N<n）抛出带中文信息的错误，UI 行内 Alert，不出静默结果。
  - 样本量结果设展示上限保护（如 n ≤ 10,000,000），超出提示缩小精度要求而非卡顿渲染。
- **UI（`index.tsx` + `constants.ts` + `index.module.css`，与既有 time-math 计算器同构）**
  - 模式 Radio：① 求样本量 / ② 求误差范围，切换时复用同一组字段。
  - 字段：置信水平 Select（默认 95%）、误差范围 InputNumber（%，模式①）或样本量 InputNumber（模式②）、预期比例 p InputNumber（%，默认 50%）、总体规模 N InputNumber（可选，placeholder「留空 = 无限总体」）。
  - 结果区：主结果大字号（所需样本量 n 或可达误差 e%）+ 次级信息行（n₀ 基准值、FPC 校正比例、对应 Z 值）；示例 chips（95%/5%/p=0.5 经典 385 向量、N=1000 有限总体向量）、复制 / 清空、错误 Alert。
  - FAQ 至少含「为什么 p=0.5 时样本量最大」「有限总体校正什么时候生效」「算出的样本量是否还要考虑无应答率」「与假设检验的功效分析有何区别」。
- **注册**：`registry.ts` 追加双语 ToolMeta，category = `ToolCategoryEnum.TIME_MATH`（与 `descriptive-statistics`、`linear-regression` 同类），iconName = `Sigma`，isNew / MAINTHREAD，defaultSampleInput 采用经典 95%/5%/p=0.5 配置；`loaders.ts` 追加懒加载。
- **测试（`utils/sample-size.test.ts`，Vitest 固定向量，不 Mock 纯函数）**
  - 固定向量：Z(95%)≈1.959964；无限总体 95%/e=5%/p=0.5 → n₀≈384.15、ceil=385；N=1000 同参 → nAdjusted raw≈277.73、ceil=278；N=500 → raw≈217.49、ceil=218（数值已用 Node 实算复核）。
  - 逆运算自洽：对 (z,p,e) 求 n 后，将 ceil(n) 回代 `marginOfError`，所得 e′ ≤ 原 e（取整只会让误差更小）。
  - 边界：p=0.5 为同条件最大 n₀（对比 p=0.1/0.3）；N 缺省时 nAdjusted===n₀；N<n、e=0、p 越界、非法 level 均抛错；90%/99% 档结果与公开抽样教科书表格方向一致（90% 同参 n<385、99% n>385）。
