## 描述

实现 Segment KSUID（K-Sortable Unique IDentifier）的生成与解析：20 字节负载（4 字节自定义纪元 `1400000000` 起算的秒时间戳 + 16 字节随机 payload），以 27 位 Base62 字符串（0-9A-Za-z 字母表）表示。生成模式使用 `crypto.getRandomValues` 产生随机部分；解析模式从字符串反解出嵌入的 UTC 时间戳与 16 字节随机 payload（十六进制展示），并对非法字符、长度不符、时间戳越界给出错误提示。全部本地运算、零新增依赖，固定结构可由已知向量验收。延续池中 UUID v7 / ULID / Snowflake / Nano ID 等「分布式标识符」工具系列。
