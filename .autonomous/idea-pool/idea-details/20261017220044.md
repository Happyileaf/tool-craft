## 描述

把同一数值按不同区域设置渲染成本地化表现：千分位分组符、小数点符号、小数位与舍入方式、货币符号及其位置、负值括号写法、百分比与紧凑记法（1.2K / 1.2M / 1.2 万）。用于多语言产品文案、报价与财务报表的格式核对。现有百分比计算器与描述性统计计算器只做数值计算、不作区域化排版，关注点不同；工具集中无本地化数字格式化能力。基于浏览器原生 Intl.NumberFormat 的纯函数封装实现，零新增运行时依赖。

## 设计内容（进入 Claimed 前补全）

- **slug**：`number-locale-formatter`
- **分类**：数值与计算（ToolCategoryEnum.TIME_MATH，与 percentage-calculator / chinese-currency 同分类），iconName 用 `Gauge`，MAINTHREAD，isNew
- **查重**：与已有 `chinese-currency`（数字转中文大写金额，发票合同文本）关注点不同；percentage-calculator、descriptive-statistics 只做数值计算不做区域排版，无功能重叠
- **形态**：单数值输入 + 多区域并排结果；纯浏览器本地运算（原生 Intl.NumberFormat）、零新依赖
- **纯函数层** `utils/formatter.ts`（不依赖 DOM/React）：
  - `FormatNumberOptions { locale, mode(decimal/currency/percent), currency(ISO 4217), notation(standard/compact), useGrouping, minimumFractionDigits?, maximumFractionDigits?, negativeParentheses }`
  - `parseNumberInput(input)`：返回有限数值或 `'empty'` / `'invalid'`（拒绝千分位逗号输入、Infinity）
  - `formatNumber(value, options)`：封装 `new Intl.NumberFormat(locale, options)`；货币模式设 style=currency；百分比 style=percent；compact 走 notation；小数位夹到 0-20
  - 负数括号后处理：对 Intl 结果去负号并包 `()`，兼容前缀负号（-1,234）与中缀负号（-$5）
  - `formatNumberAcrossLocales(value, locales[], options)`：按顺序批量输出 `{ locale, text }[]`
- **UI 层** `index.tsx`：antd Input 数值；Radio 模式（数字/货币/百分比，货币时 Select ISO 代码）；Radio 记法（标准/紧凑）；Checkbox 千分位分组 / 负数括号 / 固定小数位（勾选后 InputNumber 0-20）；多选 Select 区域（默认 zh-CN、en-US、de-DE、ja-JP，内置 8 个常用区域）；结果逐行显示区域名 + 等宽排版文本；非法输入 Alert；底部说明输出依赖运行环境 ICU
- **常量** `constants.ts`：模式与记法 enum + 中文标签、LOCALE_OPTIONS（8）、COMMON_CURRENCIES（8）、默认数值 1234567.895、默认勾选区域
- **注册**：`registry.ts` 追加完整双语 ToolMeta；`loaders.ts` 追加懒加载
- **测试**：`utils/formatter.test.ts` 15 个用例——解析合法/空/非法（逗号、Infinity）；en-US 与 de-DE 分组小数点；关分组；固定小数位四舍五入；紧凑 1.2M / 123万；美元 / 欧元符号位置；日元零小数；人民币；百分比乘 100；负数括号（数字与货币）；非负数括号不受影响；多区域批量顺序
