## 描述

将文本在常见命名风格之间互转（camelCase、PascalCase、snake_case、kebab-case、CONSTANT_CASE、Title Case 等），解决开发者命名转换的高频需求。现有 `word-count` 只做统计，无任何大小写 / 命名风格转换能力。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：把输入文本切分为词元后，按目标风格重新拼装，支持 camelCase、PascalCase、snake_case、SCREAMING_SNAKE_CASE、kebab-case、dot.case、Title Case、Sentence case、lower case、UPPER case 等常见风格。
- **核心交互**：输入框输入任意文本，选择目标风格后即时输出转换结果；同时列出所有风格的对照结果，每项可一键复制。
- **输入输出**：输入任意字符串，输出对应风格字符串；空输入输出空串。
- **边界情况**：需正确拆分 camelCase / PascalCase（如 `getUserID` → `get`/`user`/`ID`）、空格 / 连字符 / 下划线 / 点分隔、连续大写缩写（如 `HTTPResponse`）、数字前缀（如 `v2Update`）；首尾空白与多余分隔符需归一化。
