## 描述

在浏览器内对文本或字节数据进行 gzip / raw deflate / zlib 格式的压缩与解压，展示压缩前后字节数、压缩率，并可导出压缩产物（Hex / Base64 表示）或从 Hex / Base64 载荷还原原始文本。解决本地验证压缩数据、接口调试时手工编解码 gzip 载荷的问题。基于浏览器原生 `CompressionStream` / `DecompressionStream`（Chrome/Edge/Firefox/Safari 现代版本均支持），零新增运行时依赖、纯本地运算，不调用任何服务端接口；压缩/解压可用固定向量（如 RFC 1951 固定字符串的已知 gzip 输出、gzip 头魔数 `1f 8b` 校验）与往返一致性（解压(压缩(x)) === x）验收。与现有 hash-generator / crc32-checksum（只算摘要不压缩）、base64-codec（编码非压缩）均不重复。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：文本 ↔ gzip / deflate（CompressionStream 支持的 `gzip`、`deflate`）压缩解压；压缩产物支持 Hex / Base64 表示与复制，工具 slug 为 `gzip-codec`。
- **核心交互**：
  - 压缩：输入文本 → 选择算法（gzip / deflate）→ 输出 Hex 与 Base64，展示原始字节数、压缩后字节数、压缩率。
  - 解压：粘贴 Hex / Base64 压缩载荷 → 自动去除空白 → 解压还原 UTF-8 文本。
  - 往返校验：展示「解压(压缩(输入))」是否一致的状态；输入输出一键交换。
- **输入输出**：核心逻辑放 `utils/gzip.ts`（基于 `CompressionStream`/`DecompressionStream` + `TextEncoder/Decoder`，汇聚流字节），不触碰 DOM；Hex/Base64 辅助为纯函数可直接单测。
- **边界情况**：空输入；非法 Hex / Base64 或解压失败（魔数/格式错误）给出明确错误不抛到页面；gzip 输出前两字节为 `1f 8b`。运行环境不支持 CompressionStream 时显示降级提示。
