## 描述

输入 MIDI 音符编号（0–127）、音名（如 C4、A#3）或频率（Hz）任一项，实时互转其余两项，支持自定义 A4 基准频率（如 432Hz），并可展开指定八度的全音符频率表。音乐制作、乐器调音、嵌入式音频开发常用。现有已注册工具与池内条目均无音乐/音频方向，NATO 音标字母转换（20261023040538）为语音字母文本方向，不重叠。十二平均律频率计算与音符表生成为纯函数，零依赖、纯本地。

- **分类 / 图标**：`ToolCategoryEnum.TIME_MATH`（公式型数值计算，与 percentage / aspect-ratio 同类；无音频专属分类）；图标 `FieldNumberOutlined`

- **文件结构**（三件套，零新依赖）：
  - `constants.ts`：`NOTE_NAMES = ['C','C#','D','D#','E','F','F#','G','G#','A','A#','B']`、`InputModeEnum`（midi/name/frequency）、`MODE_OPTIONS`、`DEFAULT_MIDI_NOTE = 69`、`DEFAULT_A4_FREQUENCY = 440`、`MIN_MIDI = 0`、`MAX_MIDI = 127`
  - `utils/midi.ts`：纯函数
    - `midiToFrequency(note, a4Frequency = 440)`：`a4Frequency * 2 ** ((note - 69) / 12)`
    - `midiToNoteName(note)`：音名序号 `note % 12`，八度 `Math.floor(note / 12) - 1`（MIDI 60 = C4、69 = A4），返回 `{ name, octave, full }`
    - `noteNameToMidi(input)`：正则 `/^([A-Ga-g])([#b]?)(-?\d+)$/` 解析（支持 `C4`、`A#3`、`Bb3`），`midi = (octave + 1) * 12 + pitchClass`，越界（<0 或 >127）抛错
    - `frequencyToMidi(frequency, a4Frequency = 440)`：返回 `{ midi: 浮点值, nearestNote: 整数, cents: 与最近音分差 }`，`midi = 69 + 12 * log2(f / a4)`，cents = `(midiFloat - nearest) * 100`
    - `getOctaveNotes(octave, a4Frequency)`：返回该八度 12 个半音的 `{ midi, name, frequency }`（C 到 B）
  - `index.tsx`：Radio 选择输入方式（MIDI 编号 / 音名 / 频率 Hz）；单一 Input 实时换算；A4 基准频率 Input（默认 440）；结果区展示 MIDI 编号、音名、精确频率（保留 2 位小数），频率模式额外显示最近音符与音分偏差；可折叠面板选择八度（-1–9）展示 12 音频率表（antd Table）；错误 Alert；载入示例（69 / A4 / 440）/ 清空
  - `index.module.css`：container/toolbar/resultGrid/label/hint
- **注册**：`registry.ts` 追加双语 ToolMeta（TIME_MATH / FieldNumberOutlined / isNew / MAINTHREAD / defaultSampleInput='69'）；`loaders.ts` 追加懒加载条目；FAQ 至少含「为什么 MIDI 69 是 A4」「十二平均律频率公式」「自定义 432Hz 基准的作用」
- **边界**：MIDI 编号仅接受 0–127 整数；音名必须为 A–G 字母 + 可选 `#`/`b` + 八度整数，且换算结果落在 0–127；频率必须为正数；A4 基准频率必须为正数；频率输出保留 2 位小数；不处理微分音自定义律制，仅十二平均律

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] MIDI 69（A4=440）→ 音名 `A4`、频率 440.00 Hz；MIDI 60 → `C4`（中央 C）
- [ ] 音名 `A4` → MIDI 69；`C4` → MIDI 60；`A#4` → 70；支持 `Bb3` 等降号写法
- [ ] 频率（A4=440）：440 → 最近音 A4、偏差 0 音分；70 号音频率 ≈ 440 × 2^(1/12) ≈ 466.16 Hz，相邻半音频率比为 2^(1/12)
- [ ] 自定义 A4=432：MIDI 69 → 432.00 Hz，所有换算同步变化
- [ ] 频率反算：输入约 432Hz（A4=440）时最近音为 A4 且音分偏差约为 -31.6 音分
- [ ] 八度表：八度 4 展开为 C4–B4 共 12 行，MIDI 编号 60–71，频率随半音递增
- [ ] 非法输入（MIDI 128 / -1 / 小数、音名 `H4` / `C` 缺八度、频率 0 / 负数、A4 非正数）给出明确错误，不崩溃
