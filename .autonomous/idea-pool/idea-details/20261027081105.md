## 描述

通过表单或条目列表填写站点标题、链接、描述与文章条目（标题、链接、发布时间、摘要），本地生成符合 RSS 2.0 与 Atom 1.0 规范的 XML 订阅文件并预览、复制、下载。面向个人博客、静态站点作者快速产出 feed。与已有「iCalendar 生成器」「sitemap.xml 生成器」同属文件生成类但输出格式与领域完全不同，不重叠。

## 设计内容（进入 Claimed 前补全）

- 功能范围：填写站点标题、站点链接、描述与语言（可选），维护文章条目列表（标题、链接、发布时间、摘要）；在 RSS 2.0 与 Atom 1.0 两种规范间切换生成完整 XML，支持预览、复制与下载 `.xml`。
- 核心交互：元数据与条目表单实时驱动 XML 预览；条目可增删；切换格式后保留同一份表单数据；发布时间接受 ISO 8601 / `YYYY-MM-DD` / RFC 822 字符串，非法日期给出定位提示；必填项（站点标题、站点链接、条目标题与链接）为空时展示校验错误而非输出残缺文档。
- 输入输出：输入为表单字段与条目列表，输出为带 XML 声明的 RSS 2.0 或 Atom 1.0 文档文本；RSS 输出 RFC 822 格式 `pubDate`，Atom 输出 RFC 3339 格式 `updated`。
- 边界情况：标题 / 描述 / 摘要中的 `&`、`<`、`>`、`"`、`'` 全部实体转义；无条目时生成合法空 feed；站点链接校验为绝对 URL；RSS 的 `guid` 取条目链接并标记 `isPermaLink="true"`，Atom 的 `id` 取条目链接。
