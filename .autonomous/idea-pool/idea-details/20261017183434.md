## 描述

将阿拉伯数字金额转换为中文大写（壹、贰、叁……元角分）用于发票、收据与合同填写，同时支持英文数字转单词；正确处理零、角分、整数与小数边界。现有 `number-base-converter` 仅做进制转换，不涉及金额大写，而财务开票场景对此有明确需求。

## 设计内容（进入 Claimed 前补全）

- **slug**：`chinese-currency`；分类 TIME_MATH；主线程同步运算；图标 Gauge。
- **纯函数层** `tools/chinese-currency/utils/rmb.ts`：
  - `convertToRmb(input): { text, error }`：去空白、严格校验千分位分组（`1,234.56`）与普通十进制；拒绝负数、非法字符、`00` 等。
  - 整数部分按 4 位一节转换，节内位权拾/佰/仟，节单位万/亿/万亿；正确处理节间补零（壹亿零壹仟）与连续零合并；上限 16 位整数。
  - 小数最多 2 位（角/分），更多位四舍五入到分，进位到整数时用 BigInt 安全进位。
  - 规范：零元→「零元整」；整元→「…元整」；有角无分→「…X角」；角零分有→「…元零Y分」；纯角分不输出「零元」。
- **测试** `utils/rmb.test.ts`（45 个用例）：零与整数边界、101/1001/1010、万节（10001/10010/10100/11000）、亿节（壹亿零壹、壹亿零壹万、壹亿零壹仟）、16 位千万亿、角分九种组合、超两位小数四舍五入（含 1.999→贰元整进位）、千分位与空白、空输入、非法输入组、超长错误。
- **UI** `index.tsx` + `constants.ts` + `index.module.css`：大输入框（addon「元」）、示例 chips、实时大写结果、复制 / 清空、错误 Alert 与规则提示。
- **注册**：registry.ts 追加完整双语 ToolMeta（含 faqs），loaders.ts 追加懒加载映射。
