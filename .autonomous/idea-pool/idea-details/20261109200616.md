## 描述

在传统论坛、phpBB / Discuz 等社区中 BBCode（如 `[b]`、`[url=]`、`[img]`、`[quote]`、`[code]`、`[list]`）仍是主流标记，用户经常需要把 BBCode 帖子内容转成可粘贴到博客 / CMS 的 HTML，或反向把一段 HTML 降级为论坛可用的 BBCode。本工具提供纯浏览器本地的双向转换，覆盖常见标签映射、嵌套、属性解析与转义，并对无法映射的结构给出降级处理。现有 `markdown-preview` / `markdown-table-generator` 只处理 Markdown 语法，`html-entity-codec` 只做实体编解码，均不覆盖 BBCode 这一标记语言；本工具补齐「论坛标记 ↔ HTML」方向的空白，核心逻辑为确定性纯函数。
