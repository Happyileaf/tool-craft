## 描述

输入名义年利率（APR）与复利频次（按月 / 按季 / 按半年 / 按日 / 连续复利），计算实际年利率 EAR（APY），并反向由目标 EAR 求所需名义利率；支持把含手续费 / 开户费的贷款折算成真实年化成本，多个方案并排对比。现有 `loan-calculator` 只算等额本息 / 等额本金月供与总利息，不做名义利率与实际年化费率之间的换算，也不把手续费摊入年化成本，本工具补齐这一金融计算缺口，全程本地纯函数运算。

## 设计内容

- **功能范围**：APR→EAR 正向换算（离散复利 EAR=(1+r/n)^n−1，连续复利 EAR=e^r−1）、EAR→APR 反求（r=n×((1+EAR)^(1/n)−1)，连续 r=ln(1+EAR)）、含手续费贷款的真实年化成本（把一次性费用摊入有效本金后反推 IRR 近似年化），最多 3 个方案并排对比，slug 为 `apr-ear-calculator`。
- **核心交互**：名义利率百分数输入、复利频次 Radio（月/季/半年/日/连续）、贷款本金与手续费 InputNumber；结果卡片展示 EAR 百分数、名义与实际利差、有效年化成本；对比表按方案列示并高亮最高/最低。
- **输入输出**：纯函数 `aprToEar(apr, periodsPerYear)` / `earToApr(ear, periodsPerYear)` / `effectiveCostRate(...)`，periodsPerYear 用 `Infinity` 表示连续复利，不触碰 DOM。
- **边界情况**：利率/本金非法或为负报错；频次必须取自枚举；手续费 ≥ 本金报错；结果统一保留 4 位小数并给出百分数；反求方向与正算可往返一致。
- **零依赖**：仅 Math.pow/Math.log/Math.exp，不新增 npm 包。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 离散复利向量：APR 12% 按月（n=12）→ EAR ≈ 12.6825%；按季（n=4）→ ≈12.5509%；按半年（n=2）→ 12.3600%；按日（n=365）→ ≈12.7475%。
- [ ] 连续复利：APR 10% → EAR = e^0.1−1 ≈ 10.5171%。
- [ ] 反求：对上述每个 EAR 调 earToApr 还原名义利率，与原始 APR 误差 < 1e−6；连续复利 r=ln(1+EAR) 往返一致。
- [ ] 含手续费方案：本金 10000、开户费 200、APR 12% 按月，输出的有效年化成本严格大于 12.6825%（费用摊薄），且费用越高有效年化越高。
- [ ] 负利率/负本金/非法频次/手续费≥本金均给出明确错误，不产出 NaN。
- [ ] 纯浏览器本地运算，无任何网络请求，无新增 npm 依赖。
