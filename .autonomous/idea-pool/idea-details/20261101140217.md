## 描述

双向转换 PHP `serialize()` 格式与 JSON：解析侧支持 `s:5:"hello";`（含带长度的字符串、引号与分号转义）、`i:42;`、`d:3.14;`、`b:1;`、`N;`、`a:2:{…}` 关联/索引数组、`O:8:"stdClass":…` 对象（数组键支持整数键与字符串键）；生成侧从 JSON 重建合法序列化串（对象默认按关联数组 `a` 输出或可选 `O` 对象包装，PHP 数组按连续 0..n-1 整数键输出索引数组）。处理长度声明与实际字节数不一致、非法类型字符、未闭合花括号等畸形输入的报错定位。典型场景：读 PHP 老系统缓存 / Laravel 队列载荷 / WordPress 数据、跨语言调试。纯本地文本解析、确定性输出、零依赖，可用固定向量验收（覆盖各类型、嵌套数组、中文多字节字符串长度按字节计算）。边界：池内已有的 env / INI / .properties / JSONC / Bencode / CBOR / MessagePack / NDJSON 转换器均面向其他数据格式；PHP serialize 特有的「类型前缀 + 长度前缀 + 花括号结构」语法无任何在池或已实现工具覆盖，不构成重复。
