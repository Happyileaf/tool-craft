## 描述

以结构化参考表呈现 HTTP 标准请求方法（GET、HEAD、POST、PUT、DELETE、CONNECT、OPTIONS、TRACE、PATCH）的语义、RFC 来源、安全性（safe）、幂等性（idempotent）、是否允许请求体、典型用途与常见误用，并对比 PUT 与 PATCH、POST 创建与 PUT 创建的区别，补齐现有 http-status-codes、well-known-ports 等速查家族中方法维度的空白。

## 设计内容（进入 Claimed 前补全）

- 单页纯前端静态参考工具，数据依据 RFC 9110/9111/5789 内置。
- 主表列：方法、语义说明、Safe、Idempotent、可缓存（Cacheable）、是否允许请求体、RFC 来源、典型场景。
- 方法详情卡：展开后含请求/响应示例片段（纯文本展示，不实际发请求）、常见状态码搭配（如 POST→201、DELETE→204）。
- 专题对比区：PUT vs PATCH（整体替换与部分更新）、POST vs PUT 的幂等与 URI 决策、OPTIONS 与 CORS 预检的关系。
- 顶部支持按方法名与关键字（如"幂等"）搜索过滤；safe/idempotent 以醒目标签可视化。
- 边界情况：搜索无结果空状态；明确标注 PATCH 本身不保证幂等取决于媒体类型；说明 CONNECT/TRACE 的安全注意事项。
- 不在范围：实际发起 HTTP 请求、状态码大全（http-status-codes 已覆盖）、请求头解析（header-parser 已覆盖）。
