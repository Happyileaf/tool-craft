## 描述

在 UTF-8 文本与十六进制表示之间双向转换，并以经典 hex dump（偏移量 | 十六进制字节 | ASCII 预览）视图展示二进制内容，支持可选 `0x` 前缀、分隔符与大小写，用于协议调试、文件头识别和逆向分析。`number-base-converter` 只对单个整数做 2/8/10/16 进制互转与位运算，`base32` / `base64` 是按编码表的整体编解码，均不提供「字节序列 ↔ 十六进制串」与转储视图。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：UTF-8 文本 ↔ 十六进制字节串双向转换 + 经典 hex dump 视图，工具 slug 拟为 `hex-dump-viewer`。
- **编码（文本→Hex）**：文本经 TextEncoder 编码为 UTF-8 字节，输出十六进制；支持大小写、可选 `0x` 前缀、字节分隔符（无 / 空格 / `0x` 每字节）。
- **解码（Hex→文本）**：容忍空白、`0x` 前缀、冒号 / 连字符等分隔，按 TextDecoder 还原 UTF-8；奇数个 hex 位或非法字符给出明确错误。
- **Hex dump**：每行 16 字节，列含 8 位十六进制偏移、字节区（前 8 / 后 8 分组）、ASCII 预览（不可打印字节显示 `.`）。
- **核心交互**：方向切换（编码 / 解码）、大小写 / 前缀 / 分隔选项、输入即时转换、复制 / 载入示例。
- **输入输出**：纯函数 `utils/hex.ts`（encode/decode/formatDump），不触碰 DOM / React；TextEncoder 以函数参数或工具函数形式封装以便单测。
- **边界情况**：空输入返回空；非法 hex（奇数长度、非 hex 字符、UTF-8 非法序列）返回明确错误而非抛异常。
