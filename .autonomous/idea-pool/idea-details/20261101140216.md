## 描述

实现 TypeID 规范（[github.com/jetify-com/typeid](https://github.com/jetify-com/typeid)，Stripe API 风格的类型化 UUID 前缀标识符）：生成侧输入类型前缀（如 `user`）与可选 UUIDv7，输出 `user_01h455vb4pex5vsknk084sn02q` 形态字符串；解析侧校验前缀（小写字母、数字、下划线，≤63 字符）、分隔符、Base32（Crockford 字母表，26 字符后缀）解码与 UUID 版本/变体合法性，拆解出类型前缀与内嵌 UUID 并提取 UUIDv7 时间戳。典型场景：设计新系统的对外 ID 方案时在线试算、核对存量 ID 是否合法。纯本地编解码、确定性输出、零依赖，可用官方规范测试向量验收。边界：`nano-id-generator` 生成随机短串、`ulid-generator` / `uuid-v7-generator` 生成裸 UUID/ULID、`base32-codec` 是通用 Base32 编解码、`uuid-inspector` 只解析裸 UUID——均不含「类型前缀 + `_` + Crockford Base32 编码 UUID」的组合编解码与整套合法性规则，TypeID 是独立标识符格式，不构成重复。

## 设计内容

- **功能范围**：TypeID 生成（类型前缀 + 内嵌 UUIDv7，随机源用浏览器原生 `crypto.getRandomValues`）与解析（拆前缀/后缀、Crockford Base32 解码 16 字节 UUID、校验版本 variant、提取 v7 毫秒时间戳），slug 为 `typeid-codec`。
- **核心交互**：生成区输入前缀、可选指定 UUID 种子，输出 TypeID 并可复制/批量；解析区粘贴 TypeID，输出前缀、内嵌标准 8-4-4-4-12 UUID、版本/变体、v7 时间戳对应的 UTC 时间，错误逐条告警。
- **输入输出**：纯函数 `encodeTypeid(prefix, uuidBytes)` / `decodeTypeid(text)` / `generateTypeid(prefix)`，编解码不触碰 DOM；仅随机字节读取 crypto。
- **边界情况**：前缀必须全小写 `[a-z][a-z0-9_]*` 且 ≤63 字符、首字符为字母；后缀严格 26 字符 Crockford 字母表（无 I/L/O/U）；空前缀（裸后缀）合法；非法分隔符/长度/字符/UUID version-variant 报错并定位；v7 时间戳 48 位提取。
- **零依赖**：Base32 与 UUID 组包全部本地实现，不新增 npm 包。
