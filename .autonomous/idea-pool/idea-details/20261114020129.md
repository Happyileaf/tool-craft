## 描述

通过表单拼装规范的 CSS `@font-face` 规则：填写 font-family 名称，选择字重（100–900 或 normal/bold）、font-style（normal/italic/oblique）、font-display（auto/block/swap/fallback/optional）、unicode-range 与 local() 备选名，按添加顺序组织 `src` 列表（`local()` 在前、`url('...') format('woff2')` 在后，覆盖 woff2/woff/ttf/otf/eot/svg 格式），实时输出可复制的 CSS 代码，并对常见错误给出校验提示（如缺少 src、format 与扩展名不一致、font-weight 非法值）。支持同时管理多组字重/样式声明并统一输出。现有 `css-unit-converter`、`box-shadow-generator`、`gradient-generator` 等 CSS 生成器均不涉及字体声明；registry 全文检索 font / woff / 字体无相关工具，活动池、completed.md、rejected.md 亦无 @font-face 条目。纯字符串拼装与固定格式映射，零依赖、主线程，S 级。
