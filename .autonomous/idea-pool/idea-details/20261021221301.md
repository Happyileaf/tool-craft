## 描述

拖拽或选择本地文件，在浏览器内基于 Web Crypto（`crypto.subtle.digest`）流式计算文件的 MD5 / SHA-1 / SHA-256 / SHA-512 校验和，并支持粘贴期望值做一致性比对（含大小写、空白归一化），用于校验下载文件完整性。现有 `hash-generator` 与 `crc32-checksum` 只接收**文本字符串**输入、无文件入口，`base64-codec` 的文件拖放只做编码转换而非摘要；本工具补齐「对文件本身取摘要 + 比对」的空白，全程不上传文件。
