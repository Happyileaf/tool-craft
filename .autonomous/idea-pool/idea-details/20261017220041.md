## 描述

在 1–3999 范围内完成整数与罗马数字的双向精确转换，支持标准加减法记法（IV、IX、XL、XC、CD、CM 等），对越界数值或非法罗马数字输入给出明确错误提示，并支持批量逐行转换。用于文档编号、年份、章节标题等场景的罗马数字书写。现有 number-base-converter 仅覆盖二进制 / 八进制 / 十进制 / 十六进制的互转与位运算，不涉及罗马数字体系；工具集中也无任何罗马数字能力。基于固定值 / 符号表的纯函数转换与校验实现，零新增运行时依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：标准罗马数字（1–3999）双向转换，工具 slug 拟为 `roman-numeral-converter`。
- **整数 → 罗马**：按 1000/900/500/400/…/1 的「值-符号」降序表贪心匹配，输出标准减法记法（IV/IX/XL/XC/CD/CM）。
- **罗马 → 整数**：逐字符查表，若当前字符值小于右侧字符值则减去，否则累加；同时严格校验合法性（字符集、重复规则、减法组合、数值范围），拒绝如 `IIII`、`VX`、`MMMM` 等非法写法。
- **批量模式**：逐行输入，每行独立转换并输出结果或错误。
- **输入输出**：纯函数，不触碰 DOM / React；输入罗马数字容忍大小写与首尾空白。
- **边界情况**：0、负数、>3999、非整数、空字符串给出明确错误；数字与罗马双向转换互为逆运算。
