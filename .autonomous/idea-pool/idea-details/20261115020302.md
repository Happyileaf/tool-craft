## 描述

在字符（0–9、A–F 及常用符号）与七段数码管段码之间双向转换：输出 a–g + dp 各段的有序位掩码（可自定义段序与位序），同时给出共阴极（段码高电平点亮）与共阳极（取反）两种十六进制/二进制字节值，并用 SVG 实时渲染对应字形预览；支持反向输入段码或十六进制字节，识别其对应字符并列出所有可行字形。面向单片机 / FPGA / 数码管模块开发者，替代手查段码表与手算取反，纯本地查表与位运算，零依赖。
