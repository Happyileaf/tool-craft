## 描述

面向嵌入式/信号处理开发者，在 Qm.n 有符号定点格式与小数之间双向转换：选择总位宽（如 16/32）与小数位数 n，给出二/十六进制补码表示、精度（2^-n）、可表示范围与饱和边界，并可视化定点乘法/加法的缩放（结果 Q 格式）、舍入与溢出行为。纯整数/补码运算，本地完成，零依赖。与 `ieee754-float-converter`（浮点二进制表示）、`number-base-converter`（进制互转）目标不同，后者不处理定点 Q 格式的小数位定标与运算语义。

## 设计内容

- **功能范围**：小数 ↔ Qm.n 双向转换（总位宽 8/16/32 可选，小数位 n 可调，m=位宽−n−1），输出二/十六进制补码、量化误差、精度 2^-n、最大/最小可表示值与饱和边界；并演示 Q 格式加法与乘法的定标、舍入（截断/四舍五入）与溢出标记，slug 为 `fixed-point-q-converter`。
- **核心交互**：位宽 Radio + 小数位 InputNumber + 十进制小数输入框，即时输出补码表示与元信息；运算区输入两个 Q 值与运算符，展示真实整数运算过程、结果 Q 格式与是否饱和。
- **输入输出**：纯函数 `floatToFixed(value, bits, fracBits)` / `fixedToFloat(raw, bits, fracBits)` / `fixedAdd` / `fixedMul`，基于 BigInt/Number 整数运算，不触碰 DOM。
- **边界情况**：n 必须满足 0≤n≤bits−1；超出可表示范围按饱和处理并明确提示；负数补码表示正确；乘法结果位宽为两操作数位宽之和，按目标 Q 格式右移定标并标注舍入误差；除零等非法运算报错。
- **零依赖**：纯整数/补码数学，不新增 npm 包。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] Q15（16 位、15 小数位）向量：0.5 → raw 0x4000（16384）、-1 → raw 0x8000（-32768）、0.999969… 为最大正值 0x7FFF；反向解码逐值一致。
- [ ] 精度 = 2^-n、范围 [−2^m, 2^m − 2^-n] 公式输出正确；越界输入触发饱和并返回边界值与告警标记。
- [ ] Q15 加法：0.5+0.25=0.75（raw 24576=0x6000）；溢出正数相加返回饱和值并标记 overflow。
- [ ] Q15 乘法：0.5×0.5，32 位乘积右移 15 定标后得 0.25（raw 0x2000），舍入模式（截断/最近）结果与误差可断言。
- [ ] 负数补码双向转换、8/16/32 三位宽切换均正确；非法 n 抛出明确错误。
- [ ] 纯浏览器本地运算，无任何网络请求，无新增 npm 依赖。
