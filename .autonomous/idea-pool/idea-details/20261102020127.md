## 描述

计算一阶 RC 低通 / 高通滤波器的核心参数：截止（-3 dB）频率 fc = 1 / (2πRC)、时间常数 τ = RC，并支持"知二求三"——给定 fc 与 R 求 C、给定 fc 与 C 求 R、给定 R 与 C 求 fc。电阻支持 Ω/kΩ/MΩ、电容支持 pF/nF/µF/uF/F 单位自动换算与 SI 前缀输出；同时给出角频率 ω=2πfc、该截止频率处的幅度增益 1/√2（约 -3.01 dB）与相位偏移（低通 -45° / 高通 +45°）。典型场景：硬件/嵌入式调试时去耦电容与上拉电阻取值、音频 RC 滤波、ADC 前端抗混叠一阶估算、面包板选型快速核对。纯本地确定性公式计算，零依赖，可用教材标准向量验收（如 R=1kΩ、C=1µF → fc≈159.15 Hz、τ=1 ms）。边界：只覆盖**一阶** RC 低通/高通（Sallen-Key、RLC 二阶、有源滤波器不在范围）；与现有 `ohms-law-calculator`（V/I/R/P 知二求二的直流欧姆定律与功率）不同——本工具围绕频率域的 R·C 乘积与传递函数截止点，输入量（C、fc、τ）与公式完全不同，不构成重复；池内无 RC / 截止频率 / 时间常数类条目。
