## 描述

SDP（RFC 8866）是 SIP、WebRTC（RTCPeerConnection）、RTSP 等场景描述媒体会话的标准文本协议，手写或排查 `v=/o=/s=/t=/m=/a=` 行时容易出现字段顺序、连接地址、payload type、ICE/DTLS 属性不一致等问题。本工具提供双向能力：① 解析模式——粘贴 SDP 文本，按会话级/媒体级分层展示字段树，校验必填行、行顺序、`m=` 端口与协议、`a=rtpmap`/`a=fmtp` 与 payload 编号的对应关系，标注 ICE（`a=candidate`/`ice-ufrag`）、DTLS 指纹、`bundle`/`rtcp-mux` 等 WebRTC 必备属性缺失或不一致；② 生成模式——选择音频/视频媒体、codec、传输模式（UDP / SRTP / DTLS-SRTP）与候选信息，输出符合 RFC 8866 行序的 SDP 文本，并可对两份 SDP 做 offer/answer 差异比对（媒体方向、codec 交集、端口协商）。现有协议类工具覆盖 HTTP、SIP 之外的 DNS/TLS/RTSP 等报文，但没有任何 SDP 文本编解码能力；四源查重全文检索「SDP / 会话描述 / Session Description / offer answer」在活动池、completed.md、rejected.md 与已注册工具中零命中。纯本地文本解析与规则校验、零新依赖、固定 SDP 样本向量可验收，符合红线。
