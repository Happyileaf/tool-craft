## 描述

实现 QOI 规范（qoi.h，公开免费规范）的无损编解码：将 RGBA 像素数据（或小型 PNG 经 Canvas 解出的像素）编码为 `.qoi` 文件并下载，反向把上传的 `.qoi` 解码为 RGBA 字节并预览；完整覆盖 QOI_OP_RGB / RGBA / INDEX / DIFF / LUMA / RUN 六种操作码与 14 字节文件头、0x00000001 结束标记，输出原始大小、压缩后大小与压缩率。QOI 规范极简（参考实现约 300 行）、无专利限制，适合零依赖手写并以官方固定向量断言。现有 `gzip-codec`/`messagepack-codec`/`rle-packbits-codec` 面向其他编码格式，`image-data-uri-converter`/`image-resizer` 不做编解码算法。纯本地计算，零依赖，M 复杂度。
