## 描述

在纯文本与 JavaScript / JSON、Python、Java 等语言的字符串字面量之间做转义与反转义（`\n`、`\t`、`\uXXXX`、引号等），便于把多行文本嵌入代码，或把日志中的转义串还原为可读明文。现有 `html-entity-codec` 只处理 HTML 实体（`&amp;` 等），`line-operations` 只处理整行操作，均不覆盖编程语言层面的字符串字面量转义，存在明确功能空白。

## 设计内容（进入 Claimed 前补全）

- **slug**：`string-escape`；分类 DEV_CODE；主线程同步运算；图标 FileCode。
- **纯函数层** `tools/string-escape/utils/escape.ts`：
  - 导出 `LANGUAGE_JS` / `LANGUAGE_PYTHON` / `LANGUAGE_JAVA`、`EscapeLanguage`、`UnescapeResult { text, error }`、`escapeString(text, language)`、`unescapeString(text, language)`、`stripQuotes(text)`。
  - 转义矩阵：通用短转义（`\b \f \n \r \t \" \\`）；JS 额外支持 `\/ \v \`` 与 `\u{码点}`；Python 额外支持 `\xHH`、`\Uxxxxxxxx`、`\a \v \' \0` 与反斜杠行连接；Java 额外支持 `\'`，Unicode 仅 `\uXXXX`。
  - `escapeString`：转义引号 / 反斜杠 / 短控制符；其余控制字符 Python 用 `\xHH`、其他语言用 `\uXXXX`；非 ASCII 一律 `\uXXXX`，astral 码点（如 emoji）拆成 UTF-16 高 / 低代理两个转义；可打印 ASCII 原样输出。
  - `unescapeString`：手写扫描器逐字符解析反斜杠序列；短转义按语言矩阵查表；`\xHH` / `\Uxxxxxxxx` 仅 Python；`\u{...}` 仅 JS；`\uXXXX` 三语言通用，高代理后随低代理时合并还原；孤立代理半片替换为 U+FFFD；非法 / 截断序列与末尾孤立反斜杠返回 `{ error }` 而非抛异常。
  - `stripQuotes`：去除首尾成对的 `"` / `'` / `` ` `` 包裹（反转义粘贴字面量时使用）。
- **测试** `utils/escape.test.ts`（30 个用例）：基础转义、多行变单行、短控制符、非 ASCII 与 emoji 代理对、Python `\x` / `\U` 差异、NUL / DEL、可打印 ASCII、空串；反转义短序列 / 代理对合并 / 三方言专有序列、Java 拒绝 `\x` 与 `\u{}`、孤立反斜杠、位数不足、`\u{}` 缺闭合或超码点、孤立高代理 → U+FFFD；三语言往返等价；stripQuotes 四种引号情形。
- **UI** `index.tsx` + `constants.ts` + `index.module.css`：转义 / 反转义方向 Radio、语言 Select（JS/JSON、Python、Java，带方言提示）、转义时「包裹引号」与反转义时「剥离外层引号」Checkbox、双栏 TextArea 实时联动、载入示例 / 清空 / 复制结果、错误 Result 面板与当前语言方言提示。
