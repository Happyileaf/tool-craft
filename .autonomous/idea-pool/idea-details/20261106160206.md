## 描述

检测文本是否以 UTF-8 BOM（U+FEFF，字节 EF BB BF）开头，支持一键添加或剥离开头 BOM，并给出 BOM 存在状态、文本字节大小（按 TextEncoder UTF-8 编码计算）与处理前后字节差；同时对文本内部（非开头）出现的 U+FEFF 做识别提示。纯本地运算，零新增依赖。

## 设计内容（进入 Claimed 前补全）

- 功能范围：
  - 检测：判断开头是否为 U+FEFF；扫描全文统计内部 U+FEFF 出现次数。
  - 添加：开头无 BOM 时在字符串前插入 U+FEFF；已有 BOM 不重复添加（幂等）。
  - 剥离：仅移除开头的一个 U+FEFF；可选移除全文所有 U+FEFF。
  - 展示处理前后 UTF-8 字节数与差值（BOM 固定 3 字节）。
- 核心交互：文本框输入；单选操作模式（自动检测 / 添加 BOM / 剥离开头 BOM / 剥离全部 U+FEFF）；结果区只读文本 + 复制按钮 + 状态 Tag。
- 输入输出：输入任意文本；输出处理后文本、BOM 状态、字节统计。
- 边界：空文本、仅含 BOM 的文本、内部含 U+FEFF（零宽不换行空格）的提示、添加操作的幂等性。
- 不做：不处理 UTF-16/UTF-32 BOM（文本框无法承载其字节语义），不做文件下载（与 line-ending-converter 保持纯文本定位）。
