## 描述

在浏览器本地完成 CBOR 二进制数据与 JSON / CBOR 诊断记法（diagnostic notation）之间的双向转换：支持 RFC 8949 主要类型（整数、字节串、字符串、数组、map、布尔/null、半/单/双精度浮点、简单值、标签 tag 如标准日期时间/大整数 bignum、indefinite-length 流式编码），输入支持十六进制 / Base64 / 文件，输出展示编码字节、逐项类型标注与可读 JSON；JSON→CBOR 支持选择确定性编码（canonical/CTAP2 风格）。解决 IoT、COSE/WebAuthn、FIDO、区块链等场景下需要快速读懂或生成 CBOR 报文的问题。纯本地字节运算（DataView / TextDecoder UTF-8）、零新增依赖，范围限定 RFC 8949 核心编码与常用标签，可用 RFC 附录中的官方编码示例做双向固定向量断言验收。查重：registry 已有 Base16/32/45/58/62/85/91、Bencode、MessagePack（pending `20261026140924`）、VarInt/LEB128 等多种编解码器，但没有 CBOR / RFC 8949 / COSE 相关条目；MessagePack 与 CBOR 是两套不同规范（类型系统、标签、确定性规则不同），不构成重复。
