## 描述

以可搜索、按请求/响应/表示/缓存/CORS/安全分类的参考表，呈现常用 HTTP 头字段（如 `Content-Type`、`Authorization`、`Cache-Control`、`ETag`、`Access-Control-Allow-Origin`、`Content-Security-Policy` 等）的用途、方向（请求头/响应头/两者）、取值语法、示例与禁止的首部类型（forbidden header name），与现有 header-parser（解析实际报文）互补，专注字段含义查阅。

## 设计内容（进入 Claimed 前补全）

- 单页纯前端静态参考工具，条目数据依据 MDN / RFC 9110 系列内置，无外部请求。
- 收录约 50–60 个高频头字段，每条含：名称、方向标签（请求/响应/通用）、分类、一句话说明、取值语法或枚举、示例、关联 RFC/标准、常见坑（如 `Pragma` 已被 `Cache-Control` 取代）。
- 分类：通用与表示（General/Representation）、请求、响应、条件请求与缓存、认证与 Cookie、CORS、安全（CSP/HSTS/X-Frame-Options 等）、内容协商。
- 顶部搜索：按头名称（不区分大小写、支持连字符模糊）与关键字过滤；分类筛选器与方向标签联动。
- 点击条目展开详情并一键复制头字段名称；对禁止修改的首部（forbidden request header name，如 `Host`、`Origin`）加醒目标记。
- 边界情况：搜索无结果空状态；明确标注废弃/受限头（如 `X-Frame-Options` 与 CSP `frame-ancestors` 的关系）；不做实际报文解析。
- 不在范围：报文解析（header-parser 已覆盖）、缓存指令详解（cache-control-analyzer 已覆盖）、内容协商排序（content-negotiation-parser 已覆盖）、CORS 预检流程演示。
