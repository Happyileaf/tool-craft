## 描述

输入共同祖先版本（base）、我方版本（ours）、对方版本（theirs）三段文本，执行基于行的三路合并（diff3 语义）：先分别对 base↔ours、base↔theirs 求 LCS 行级差异，再逐区块合并——仅一方修改的区块直接采纳、双方一致修改采纳一次、双方对同一区块做了不同修改则标记为冲突，并输出标准冲突标记块（`<<<<<<<` / `=======` / `>>>>>>>`），同时支持 diff3 风格在冲突中展示 base 区块（`|||||||`）。界面提供冲突区块的逐块「采纳我方 / 采纳对方 / 保留双方 / 手动编辑」解决交互与最终合并结果复制，并统计自动合并行数与冲突数。全部在浏览器本地完成，核心为 LCS 动态规划的纯函数实现，零新增依赖。与现有 text-diff（只做两段文本的双向高亮对比，不产出合并结果、无冲突标记）有本质区别：本工具解决「共同祖先 + 两个分支」的三方合并与冲突消解，是其能力之外的新场景。
