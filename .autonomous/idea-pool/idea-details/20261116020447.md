## 描述

输入自定义数组或随机生成数据，逐步演示冒泡、选择、插入、归并、快速排序的执行过程：每一步标出当前比较的两个元素、是否交换、已定位的有序区间与递归/分区边界，并实时统计比较次数与交换（或移动）次数，与理论复杂度（最好 / 平均 / 最坏）对照。用于算法学习、教学演示与面试复习；排序步骤由纯函数生成，可暂停、单步前进/后退与调速播放，纯本地运行。

## 设计内容（进入 Claimed 前补全）

功能范围：五种算法（可多选对比各自步数）；数组长度限制（如 4–40）与元素值范围；「随机 / 自定义 / 已有序 / 逆序」四种初始数据；每步事件类型（比较、交换、赋值/移动、区间标记、完成）与可选说明文案；统计面板（比较次数、交换/移动次数、步数）与复杂度对照表。

核心交互：数组条块可视化（值映射高度与位置，比较高亮、交换动画、已排序区置灰或着色）、播放控制（播放/暂停、上一帧/下一帧、重置、速度滑块）、算法与初始数据切换、步骤日志列表。

输入输出：输入数组与算法选择；输出逐步帧序列（每帧含数组快照、高亮索引、事件类型与累计计数）以及最终有序数组和统计结论。

边界情况：空数组与单元素数组直接完成（0 次比较）；重复值按稳定 / 不稳定如实标注；归并排序展示辅助数组与合并过程；快速排序展示基准选取与递归区间；负数与小数排序按数值比较；超大数组给出长度提示并拒绝生成过多帧。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 输入 `[5,3,1,4,2]` 用冒泡排序，最终快照为 `[1,2,3,4,5]`，比较次数为 10（固定向量）
- [ ] 插入排序对已有序数组 `[1,2,3,4]` 的比较次数为 3，体现最好情况
- [ ] 归并 / 快排的每帧均可回放并自动核对：按帧顺序应用事件后得到正确有序数组
- [ ] 选择排序的交换次数不超过 n-1，且在固定向量上给出确定值
- [ ] 空数组与单元素数组不报错，帧数为 1 且比较次数为 0
- [ ] 含重复值的数组排序后顺序满足对应算法稳定性描述（稳定算法保持相同值相对次序）
