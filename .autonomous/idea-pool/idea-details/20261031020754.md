## 描述

粘贴 JSON 样本，推断类型并生成可直接使用的 Rust 结构体定义：标量映射为对应类型（整数优先 `i64`、浮点 `f64`、布尔 `bool`、字符串 `String`、null 退化为 `Option<…>`），对象生成嵌套 `#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]` 的 struct，数组按元素推断（同型取元素类型 `Vec<T>`、异型或空数组标记待确认），字段默认使用 snake_case 并通过 `#[serde(rename = "原键名")]` 保留 JSON 原始键，自动处理重复结构体内命名与非法标识符，输出可复制代码。解决 Rust 后端开发中为 JSON 接口手写 serde 结构体繁琐、rename 易漏的问题。纯 JSON 解析 + 确定性类型推断与代码模板生成、零新增依赖、纯本地运算，可用固定 JSON 样本做输出快照验收。查重：已注册的 json-to-typescript 只输出 TypeScript interface；池内 json-to-go（`20261030140201`）、json-to-python-dataclass（`20261030200910`）、json-to-zod（`20261030021006`）均面向其他语言，无 Rust；rejected 的 `20261021180801`（多语言模型一次覆盖 Go/Python/Java/C#）因整体范围达 L 级被拒，并明确「单语言子集拆分后才可重新评估」，本条即该规则下的单一语言子集，不构成重复。
