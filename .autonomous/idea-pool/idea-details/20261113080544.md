## 描述

在 C99/C++17 十六进制浮点字面量（如 `0x1.8p+1`、`0x1p-4`、`-0x1.f4p+3`）与普通十进制数值（`3.0`、`0.0625`）之间双向转换，并展示其内部的符号、十六进制尾数、2 的幂指数三段结构与等价二进制科学计数法。开发者在阅读 C/C++ 调试输出（`%a` 格式）、Java `Double.toHexString`、精确浮点测试向量时，常需要核对 hexfloat 的真实数值，而普通进制转换工具只能处理整数、IEEE754 工具只展示内存位级 hex（如 `3FF0000000000000`），均不能解析带 `p` 指数的 hexfloat 字符串。该工具填补这一空白，纯本地确定性计算、零新增依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：实现 IEEE 754 double 精度下 hexfloat 字符串 ↔ 十进制数的双向转换，工具 slug 拟为 `hexfloat-converter`。
- **核心算法**：
  - 解析方向：手写扫描器拆分可选符号、`0x` 前缀、十六进制尾数（含小数点）、`p` 后的十进制有符号指数；按 `value = (-1)^s × mantissa × 2^exp` 精确求值，全程用 `Number` / 必要时 BigInt 保证整数尾数精确，避免中间舍入误差。
  - 生成方向：从十进制 number 出发，取其 IEEE754 表示，还原出最短（或规范化）的 `0x1.xxx p±n` hexfloat 形式，正确处理 0、负数、Infinity、NaN、subnormal 次正规数。
- **结构化展示**：分段呈现符号位、十六进制有效数、二进制指数、等价十进制值，以及与内存 hex（`3FF...`）的对照，帮助理解 `%a` 输出。
- **核心交互**：方向切换（hexfloat→十进制 / 十进制→hexfloat）、输入即时转换、错误提示、复制 / 载入示例。
- **输入输出**：纯函数 `utils/hexfloat.ts`，不触碰 DOM / React，便于单测。
- **边界情况**：空输入返回空；非法字符、缺指数、截断的 `0x1.` 等返回明确错误而非抛异常；次正规数与 ±0、±Infinity、NaN 有确定输出；大小写 `0X` / `P` 不敏感；往返（round-trip）数值一致。

## 验收标准

- [ ] `0x1.8p+1` → `3`、`0x1p-4` → `0.0625`、`-0x1.f4p+3` → 十进制 `-15.625`（`0x1.f4 = 1 + 0xf4/256 = 1.953125`，再 ×2³ = ×8）等固定向量正确。
- [ ] 十进制→hexfloat：`3.0` → `0x1.8p+1`、`0.1` 给出其精确 hexfloat 表示（`0x1.999999999999ap-4`），与 C `%a` / Java `toHexString` 一致。
- [ ] 正确处理次正规数、±0、负数、Infinity、NaN；非法输入（如 `0x1.p`、`0xggp1`）返回可读错误而不抛异常。
- [ ] 任意合法 double 往返转换数值严格相等；核心逻辑为纯函数并配单元测试，纯本地计算、零新增依赖、主线程即时完成。
