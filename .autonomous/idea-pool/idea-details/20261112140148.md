## 描述

实现 RFC 6570 URI Template 的 Level 1–4 展开：输入 URI 模板（如 `https://api.example.com/{+path}{?q,page,limit}`）与一组变量值（字符串、列表、关联数组），按表达式类型（简单 `{var}`、保留 `{+var}`、片段 `#`、点 `.`、路径 `/`、路径参数 `;`、查询 `?`、查询续接 `&`）和运算符规则展开为完整 URI，并正确处理 `pct-encoding`（保留字符 vs 需编码字符）、长度限制 `{var:3}`、列表与键值对的分隔符及空值/未定义变量省略规则；支持反向从示例 URI 提取变量值的辅助校验。纯字符串算法、零新增依赖，S–M 复杂度，纯函数可用 RFC 6570 附录的官方测试向量验收。

## 设计内容（进入 Claimed 前补全）

- 工具目录：`apps/web/src/tools/uri-template-expander/`（index.tsx + index.module.css + constants.ts + utils/uri-template.ts + utils/uri-template.test.ts）。
- 核心纯函数（utils/uri-template.ts）：
  - `expandUriTemplate(template, variables)`：正则扫描 `{…}` 表达式，按操作符表（8 种操作符的 first/separator/reserved/named/emptyName 规则）逐变量展开；输出 `{ uri, valid, errors }`。
  - 百分号编码按 RFC 3986 unreserved 逐 UTF-8 字节处理；`+`/`#` 保留 sub-delims 与 `:/@?`；前缀截断按 Unicode 码点（Array.from）。
  - 复合值：数组/对象支持普通逗号拼接与 explode（`*`），命名操作符下输出 `key=value` 形式。
  - `extractTemplateVariables(template)`：提取去重变量名供 UI 标签与缺失提示。
- UI（Ant Design）：模板 TextArea（自动列出引用变量，缺失红色 Tag）、变量 JSON TextArea（语法校验）、实时展开结果 Alert（可复制）、操作符速查 Table。
