## 描述

实现 RFC 6570 URI Template 的 Level 1–4 展开：输入 URI 模板（如 `https://api.example.com/{+path}{?q,page,limit}`）与一组变量值（字符串、列表、关联数组），按表达式类型（简单 `{var}`、保留 `{+var}`、片段 `#`、点 `.`、路径 `/`、路径参数 `;`、查询 `?`、查询续接 `&`）和运算符规则展开为完整 URI，并正确处理 `pct-encoding`（保留字符 vs 需编码字符）、长度限制 `{var:3}`、列表与键值对的分隔符及空值/未定义变量省略规则；支持反向从示例 URI 提取变量值的辅助校验。纯字符串算法、零新增依赖，S–M 复杂度，纯函数可用 RFC 6570 附录的官方测试向量验收。
