## 描述

实现 basE91 编码方案（由 Joachim Henke 提出的 91 个可打印 ASCII 字符字母表），支持文本与十六进制 / 原始字节输入双向编解码。相比 Base64，basE91 在相同内容下编码体积约再减少 8%–10%，常见于二进制数据紧凑传输、特定配置与逆向 / CTF 场景。与已实现的 base64 / base32 / base45 / base58 / base62 / ascii85 系列同属编码工具，但字母表与算法不同（basE91 使用可变的 13/14 bit 分组与除法余数机制），现有工具均不覆盖该格式。全部为确定性字节运算，纯函数实现，零新增依赖，可用官方测试向量验收。
