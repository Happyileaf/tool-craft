## 描述

按 RFC 9562 批量生成 UUID v7：48 位 Unix 毫秒时间戳 + 版本 / 变体位 + 随机位，生成结果附时间戳标注，支持大写 / 连字符格式选项。v7 前缀时间有序，作为数据库主键可改善索引写入局部性、替代「v4 主键 + 独立创建时间列」的组合，后端建表场景需求明确。现有 uuid-generator 仅批量生成 v4（纯随机、无序）；池内 20261021221302 为 UUID 解析校验器（解析既有 UUID、不生成）、20261017160148 为 ULID 生成器（另一套 Crockford Base32 编码 ID 体系），定位互不重复。时间戳拼接与随机位生成均在本地完成（crypto.getRandomValues），零新依赖、纯本地。
