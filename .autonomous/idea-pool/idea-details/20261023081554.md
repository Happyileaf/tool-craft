## 描述

按 RFC 9562 批量生成 UUID v7：48 位 Unix 毫秒时间戳 + 版本 / 变体位 + 随机位，生成结果附时间戳标注，支持大写 / 连字符格式选项。v7 前缀时间有序，作为数据库主键可改善索引写入局部性、替代「v4 主键 + 独立创建时间列」的组合，后端建表场景需求明确。现有 uuid-generator 仅批量生成 v4（纯随机、无序）；池内 20261021221302 为 UUID 解析校验器（解析既有 UUID、不生成）、20261017160148 为 ULID 生成器（另一套 Crockford Base32 编码 ID 体系），定位互不重复。时间戳拼接与随机位生成均在本地完成（crypto.getRandomValues），零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- slug：`uuid-v7-generator`，分类 CRYPTO_ENCODING，主线程，零新增依赖。
- 纯函数 `generateUuidV7(timestampMs?)`：按 RFC 9562 写 48 位大端毫秒时间戳、版本位 7、变体位 10、12 位 rand_a 与 62 位 rand_b；随机数来自 crypto.getRandomValues；字节数组算术实现（不使用 BigInt 字面量，兼容 ES2020 以下编译目标）；返回 uuid/timestampMs/isoTime/fields/valid/error。
- `generateBatch(count, timestampMs?)`：数量夹紧 1..1000，非法返回 []；同毫秒 rand_b 加一、溢出进位 rand_a、74 位占满重新随机，保证批内唯一且严格字典序递增。
- `inspectUuidV7(input)`：容忍空白/花括号/urn:uuid:/大写；校验 36 位、hex、版本 7、变体位 8/9/a/b；反解时间戳与 rand 段。
- UI：顶部数量控制+生成/复制全部，左栏批量结果，右栏 Descriptions 反解首个 UUID。
- 边界：时间戳超 48 位、空输入、v4 串、非法变体均中文报错。
