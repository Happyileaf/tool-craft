## 描述

统计粘贴文本中各单词（支持中文按字 / 按分词两种简单模式）的出现次数与频率，输出可排序的词频表、停用词过滤与 Top N 结果，可导出 CSV，用于文案分析、日志关键词排查、SEO 关键词梳理。`word-count` 仅给出字符 / 词 / 行 / 段落总数，`line-operations` 只做整行排序去重，均不提供逐词频次与高频分析。

## 设计内容（进入 Claimed 前补全）

- slug：`word-frequency`，分类 TEXT_CONTENT，主线程处理，零新依赖。
- 纯函数模块 `utils/frequency.ts`：`tokenize`（Unicode 字母数字拉丁词，支持撇号 / 连字符；CJK 模式逐字，bigram 模式相邻汉字二元组；纯数字片段不计词）/ `parseStopWords` / `countWords`（计数 + 频率，频率分母为停用词过滤后的有效词次）/ `sortWords`（次数升降序、字母序、同次数按词字典序稳定排序，Top N 截取）/ `toCsv`（RFC 4180 风格转义）。
- UI：Ant Design 三 Card（输入 / 选项 / 结果），Radio.Group 切换分词模式与排序，Switch 控制内置英文停用词，Input 填自定义停用词与 Top N，Table 展示词、次数 Tag、频率百分比与归一化条形，支持复制 CSV 与下载 .csv（Blob 本地导出）。
- 边界：空文本统计为 0 且不除零；空结果显示 Empty；停用词输入支持逗号 / 空白混合分隔，拉丁词统一小写匹配。
