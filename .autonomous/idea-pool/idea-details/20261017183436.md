## 描述

按 1xx / 2xx / 3xx / 4xx / 5xx 分类速查 HTTP 状态码的含义、典型触发场景与排错建议，支持按编号或关键词搜索。现有开发工具集中无 HTTP 协议参考类能力，而前后端联调时频繁需要查阅状态码语义。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：HTTP 状态码参考速查，工具 slug 拟为 `http-status-codes`。
- **数据**：内置静态数据表，覆盖 IANA 注册的常见 1xx–5xx 状态码（编号、英文 Reason-Phrase、中文含义、分类、典型场景、排错建议/是否可重试）。
- **检索**：支持按编号精确 / 前缀过滤与关键词（中英文名称、短语）模糊搜索；按类别（1xx/2xx/3xx/4xx/5xx）分组展示。
- **核心交互**：搜索框实时过滤 + 类别筛选；点击条目展开详情。
- **输入输出**：检索逻辑为纯函数，不触碰 DOM / React，零新增依赖，无网络请求。
- **边界情况**：无匹配时给出空状态提示；非法输入不抛异常。
