## 描述

实现 Google Open Location Code（Plus Codes）双向转换：经纬度坐标 → plus code（支持指定码长与含参考位置的短码 shortening），plus code → 经纬度编码区域（中心、四角边界与精度），并对非法字符、长度与分隔符位置做合法性校验。解决没有街道门牌地区分享位置、物流与户外场景定位的问题；算法为确定性的 Base20 格网编码，纯函数实现、零依赖，可直接用 Google 官方测试向量验收。
