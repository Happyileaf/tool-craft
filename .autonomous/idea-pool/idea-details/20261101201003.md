## 描述

实现 Redis Serialization Protocol 报文构造与解析：编码侧把命令/参数（或 RESP 类型值）序列化为 `*3\r\n$3\r\nSET...` 批量字符串报文；解析侧把粘贴的 RESP 字节流按帧拆解为带类型的结构树（Simple String / Error / Integer / Bulk String / Array，以及 RESP3 的 Null `_`、Double `,`、Boolean `#`、Big Number `(`、Bulk Error `!`、Verbatim String `=`、Map `%`、Set `~`、Push `>`），支持一帧不完整时提示「等待更多字节」与多帧连续解析。典型场景：手写 redis-cli 原始报文调试、分析 RESP3 回复、构造代理/中间件测试数据、学习协议帧格式。纯本地确定性解析，零依赖，可用 Redis 官方协议文档示例验收。边界：现有 `magnet-link-parser`、`raw-http-message`（Pending）、`nmea-parser`（已完成）、`bencode-codec`、`protobuf wire decoder`（Pending）等分属其他协议/格式；HTTP、磁力、NMEA、BitTorrent、Protobuf 均不含 RESP 的首字节类型标记 + CRLF 帧格式，不构成重复。
