## 描述

输入未配平的化学方程式（如 `Fe + O2 -> Fe2O3`、`C2H6 + O2 -> CO2 + H2O`），解析各反应物与生成物的元素组成（支持括号与水合点，如 `Ca(OH)2`、`CuSO4·5H2O`），通过建立元素守恒线性方程组并求最小正整数解，输出配平系数与配平后方程式；再基于系数做化学计量换算（给定某物质质量/物质的量，求其他物质的量、质量、标况气体体积）。是化学教学与作业核对的高频需求。现有 `20261026200348` 化学式摩尔质量计算器只做单式摩尔质量、不解析完整方程式也不配平；本工具是其上游的独立场景。线性方程组可用零依赖高斯消元+整数化（分数运算）实现。

## 设计内容（进入 Claimed 前补全）

- 纯函数层 `utils/chemistry.ts`：parseFormula（元素/下标/嵌套括号/水合点，输出元素组成与摩尔质量）、parseEquation（箭头/等号分隔、自动剥离前导系数、重复物种检测）、balanceEquation（BigInt 分数 RREF 求零空间，维数恰为 1 才整数化+GCD 约分）、stoichiometryFromMoles/molesFromMass（mol、g、标况 22.4 L/mol）。
- UI 层两个 Tab：配平页（方程式输入+预设、配平结果框、逐物种系数/元素组成/摩尔质量卡片）、计量页（已知物种选择、mol/g 输入、全物种换算 Table）。
- 边界：括号不匹配、未知元素、缺箭头、单侧元素、欠定体系（零空间维数 >1）均明确报错；输入带前导系数时自动剥离。
