## 描述

通过表单与预设模板交互式生成 `.gitattributes` 文件：一键添加常见规则——强制全仓库 LF/CRLF（`* text=auto eol=lf`）、按扩展名指定（`*.sh text eol=lf`、`*.bat text eol=crlf`）、二进制文件标记（`*.png binary` 及 `-diff -merge -text` 等价写法）、常见二进制类型预设（图片 / 字体 / 压缩包 / 办公文档）、自定义 merge/diff driver（`package-lock.json merge=ours` 等）、GitHub Linguist 覆盖（`linguist-vendored` / `linguist-generated` / `linguist-documentation` / `linguist-language`）与 export-ignore；支持规则分组、启用/停用单条、实时预览生成内容并一键复制，另附常见项目类型模板（Node / Python / Unity 等）。

池中已完成 `.gitignore`、`.editorconfig`、`robots.txt`、`security.txt` 等 dotfile/配置生成器，但尚无 `.gitattributes`；它是解决跨平台 CRLF/LF 问题（池中 `line-ending-converter` 只处理文件内容本身）和 linguist 统计修正的标准手段，与 `.gitignore` 同属仓库初始化高频配置。纯前端字符串拼装、零依赖，输出可用固定表单状态确定性验收，复杂度 S。
