## 描述

基于浏览器原生 CompressionStream / DecompressionStream API，对文本或任意小文件执行 Gzip 与 Deflate 压缩、解压，展示压缩前后大小与压缩率，支持压缩结果以 Base64 输出便于复制传输。接口报文调试、教学演示与压缩体积对比场景常用；现有编码家族工具（Base64、URL 编码等）均无压缩能力。历史被拒的 Code minifier（20261017125915）因需词法与语法分析属 L 级，本 Idea 仅调用原生流式 API、无自研算法，S–M 复杂度，零新依赖、纯本地。
