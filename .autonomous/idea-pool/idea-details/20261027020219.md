## 描述

对输入文本或字节（支持十六进制字节流输入）计算多种工程常用校验和：CRC-16/CCITT-FALSE、CRC-16/ARC（MODBUS 常用变体）、CRC-16/XMODEM 等常见 CRC-16 参数模型（按 width / poly / init / refin / refout / xorout 参数化实现，一次实现覆盖多个变种），以及 Adler-32；输出十进制与十六进制结果。典型场景：嵌入式串口 / Modbus 通信帧核对、zlib 流的 Adler-32 校验、协议调试。已实现的 crc32-checksum 只覆盖 CRC-32 单一算法，non-crypto-hash（FNV / MurmurHash3 / djb2 等）是非校验和类哈希，二者均不含 CRC-16 家族与 Adler-32；本地文件哈希（20261021221301）面向 MD5/SHA 文件校验。CRC 是纯位运算的表驱动 / 直驱算法，Adler-32 仅需双累加器取模，纯函数、零新依赖、确定性输出，可用官方标准向量（check 值）验收各参数模型，如空串与 "123456789" 的已知 CRC 值、Adler-32 标准值。
