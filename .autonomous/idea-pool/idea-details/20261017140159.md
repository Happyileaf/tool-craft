## 描述

解析 `.env` 文件内容，校验键名格式与引号规则、检测重复键，并在 `.env`、JSON、YAML 以及 shell `export` 语句之间互相转换，用于环境变量配置的整理与迁移。现有工具缺少面向环境变量配置的解析与转换能力。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：`.env` 解析与多格式互转，工具 slug 拟为 `env-converter`。
- **解析**：逐行解析 `KEY=VALUE`；忽略空行与 `#` 注释；支持单/双引号与无引号值，双引号内处理常见转义（`\n`、`\t`、`\"`、`\\`）；可选识别 `export ` 前缀。
- **校验**：键名非法（非 `[A-Za-z_][A-Za-z0-9_]*`）给出带行号错误；重复键给出警告（以后值为准并标注）。
- **转换**：在 `.env`、JSON、YAML（扁平 `key: value`）、shell `export` 语句四种格式间互转；JSON/YAML 输入解析为扁平键值对象（嵌套对象不支持，给提示）。
- **核心交互**：源格式选择 + 文本输入 + 目标格式选择，实时输出；错误带行号。
- **输入输出**：解析 / 序列化均为纯函数，不触碰 DOM / React，零新增依赖。
- **边界情况**：空输入、仅注释、引号转义、重复键、非法键名、值含 `=`。
