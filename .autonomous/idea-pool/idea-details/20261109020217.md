## 描述

实现经典 Porter Stemming Algorithm（Porter 1980 确定性规则算法，可选 Porter 2 修订版），对粘贴的英文文本批量提取词干，并按词干归并展示「词干 → 原始词形列表 / 出现次数」，用于搜索引擎索引预处理、文本分析与 NLP 教学。与现有 `word-frequency`（按原词计数）和 `text-similarity`（相似度评分）互补：本工具输出规则化词干与词形族，不做统计评分。算法仅约百条后缀规则、零数据依赖、纯函数可固定向量验收，不触碰 rejected.md 中「大型静态数据集 / LLM 依赖」类否决先例。

## 设计内容（进入 Claimed 前补全）

- 工具 slug：`porter-stemmer`，分类 TEXT_CONTENT（文本加工），主线程纯函数，零新依赖。
- 核心算法：Porter 1980 经典五阶段后缀剥离（步骤 1a/1b/1c/2/3/4/5a/5b），基于 `m`（元音-辅音序列度量）条件判定；输入小写化后按规则确定性处理。
- 输入：多行英文文本框；按非字母字符分词，保留原始词形与出现顺序。
- 输出：① 每个 token 的「原词 → 词干」明细表；② 按词干归并视图（词干 → 原始词形列表 + 总出现次数，按次数降序）；③ 汇总统计（总词数、词干数、归并压缩比）。
- 边界：空输入、纯标点、短于 3 字符的词原样返回；大写/混合大小写统一小写；不做停用词过滤（与 word-frequency 职责区分）。
