## 描述

提供 RFC 4648 标准字母表及去填充变体的 Base32 文本编解码，支持对 TOTP secret、密钥材料等 Base32 字符串做快速转换与合法性校验。现有 `base64-codec` 仅覆盖 Base64 与 URL 编码，缺少 Base32 这一在认证场景中常用的编码。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：Base32 文本编解码与合法性校验，工具 slug 拟为 `base32-codec`。
- **编码**：使用 RFC 4648 标准字母表 `A-Z2-7`，支持填充（`=`）与去填充（unpadded）两种输出变体；输入文本按 UTF-8 编码处理。
- **解码**：支持带填充与去填充输入，解码大小写不敏感；非法字符、非法长度、填充位置错误给出明确错误提示。
- **校验**：对输入的 Base32 字符串进行合法性校验并报告问题位置。
- **核心交互**：方向切换（编码 / 解码）、去填充开关、输入即时转换、复制 / 清空 / 载入示例。
- **输入输出**：纯函数，不触碰 DOM / React。
- **边界情况**：空输入返回空；长度不是 8 的倍数且无填充时按规范处理；非法字符不抛异常只报错。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] RFC 4648 标准测试向量全部通过：`""`→`""`、`"f"`→`"MY======"`、`"fo"`→`"MZXQ===="`、`"foo"`→`"MZXW6==="`、`"foob"`→`"MZXW6YQ="`、`"fooba"`→`"MZXW6YTB"`、`"foobar"`→`"MZXW6YTBOI======"`。

- [ ] 非法字符 / 非法长度给出明确错误提示，不抛异常。
- [ ] UTF-8 中文文本编解码往返一致。
- [ ] 纯浏览器本地运算，无任何网络请求。
