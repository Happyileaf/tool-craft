## 描述

粘贴一段 JSON（单对象或对象数组，数组时综合所有样本推断），推断每个字段的 SQL 列定义并生成建表 DDL：类型推断规则覆盖 null（样本不足时回退占位）、布尔→BOOLEAN（或目标方言 TINYINT(1)）、整数→INT/BIGINT（按值域）、浮点→DOUBLE/DECIMAL、字符串→VARCHAR(n)（按样本最大长度并给余量/可切换 TEXT）、JSON 嵌套对象/数组→JSON/TEXT；支持选择方言（MySQL / PostgreSQL / SQLite）、自定义表名、snake_case 列名转换（可复用池中已有的键名转换思路）、主键自增列（id BIGINT AUTO_INCREMENT / SERIAL / INTEGER PRIMARY KEY）、NOT NULL 推断（所有样本均非空）、是否生成列注释（含原始字段名）、可选 `IF NOT EXISTS` 与 `DROP TABLE` 前缀；实时预览并一键复制。

池中已完成的 `csv-to-sql` 只把行数据转成 `INSERT INTO ... VALUES (...)`，不做类型推断、不输出 CREATE TABLE；本工具补足「先有 JSON 数据样例 → 设计表结构」这一独立方向（DDL 而非 DML），二者输入与产物均不同。纯前端递归分析、零依赖，用固定 JSON 样本与三方言输出可确定性验收，复杂度 M。
