## 描述

在二进制 / 八进制 / 十进制 / 十六进制之间互转，并可视化位（bit）分组与位运算结果，覆盖底层调试、权限位、协议字段解析等场景。当前工具集没有任何进制或位运算工具。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：进制互转 + 位可视化 + 位运算，工具 slug 拟为 `number-base-converter`。
- **进制互转**：在二进制（2）/八进制（8）/十进制（10）/十六进制（16）之间互转；支持可选输入进制；使用 `BigInt` 支持超出 32 位的大整数；支持正负号。
- **位可视化**：按所选位宽（8/16/32/64）分组展示二进制位（每 4 位或 8 位分隔），并给出置位（1）的个数（popcount）。
- **位运算**：对两个输入值执行 AND / OR / XOR，对单值执行 NOT / 左移 / 右移（按定位宽处理补位）。
- **输出**：同一数值的 2/8/10/16 进制结果一览，便于复制。
- **核心交互**：输入数值并选择输入进制，实时输出各进制结果与位分组；位运算区块输入两个操作数与运算符后输出结果。
- **输入输出**：纯函数，不触碰 DOM / React。
- **边界情况**：非法字符、超出所选进制范围、空输入给出明确错误提示；大整数按 BigInt 处理避免精度丢失。
