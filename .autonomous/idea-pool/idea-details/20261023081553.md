## 描述

IPv4 点分十进制 ↔ 32 位无符号整数 / 十六进制 / 二进制，以及 IPv6 压缩格式 ↔ 128 位大整数 / 完整十六进制展开的双向转换与批量处理，常用于数据库 IP 存储（inet_aton 类场景）、日志字段解析与 ACL 配置核对。现有 cidr-subnet-calculator 只做子网划分计算（网络地址、广播地址、主机范围），不提供地址与数值格式的互转输出；number-base-converter 仅转换纯数字进制，不解析 IP 文本格式；池内亦无同类条目。地址解析与格式化为确定性纯函数（IPv6 用 BigInt 运算，与 cidr 工具内部实现同一路线），零新依赖、纯本地。

## 设计内容

- IPv4：点分十进制 ↔ uint32 十进制整数 / 十六进制（`0x` 前缀）/ 32 位二进制，双向转换；逐段校验 0–255。
- IPv6：解析压缩形式（`::`）与完整形式为 128 位 BigInt，输出完整展开、压缩形式、十六进制整数、二进制；支持内嵌 IPv4（如 `::ffff:192.168.0.1`）。
- 批量模式逐行处理，非法行 warning 带行号；错误以结果对象返回不抛异常。
- 纯函数逻辑放 `utils/ip-convert.ts`（BigInt 运算），组件仅负责交互；零新依赖、主线程（S–M）。
