## 描述

在 IPv4 点分十进制子网掩码（如 `255.255.255.0`）与 Cisco ACL 反掩码 / 通配符掩码（wildcard mask，如 `0.0.0.255`）之间双向转换，并校验掩码合法性（必须由连续 1 后接连续 0 构成），同时输出前缀长度（/24）、网络地址与广播地址。解决配置 OSPF、ACL 时手写反掩码容易逐位取反出错的高频问题。纯位运算、零依赖、纯本地计算。

## 设计内容（进入 Claimed 前补全）

- 功能范围：子网掩码 → 反掩码、反掩码 → 子网掩码双向转换；校验掩码合法性（连续 1 后接连续 0）；输出前缀长度、主机位、网络地址、广播地址与可用主机范围。
- 核心交互：单值输入框 + 模式切换（自动识别 / 强制子网→反掩码 / 反掩码→子网），多行批量逐行处理，非法行原样保留并带行号告警。
- 输入输出：输入点分十进制掩码（如 255.255.255.0）或反掩码（如 0.0.0.255）；输出对侧掩码、/前缀长度、网络/广播地址（需配合给定 IP，缺省仅给掩码推导量）。
- 边界情况：0.0.0.0 与 255.255.255.255 合法（/0、/32）；非连续掩码（如 255.0.255.0）报非法；八位组越界（>255）、非数字、段数不为 4 报错；纯 BigInt/位运算实现。
