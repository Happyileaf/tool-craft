## 描述

只读解析 MP4 / MOV 等 ISO-BMFF（ISO/IEC 14496-12）文件的 atom（box）层级结构：识别四字符类型（ftyp / moov / mvhd / trak / mdia / minf / stbl / mdat / free 等）、32 位与 64 位 largesize、逐层展开嵌套容器 box，以树形展示每个 atom 的类型、偏移、大小与文件总览信息（如 ftyp 的 major brand、兼容品牌，mdat 数据区大小），并对截断文件、size 越界、未知 box 类型给出提示。延续池中 ELF / ZIP / TAR / WAV / PNG 系列「二进制文件只读结构解析」的定位，不上传文件、不重新编码视频，纯字节解析，零新增依赖。
