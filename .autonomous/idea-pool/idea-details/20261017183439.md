## 描述

在十进制浮点数与 IEEE 754 单精度（32 位）/ 双精度（64 位）的十六进制、二进制表示之间互转，并拆解展示符号位、指数位、尾数位，用于排查浮点数精度与序列化问题。现有计算类工具无浮点数底层表示转换能力。

## 设计内容（进入 Claimed 前补全）

- **工具 slug**：`ieee754-float-converter`
- **分类 / 图标**：`ToolCategoryEnum.DEV_CODE`（面向研发的底层数值调试）；图标 `Binary`
- **查重结论**：`number-base-converter` 仅做整数进制转换，不涉及浮点位域 / 偏置指数 / 隐藏位；`decimal-fraction-converter` 做十进制小数 ↔ 分数精确值，不做 IEEE 754 表示；rejected.md 无同类归档，池内无同类条目。不构成重复。
- **文件结构**（四件套，零新依赖，用 `ArrayBuffer` + `DataView` 做确定性位操作）：
  - `constants.ts`：`PrecisionEnum`（single32 / double64）与 `PRECISION_OPTIONS`、各精度位宽常量（32: 符号 1 / 指数 8 / 尾数 23 / 偏置 127；64: 1 / 11 / 52 / 1023）、`ModeEnum`（decimalToBits 十进制→表示 / bitsToDecimal 表示→十进制）与 `MODE_OPTIONS`、`DEFAULT_SAMPLE = '0.1'`
  - `utils/ieee754.ts`：纯函数
    - `encodeFloat(value, precision)`：DataView setFloat32 / setFloat64 取出位串，返回 `{ binary, hex, sign, exponentBits, exponentValue (去偏置), mantissaBits, mantissaHex, isSpecial: 'none'|'zero'|'inf'|'nan' }`
    - `decodeBits(input, base: 2|16, precision)`：校验长度（32 位 / 64 位，hex 8 / 16 字符），按位域重组后 DataView 还原数值；正确还原 ±0 / ±Infinity / NaN
    - `parseDecimal(text)`：接受十进制数字面量与 `Infinity` / `-Infinity` / `NaN`
    - `toBinary(value, width)` / `toHex(value, width)` / `fromBits(bits, width)`：位工具
  - `index.tsx`：精度 Radio（32 位单精度 / 64 位双精度）、模式 Radio（十进制→表示 / 表示→十进制）；正向输入十进制，输出十六进制（`0x...`）、64/32 位二进制（按 1|11|52 / 1|8|23 分段着色）、符号 / 指数 / 尾数位域表与去偏置指数；反向接受二进制或十六进制串（自动识别 base），输出十进制；±0 / Inf / NaN 特殊态 Tag 提示；复制 / 载入示例 / 清空
  - `index.module.css`：container/toolbar/result/bits/field 等
- **注册**：`registry.ts` 追加双语 ToolMeta（DEV_CODE / Binary / isNew / MAINTHREAD / defaultSampleInput='0.1'）；`loaders.ts` 追加懒加载；FAQ 至少含「为什么 0.1 不能精确表示」「偏置指数（bias）是什么」「32 位与 64 位表示差异」
- **边界**：单精度溢出 / 下溢按 IEEE 754 round-to-nearest 行为（DataView 默认）；反向输入位数不符报错；不做任意精度（BigDecimal）运算、不做 half-float（16 位）
