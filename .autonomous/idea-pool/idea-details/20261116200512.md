## 描述

以太网排障与交换网络教学中，常需要在帧的十六进制转储里识别或手工构造 802.1Q VLAN 标签（TPID `0x8100`、PCP、DEI、VID），运营商场景还会遇到 QinQ 双层标签（外层 TPID `0x88A8`）。本工具在浏览器本地完成 VLAN 标签的字段解析与字节级构建，双向对照「字段 ↔ 4 字节标签 hex」，并支持 QinQ 双标签拼装与从以太网帧 hex 中定位标签，纯确定性位运算、零依赖。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 单层 802.1Q 标签构建：输入 PCP（0–7）、DEI（0/1）、VID（1–4094，0 与 4095 保留）、TPID 可选（默认 `0x8100`），输出 4 字节大端标签 hex 与各字段位布局；② 反向解析：粘贴 4 字节（或含标签的帧 hex），拆出 TPID、PCP、DEI、VID，并标注 PCP 对应的 802.1p 服务等级含义；③ QinQ 双层：外层（S-TAG，TPID `0x88A8`）+ 内层（C-TAG，TPID `0x8100`）拼装为 8 字节，并解析回两层结构；④ 帧内定位：在以太网帧 hex 中扫描源 MAC 后的 TPID，识别单/双标签并给出标签起始偏移与标签后 EtherType。

**核心交互**：模式 Radio（构建 / 解析 / QinQ）；PCP、DEI、VID 数字输入与 TPID 选择；hex 输入输出框（等宽字体、按字节空格分组）、字段位布局示意条、PCP 等级说明表、一键复制 hex；错误以 Result 面板呈现。

**输入输出**：输入为 PCP/DEI/VID 等字段或标签/帧的十六进制字符串；输出为 4 字节（单层）或 8 字节（QinQ）标签 hex、字段位分解、PCP 等级语义、标签偏移与标签后 EtherType。

**边界情况**：VID 为 0（保留）或 4095（保留）→ 报错；PCP 越界（>7）、DEI 非 0/1 → 报错；hex 长度不为 4 的倍数或含非十六进制字符 → 报错；解析帧时未在预期偏移找到已知 TPID（`0x8100`/`0x88A8`/`0x9100`）→ 提示「未检测到 VLAN 标签」；hex 前缀 `0x` 与空格/换行自动归一；不足以太网首部最小长度的截断输入给明确错误。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [x] 构建：TPID `0x8100`、PCP=5、DEI=0、VID=100（0x064）→ 标签 hex 为 `81 00 a0 64`（PCP/DEI/VID 三字段合成 16 位 = 5<<13 | 0<<12 | 100 = 0xa064），往返解析回各字段一致
- [x] 解析 `81 00 a0 64`：TPID=0x8100、PCP=5、DEI=0、VID=100，并标注 PCP=5 的 802.1p 等级名称
- [x] QinQ：外层 PCP=0/DEI=0/VID=20（TPID `0x88A8`）、内层 PCP=3/DEI=1/VID=300（TPID `0x8100`）→ 输出 8 字节，前两字节为 `88 a8`，解析回两层且各字段一致
- [x] 帧内定位：给定含「源 MAC 后紧跟 `81 00 .. ..` 再跟 EtherType」的帧 hex，能给出标签起始偏移、单标签结论与标签后 EtherType；无标签帧返回「未检测到 VLAN 标签」
- [x] 输入 VID=0、VID=4095、PCP=8、奇数位非法 hex、长度不足 4 字节时分别返回明确错误，不抛到页面
