## 描述

粘贴 DNA 或 RNA 序列（支持 FASTA 头、空白、换行与行号），自动识别核酸类型并计算长度、碱基组成与 GC 含量，生成互补链、反向互补链与转录得到的 mRNA；按标准遗传密码表对正链与反向互补链各三个读框（六框）翻译为氨基酸序列，标注终止密码子与不完整末尾密码子。用于分子生物学习、引物检查与 ORF 快速浏览；纯本地文本处理，序列不上传。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 序列清洗：忽略 FASTA 头行（以 `>` 开头）、空格 / 制表 / 换行 / 数字（行号）与 `-`（比对空位，统计移除数量），统一转大写；② 类型识别：含 U 且不含 T → RNA，含 T 且不含 U → DNA，同时含 T 与 U → 报错，均不含 T/U → 按 DNA 处理并注明；③ 统计：长度、A / C / G / T / U 计数、GC 含量、AT 含量、IUPAC 模糊碱基数量；④ 序列变换：互补链、反向互补链、转录 mRNA（DNA 的 T→U，RNA 原样）；⑤ 六框翻译：正向 +1 / +2 / +3 与反向 −1 / −2 / −3，标准遗传密码表（64 密码子），终止密码子输出 `*`，含模糊碱基的密码子输出 `X`，末尾不足 3 个碱基的部分不翻译并提示剩余长度；⑥ IUPAC 互补：A↔T（RNA 为 A↔U）、C↔G、R↔Y、S↔S、W↔W、K↔M、B↔V、D↔H、N↔N。

**核心交互**：序列输入框（支持多行粘贴）、示例序列一键填充、类型与统计卡片、互补 / 反向互补 / mRNA / 六框翻译结果分区（等宽字体展示、可单独复制）、模糊碱基与不可翻译部分提示。

**输入输出**：输入为 DNA / RNA / IUPAC 序列文本；输出为类型、清洗后长度、碱基组成、GC / AT 含量、互补链、反向互补链、mRNA、六个读框的氨基酸序列及终止密码子位置。

**边界情况**：空序列或清洗后为空 → 明确错误；长度上限 100000 nt，超出提示拒绝；含 IUPAC 之外的字符（如 X、Z、数字以外的符号）→ 报错并给出去清洗后 1-based 位置；同时含 T 与 U → 报错；纯模糊碱基（如 NNN）按 DNA 处理且 GC 为 0；小写输入等同大写；`-` 空位移除并在提示中给出数量；多行序列自动拼接；翻译结果中终止密码子保留 `*` 以便识别完整 ORF；RNA 输入的反向互补以 U 互补，不产生 T。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 输入 `ATGCGTACGTAG`：识别为 DNA，长度 12，A=3 / C=2 / G=4 / T=3，GC 含量 50.00%
- [ ] 上例反向互补链为 `CTACGTACGCAT`，转录 mRNA 为 `AUGCGUACGUAG`
- [ ] 上例正向 +1 读框翻译为 `MRT*`（ATG→M、CGT→R、ACG→T、TAG→终止）
- [ ] 上例 +2 读框为 `CVR`、+3 读框为 `AYV`，反向 −1 读框为 `LRTH`（不完整末尾密码子被忽略）
- [ ] 输入 RNA `AUGGCU`：识别为 RNA，反向互补为 `AGCCAU`，+1 读框为 `MA`
- [ ] 输入 `>seq1` 换行 `ATG CGT` 换行 `ACG TAG`（含 FASTA 头与空格）：清洗后长度 12，结果与首条一致
- [ ] 输入 `GGG`：GC 含量 100.00%，+1 读框为 `G`；输入 `TAA`：+1 读框为 `*`；输入 `ATN`：+1 读框为 `X`
- [ ] 输入空序列、`ATGX`（非法字符 X）、`ATUG`（同时含 T 与 U）时分别返回明确错误；长度超过 100000 时提示拒绝
