## 描述

输入任意 CSS 选择器（含后代/子代/相邻组合、属性选择器、伪类，以及 `:is()` / `:not()` / `:where()` 等），解析并计算其权重三元组 `(a, b, c)` 与可读说明，多个选择器可并排对比并标注哪个会胜出、哪个被覆盖。前端调试样式覆盖问题时这是必备能力，而当前「开发与调试」分类已有正则测试、代码美化等工具，却缺少 CSS 权重计算。

## 设计内容（进入 Claimed 前补全）

- **slug**：`css-specificity-calculator`
- **分类**：开发与调试（ToolCategoryEnum.DEV_CODE），iconName 用 `Code`，MAINTHREAD，isNew
- **形态**：单页文本域（每行一个选择器）+ 逐行结果列表，实时联动，纯浏览器本地运算、零新依赖
- **纯函数层** `utils/specificity.ts`（不依赖 DOM/React）：
  - `Specificity { a, b, c }`、`SpecificityResult { selector, valid, specificity, reason? }`
  - `addSpecificity` / `maxSpecificity` / `compareSpecificity`（1 / -1 / 0）
  - 零依赖手写递归下降 `SelectorParser`：类型 / 通配 / `&` / 命名空间 `ns|tag`、类（b）、ID（a）、属性（b，扫描引号与括号配对）、伪类（b）、伪元素（c，含 `:before` 旧式单冒号）
  - `:is()` / `:not()` / `:has()` 递归解析参数列表取最高权重（函数自身不 +1）；`:has()` 参数允许前导组合子（如 `> h2`）；`:where()` 恒 0
  - `:nth-child(An+B of S)` / `:nth-last-child` 自身 b:1，存在顶层 `of S` 时叠加过滤选择器 S 的权重
  - 组合子：后代（空白）、子代 `>`、相邻 `+`、兄弟 `~`；顶层拒绝前导 / 尾随 / 连续组合子；空串、括号不配对等判非法并给 reason
  - `calculateSpecificity(input)`（逗号列表取最高、任一段非法整体非法）、`calculateSpecificityLines(text)`（忽略空行）、`formatSpecificity(s)` → `(a, b, c)`
- **UI 层** `index.tsx`：antd `Input.TextArea` 多行输入；逐行展示原文 + 三元组；合法行中权重最高者绿色底 + 「权重最高」Tag（相等取首行，与源码顺序规则在 FAQ 说明）；非法行 antd `Alert` 报错；顶部 a/b/c 三色图例
- **常量** `constants.ts`：旧式伪元素表、取最高权重伪类表、nth-of 伪类表、列标签、默认示例
- **注册**：`registry.ts` 追加完整双语 ToolMeta；`loaders.ts` 追加懒加载映射；路由由 generateStaticParams 自动生成
- **测试**：`utils/specificity.test.ts` 覆盖三元组工具函数、五类简单选择器、四种组合子、属性选择器引号 / 逗号、伪元素新旧写法、:is/:not/:has/:where 取最高与 :where 恒 0、嵌套函数、nth-child of 语法、列表取最高、空串 / 尾随组合子 / 前导组合子 / 括号不配对非法、`&` 嵌套、多行与格式化，共 20 个用例
