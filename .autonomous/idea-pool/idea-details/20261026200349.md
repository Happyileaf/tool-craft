## 描述

提供学习与工程常用的线性代数矩阵运算：矩阵 / 向量输入（可视化网格，支持粘贴以空格、逗号、换行分隔的数字，自动识别行列）、矩阵加法与标量乘法、矩阵乘法（含维度不匹配报错）、转置、行列式（高斯消元，分数 / 小数两种显示）、逆矩阵（奇异矩阵给出明确提示）、矩阵的秩、简化行阶梯形（RREF）展示逐步消元结果、解线性方程组 Ax=b（唯一解 / 无解 / 无穷多解判定）。典型场景：线性代数作业验算、图形学 / 机器人坐标变换核算、最小二乘前置推导。纯本地数值 / 分数运算、确定性输出、零依赖（采用部分主元 Gauss-Jordan 消元，小矩阵数值稳定；可选 BigInt 分数模式保证课堂场景精确结果），可用固定向量验收（单位阵、2×2 / 3×3 行列式经典值、已知逆矩阵互乘为单位阵、奇异矩阵报错、RREF 标准结果、方程组三类解的判定）。已实现工具中 number-theory-calculator / combinatorics-calculator / percentage-calculator 等均不覆盖矩阵运算；在池 Idea「CSS transform 矩阵计算器」仅面向 CSS `matrix()` 字符串与 2D 变换参数互转，本工具是通用线性代数运算，二者范围与对象完全不同，不构成重复。

## 设计内容（进入 Claimed 前补全）

- slug：`matrix-calculator`，分类 TIME_MATH，主线程纯浏览器运算，零新增依赖。
- `utils/fraction.ts`：BigInt 不可变精确分数（自动约分、分母恒正、0 化为 0/1、除零报错），`parseFraction` 支持整数 / 小数 / `a/b`。
- `utils/matrix.ts` 纯函数：`parseMatrix`（空白/逗号分列、换行/分号分行、行数校验）、加减、标量乘、矩阵乘（维度校验）、转置、单位阵；部分主元 Gauss-Jordan 消元返回 RREF + 秩 + 逐步记录；行列式（带行交换变号的高斯消元）；逆矩阵（[A|I] 消元后校验左上 n×n 为单位阵，奇异返回 null）；`solveSystem` 判定唯一解 / 无解（零系数行增广列非零）/ 无穷多解（收集自由变量列）。
- UI：运算下拉（10 种运算）、矩阵 A 主输入，按运算动态显示矩阵 B / 标量 k / 向量 b；分数/小数显示开关；结果以矩阵网格、标量或向量呈现；秩/RREF/方程组展示可折叠消元步骤；示例、清空、复制，错误 Alert 显示中文信息。
- 精度策略：内部全程 BigInt 分数，比较主元大小时交叉相乘避免除法；小矩阵定位（FAQ 提示约 12 阶以内）。
