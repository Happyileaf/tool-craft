## 描述

检测粘贴或拖入文本中实际使用的行结束符，统计 LF（`\n`，Unix/macOS）、CRLF（`\r\n`，Windows）、CR（`\r`，经典 Mac）各自的出现次数与是否混排（mixed line endings），并在 LF / CRLF / CR 之间一键批量归一化转换；同时显示总行数、文件字节大小变化（如 CRLF→LF 每行省 1 字节）、末尾换行（final newline）有无以及 BOM（UTF-8 `EF BB BF`）检测与可选剥离。典型场景：跨平台协作时消除 git diff 整文件变动、shell 脚本在 Linux 上报 `bad interpreter: ^M`、清洗从旧系统导出的文本。纯本地确定性处理（基于字节/字符串扫描，可通过 File API 在浏览器本地完成，不上传文件）、零新增依赖，可用固定向量（纯 CRLF 文本、混合换行文本、仅 CR 文本、带 BOM 与末尾无换行的边界样例）精确验收。与已实现的 line-operations（排序 / 去重 / 反转 / 过滤等行内容变换）、string-escape（编程语言字符串字面量转义）、全角/半角转换器不同：现有工具均不检测也不改写行结束符字节本身；与在池的「Hex / 文本互转」（hex dump 视图）也不同，它只呈现而不做归一化转换，不构成重复。
