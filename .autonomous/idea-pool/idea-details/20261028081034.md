## 描述

在原始字节数与人类可读的文件大小表示之间双向转换：正向把字节数按二进制（1024，KiB/MiB/GiB）或十进制（1000，KB/MB/GB）规则格式化为带单位字符串并可选小数位；反向解析 `1.5 MB`、`2048 KiB`、`3GB` 等字符串为精确字节数。服务于开发中显示/解析文件大小的常见需求，纯本地纯函数，零依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：字节数 ↔ 人类可读文件大小双向转换，工具 slug 拟为 `file-size-converter`。
- **格式化（bytes→字符串）**：支持二进制（基数 1024，单位 B/KiB/MiB/GiB/TiB/PiB）与十进制（基数 1000，B/KB/MB/GB/TB/PB）两套单位；可选小数位（默认智能保留至多 2 位、去尾零）；小于基数直接显示 `N B`。
- **解析（字符串→bytes）**：容忍空白与大小写，识别 `1.5 MB`、`2048 KiB`、`3GB`、`1,024 KB` 等；单位按其 IEC（KiB 系=1024）/ SI（KB 系=1000）定义取基数；结果四舍五入为整数字节。
- **核心交互**：进制规则切换（二进制 / 十进制）、小数位设置、方向切换、输入即时转换、复制 / 载入示例。
- **输入输出**：纯函数 `utils/file-size.ts`（formatBytes/parseSize），不触碰 DOM / React。
- **边界情况**：空输入返回空；负数、无法识别的单位、非数字返回明确错误而非抛异常；0 字节显示 `0 B`。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [x] 二进制：`1023`→`1023 B`，`1024`→`1 KiB`，`1536`→`1.5 KiB`，`1048576`→`1 MiB`。
- [x] 十进制：`1000`→`1 KB`，`1500`→`1.5 KB`，`1000000`→`1 MB`。
- [x] 解析：`"1.5 MB"`→1500000，`"2048 KiB"`→2097152，`"3GB"`→3000000000；与格式化方向往返一致。
- [x] 解析容忍首尾空白、大小写、千分位逗号。
- [x] `0`→`0 B`；负数、空单位、未知单位（如 `1.5 XB`）返回明确错误，不抛异常。
- [x] 纯浏览器本地运算，无任何网络请求。
