## 描述

呼叫中心排班需要根据预测来话量、平均处理时长（AHT）与目标服务水平（如 80% 来话在 20 秒内接通）反算所需坐席数，或评估给定坐席配置下的等待概率、平均等待时长（ASA）与坐席占用率。本工具基于 Erlang C 排队模型（M/M/N 等待制队列）双向计算：① 输入时段来话量、AHT、统计周期、目标服务水平阈值与收缩率（shrinkage），输出满足服务水平的最小坐席数、等待概率 P(W>0)、目标阈值内接通率、ASA、最大占用率与含收缩率的排班人数；② 输入既定坐席数，反推各项服务水平指标，并给出过载（占用率 >100% 或无解）提示与坐席数灵敏度对照表。现有 erlang-b-calculator 仅覆盖中继线阻塞模型（Erlang B，损失制、无排队），与排队制坐席模型的公式、输入输出完全不同；四源查重全文检索「Erlang C / 呼叫中心 / 坐席 / 服务水平 / ASA」在活动池、completed.md、rejected.md 与已注册工具中零命中。纯本地数学计算、零新依赖、固定输入向量可复现验收，符合红线。
