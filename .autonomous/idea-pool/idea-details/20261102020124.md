## 描述

在浏览器本地计算 Git 底层对象（Git Object）的 SHA-1 / SHA-256 哈希，等价于 `git hash-object` 与 `git cat-file` 的只读计算侧。支持四种对象类型：blob（内容前拼接 `blob <长度>\0` 头）、tree（按 `mode SP name \0 <20 字节二进制 SHA>` 规范化条目、目录名不带尾斜杠、条目按名排序后前拼接 `tree <长度>\0`）、commit 与 annotated tag（对规范化后的原始文本前拼接 `commit <长度>\0` / `tag <长度>\0`）。典型场景：排查"工作区文件内容哈希为什么和 Git 库里的不一致"、手工构造/校验 loose object、教学演示 Git 内容寻址模型、无需安装 Git 即可验证 CI 产物哈希。纯本地确定性计算，零依赖（SHA-1 / SHA-256 用 Web Crypto，tree 条目的二进制摘要用纯函数组装），可用 `git hash-object` / `git mktree` 产出的固定向量验收。边界：现有 `hash-generator` / `sri-hash-generator` / `file` 哈希校验工具（20261021221301，Pending）都是对**原始字节**直接做摘要，不拼接 Git 的类型+长度头，也不做 tree 条目的二进制规范化与递归组装，消费场景不同，不构成重复；不做 packfile 解析、不做对象写入/打包。
