## 描述

面向嵌入式 / 单片机 / LCD 驱动开发场景，在 24 位 RGB888（`#RRGGBB`）与 16 位帧缓冲像素格式之间双向转换：支持 **RGB565**（红 5 位 / 绿 6 位 / 蓝 5 位，ST7735/ILI9341 等常见 TFT 屏使用）与 **RGB555 / RGB1555**（各 5 位，最高位未用或作 a 位）两种布局，输出大端 / 小端两种字节序（`0xF800`、`0x00F8`、`0xFFE0` 等）以及 C 语言十六进制字面量（`0xFFFF`）与高低字节拆分（`HIGH_BYTE` / `LOW_BYTE`），并支持批量粘贴（每行一个 `#RRGGBB`）一次转换一列；反向支持把 `0xF800` 这类 16 位值还原成最接近的 RGB888（低位补 1 扩展以减小量化误差，符合常见 SDK 做法）并显示量化前后色差。典型场景：写屏幕取模代码、对着示波器 / 调试器里的像素值反查颜色、UI 配色表落地。纯本地位运算、确定性输出、零依赖，可用固定向量验收（白 `#FFFFFF` / 黑 `#000000` / 红 `#FF0000` / 绿 `#00FF00` / 蓝 `#0000FF` 在 RGB565 与 RGB555 下的精确值与字节序、非法 16 位值与非法 hex 的报错、批量模式行数一致）。已实现的 color-palette / oklch-workbench / color-mixer / color-harmony / dark-mode-converter / color-naming-token / css-unit-converter 等颜色工具全部面向设计与 CSS，在池 Idea 中亦无任何嵌入式像素格式条目，不构成重复。
