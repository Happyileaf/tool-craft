## 描述

开发者为 JavaScript / TypeScript 函数补文档注释时，需要手工把参数名、类型、返回值与可选/默认值同步到 `@param` / `@returns` / `@throws` 等标签，签名一改注释就容易漂移；逆向维护旧代码时又常需从注释块提取结构化信息。本工具提供双向转换：① 生成模式——粘贴函数签名（支持 TS 类型注解、可选参数 `?`、默认值、剩余参数 `...args`、泛型与 `async` 返回的 Promise 包装），自动生成对齐的 JSDoc 注释块，TS 模式额外输出 TSDoc 风格（`@typeParam`、避免冗余类型、`@remarks` 占位），并可勾选是否带描述占位行；② 解析模式——粘贴已有 JSDoc/TSDoc 块，解析出摘要、各 tag（含 `@param {type} name - desc` 的花括号类型与连字符描述变体）、行内类型与函数签名的一致性，报告缺失/多余的 `@param`、名称不匹配与返回值标签缺失。现有代码生成类工具集中在 JSON → 多语言模型、Zod schema、SQL DDL 等方向，文本类工具覆盖大小写转换、转义、换行/行号处理，均不涉及注释块结构化生成；与 conventional-commit-generator、changelog-generator 同属「研发文本规范生成」品类但产物完全不同。四源查重全文检索「JSDoc / TSDoc / docblock / 文档注释」在活动池、completed.md、rejected.md 与已注册工具源码中零命中（既有工具源码内的注释仅为自身实现，不构成该能力）；基于正则与轻量词法解析即可在纯函数中完成，零新依赖、可用固定签名向量验收，符合红线。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 签名解析——识别 `function` 声明、`const` 箭头函数与对象方法简写，提取函数名、泛型类型参数、参数列表（含 TS 类型注解、可选 `?`、默认值、`...rest` 剩余参数）与返回类型；词法层处理括号嵌套、字符串引号与顶层逗号切分。② 注释块生成——JSDoc 方言输出花括号内联类型（`@param {T} name`、可选参数 `[name]`、async 自动将返回类型包 `Promise<T>`，已是 Promise 不重复包装），TSDoc 方言输出 `@typeParam`、无花括号类型与「（可选）」标注；void/undefined/never 返回值跳过 `@returns`；可勾选描述占位行。③ 注释块解析——从既有 JSDoc/TSDoc 文本提取摘要与 `@param`/`@returns`/`@throws` 等标签，兼容花括号类型、`-` 描述变体与跨行折叠。④ 一致性比对——将解析结果与函数签名对照，报告缺失/多余 `@param`、名称顺序漂移与返回值标签缺失。

**核心交互**：生成/解析双 Tab；签名输入框 + 方言切换（JSDoc/TSDoc）+ 描述占位开关；生成结果为带复制按钮的代码块；解析区展示参数/类型参数/异常标签表格与比对告警 Alert；内置 async 泛型示例签名与示例注释块。

**输入输出**：输入为函数字符串或注释块文本；输出为规范化签名结构、注释块字符串、解析文档结构、比对报告与可读错误。

**边界情况**：无法识别的函数名或括号不匹配 → 带定位的报错；对象类型返回值（如 `{ x: number; y: string }`）内部分号不被误切；rest 参数按 JSDoc 惯例不加可选方括号；生成→解析往返零漂移；空输入不崩溃。
