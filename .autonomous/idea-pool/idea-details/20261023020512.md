## 描述

通过授权 IP、include、a / mx、all 限定符（-all / ~all / ?all）等选项拼装发信域的 SPF DNS TXT 记录，并可对粘贴的现有记录做语法校验，重点统计 RFC 7208 规定的 10 次 DNS 查询上限（lookup limit）风险并提示机制顺序。SPF 配错会直接导致邮件被拒收或域名可被仿冒，而 include 嵌套导致的 lookup 超限是最隐蔽的坑；现有工具与池内条目均不覆盖 DNS 邮件域记录——HTTP 安全响应头生成器（20261017220048）面向 HTTP 响应头。SPF 是「限定符 + 机制」组成的小型有限词法，纯函数即可完成解析、查询计数与生成，零新依赖、纯本地。
