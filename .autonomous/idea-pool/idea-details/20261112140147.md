## 描述

解析与生成 RFC 7239 定义的 `Forwarded` HTTP 请求头：把逗号分隔的代理链（每跳含 `for` / `by` / `proto` / `host` 等 token，值可能是裸 IPv4、带方括号的 IPv6、`_hidden` / `_obfuscated` 标识符或带引号字符串）解析为结构化的逐跳表格，并支持从结构化数据反向拼装合法头值；对 `for` / `by` 中的 IPv6 自动加方括号、对含特殊字符的值自动加引号并做反斜杠转义，同时给出非法 token 的错误定位。纯字符串/规则解析，零新增依赖，S–M 复杂度，纯函数可在 Vitest 中以固定 RFC 示例向量验收。

## 设计内容（进入 Claimed 前补全）

- 工具目录：`apps/web/src/tools/forwarded-header-codec/`（index.tsx + index.module.css + constants.ts + utils/forwarded.ts + utils/forwarded.test.ts）。
- 核心纯函数（utils/forwarded.ts）：
  - `parseForwardedHeader(input)`：引号感知的逗号/分号两级切分，token 名小写归一，quoted-string 去引号与反斜杠转义还原；输出 `{ valid, elements, errors }`，错误带跳数定位。
  - `validateNode(node)`：覆盖 IPv4 / IPv4:port / 裸 IPv6 / `[IPv6]:port` / `unknown` / `_obfuscated`，非法地址与端口返回错误。
  - `generateForwardedHeader(elements)`：固定 for→by→host→proto 顺序，token 字符集外的值自动加引号并转义内部引号/反斜杠。
- UI（Ant Design）：解析/构造双模式 Radio 切换；解析模式 TextArea + 逐跳 Table + 告警 Alert；构造模式逐跳卡片表单（增删跳），结果卡片可一键复制；解析结果可「载入构造器」再编辑。
