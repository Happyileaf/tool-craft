## 描述

为粘贴的多行文本批量添加行号前缀（可配置起始号、步长、分隔符、零填充对齐宽度、是否给空行编号），并支持反向剥离已有的行号前缀还原原文，用于代码评审引用、日志贴工单、终端输出整理等场景。现有 `line-operations` 只做排序 / 去重 / 反转 / 过滤，不含编号与剥离能力；`text-wrap-formatter` 只做折行。纯字符串确定性处理、零依赖、纯本地计算。

## 设计内容（进入 Claimed 前补全）

- 功能范围：为多行文本批量添加行号前缀（添加模式），并反向剥离已有行号前缀还原原文（剥离模式）。
- 核心交互：添加模式可配置起始号、步长、分隔符（:、.、)、|、自定义）、零填充对齐宽度（自动按最大行数或手动指定）、是否给空行编号；剥离模式自动识别「数字 + 分隔符 + 空白」前缀。
- 输入输出：左侧原始文本，右侧带行号/还原后文本，一键复制；纯字符串确定性处理。
- 边界情况：空输入、全空行、起始号/步长非法（负数、非整数）报错；剥离模式对无行号行原样保留；填充宽度不足时按实际最大宽度兜底；不依赖现有 line-operations 的排序/去重能力。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [x] 添加模式默认起始 1、步长 1，输出 `1: a` / `2: b` 形式且可切换分隔符
- [x] 零填充对齐：3 行宽度 2 时输出 `01:`、`02:`、`03:`

- [x] 剥离模式能把 `1: a`、`02 | b` 还原为 `a`、`b`，无行号行原样保留
- [x] 非法起始号/步长/填充宽度明确报错，不产出错误结果
