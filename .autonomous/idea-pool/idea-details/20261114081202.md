## 描述

为粘贴的多行文本批量添加行号前缀（可配置起始号、步长、分隔符、零填充对齐宽度、是否给空行编号），并支持反向剥离已有的行号前缀还原原文，用于代码评审引用、日志贴工单、终端输出整理等场景。现有 `line-operations` 只做排序 / 去重 / 反转 / 过滤，不含编号与剥离能力；`text-wrap-formatter` 只做折行。纯字符串确定性处理、零依赖、纯本地计算。

## 设计内容（进入 Claimed 前补全）

- 功能范围：提供「添加行号」与「剥离行号」两种模式。添加模式支持起始编号（0–999999）、步长（1–9999）、分隔符（`: `、`. `、`) `、` | `、Tab、空格）、零填充对齐宽度（0 表示按最大编号自动对齐）以及是否为空行编号；剥离模式自动识别行首的 `数字 + : . ) | Tab` 前缀（允许数字与分隔符之间存在对齐空格）并移除，无前缀的行原样保留。
- 核心交互：模式切换与参数调整后对输入文本实时重算，展示编号行数 / 总行数统计；输出区支持一键复制、下载 `.txt`、清空与载入样例；参数非法时给出明确错误提示。
- 输入输出：输入为多行纯文本（保留原有空行与行内空白），输出为带行号文本（添加模式）或移除行号后的还原文本（剥离模式）。
- 边界情况：空输入返回空输出；空行默认不编号且不消耗步长，开启后按当前序号编号；行尾 `\r` 在按行处理时保留 CRLF 语义；剥离模式对 `2026.11.15` 这类非连续编号内容不做贪婪匹配。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 添加模式按起始值、步长、分隔符与零填充宽度生成固定向量：起始 3、步长 2、分隔符 `. `、宽度 3 时 `a\n\nb` 得到 `003. a\n\n005. b`
- [ ] 空行编号开关生效：关闭时空行不编号且不递增序号，开启时空行获得当前序号
- [ ] 剥离模式可移除 `1. `、`02: `、`3) `、`4 | `、`5\t` 等常见前缀并还原原文，无前缀行不被误删
