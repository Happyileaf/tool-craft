## 描述

面向音视频整理与流媒体调试场景，在结构化条目列表与 M3U/M3U8 文本之间双向转换：生成方向支持普通播放列表（`#EXTM3U` + `#EXTINF` 时长 / 标题 + 资源路径）与 HLS 媒体播放列表（`#EXT-X-VERSION`、`#EXT-X-TARGETDURATION`、`#EXTINF` 分片序列、`#EXT-X-ENDLIST`，可选 `#EXT-X-MEDIA-SEQUENCE` / `#EXT-X-PLAYLIST-TYPE`）；解析方向将粘贴的 M3U8 还原为可编辑表格、校验时长标签与分片 URI 配对、统计总时长并报告格式错误。纯本地文本处理，零依赖、不发起任何媒体请求。

## 设计内容（进入 Claimed 前补全）

纯客户端单页工具，零网络、零新增依赖；解析/生成逻辑收敛为可单测纯函数 `utils/m3u.ts`。

- **解析模式**：逐行识别 RFC 8216 标签（EXT-X-VERSION、TARGETDURATION、MEDIA-SEQUENCE、PLAYLIST-TYPE、ENDLIST、EXTINF 等）与分片 URI，输出头信息、分片列表与诊断；错误带行号。
- **生成模式**：由结构化数据拼装规范 M3U8 文本，时长支持秒与 HH:MM:SS 时钟格式互转。
- **边界**：缺失 EXTINF 时长、分片超过 TARGETDURATION 等给出诊断；空白与注释行安全跳过。
