## 描述

面向音视频整理与流媒体调试场景，在结构化条目列表与 M3U/M3U8 文本之间双向转换：生成方向支持普通播放列表（`#EXTM3U` + `#EXTINF` 时长 / 标题 + 资源路径）与 HLS 媒体播放列表（`#EXT-X-VERSION`、`#EXT-X-TARGETDURATION`、`#EXTINF` 分片序列、`#EXT-X-ENDLIST`，可选 `#EXT-X-MEDIA-SEQUENCE` / `#EXT-X-PLAYLIST-TYPE`）；解析方向将粘贴的 M3U8 还原为可编辑表格、校验时长标签与分片 URI 配对、统计总时长并报告格式错误。纯本地文本处理，零依赖、不发起任何媒体请求。

## 设计内容（进入 Claimed 前补全）

- 生成方向：两种模式——普通 M3U（`#EXTM3U` 头，每条目 `#EXTINF:<duration>,<title>` + 资源 URI 两行）与 HLS 媒体播放列表（`#EXT-X-VERSION`、`#EXT-X-TARGETDURATION`（取各分片时长向上取整最大值）、可选 `#EXT-X-MEDIA-SEQUENCE` 与 `#EXT-X-PLAYLIST-TYPE:VOD/EVENT`、分片序列、末尾 `#EXT-X-ENDLIST`）
- 解析方向：逐行状态机解析，还原条目数组（uri、duration 秒、title）与全局 HLS 标签；`#EXTINF` 缺少配对 URI、时长非数字等畸形行收集为错误列表而非抛异常
- 核心交互：左侧结构化条目可增删编辑（路径 / 时长 / 标题），右侧实时生成文本；Tab 切换到解析模式粘贴文本，输出表格 + 总时长统计 + 格式错误
- 输入输出：文本域 + 条目表格；一键复制生成结果；下载 .m3u8 文件
- 边界情况：空列表、CRLF/LF 混用、BOM、带空白与注释行（`#` 开头非已知标签）、相对/绝对 URI、时长为浮点、缺失 `#EXTM3U` 头时给出警告但仍尽力解析
- 纯本地文本处理，零依赖、不发起任何媒体请求

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 生成模式：给定 3 条媒体（路径、时长、标题），输出首行为 `#EXTM3U`，每条目严格为 `#EXTINF` 行 + URI 行，顺序与输入一致
- [ ] HLS 模式：输出包含 `#EXT-X-VERSION:3`、`#EXT-X-TARGETDURATION`（等于各分片时长向上取整最大值）、`#EXT-X-ENDLIST`；设置 mediaSequence=10 时出现 `#EXT-X-MEDIA-SEQUENCE:10`
- [ ] 解析模式：粘贴 RFC 8216 官方简单媒体播放列表示例，正确还原全部分片 uri/duration 与总时长；往返（生成→解析）数据一致
- [ ] 异常输入：空文本、缺失 `#EXTM3U` 头、`#EXTINF` 后无 URI、时长非数字均给出明确错误/警告，不抛异常、不丢行
- [ ] 全程本地运行，无网络请求、无第三方依赖
