## 描述

面向音视频整理与流媒体调试场景，在结构化条目列表与 M3U/M3U8 文本之间双向转换：生成方向支持普通播放列表（`#EXTM3U` + `#EXTINF` 时长 / 标题 + 资源路径）与 HLS 媒体播放列表（`#EXT-X-VERSION`、`#EXT-X-TARGETDURATION`、`#EXTINF` 分片序列、`#EXT-X-ENDLIST`，可选 `#EXT-X-MEDIA-SEQUENCE` / `#EXT-X-PLAYLIST-TYPE`）；解析方向将粘贴的 M3U8 还原为可编辑表格、校验时长标签与分片 URI 配对、统计总时长并报告格式错误。纯本地文本处理，零依赖、不发起任何媒体请求。

## 设计内容（进入 Claimed 前补全）

- 工具 slug：`m3u-playlist-codec`，分类 TEXT（文本与字符），主线程零依赖纯文本处理。
- 核心纯函数（utils/m3u.ts）：
  - `parseM3u(text)`：解析为结构化条目数组 `{ duration, title, uri, attrs: Record<string,string> }`；识别 `#EXTM3U` 头、`#EXTINF:<duration>,<title>`、`#EXT-X-KEY`、`#EXT-X-STREAM-INF`（HLS 变体流，属性按 KEY=VALUE 解析，带引号 VALUE 去引号）、普通注释 `#` 行跳过、URI 行与前一条 EXTINF 配对；无 EXTM3U 头时按宽松模式解析并标记 `headerMissing`。
  - `stringifyM3u(entries, options)`：反向序列化，保留 HLS 指令行（key/streamInf 等以原始指令透传或由 attrs 重建），输出 LF 换行。
  - `relativeToAbsolute(baseUrl, m3uText)`：把相对 URI 按 base URL 解析为绝对 URI（仅处理 http/https 相对路径，不依赖 URL 以外能力）。
  - `validateM3u(text)`：校验报告——缺 EXTM3U 头、EXTINF 无后续 URI、duration 非数字、HLS target duration 缺失等问题带行号。
- 边界：CRLF 归一化、空文件/仅注释、`#EXTINF:-1,` 直播流时长、属性值内逗号、BOM 剥离；解析不抛异常，错误进 issues 列表。
- 组件：左右双栏（输入 TextArea / 结构化表格结果）、生成模式（表格增删行→M3U 文本）、校验告警 Alert、相对转绝对输入框、示例与复制下载。
