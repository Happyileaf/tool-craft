## 描述

填写应用名、图标列表（尺寸 / 类型 / purpose）、主题色、背景色、显示模式（standalone / fullscreen 等）、起始页与 shortcuts 后，生成 manifest.json 及配套 `<link rel="manifest">` 与主题色 meta 片段，用于把网站接入为可安装 PWA。manifest 字段繁多（icons 的 sizes / type / purpose 组合、display 与 display_override、shortcuts 图标要求），手写易错且文档分散；现有工具与池内条目均不覆盖——Open Graph / SEO 元标签生成器（20261018000142）面向 head 元标签，不产出 manifest 文件。表单字段到 JSON 的映射为纯函数拼装，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：表单生成 PWA Web App Manifest（manifest.json + head 片段），工具 slug 为 `web-manifest-generator`。
- **基础字段**：name、short_name、description、start_url、scope、display（fullscreen/standalone/minimal-ui/browser）、orientation、theme_color、background_color、lang、dir、id、categories。
- **图标**：可增删多行图标（src / sizes / type / purpose 复选 any、maskable、monochrome），空 src 行被过滤。
- **shortcuts**：可增删多条快捷方式（name / short_name / url / icon src+sizes）。
- **输出**：格式化 JSON（2 空格缩进、空值字段省略），另输出 `<link rel="manifest" href="/manifest.json">` 与 theme-color meta 片段；一键复制。
- **校验**：必填字段缺失（name / start_url）、颜色格式非法、图标 src 非法 URL 等给出明确提示。
- **输入输出**：纯函数 `buildManifest(form)` 与 `buildHeadSnippet(form)`，不触碰 DOM / React。
- **边界情况**：全空表单给出空态；空图标 / 空 shortcut 自动过滤；布尔 / 枚举默认值不输出冗余字段。
