## 描述

通过表单配置 User-agent、Allow / Disallow 规则、Sitemap 地址与 Crawl-delay 等指令，自动生成符合规范的 robots.txt 文本，并提供常见爬虫（Googlebot、Bingbot 等）预设、常用规则模板与基础语法校验（如缺少 User-agent 分组、路径未以 / 开头等提示）。现有工具集中无站点配置文件生成类能力，而站点上线时 robots.txt 的编写与排查属常见需求；纯函数文本生成，零新增依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：表单编辑多组爬虫规则生成 robots.txt 文本，工具 slug 为 `robots-txt-generator`。
- **规则模型**：多条规则组，每组含 User-agent 列表（支持 `*` 等通配）、Allow / Disallow 路径列表与可选 Crawl-delay；全局可配多条 Sitemap 地址。
- **预设**：内置全部允许、全部禁止，以及 Googlebot / Bingbot 等常见爬虫预设，一键填充。
- **校验**：路径未以 `/` 开头、缺少 User-agent 分组、Sitemap 非 http(s) URL 等给出明确提示；非法路径不阻断其余组输出。
- **输出**：按组拼装规范文本（`User-agent:` / `Allow:` / `Disallow:` / `Crawl-delay:` / 空行分组 + 末尾 Sitemap），一键复制。
- **输入输出**：纯函数 `generateRobotsTxt(groups, sitemaps)` 与校验函数，不触碰 DOM / React。
- **边界情况**：空表单输出空态；空 User-agent 组被跳过或报错；重复路径不去除语义仅按输入输出。
