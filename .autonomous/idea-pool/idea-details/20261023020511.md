## 描述

输入 Twitter / X、Discord 等平台使用的 Snowflake ID，解析出创建时间（毫秒时间戳并本地化展示）与机器位、序列号，并支持反向由时间戳生成示例 ID。社区运营、客服排查与数据迁移常需要从消息 / 用户 / 频道 ID 直接还原创建时间（如 Discord 消息链接中的 ID）；现有 uuid-generator 仅生成 UUID，池内 UUID 解析校验器（20261021221302）面向 UUID 版本位与变体位、ULID 生成器（20261017160148）面向 ULID，位布局均与 Snowflake（平台纪元 + 41 位毫秒时间戳 + 10 位机器位 + 12 位序列号）不同，互不重叠。按位拆解与纪元换算是纯函数运算，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：64 位 Snowflake ID 位拆解与时间还原，工具 slug 拟为 `snowflake-id-parser`。
- **位布局**：最高位 1 bit 保留 + 41 bit 毫秒时间戳（相对纪元）+ 10 bit 机器 / Worker ID + 12 bit 序列号；时间戳 = (id >> 22) + epoch。
- **纪元预设**：内置 Twitter/X（1288834974657）、Discord（1420070400000）纪元，并允许自定义纪元毫秒值。
- **解析输出**：十进制 / 十六进制 / 二进制展示，时间戳（毫秒）、UTC 与本地 ISO 时间、机器 ID（0–1023）、序列号（0–4095）。
- **反向生成**：给定时间（与可选机器位 / 序列位）拼装示例 Snowflake（机器位、序列位默认 0，可填）。
- **输入输出**：纯函数，不触碰 DOM / React。
- **边界情况**：非数字、负数或超过 64 位安全范围（> 2^63-1）给出明确错误；解析出的时间戳早于纪元时提示。
