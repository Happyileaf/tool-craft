## 描述

基于理想运放「虚短、虚断」模型，对四种经典负反馈拓扑做参数计算：反相放大器（增益 `−Rf/Rin`）、同相放大器（增益 `1+Rf/Rg`）、反相加法器（多通道按 `−Rf·Σ(Vi/Ri)` 求和）与差分放大器（`Rf/R1·(V2−V1)`，含电阻匹配条件提示）。用户输入电阻值（支持 Ω/kΩ/MΩ 单位后缀）与输入电压，输出闭环增益、输出电压、输入阻抗（反相拓扑）与同相拓扑反馈支路电流，并给出电路连接示意（纯 SVG/CSS）；同时支持由目标增益反推推荐电阻比值。面向电子工程教学、电路设计评审与硬件面试复习场景，全部为本地确定性数值运算，零新增依赖。与现有 ohms-law-calculator（单电阻 V/I/R）、resistor-voltage-divider（无源分压）、resistor-network-calculator（串并联等效）、rc-filter-calculator、ne555-astable-calculator 等不重复：现有工具均不涉及有源器件与负反馈拓扑增益公式，本工具补齐模拟电路家族的运放缺口。

## 设计内容（进入 Claimed 前补全）

- 四种拓扑（理想运放虚短/虚断模型）：
  - 反相放大器：Av = −Rf/Rin，Vout = Av·Vin，输入阻抗 ≈ Rin，反相端虚地
  - 同相放大器：Av = 1 + Rf/Rg，Vout = Av·Vin，输入阻抗极高（理想为 ∞，标注近似）
  - 反相加法器（2–4 通道）：Vout = −Rf·Σ(Vi/Ri)，每通道独立 Ri
  - 差分放大器：Vout = (Rf/R1)·(V2−V1)（Rf/R1 = Rg2/Rg1 匹配时），不匹配时给出共模抑制警告与通用公式
- 输入：电阻支持 Ω/kΩ/MΩ 后缀（不区分大小写）与纯数字（按 Ω）；电压支持 V/mV 后缀；非法/零/负值明确报错（电阻必须 > 0）
- 输出：闭环增益（带符号）、输出电压 V、反相拓扑输入阻抗、同相/差分拓扑反馈支路电流 If = (V−−Vout)/Rf（虚短下 V− = V+），数值保留合理有效数字
- 反推模式：给定目标增益（同相/反相），输出推荐 Rf/Rin（或 Rf/Rg）比值，并给一组 E24 标称阻值建议（Rin/Rg 取 10kΩ 基准）
- 每种拓扑配纯 SVG 电路连接示意图（电阻、运放三角符号、节点标注），无外部图片
- 边界：零电阻、空输入、加法器通道为空、差分电阻不匹配、增益数值溢出（有限性检查）均有明确提示
- 纯本地确定性数值运算，零新增依赖

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 同相：Rg=10kΩ、Rf=90kΩ 时 Av=10；Vin=0.2V 时 Vout=2V
- [ ] 加法器：两通道 V1=0.1V/R1=10k、V2=0.2V/R2=10k、Rf=100k 时 Vout=−3V
- [ ] 差分：R1=Rg1=10k、Rf=Rg2=100k、V1=0.1V、V2=0.3V 时 Vout=2V；不匹配时出现警告
