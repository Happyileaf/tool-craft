## 描述

在浏览器本地按 AWS Signature Version 4 规范，对一次 HTTP 请求生成 `Authorization` 签名头（含 Canonical Request、String to Sign、Signing Key 派生过程的分步展示），用于调试 S3、API Gateway、STS 等 AWS SigV4 鉴权请求。解决手工拼 SigV4 签名（规范请求、凭证范围、多步 HMAC 派生）极易出错且缺少分步排错视图的问题。密钥仅在浏览器内参与 HMAC-SHA256 计算，不上传。
