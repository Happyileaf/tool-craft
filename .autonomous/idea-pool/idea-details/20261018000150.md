## 描述

计算并简化宽高比，在宽度、高度、比值三者中给定任意两项时补全第三项，支持按比例缩放尺寸、识别常见标准比例（16:9、4:3、3:2、21:9 等）并给出近似匹配提示，用于图片、视频与布局的尺寸推导。当前图像类工具聚焦压缩与裁剪，不提供独立的宽高比换算。

## 设计内容（进入 Claimed 前补全）

工具 slug：`aspect-ratio-calculator`，分类「时间与计算」（time-math），复杂度 S，主线程纯函数运算，零新依赖。

- 三种模式：①化简比例（输入宽高 → 最简整数比 + 标准比例近似匹配，容差 1%）；②知二求三（输入 `W:H` 比值与一条边，选择求宽 / 求高，补全另一边）；③按比例缩放（输入原始宽高，按目标宽度 / 目标高度 / 倍数等比换算）。
- 纯函数位于 `utils/aspect-ratio.ts`：`parsePositive`、`parseRatioText`、`gcd`、`simplifyRatio`（小数先按 1e6 整数化再约去 GCD）、`resolveSide`、`scaleByFactor`、`scaleToWidth`、`scaleToHeight`、`matchStandardRatio`、`formatResult`，非法 / 零 / 负数输入返回 null，由 UI 提示。
- UI 按 percentage-calculator 模式：`'use client'` + antd Card/Radio/Input/Tag/Alert + CSS Modules，输入实时联动。
- 注册 `registry.ts`（中英双语 ToolMeta + doc）与 `loaders.ts` 懒加载；Vitest 同目录单测覆盖全部纯函数与边界。
