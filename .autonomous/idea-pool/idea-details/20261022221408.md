## 描述

输入缩进列表或换行分隔的路径列表（如 `src/main.ts`、`src/utils/a.ts`），生成 tree 命令风格的 ASCII 目录树（`├──`、`└──`、`│` 连接线），支持控制展示深度、排序方式与目录 / 文件过滤，可一键复制用于 README 或技术文档。现有 Markdown 工具（目录 TOC 生成器、表格生成器）均不涉及目录结构可视化，手写 tree 连接字符既繁琐又易对不齐。核心为树构建与纯字符串处理算法，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- 纯函数核心（`utils/tree.ts`）：
  - 解析：按换行拆分路径列表，trim 后跳过空行；同时兼容 `/` 与 `\` 分隔符（统一按 `/` 切分）；自动去掉首尾分隔符；重复路径去重。
  - 建树：以嵌套 Map 构建目录树（中间缺失的目录自动补为目录节点，如只给 `a/b/c.ts` 也能生成完整层级）；同名字段冲突时文件优先展示。
  - 排序选项：名称字典序（目录优先）/ 保持输入顺序；可选仅目录、隐藏条目（`.` 开头）过滤；可选最大深度（超出显示 `…`）。
  - 渲染：递归生成 tree 风格文本，前缀用 `├── `、`└── `、`│   `、`    ` 连接；可选根名标题行。
- UI：左侧路径 TextArea（带样例）、右侧等宽字体 `<pre>` 结果；排序/深度/过滤控件；一键复制；统计条目数。零依赖、主线程。
