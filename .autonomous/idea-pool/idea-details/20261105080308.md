## 描述

在浏览器本地完成 SQL 字符串字面量的双向转义：编码方向把任意文本按 SQL 标准（单引号字符串内 `'` 双写为 `''`，反斜杠按所选方言可选处理为 `\\`，换行输出为 `CHAR(13)+CHAR(10)` 拼接或 `\n` 转义）包裹为可直接嵌入 SQL 的字面量；解码方向把带单引号的 SQL 字面量还原为原始文本（处理 `''` 转义、可选反斜杠转义模式），并对未闭合引号、非法转义报错。另提供 LIKE 模式转义子能力：把用户输入中的 `%`、`_`、`\` 按指定 ESCAPE 字符转义，避免通配符注入，并生成对应的 `LIKE '...' ESCAPE '\'` 片段。

现有 `string-escape` 仅支持 JavaScript/JSON、Python、Java 三种双引号字面量，不覆盖 SQL 的单引号双写规则与 LIKE 通配符语义；`csv-to-sql`、`json-to-sql-ddl` 面向批量语句/DDL 生成，不做通用文本与字面量的互转。规则由 SQL 标准与各主流方言（MySQL `NO_BACKSLASH_ESCAPES` 开关、PostgreSQL 标准 conforming strings）确定，零依赖纯函数可对固定向量做确定性断言，复杂度 S。
