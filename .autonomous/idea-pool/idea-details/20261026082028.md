## 描述

提供复利收益测算：输入初始本金、年化利率、投资期限（按年或按月）、复利频率（年 / 季 / 月 / 日）以及可选的每期定投金额与投入时点（期初 / 期末），输出期末本息总额、累计投入本金、累计收益，并给出逐期增长明细与同等条件下单利结果的对比，帮助用户直观理解复利效应与长期定投的终值。纯本地确定性财务公式（等比数列求和）、零新增依赖，可用已知金融算例（固定本金 + 年利率 + 年限、固定月投 + 月利率 + 期数）精确验收。与已实现的 percentage-calculator（百分比换算）及在池的「贷款 / 月供计算器（等额本息与等额本金）」不同：本工具面向投资增长与定期定额投入的终值测算，现金流方向与公式目标均不同，不构成重复。
