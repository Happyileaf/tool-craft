## 描述

提供一个支持运算符优先级、括号嵌套、常用数学函数（sin / cos / tan / asin / log / ln / sqrt / abs / pow / floor / round 等）、常量（pi / e）与变量赋值复用的表达式求值器（科学计算器），并展示逐步计算过程与语法错误定位。现有工具集中仅有 JSON、时间戳、数字进制、百分比等专项转换，缺少通用的数学表达式解析与求值能力；基于 Shunting-yard / 递归下降自研纯函数解析器即可实现，零新增依赖。

## 设计内容（进入 Claimed 前补全）

- slug：`math-expression-evaluator`，分类 TIME_MATH，主线程纯浏览器运算，零新增依赖。
- 核心为 `utils/evaluator.ts` 纯函数：词法分析（数字含小数/科学计数法、标识符、操作符、括号、逗号）→ 递归下降 Parser（幂右结合、一元正负、阶乘后缀、函数调用、ident 赋值检测）→ AST 求值并记录逐步 trace。
- 支持四则、取模、幂、阶乘、括号；sin/cos/tan/asin/acos/atan/atan2（角度模式自动换算）、sinh/cosh/tanh、sqrt/cbrt/abs/floor/ceil/round/exp/log/ln/log10/log2/pow/min/max；常量 pi/e/tau；多行语句与变量赋值复用；# 与 // 注释。
- 错误信息带行号、列号与中文说明（未定义变量、除零、阶乘限制、参数个数、域名校验等）。
- UI：左输入右结果双栏 Card，角度开关、示例切换、清空、复制结果，变量以 Tag 展示，逐步过程按行分组。
