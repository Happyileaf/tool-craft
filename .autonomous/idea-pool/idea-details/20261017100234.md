## 描述

根据 Base32 密钥生成符合 RFC 6238 的基于时间的一次性密码（TOTP），展示当前验证码与剩余有效期，用于本地调试双因素认证流程。现有加密类工具（`hash-generator`、`bcrypt-hash`、`jwt-parser` 等）均为静态摘要 / 令牌能力，缺少时间同步的一次性密码生成。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：实现 RFC 6238 TOTP：Base32 密钥解码 → 时间步计数（默认 30s）→ HMAC（默认 SHA-1，支持 SHA-256 / SHA-512）→ 动态截断 → 指定位数（默认 6 位，支持 8 位）十进制验证码。
- **核心交互**：输入 Base32 密钥，展示当前验证码（分组显示）、剩余有效期进度条与秒数倒计时并自动刷新；可调整位数、时间步、算法；提供 RFC 6238 附录 B 测试向量一键载入与校验。
- **输入输出**：输入 Base32 密钥与参数，输出当前及相邻时间步的验证码；非法 Base32 输出可读错误。
- **边界情况**：密钥含空格 / 小写 / 填充符 `=` 需容错归一化；非 Base32 字符报错；计数器溢出与时间戳（秒）注入以支持确定性测试；HMAC 依赖 Web Crypto（`crypto.subtle`），需处理异步与不可用场景。
