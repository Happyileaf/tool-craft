## 描述

以结构化表单填写姓名、职务、组织、电话、邮箱、网址、地址与备注等字段，生成符合 vCard 3.0 / 4.0 规范的联系人文本（.vcf），正确处理换行与特殊字符转义、多值字段与字段类型标记，并支持一键复制与下载文件。用于为通讯录导入、邮件签名或名片二维码快速准备标准的 vCard 内容。现有 qr-generator 只生成二维码图像、不产出 vCard 文本，工具集中无 vCard 生成能力。基于静态字段映射与转义的纯函数实现，零新增运行时依赖。

## 设计内容（进入 Claimed 前补全）

- 纯函数核心（`utils/vcard.ts`，零依赖）：
  - 转义：文本值中的 `\`、`,`、`;`、换行按 vCard 规范转义（`\\`、`\,`、`\;`、`\n`）；结构化字段 N/ADR 以 `;` 拼 5 段（姓;名;中间;前缀;后缀 / 邮政信箱;扩展;街道;城区;区域;邮编;国家）。
  - 行折叠：输出按 RFC 6350 规则在 75 字符处折行（续行以单个空格开头，按字符数折叠）。
  - 字段：FN（必填）、N、TITLE、ORG、TEL（带 TYPE，3.0 用 `HOME,VOICE` 逗号、4.0 用 `;TYPE=` 分号与 `tel:` URI）、EMAIL（TYPE）、URL、ADR、NOTE、BDAY（YYYY-MM-DD）；多值电话/邮箱输出多行；版本 3.0 与 4.0 语法差异由版本参数切换。
  - 组装：`BEGIN:VCARD / VERSION / … / END:VCARD`，行尾 CRLF；FN 缺失返回校验错误。
- UI：antd 表单（姓名必填、职务、组织、生日、动态增删多个电话/邮箱、网址、地址分段、备注）+ 版本 Radio（3.0/4.0）；实时预览；复制文本与下载 `.vcf`（Blob，本地生成）。零依赖、主线程。
