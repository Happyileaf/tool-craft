## 描述

通过表单字段（收件人 to 多个、抄送 cc、密送 bcc、主题 subject、正文 body）生成符合 RFC 6068 / RFC 2368 的 `mailto:` 链接，自动对主题与正文做 `application/x-www-form-urlencoded` 百分号编码（空格为 `%20`、保留换行 `%0D%0A`、多收件人用逗号连接），并提供可复制链接与「试试打开邮件客户端」预览；反向支持粘贴已有 mailto 链接解析回填各字段。用于在文档、网页、工单模板中快速生成预填邮件。与已实现的 `url-parser`（解析通用 URL 各组件与查询串）不同：该工具面向浏览型 URL 解析，不生成 mailto、不处理 hfields（cc/bcc/subject/body 邮件专有头）与多收件人逗号规则，也不做邮件正文换行编码；本工具是面向 mailto URI 规范的双向专用工具，能力不重叠。纯确定性字符串处理，纯函数实现，零新增依赖。
