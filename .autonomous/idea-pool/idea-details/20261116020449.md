## 描述

把任意字符串安全地转成 shell 命令参数形式，并支持反向去引用还原：POSIX sh（单引号包裹、内含单引号时按 `'\''` 断开、含控制字符时给出 `$'...'` 形式说明）、Windows CMD（双引号包裹与 `^` 转义规则、`%` 变量提示）、PowerShell（单引号包裹与内部单引号双写）。用于生成可复制的命令行、排查「参数含空格 / 引号 / 通配符导致命令失败」的问题、编写跨平台脚本与 CI 配置；纯本地字符串处理，不执行任何命令。

## 设计内容（进入 Claimed 前补全）

功能范围：目标 shell 单选（POSIX sh / Windows CMD / PowerShell）；双向模式（原文 → 引用参数 / 引用参数 → 原文）；批量模式按行处理每个参数；POSIX 下检测换行、制表符等控制字符并提示 `$'...'`；CMD 下检测 `%VAR%` 与 `!VAR!` 延迟展开并提示；输出附「可直接粘贴的命令片段」（如 `command '<quoted>'` 占位模板）。

核心交互：单行 / 多行输入、shell 与方向切换、一键互换、示例（含空格、单引号、`$`、反斜杠、`%`、换行）预置、逐行结果与告警、复制结果。

输入输出：输入原始字符串或已引用的参数字面量；输出目标 shell 的安全引用形式或还原后的原始字符串，以及逐条告警（不可打印字符、变量展开风险、无法无损还原的写法）。

边界情况：空字符串输出 `''`；已引用输入若不符合该 shell 语法则报错并定位；跨 shell 的不兼容写法（如 CMD 双引号内含 `"` 的处理）明确说明；含 NUL 字节拒绝处理并告警；不尝试解析完整命令行（管道、重定向、多条命令不在范围内）。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] POSIX 下 `Hello World` → `'Hello World'`，`it's` → `'it'\''s'`
- [ ] POSIX 下含换行的输入给出 `$'...\n...'` 形式并附说明

- [ ] PowerShell 下 `it's` → `'it''s'`，反向还原回到 `it's`
- [ ] 三种 shell 的引用 → 去引用往返在固定向量上均可无损还原
- [ ] 空串、含 `$` / 反斜杠 / 通配符 `*` 的输入均能输出稳定结果，非法已引用输入返回定位明确的错误
