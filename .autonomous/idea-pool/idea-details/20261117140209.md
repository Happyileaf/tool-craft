## 描述

照明设计入门计算（利用系数法/流明法）：输入房间长、宽、灯具安装高度与工作面高度（得计算高度 hrc）、室空间比 RCR 自动计算、灯具单灯光通量、灯具数量、维护系数 MF、利用系数 CU（可手动给或按 RCR 线性插值表输入），输出工作面平均维持照度 Eavg = N·Φ·CU·MF / A，并支持反算所需灯具数量与所需单灯光通量；另给室空间比 RCR=5·hrc·(L+W)/(L·W) 与室形指数 RI=(L·W)/(hrc·(L+W)) 两个中间量。现有工具无任何照明类（lumen/lux/illuminance/lamp/light 注册表仅命中无关的 clamp-typography），池内"照明"命中项为色温转换器（20261027040226，输出光色而非照度），"流明/照度/利用系数/维护系数/均匀照度"零命中。纯算术与查表插值，零依赖，S 复杂度。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：①几何量：面积 A、计算高度 hrc=安装高度−工作面高度、RCR、RI；②正算 Eavg（流明法公式）；③反算模式：目标照度 → 所需灯具数 N（向上取整并给实际照度复核），或目标照度+固定 N → 所需单灯光通量；④CU 支持直输或 RCR→CU 对照表插值（表数据由用户在界面可编辑，预置一组示例行并注明需替换为厂商光度数据）；⑤MF 给常用参考区间提示（0.6–0.8，洁净/一般/污染环境）。
- **核心交互**：房间尺寸与高度表单；正算/反算模式切换；CU 输入方式切换（直输/插值表）；结果卡片显示 Eavg（lux）、N、RCR、RI 与利用率诊断（RCR 过大提示利用系数偏低）。
- **输入输出**：长度 m、光通量 lm、照度 lux；N 为正整数；反算 N 时输出 ceil 值与取整后实际 Eavg。
- **边界情况**：任一尺寸 ≤0、工作面高度 ≥ 安装高度、CU/MF 超出 (0,1] 区间、N≤0 均明确报错；插值表为空或 RCR 超出表范围时报错或提示外插不可用；反算结果 N 给出上限保护（如 >10000 提示输入异常）。
- **核心算法**（纯函数，零依赖，放 `utils/lumen-method.ts`）：roomCavityRatio / roomIndex / averageIlluminance / requiredLuminaireCount / lerpInterp 独立纯函数；插值为分段线性，表按 RCR 升序校验。
- **测试覆盖**（`utils/lumen-method.test.ts`）：教材向量——例：10 m×8 m、hrc=2.5 m、Φ=3000 lm、N=12、CU=0.55、MF=0.8 → Eavg 与手算一致；RCR=5×2.5×18/80=2.8125、RI=1/0.5625 关系 RI=2.5/RCR 校验；反算 N 向上取整且复核照度 ≥ 目标；插值在表节点上精确、节点间线性；非法输入与表乱序/越界抛错。
