## 描述

可视化选择前景 / 背景色（标准 8/16 色、256 色与 RGB 真彩色）与样式（加粗、斜体、下划线、闪烁等），实时预览终端渲染效果（本地 CSS 模拟），并生成对应的 ANSI 转义序列（如 `\x1b[38;5;196m`）、字符串字面量形式与 `echo -e` 可用的 Shell 命令。CLI 开发与日志着色调试时需要反复查表拼接转义码，容易记错色彩空间参数段；现有颜色类工具（oklch-workbench、color-mixer、css-filter-generator 等）全部面向 CSS，无终端领域覆盖。转义序列构造为纯字符串拼接与编号映射，零新依赖、纯本地。
