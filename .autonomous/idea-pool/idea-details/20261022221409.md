## 描述

可视化选择前景 / 背景色（标准 8/16 色、256 色与 RGB 真彩色）与样式（加粗、斜体、下划线、闪烁等），实时预览终端渲染效果（本地 CSS 模拟），并生成对应的 ANSI 转义序列（如 `\x1b[38;5;196m`）、字符串字面量形式与 `echo -e` 可用的 Shell 命令。CLI 开发与日志着色调试时需要反复查表拼接转义码，容易记错色彩空间参数段；现有颜色类工具（oklch-workbench、color-mixer、css-filter-generator 等）全部面向 CSS，无终端领域覆盖。转义序列构造为纯字符串拼接与编号映射，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- 纯函数核心（`utils/ansi.ts`）：
  - 前景/背景三类色彩空间：标准 16 色（30–37/40–47 与亮色系 90–97/100–107）、256 色（`38;5;n` / `48;5;n`，n=0–255）、真彩色（`38;2;r;g;b` / `48;2;r;g;b`）。
  - 样式 SGR 属性：reset=0、bold=1、dim=2、italic=3、underline=4、blink=5、reverse=7、hidden=8、strikethrough=9。
  - 构造转义序列：`\x1b[<参数以 ; 连接>m<文本>\x1b[0m`；同时产出 JS 字符串字面量形式（`\x1b` 转义）与 `echo -e '...'` Shell 命令（用 `\033` 或 `\e`）。
- UI：文本输入、前景/背景取色（模式切换 + 颜色面板/RGB 输入）、样式多选开关、终端样式实时预览（本地 CSS）、三种结果一键复制；零依赖、主线程。
