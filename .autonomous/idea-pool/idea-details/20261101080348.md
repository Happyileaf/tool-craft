## 描述

按 RFC 9116 生成放置于 `/.well-known/security.txt`（以及可选的 `/.well-known/security.txt` 传统路径）的安全联系人策略文件：通过表单录入必填的 `Contact`（支持多个，如 mailto / https / tel URI）与 `Expires`（带过期时间的日期校验提示），以及可选的 `Encryption`、`Acknowledgments`、`Preferred-Languages`、`Canonical`、`Policy`、`CSAF` 字段，按规范顺序输出纯文本（`\r\n` 换行、末尾数字签名注释位），并支持一键复制；同时提供解析模式：粘贴已有 security.txt 校验必填字段、字段拼写、过期时间是否临近。延续池中 robots.txt / sitemap.xml / SPF / DMARC / HTTP 安全响应头等「Web/邮件策略文件生成」系列，纯本地文本生成、零新增依赖。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：按 RFC 9116 生成与校验 `/.well-known/security.txt`，工具 slug 拟为 `security-txt-generator`。
- **字段**：必填 `Contact`（可多个，mailto/https/tel URI）与 `Expires`（RFC 5322 或 ISO 日期时间）；可选 `Encryption`、`Acknowledgments`、`Preferred-Languages`、`Canonical`、`Policy`、`CSAF`，多值字段均支持多条。
- **生成**：按 RFC 规定字段顺序输出（Contact、Expires、Encryption、Acknowledgments、Preferred-Languages、Canonical、Policy、CSAF），CRLF（`\r\n`）换行，值做行长度提示；一键复制并给出部署路径提示。
- **解析校验**：粘贴已有 security.txt，检查必填 Contact / Expires 是否存在、字段名拼写（未知字段提示）、Expires 是否过期或 30 天内临期、是否含 PGP 签名块。
- **边界情况**：缺必填字段、过期时间、重复字段均给出中文提示；纯函数不触碰 DOM / React。
