## 描述

在常见数据库与驱动占位符风格之间转换 SQL 语句：位置式 `?`、编号式 `$1`（PostgreSQL）与 `:1`、命名式 `:name` / `@name` / `%(name)s` / `{{name}}`、SQL Server 编号式 `@p1` 与 Python 位置式 `%s`；扫描时跳过单引号字符串、双引号 / 反引号 / 方括号标识符、`--` 与 `/* */` 注释以及 PostgreSQL 美元引用字符串，输出转换后 SQL、参数顺序 / 名称清单与绑定次数。用于数据库迁移、驱动切换与统一日志中的参数写法；纯本地词法扫描，不做 SQL 语法解析或格式化。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 支持九种风格：`?`、`%s`（位置式）；`$n`、`:n`、`@pN`（编号式）；`:name`、`@name`、`%(name)s`、`{{name}}`（命名式）；② 源风格自动识别或手动指定；自动识别时若同一语句出现多种风格 → 报错并列出风格；③ 统一参数模型：位置式按出现顺序编号 1..N；编号式要求从 1 开始连续且同号可重复；命名式按首次出现顺序记录，同名可重复；④ 目标风格转换：命名式 → 编号式（同名复用同一编号，参数清单去重）；命名式 → 位置式（同名重复展开为多个占位符，参数清单按绑定顺序重复）；位置式 → 命名式（生成 `p1`..`pN`，前缀可自定义）；命名式 → 命名式（保留原名，校验名称合法）；⑤ 跳过区域：单引号字符串（支持 `''` 与反斜杠转义）、双引号标识符（`""`）、反引号标识符、方括号标识符（`]]` 转义）、`--` 行注释、`/* */` 块注释、`$$...$$` 与 `$tag$...$tag$` 美元引用字符串；⑥ 输出：转换后 SQL、参数清单（序号 / 名称 / 绑定次数）、未转换或需要注意的项、字符偏移定位的错误信息。

**核心交互**：SQL 输入框、源风格下拉（自动 / 九种之一）、目标风格下拉、命名前缀输入（位置式 → 命名式时生效）、转换按钮或实时转换、结果区（转换后 SQL、参数表）、复制按钮、示例（MyBatis / JDBC / psycopg2 片段）；错误时标出偏移位置。

**输入输出**：输入为 SQL 文本、源风格（可选自动）、目标风格、命名前缀；输出为转换后的 SQL、参数清单与绑定次数、检测到的源风格、错误或提示。

**边界情况**：空输入 → 明确错误；未发现任何占位符 → 提示且不改写；`$0`、编号从 2 开始或跳号 → 编号式错误；`::` 类型转换不当作 `:name`；`@@version` 不当作 `@name`；`?|`、`?&`（PostgreSQL jsonb 运算符）不作为 `?` 占位符；`$$` / `$tag$` 内不扫描占位符，未闭合 → 报错；未闭合的字符串 / 标识符 / 块注释 → 报错并给偏移；命名占位符名称须匹配 `[A-Za-z_][A-Za-z0-9_]*`（`%(name)s` 同规则），非法名称报错；不同名大小写按区分处理并提示；单引号内 `\%s`、`%(x)s` 不改写；明确说明 PostgreSQL 普通 `?` jsonb 存在运算符、MySQL `@user` 用户变量与本工具命名风格存在歧义，需要时手动指定源风格。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] `SELECT * FROM t WHERE a = ? AND b = ?` 转 `$n`：输出 `... a = $1 AND b = $2`，参数清单 2 项、各绑定 1 次
- [ ] `SELECT * FROM t WHERE a = $1 AND b = $2 AND c = $1` 转 `?`：输出三个 `?`，绑定顺序为 `1, 2, 1`，去重参数 2 项
- [ ] `SELECT * FROM t WHERE a = :id AND b = :name AND c = :id` 转 `$n`：输出 `$1 / $2 / $1`，去重参数为 id、name；转 `?`：输出三个 `?`，绑定次数为 id×2、name×1
- [ ] `SELECT * FROM t WHERE a = ? AND b = ?` 转 `:name`（前缀 p）：输出 `:p1`、`:p2`；转 `%(name)s`：输出 `%(p1)s`、`%(p2)s`
- [ ] `@p1` / `@p2` 转 `:name`：输出 `:p1` / `:p2`；`%s` 转 `$n`：按顺序输出 `$1` / `$2`
- [ ] `{{{a}}}` 转 `?`：输出两个 `?`；`%(a)s` 与 `%(b)s` 转 `$n`：输出 `$1` / `$2`
- [ ] 跳过测试：`SELECT '?' AS q, "?" AS c, \`?\` AS b, $$?$$ AS d /* ? */ -- ?\nFROM t WHERE id = ?` 转 `$n`：仅末尾一个占位符被转换，输出 `$1`，字符串 / 标识符 / 注释 / 美元引用内容原样保留
- [ ] 混合风格 `WHERE a = ? AND b = :name` 自动识别 → 明确报错；`SELECT $2` 或 `SELECT $1, $3` → 编号错误；未闭合 `'abc`、`/* x`、`$tag$ x` → 带偏移的报错
