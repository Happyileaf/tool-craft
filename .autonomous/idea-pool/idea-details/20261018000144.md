## 描述

解析 ISO 8601 时长字符串（如 `P1Y2M3DT4H5M6S`、`PT90M`）为各时间单位明细与总秒数，并可将秒数 / 时分秒反向格式化为标准 ISO 8601 时长；处理周（`P2W`）表示、负数时长与超长单位归一化。当前时间类工具覆盖时间点换算（timestamp）与调度解析（cron），但缺少"时长/间隔"这一维度的解析与格式化。

## 设计内容（进入 Claimed 前补全）

- **工具 slug**：`iso8601-duration`
- **分类 / 图标**：`ToolCategoryEnum.TIME_MATH`（与 timestamp、cron 同属时间类）；图标 `Clock`
- **查重结论**：timestamp 工具处理「时间点」、cron 工具处理「调度表达式」，均不覆盖时长 / 间隔维度，无重复。
- **文件结构**（三件套，零新依赖）：
  - `constants.ts`：`DurationModeEnum`（parse/format）、`MODE_OPTIONS`、`DEFAULT_DURATION='P1Y2M3DT4H5M6S'`、`DEFAULT_SECONDS=90540`、折算常量（365 天/年、30 天/月、86400/3600/60）、`MAX_COMPONENT_VALUE=1e12`
  - `utils/duration.ts` 纯函数：
    - `parseDuration(input)`：带粘滞正则 `/(\d+(?:[.,]\d+)?)([A-Za-z])/y` 逐分量扫描；支持 ± 前缀、P、T/t 分隔、Y/M/W/D 与 H/M/S；校验缺 P、空 P/PT、单位重复、周与其他分量互斥、小数只允许末分量、T 后日期单位等
    - `durationToSeconds(value)`：固定折算（年 365 天、月 30 天、周 7 天），返回带符号总秒数
    - `normalizeSeconds(totalSeconds)`：按日→时→分→秒进位，sign 独立、分量非负，秒保留 3 位小数
    - `formatDuration(value)`：非零分量拼接，零时长 `PT0S`，负号前缀；周存在时只输出 W
    - `describeSeconds(totalSeconds)`：中文可读描述（天/小时/分/秒，负时长加「负」）
  - `index.tsx`：Radio 双模式；解析模式 Input 输入 ISO → 七分量卡片网格 + 负时长 Tag + 折算总秒数 + 错误 Alert；格式化模式 InputNumber 秒数（负/小数）→ 归一化分量 + ISO 输出 + 可读描述 + 复制
  - `index.module.css`：container/toolbar/mono/grid/cell(cellKey/cellValue)/totalRow/hint
- **注册**：`registry.ts` 双语 ToolMeta（TIME_MATH / Clock / isNew / MAINTHREAD，3 条 FAQ：年月折算近似、周互斥、小数末分量规则）；`loaders.ts` 懒加载
- **边界**：不做历法精确加减（年月无固定秒数，UI 明确标注近似）；反向格式化只输出 D/H/M/S（不引入年/月）；不引入任何日期库
