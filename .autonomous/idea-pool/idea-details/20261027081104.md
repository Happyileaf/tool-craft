## 描述

提供 RFC 7386 定义的 JSON Merge Patch 能力：在两个 JSON 文档之间生成最小 merge patch（null 表示删除键），或将给定 patch 应用到原文档输出结果，并高亮变更。面向 API 开发与调试中按 merge patch 语义做部分更新的场景。与已有 JSON 工具不重叠：`json-formatter` 只做格式化校验、`json-flatten` 做点路径扁平化、JSON 结构化差异对比只做展示，本工具产出符合 RFC 7396 语义、可直接发送给服务端的 patch 文档。
