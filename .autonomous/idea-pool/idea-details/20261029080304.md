## 描述

在公历日期时间（含一天内的小数日）、儒略日 JD 与约化儒略日 MJD（= JD − 2400000.5）之间双向精确换算，并给出对应的 Unix 时间戳参考。纯本地确定性历法算法（Fliegel–Van Flandern 或等价整数/浮点公式）、零依赖。解决天文、卫星、科学数据（FITS 等）中大量以 JD/MJD 记录时间、需要与日常日期对照核对的需求。

## 设计内容（进入 Claimed 前补全）

- 纯函数核心（`utils/julian.ts`）：
  - 公历日期时间 → JD：`JD = 2415020 + 365*(y-1900) + floor((y-1901)/4) - floor((y-1901)/100) + floor((y-1901)/400) + dayOfYear-1 + 当日小数`，统一以 1900-01-01T00:00 UT 基准日（JD 2415019.5）实现；MJD = JD − 2400000.5。
  - JD → 公历：用 Fliegel–Van Flandern 整数公式取日期部分，再由小数日反解时、分、秒；JD 含 0.5 天偏移（JD 日从正午 UT 起算）。
  - Unix 时间戳参考：JD 2440587.5 = 1970-01-01T00:00:00Z。
- UI：日期时间选择（年月日 + 时分秒，UTC）、JD / MJD 数字输入双方向转换，输出保留足够小数位，非法输入给出明确错误；零依赖、主线程。
