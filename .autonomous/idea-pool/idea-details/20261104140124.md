## 描述

实现 Apple Mach-O 可执行文件的只读二进制结构解析器：识别魔数 `FE ED FA CE/CF`（32/64 位，及字节序）与 Fat/Universal `CA FE BA BE/BE BA FE CA`；解析 mach_header(_64) 的 cputype（x86_64 / arm64 等）、cpusubtype、filetype（EXECUTE / DYLIB / BUNDLE 等）、ncmds 与 flags；逐项解析 load commands（LC_SEGMENT(_64) 的段名/vmaddr/vmsize/sections 计数、LC_SYMTAB、LC_DYSYMTAB、LC_UUID、LC_ID_DYLINKER、LC_CODE_SIGNATURE、LC_ENCRYPTION_INFO 等常见类型，未知 cmd 按原始 cmd/cmdsize 展示）；Fat 头列出每个切片的 cputype、offset、size 与对齐。以字段树 + 十六进制偏移对照展示，不解析代码段内容。

池中已有 ELF、PE、Java .class、WASM、PNG、ZIP、TAR 等「二进制文件头只读解析」家族工具，Mach-O 是 Apple 平台最后一个主流可执行格式且尚未覆盖，逆向分析、macOS/iOS 构建产物排障与安全审计需求明确。纯前端 ArrayBuffer 解析、文件不上传，头部与 load command 表为定长/自描述结构，可用真实 Mach-O（如 macOS 系统二进制）截取头部作为固定验收样本，复杂度 S–M。
