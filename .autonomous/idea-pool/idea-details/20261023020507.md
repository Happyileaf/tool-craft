## 描述

粘贴或上传字幕后在 SRT 与 WebVTT 两种格式之间双向转换：处理时间戳分隔符（逗号 ↔ 点）、WEBVTT 文件头、Cue 编号与空行规范，并提供整体时间轴平移 / 缩放选项。视频创作者在浏览器播放器（要求 VTT）与剪辑软件、字幕站点（普遍 SRT）之间迁移字幕时，手工批量修改时间戳分隔符与编号规则极易出错；现有已注册工具中无任何字幕相关能力，池内亦无相近条目。两种格式均为「编号 / 时间轴 / 文本行 + 空行」的纯文本行结构，解析与生成都可用纯函数完成，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- slug：`srt-vtt-converter`，分类 TEXT_CONTENT，主线程，零新增依赖。
- 纯函数 `convertSubtitle(input, mode, options?)`：解析 cue 块（数字序号/cue id + 时间戳行 + 多行正文），时间戳支持 `HH:MM:SS[.,]mmm` 与 `MM:SS.mmm`（时<100、分秒<60）；srt2vtt 补 `WEBVTT` 头、逗号改点号、保留序号与 VTT 定位设置；vtt2srt 剥 WEBVTT 头与 NOTE/REGION/STYLE 块、剥定位设置、点号改逗号并从 1 重编号；返回 output/warnings/cueCount/valid/error。
- `shiftMs` 整体毫秒偏移：任一 cue 偏移后起或止 <0 按序号报错。
- 归一化：去 BOM、CRLF→LF、去每行尾随空白；无时间戳行的块告警跳过；vtt2srt 强制首行 WEBVTT。
- UI：左右双栏 TextArea + 右上方向 Radio + 底部时间偏移 InputNumber + 复制，实时转换。
- 边界：空输入、非法时间戳、非 VTT 输入均中文报错。
