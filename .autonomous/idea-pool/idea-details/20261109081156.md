## 描述

输入电源电压、LED 正向压降（可按红 / 黄 / 绿 / 蓝 / 白常用颜色给参考值但允许手填）与期望工作电流，按欧姆定律 `R = (Vs − Vf) / If` 计算所需限流电阻、实际电流与电阻功耗，并给出 E24 标称系列中最接近的可选阻值（向上取整优先，避免过流）及其对应实际电流偏差；支持多颗 LED 串联 / 并联拓扑的参数换算。面向电子入门与选型场景。现有工具集中无任何电子电路计算类工具（`resistor-color-code-calculator` 做色环与阻值互转，不含电路方程与选型）；全部为四则运算与内置 E24 常量数组（24 个数值，非大表），零新依赖，S–M 复杂度。

## 设计内容（进入 Claimed 前补全）

- 工具 slug：`led-resistor-calculator`，分类 TIME_MATH（计算类，与 lc-resonance/three-phase 等电子计算工具一致），主线程纯函数，零新依赖。
- 输入：电源电压 Vs、LED 正向压降 Vf（红 2.0/黄 2.1/绿 2.2/蓝 3.2/白 3.2 快捷预设 + 手填）、期望电流 If(mA)；拓扑选择单颗 / N 颗串联 / N 颗并联。
- 计算：`R=(Vs−Vf_total)/If`、电阻功耗 `P=I²R`、实际电流；E24 系列 24 个常量中选最接近且不小于理论值的标称阻值（向上优先防过流），回算实际电流与偏差百分比。
- 输出：理论阻值、推荐 E24 标称值（Ω/kΩ 自适应量级）、实际电流、功耗与额定功率建议（≥2 倍冗余）、电流偏差。
- 边界：Vs ≤ Vf 总压降时报错（无法限流）、If ≤ 0 报错、并联拓扑按支路电流换算。
