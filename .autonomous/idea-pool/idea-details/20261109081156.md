## 描述

输入电源电压、LED 正向压降（可按红 / 黄 / 绿 / 蓝 / 白常用颜色给参考值但允许手填）与期望工作电流，按欧姆定律 `R = (Vs − Vf) / If` 计算所需限流电阻、实际电流与电阻功耗，并给出 E24 标称系列中最接近的可选阻值（向上取整优先，避免过流）及其对应实际电流偏差；支持多颗 LED 串联 / 并联拓扑的参数换算。面向电子入门与选型场景。现有工具集中无任何电子电路计算类工具（`resistor-color-code-calculator` 做色环与阻值互转，不含电路方程与选型）；全部为四则运算与内置 E24 常量数组（24 个数值，非大表），零新依赖，S–M 复杂度。

## 设计内容（进入 Claimed 前补全）

纯客户端单页工具，零网络、零新增依赖；电路计算与选型收敛为可单测纯函数 `utils/led.ts`，UI 负责参数录入与结果渲染。

- **输入**：电源电压 Vs、LED 正向压降 Vf（红 2.0 / 黄 2.1 / 绿 2.2 / 蓝白 3.2 预设可覆盖）、目标电流 If、LED 数量与拓扑（单路 / 串联 / 并联独立电阻）。
- **核心处理**：
  1. 理想电阻 R=(Vs−Vf_total)/If，功耗 P=I²R；
  2. 串联 Vf_total=N×Vf；并联每路按单路计算并汇总总电流 N×If；
  3. 在 E24 全系列（1Ω–9.1MΩ）选不小于理想值的最接近标称阻值，回算实际电流与偏差百分比。
- **输出**：理论电阻、推荐 E24 标称值、实际电流与偏差、电阻功耗。
- **边界**：Vs ≤ Vf_total、If ≤ 0、N 非正整数、缺失/非数值均返回中文可读错误，不抛异常。
