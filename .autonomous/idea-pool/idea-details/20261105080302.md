## 描述

在浏览器本地完成 Java 字节码层面的名称与类型表示互转：(1) 内部名（binary name，以 `/` 分隔，如 `java/util/Map$Entry`）与源码类名（以 `.` 分隔，如 `java.util.Map.Entry`）双向转换；(2) 按 JVMS §4.3 生成与解析字段描述符（field descriptor，如 `[[Ljava/lang/String;`、`I`、`Z`）；(3) 按 JVMS §4.3.3 生成与解析方法描述符（method descriptor，如 `(Ljava/lang/String;I)V`），拆解参数类型列表与返回类型；(4) 支持数组维度、原始类型（`B/C/D/F/I/J/S/Z`）与引用类型的语法校验，非法描述符给出具体错误位置。

现有 `20261102020125 Java .class 字节码文件头解析器` 只读取 class 文件头结构（魔数/版本/常量池计数），不做描述符字符串的生成与双向转换；JSON 转各语言模型类工具输出的是源码层面的类定义，与字节码描述符无关。转换规则由 JVMS 规范完全确定，零依赖纯函数可用固定向量断言，复杂度 S–M。
