## 描述

在普通文本与 NATO 音标字母（Alpha / Bravo / Charlie / Delta …）之间双向转换，逐字符给出拼写形式，数字采用标准读法（One / Two / Three …）。客服口述订单号、电话中拼读验证码、无线电与航空通信等场景高频需要标准拼写确认，池内摩尔斯电码条目是另一套电报编码（点划体系），与本工具的用途（拼写确认）和映射体系（36 项固定音标表）均不同。映射表为固定小体量常量（无数据维护成本），转换与反向解析均为纯函数，零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- **工具 slug**：`nato-phonetic-converter`
- **分类 / 图标**：`ToolCategoryEnum.CRYPTO_ENCODING`（与摩尔斯电码同属编码 / 密码学分类）；图标 `Type`（字母拼写语义，在 tool-icon 白名单内）
- **查重结论**：池内与 registry 无同功能工具；`morse-codec` 是点划电报编码，映射体系与「人声拼读确认」用途完全不同（已在 FAQ 说明区别）。
- **文件结构**（三件套，零新依赖）：
  - `constants.ts`：`PhoneticModeEnum`（encode/decode）、`MODE_OPTIONS`、`DEFAULT_TEXT='TRAE 42'`、`DEFAULT_PHONETIC`（由示例拼写生成）、`WORD_SEPARATOR='/'`
  - `utils/phonetic.ts`：`NATO_TABLE`（A–Z、0–9 共 36 项；A=Alfa、J=Juliett、9=Niner 为规范拼写）；`DECODE_ALIASES`（Alpha→Alfa、Juliet→Juliett、Nine→Niner）；`REVERSE_TABLE` 由表派生（小写键）并叠加异写
  - 纯函数：`encodePhonetic(text)`（空白折叠为单词边界，输出 `word1 / word2`，词内空格分词；非法字符返回 Error 信息）、`buildSpellGroups(text)`（返回 `{source, tokens:[{char,word}]}` 供逐字符卡片展示）、`decodePhonetic(phonetic)`（按 `/` 或多段空白分词、忽略大小写、支持 X-ray 连字符；非法字符 / 未识别单词报错）
  - `index.tsx`：Radio 双向切换、TextArea 输入、编码结果 TextArea + 逐字符拼写卡片（源单词分组、斜杠 Tag 分隔）、错误 Alert、复制结果、载入示例 / 清空
  - `index.module.css`：container/toolbar/mono/groups/group/token(tokenChar 蓝、tokenWord 灰)/hint
- **注册**：`registry.ts` 追加双语 ToolMeta（CRYPTO_ENCODING / Type / isNew / MAINTHREAD / defaultSampleInput='TRAE 42'，3 条 FAQ：与摩尔斯区别、9 为何 Niner、为何拒绝标点）；`loaders.ts` 追加懒加载条目
- **边界**：仅支持 A–Z、0–9（大小写不敏感）；标点 / 中文 / emoji 一律报错不静默丢弃；空输入返回空输出不报错；不引入音频播放（人声拼读工具无需）
