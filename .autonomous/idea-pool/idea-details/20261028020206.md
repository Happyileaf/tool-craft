## 描述

在 Java `.properties` 配置文本（`key=value` / `key:value` 风格）与 JSON 对象之间双向转换。解析方向需正确处理 `.properties` 语法细节：`=`/`:`/空白三种键值分隔符、行 continuation（行尾反斜杠续行）、转义序列（`\n \t \r \\ \uXXXX` 等，含 Unicode 转义解码）、`#`/`!` 注释行、空白行、键与值的首尾空白规则、重复键的覆盖策略；输出为扁平 JSON 对象（键原样保留，不臆造嵌套）。JSON→properties 方向将扁平字符串对象序列化，自动对特殊字符与分隔符做转义、必要时续行，并可选注释。与现有 INI↔JSON（INI 有 section / 段落结构）、YAML↔JSON、CSV↔JSON 不同：`.properties` 是无段落、扁平、以转义和续行为核心难点的 Java 生态配置格式，规则独立。纯本地确定性字符处理，纯函数实现，零新增依赖；复杂度为 S–M（单层词法解析，无需完整语言语法），可凭固定向量验收。
