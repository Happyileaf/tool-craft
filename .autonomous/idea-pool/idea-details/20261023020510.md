## 描述

通过参数调节实时生成三角形、箭头、圆形、椭圆、对话气泡、八角形、梯形等常用 CSS 形状，输出可直接复制的 border / clip-path / border-radius 代码。气泡提示尖角、下拉箭头、徽标角标等 UI 细节高频使用这类形状，手写 border 三角与 clip-path polygon 坐标既繁琐又易错；现有 CSS 生成器家族（box-shadow-generator、gradient-generator、css-filter-generator）不含形状能力，池内 Flexbox 布局可视化生成器（20261021221304）面向布局容器而非形状。形状参数到 CSS 代码是确定性纯函数（polygon 坐标可由几何公式推导），零新依赖、纯本地。
