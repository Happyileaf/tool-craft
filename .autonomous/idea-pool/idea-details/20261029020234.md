## 描述

面向音频、电子与射频工程，做分贝（dB）与线性倍数的双向换算，并区分功率量与场量（幅值 / 电压 / 声压）两种定义：功率比 dB=10·log₁₀(P/P₀)、倍数=10^(dB/10)；电压 / 幅值比 dB=20·log₁₀(V/V₀)、倍数=10^(dB/20)。支持常见参考值速查（+3 dB ≈ ×2 功率、−3 dB ≈ ×0.5、+6 dB ≈ ×2 电压、+20 dB ≈ ×10、−∞ dB = 0）与多级增益级联求和。与已实现的「欧姆定律与功率计算器」（V/I/R/P 电路量关系）不同：本工具处理对数域的分贝 / 倍数换算与级联，不涉及欧姆定律；现有工具中无任何 dB 计算。纯确定性数值计算，纯函数实现，零新增依赖。
