## 描述

对三端无源网络做三角形（Δ / Delta）与星形（Y / Wye）等效互换：输入 Δ 三边阻抗（或纯电阻）Z_AB、Z_BC、Z_CA，按「邻边乘积除以三边和」求出 Y 三臂 Z_A、Z_B、Z_C；反向输入 Y 三臂按「两两乘积之和除以对臂」还原 Δ。支持纯电阻实数模式与复数阻抗模式（直角坐标 R+jX 或极坐标 |Z|∠θ 输入），并提供等效性校验：变换前后任意两端口间等效阻抗两两相等。面向电路化简、三相接线分析与桥式网络求解教学，补全现有 `resistor-network-calculator`（仅串并联）、`resistor-voltage-divider`（分压）之外的三端拓扑能力；纯公式计算，零依赖。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① Δ → Y：Z_A = Z_AB·Z_CA / SΔ、Z_B = Z_AB·Z_BC / SΔ、Z_C = Z_BC·Z_CA / SΔ，其中 SΔ = Z_AB + Z_BC + Z_CA（复数按复数四则运算）。② Y → Δ：Z_AB = (Z_A·Z_B + Z_B·Z_C + Z_C·Z_A) / Z_C，Z_BC = 同分子 / Z_A，Z_CA = 同分子 / Z_B。③ 两种输入模式：纯电阻（实数，单位 Ω，支持 kΩ / MΩ 后缀归一）与复阻抗（每元件 R + jX，或幅值 + 角度° 内部互转）；输出同时给直角与极坐标形式。④ 等效性自校验：对结果自动计算 A-B、B-C、C-A 三个端口对的等效阻抗（Δ 侧为单边与另两边串联的并联；Y 侧为两臂串联），断言三对数值相等（容差 1e-9 相对误差）并展示校验表。⑤ 平衡网络快捷结论：三边相等 RΔ ↔ 三臂相等 RY = RΔ/3，作为内置示例。

**核心交互**：Δ→Y / Y→Δ 方向切换、实数 / 复数模式切换、三元件输入卡片（带拓扑示意 SVG，标注 A/B/C 节点与元件名）、结果区（三臂 / 三边值 + 极坐标 + 端口等效校验表）、复制按钮、平衡网络与非平衡示例一键填充。

**输入输出**：输入为三个电阻或复阻抗、方向与模式；输出为变换后三个元件值（Ω、直角 / 极坐标）、端口对等效阻抗校验表、除零 / 非法输入错误。

**边界情况**：纯电阻模式任一输入 ≤ 0 → 报错（无源正电阻约束；复阻抗模式允许 R=0 的纯电抗但拒绝全零臂）；Δ→Y 时 SΔ = 0 → 除零报错；Y→Δ 时任一臂为 0 导致对边公式除零 → 明确报错并解释该拓扑退化为短路；复数结果浮点尾数按固定精度展示，校验使用原始计算值；空白输入 → 占位提示；千分位与单位后缀（k/M）正确归一。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 平衡 Δ：三边均为 30 Ω → Y 三臂均为 10 Ω（RΔ/3）；反向 10 Ω 星形 → 30 Ω 三角形，闭环一致
- [ ] 非平衡电阻 Δ：Z_AB=20、Z_BC=30、Z_CA=50 Ω（S=100）→ Z_A=10、Z_B=6、Z_C=15 Ω；端口等效校验：R_AB(Y)=16 Ω 与 Δ 侧 20∥(30+50)=16 Ω 相等，其余两对同样相等
- [ ] Y → Δ 非平衡：Z_A=10、Z_B=6、Z_C=15 Ω → 还原 Z_AB=20、Z_BC=30、Z_CA=50 Ω（分子 = 60+90+150=300）
- [ ] 复阻抗：Δ 三边 10+j0、0+j10、10+j10 Ω → 按复数公式输出三臂，端口对等效阻抗实部 / 虚部在 1e-9 相对容差内两两一致；极坐标展示角度与幅值和直角坐标互洽
- [ ] 单位归一：输入 `1k`、`2.2k`、`4.7M` → 按 1000 / 2200 / 4700000 Ω 参与计算
- [ ] 异常：电阻 0 或负值、SΔ=0 构造、Y 臂含 0 → 均返回明确错误；空输入不崩溃
