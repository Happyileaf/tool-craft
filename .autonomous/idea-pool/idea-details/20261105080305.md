## 描述

在浏览器本地解析与生成 GNU gettext 消息目录文件：解析 `.po` / `.pot` 文本中的 msgid / msgstr、msgctxt、复数形式（msgid_plural / msgstr[n]）、多行续行字符串（`""` 拼接）、`#` 翻译者注释 / `#:` 行号引用 / `#,` 格式标志 / `#|` 旧值注释，以及头部 `msgid ""` 元数据块；输出为结构化 JSON（键含 msgid、msgstr、context、plurals、comments、references、flags），并支持从该 JSON 结构反向生成合法 PO 文本（含转义 `\"`、`\n`、`\\` 与多行折叠）。用于本地化流程中把翻译目录接入 Web/JSON 工具链或做批量检视。

现有配置转换工具（INI / .env / .properties / YAML / TOML 相关）均不覆盖 gettext 目录语法；`strings-json-converter` 面向 Apple `.strings`，格式与 PO 完全不同。PO 语法由 GNU gettext 手册确定，零依赖行状态机即可解析，固定样本可确定性断言，复杂度 M。
