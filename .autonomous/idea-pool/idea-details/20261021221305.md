## 描述

在页面中按下任意键或组合键，实时展示 KeyboardEvent 的 `key`、`code`、`keyCode`/`which`、`location` 以及 ctrl/meta/alt/shift 修饰键状态，并提供常用按键（功能键、方向键、数字字母）到键码的速查表，用于前端处理键盘快捷键、游戏按键时快速取值。当前 49 个工具无任何键盘/事件类能力，纯浏览器事件 + 静态映射即可，零依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：键盘事件实时监听面板 + 常用按键速查表，工具 slug 为 `keyboard-event-viewer`。
- **核心交互**：
  - 聚焦监听区域后按键，实时展示最新一次 KeyboardEvent 的 `key`、`code`、`keyCode`/`which`（legacy）、`location`（标准/左/右/小键盘）与 ctrlKey / metaKey / altKey / shiftKey / repeat 状态；同时展示可读的组合键表示（如 `Ctrl+Shift+A`）。
  - 监听时 `preventDefault` 可选开关（默认不阻止，避免页面不可用）；最近事件历史列表（最近若干条）。
  - 速查表：字母数字（A–Z、0–9）、功能键 F1–F12、方向键、空格/回车/Tab/Esc、Backspace/Delete 等的 keyCode、`code`、`key` 对照，支持按按键名/键码过滤。
- **输入输出**：速查表数据与组合键格式化、location 名称映射等放在纯函数 `utils/keyboard.ts` 并用 Vitest 覆盖；组件只负责事件订阅与展示。
- **边界情况**：无按键事件时展示空状态引导；失焦停止/恢复监听；keyCode 已废弃字段标注 legacy。
