## 描述

HTML 实体编解码工具。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：HTML 实体编码与解码双向转换。
- **编码**：将 `&` `<` `>` `"` `'` 等敏感字符转义为命名实体（如 `&amp;` `&lt;` `&gt;` `&quot;` `&#39;`）；可选的「编码非 ASCII 字符」开关将 Unicode 字符转为命名实体（命中则用命名实体，否则用十进制数字实体）。
- **解码**：将命名实体与数字实体（十进制 `&#123;`、十六进制 `&#x1F600;`）还原为字符，覆盖常见命名实体表。
- **核心交互**：方向切换、选项开关、输入即时转换、复制 / 清空 / 载入示例。
- **边界情况**：编码时 `&` 优先处理避免二次转义；解码时未知实体与非法数字实体保留原文并提示；孤立 `&` 不误判。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 编码：`&` `<` `>` `"` `'` 转为对应命名实体，且 `&` 不会被二次转义。
- [ ] 解码：命名实体与十进制/十六进制数字实体均正确还原为字符。
- [ ] 未知实体与非法数字实体保留原文，不抛异常。
- [ ] 支持编解码方向切换与「编码非 ASCII 字符」开关。
- [ ] 纯浏览器本地运算，无任何网络请求。
