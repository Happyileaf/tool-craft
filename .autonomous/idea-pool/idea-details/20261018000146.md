## 描述

从 Markdown 文本中提取各层级标题，生成带锚点链接的嵌套目录，支持选择有序/无序列表、限定最大标题层级，并可一键把目录插入到原文指定位置。现有 markdown-preview 仅负责正文渲染，不产出目录；长文档（README、规范文档）手动维护目录成本高且易与标题不同步。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：从 Markdown 文本提取标题生成目录，工具 slug 为 `markdown-toc-generator`；只识别 ATX 风格 `#` 标题。
- **标题提取**：逐行扫描 1–6 级 `#` 标题，正确跳过围栏代码块（``` 与 ~~~）与行内代码中的 `#`；支持 setext 标题不作为本期范围。
- **选项**：有序 / 无序列表切换、最大标题层级（1–6）、最小层级过滤、是否生成 GitHub 风格锚点链接（小写、空格转 `-`、去除标点）。
- **输出**：按标题层级缩进的嵌套列表 TOC 文本；另提供「插入原文」结果（TOC 放在首个一级标题前或指定标记处可选，默认输出 TOC + 原文拼接）。
- **核心交互**：左栏粘贴 Markdown，选项开关实时控制，右栏显示 TOC 与插入后全文，一键复制。
- **输入输出**：纯函数 `extractHeadings(markdown)` 与 `generateToc(headings, options)`，不触碰 DOM / React。
- **边界情况**：无标题输出空态；代码块内 `#` 不算标题；`#` 后须有空格；转义行首 `#`（如 `\#`）识别为非标题。
