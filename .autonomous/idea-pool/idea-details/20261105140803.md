## 描述

依据 HTML 标准（§9.2 Server-sent events，`text/event-stream`）在浏览器本地完成 SSE 线格式的双向转换：编码侧输入结构化消息（data 文本、event 事件名、id、retry 毫秒，支持批量消息列表），自动按规则输出——多行 data 拆成多个 `data:` 行、字段值中的换行按 LF/CRLF 规范化、空行作为消息分隔、`retry` 必须为十进制整数否则报错、以冒号开头的注释行（心跳）可选生成；解码侧粘贴原始 SSE 流文本，按规范的行解析算法（处理 `\r\n`/`\r`/`\n` 三种换行、忽略空行与注释、未知字段忽略、同名 data 行以 `\n` 拼接、遇到空行派发事件并重置缓冲区）还原为消息对象数组，并对畸形输入（如 `id` 含换行、`retry` 非数字）标注错误位置与规范依据。

池中协议格式工具已有 JWT、HAR、multipart/form-data（Pending）、WASM/ELF 解析等，但经全仓检索无 `text/event-stream` / EventSource 相关工具；SSE 的「字段行 + 空行分隔」语法与 JSON、表单编码均不同，是独立的 W3C 线格式，不构成重复。编解码为确定性纯文本处理，可用标准附录中的经典样例（含多行 data、注释、CRLF 混合换行）做固定断言，零依赖，复杂度 S。参考来源：HTML Living Standard §9.2 与 MDN「Server-sent events」。
