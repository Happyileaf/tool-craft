## 描述

按 RFC 9562（取代 RFC 4122）对「命名空间 UUID + 名称字符串」确定性地生成 v3（MD5）与 v5（SHA-1）名称型 UUID：选择内置命名空间（DNS / URL / OID / X.500 DN）或粘贴自定义命名空间 UUID，输入名称后输出 UUID，并展示版本/变体位的设置结果。解决同一资源标识需要跨系统、跨时间得到**相同且可复现** UUID 的需求（如根据域名、文件名、固定键派生稳定标识），与只能随机产出 v4 的 `uuid-generator` 互补。算法为确定性哈希 + 固定字节改写，纯函数实现、零新增依赖（MD5 / SHA-1 已在 `hash-generator` 中实现，Web Crypto 亦支持 SHA-1），可用 RFC 附录的标准向量验收。
