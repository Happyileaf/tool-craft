## 描述

围绕 N 位模数 / 数模转换器的量化关系做双向计算：输入分辨率位数（1–32）、参考电压（单极性 Vref 或双极性 ±Vref）与编码方式（无符号二进制 / 二进制补码），输出码值总数 2^N、LSB 步进电压、满幅码（2^N−1）、满幅电压与理想传递函数；支持「电压 → 最近码值」量化（含截断 / 四舍五入两种模式与实际量化误差、±½LSB 边界）和「码值 → 电压」还原，并给出理论动态性能：SNR = 6.02N + 1.76 dB、SINAD 理想值、有效位数 ENOB 反算、量化噪声 RMS（LSB/√12）。面向单片机 ADC 配置、数据采集电路评估与嵌入式教学；纯算术公式，零依赖、固定向量可验收。

## 设计内容（进入 Claimed 前补全）

**功能范围**：① 参数总览：N（1–32 整数）、Vref（> 0）、单 / 双极性模式；输出 LSB = Vref / 2^N（单极性满幅 Vref）或双极性 LSB = 2·Vref / 2^N（量程 −Vref..+Vref）、码值总数、满幅码、理想满幅输出电压（单极性 Vref − 1 LSB）。② 电压 → 码值：单极性码 = round(Vin / LSB)（可选 floor 截断模式），补码模式按偏移二进制 ↔ 二补码映射输出十六进制与十进制；超量程（Vin < 0 或 ≥ Vref）报错或夹取并标注 clipping；输出量化误差（V）与误差 / LSB 比值。③ 码值 → 电压：校验码值在 [0, 2^N−1]，还原 Vout = code × LSB（单极性）或 (code − 2^(N−1)) × LSB（双极性补码）。④ 动态性能：理想 SNR(dB) = 6.02N + 1.76、量化噪声 RMS = LSB/√12、峰值量化误差 = ½ LSB；反向：由实测 SINAD 反算 ENOB = (SINAD − 1.76) / 6.02。⑤ 常用分辨率预设：8 / 10 / 12 / 16 / 24 位一键切换对照。

**核心交互**：位数与 Vref 输入、极性 / 编码 / 取整模式单选、电压码值互算两个方向的输入卡片、结果区（LSB、码值、误差、SNR / 噪声表）、复制按钮；位数较大（> 24）时内部以 BigInt 处理整数码值避免精度丢失，电压浮点部分用 Number 并注明精度边界。

**输入输出**：输入为 N、Vref、模式、Vin 或 code、可选实测 SINAD；输出为 LSB、码值总数与满幅码、量化码值与 hex、量化误差、SNR / ENOB / 噪声 RMS、clipping 与非法输入提示。

**边界情况**：N 不在 1–32 或非整数 → 报错；Vref ≤ 0 → 报错；Vin 超量程 → 明确 clipping 提示（夹取模式标注误差不封顶）；code 超出满幅码 → 报错；双极性补码负数码值按二补码 hex 展示；N > 24 时码值整数用 BigInt 精确计算，SNR 等浮点指标照常；空输入给出占位提示而非崩溃。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 单极性 12 位、Vref=3.3V：码值总数 4096、满幅码 4095、LSB = 3.3/4096 ≈ 0.00080566 V（≈ 0.806 mV），满幅输出 ≈ 3.29919 V
- [ ] 同上参数 Vin=1.65V（round 模式）→ code ≈ 2048，量化误差绝对值 ≤ ½ LSB；floor 模式结果为 2047 或 2048（按 Vin/LSB 精确值核对）
- [ ] 双极性 12 位、±2.048V：code=0 → −2.048V，code=4095 → +2.048V − 1 LSB，中点 code=2048 → 0V；LSB = 4.096/4096 = 0.001V
- [ ] SNR：12 位 → 6.02×12+1.76 = 74.0 dB；16 位 → 98.08 dB；量化噪声 RMS = LSB/√12（12 位 3.3V 时 ≈ 0.0002326 V）
- [ ] ENOB 反算：SINAD=72.24 dB → ENOB ≈ 11.74 位（按公式精度核对）
- [ ] 异常：N=0、N=33、Vref=0、code=4096（12 位）、Vin=5V（Vref=3.3）→ 均返回明确错误或 clipping 标注；24 位满幅码 16777215 用 BigInt 精确输出
