## 描述

在浏览器本地对 Markdown 文档做静态链接体检（不发起任何网络请求，符合 local-first 约束）：(1) 提取全部行内链接 `[text](url)`、引用式链接 `[text][ref]` 与紧凑引用 `[ref][]`、引用定义 `[ref]: url "title"`、自动链接与裸 URL；(2) 检查引用式标签是否有未定义引用（used but not defined）、定义了但从未使用的引用（defined but unused）、同一标签重复定义；(3) 对文档内 `#anchor` 相对锚点，按 GitHub 风格 slug 规则（小写、空格转连字符、去除标点）与文中实际标题比对，报告失效锚点；(4) 汇总外链/相对链接/邮件链接/锚点链接分类计数，按行号列出问题清单。

现有 `markdown-toc-generator` 只从标题生成目录（含锚点生成），`markdown-preview` 只做渲染，`pattern-extractor` 只做通用模式抽取，均不做引用一致性与锚点有效性校验。解析规则由 CommonMark 链接语法与 GitHub slug 规则确定，零依赖纯函数可用固定文档样本做确定性断言，复杂度 M。
