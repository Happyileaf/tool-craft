## 描述

在 GFM Markdown 表格、CSV / TSV、JSON 对象数组、HTML `<table>`、LaTeX `tabular` 五种表示之间做多向互转的结构化表格工具：以规范化的中间表模型（列名 + 行数组）承接任一来源，再渲染为其余四种目标格式；正确处理 GFM 对齐冒号、单元格内 `|` 转义、CSV 引号 / 换行 / 双引号转义（RFC 4180）、HTML 实体转义、LaTeX 特殊字符转义与列对齐说明符，支持首行是否为表头切换与空单元格保留。现有 `csv-json-converter` 仅覆盖 CSV ↔ JSON 两向、`fwf-csv-converter` 仅做定宽 ↔ CSV、In Progress 的「Markdown 表格生成器」聚焦从手工列定义生成 MD 表而不做多格式互转，四源查重以 Markdown 表格、表格转换、LaTeX tabular、HTML table 检索无同类多向工具。纯浏览器本地确定性解析 / 生成、零新增依赖，用含转义边界的固定表格向量做往返（round-trip）验收。
