## 描述

把一条完整的 `docker run` 命令转换为 docker-compose.yml 中的单个服务定义：自动解析 `-p/--publish`、`-v/--volume`、`-e/--env`、`--name`、`--network`、`--restart`、`--add-host`、`--cap-add/drop`、`--health-*`、`--log-*`、`--privileged`、`-it`、`--entrypoint`、`-w/--workdir`、`-u/--user`、`--memory/--cpus`、`--sysctl/--ulimit`、`--tmpfs/--dns/--device`、`--env-file` 等选项，映射为 ports、volumes、environment、cap_add/drop、healthcheck、logging 等 compose 字段；正确处理 shell 引号、反斜杠转义与行尾续行，未识别选项以告警列出而不中断转换。容器化部署普遍经历「先 docker run 试跑、再沉淀为 compose」的过程，手工转写易错且重复；纯字符串解析、零新依赖、纯本地。

## 设计内容（进入 Claimed 前补全）

- 工具目录：`apps/web/src/tools/docker-run-to-compose/`（index.tsx + index.module.css + constants.ts + utils/docker-run.ts + utils/docker-run.test.ts）。
- 核心纯函数（utils/docker-run.ts）：
  - `tokenizeShell(input)`：shell 风格词法切分，支持单/双引号、反斜杠转义、行尾 `\` 续行。
  - `parseDockerRun(command)`：容忍 `sudo docker` / `podman` 前缀；短选项合并（-it）、`--opt=value` 形式；选项分四类处理——取值型、列表型、布尔型、键值型；`-d/--detach` 等静默忽略，`--rm/--label-file` 给告警；镜像后 token 全部归入 command；服务名取 --name 或由镜像名派生。
  - `convertDockerRunToCompose(command)`：手工缩进生成 YAML；`yamlScalar` 对含 `: `、`#`、布尔歧义词的值自动加引号，映射键走 `yamlMapKey` 标识符规则。
  - healthcheck 支持 cmd/interval/timeout/retries/start-period/disable；logging 支持 driver 与 options。
- UI（Ant Design）：左命令输入右 YAML 预览双栏，实时转换；错误 Alert、未识别选项橙色 Tag 告警；底部选项映射速查 Table；一键复制 YAML。
