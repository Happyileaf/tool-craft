## 描述

在 INI 配置（section、`key = value`、注释、可选嵌套点号键）与 JSON 之间双向转换，支持注释保留选项、布尔/数字类型推断与格式化预览。现有配置格式转换只覆盖 YAML↔JSON（`yaml-to-json`/`json-to-yaml`）与 CSV↔JSON，`rejected.md` 中被否决的是 TOML↔JSON（TOML 1.0 语法过复杂），INI 语法简单、可用零依赖纯函数解析，不触碰被否决的复杂度红线，填补常见配置格式缺口。

## 设计内容（进入 Claimed 前补全）

- slug：`ini-json-converter`，分类 DEV_CODE，主线程纯浏览器运算，零新增依赖。
- `utils/ini.ts` 纯函数：`iniToJson(text, { inferTypes, dotSections })` 与 `jsonToIni(text | object)`。
- 解析：分节 `[section]`、`=` / `:` 分隔、`;` / `#` 整行注释、单双引号及转义；布尔/整数/浮点/科学计数法/null 推断，引号强制字符串；同名分节合并、同名键后者覆盖；分节与顶层标量冲突报错（带行号）；可选点号键与点号分节展开嵌套。
- 序列化：顶层标量在前、对象输出为单层 `[section]`；字符串按需加引号转义；标量数组输出逗号分隔（有损，FAQ 说明）；二层以上嵌套与对象数组报错。
- UI：方向 Segmented 切换、两个 INI 解析开关、示例/清空、双栏 Card 实时预览与复制，错误 Alert 展示中文信息。
