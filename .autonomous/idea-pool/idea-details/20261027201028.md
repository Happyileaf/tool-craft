## 描述

对常用概率分布做数值计算：连续正态分布的 PDF、CDF 与区间概率 P(a<X<b) 及反函数（已知累积概率求分位 z），离散二项分布 B(n,p) 与泊松分布 Pois(λ) 的 PMF、CDF 与 P(X≤k) / P(X≥k) 累积；正态 CDF 用 erf/erfc 数值近似、分位用逆误差函数或牛顿迭代，离散分布用稳定的递推 / 对数阶乘求组合数，避免直接阶乘溢出。用于统计假设检验、显著性水平、可靠性与排队 / 计数建模的快速估算。与池中已有的「描述性统计计算器」（对一组样本求均值 / 方差 / 分位数等汇总量）不同：本工具不处理样本数据，而是针对给定理论分布参数求概率与分位，是推断统计而非描述统计，能力不重叠；也区别于「排列组合计算器」（只做计数）。全部为确定性数值算法，纯函数实现，零新增依赖，可用标准统计表向量验收。
