## 描述

粘贴一条 cURL 命令，解析其中方法、请求头、请求体、认证等参数，生成等价的代码片段（如 JavaScript fetch、Python requests），简化从「用 cURL 调通」到「写进代码」的迁移。当前工具集无任何请求命令 / 代码互转能力。

## 设计内容（进入 Claimed 前补全）

- **功能范围**：解析常见 cURL 参数（`-X/--request`、`-H/--header`、`-d/--data/--data-raw/--data-binary/--data-urlencode`、`-F/--form`、`-u/--user`、`-I/--head`、`-G/--get`、`--compressed`、URL、多段换行续行），生成目标语言代码片段。
- **核心交互**：输入 cURL 命令，选择目标语言（JavaScript fetch / Node.js axios / Python requests / Go），即时输出等价代码，支持一键复制；解析失败或缺少 URL 时给出可读提示。
- **输入输出**：输入 cURL 命令字符串，输出目标语言代码文本；非法输入输出可读错误说明。
- **边界情况**：shell 引号（单引号 / 双引号 / 转义）与反斜杠换行续行、`$'...'` 形式的字面量、`--data-urlencode` 与 `-F` 表单字段、重复 Header 合并、`-u` 基本认证构造 `Authorization: Basic`、未显式指定方法时按是否有请求体推断 GET / POST、URL 缺省协议补全。

## 验收标准（进入 Claimed 前补全，必须可验证）

- [ ] 输入含 `-X POST`、`-H`、`-d` 的 cURL，正确解析方法、头与请求体并生成目标代码。
- [ ] 未显式指定方法时，含请求体推断为 POST、无请求体推断为 GET。
- [ ] 正确处理单 / 双引号包裹与反斜杠换行的参数。
