## 描述

输入 HTTP/2 连接的帧字节序列（十六进制或按行粘贴抓包数据），逐帧解析 9 字节帧头中的 Length、Type、Flags、Stream Identifier，展示帧类型名称与标志位含义，并对 DATA、HEADERS、SETTINGS、WINDOW_UPDATE、RST_STREAM、PING、GOAWAY、CONTINUATION、PRIORITY 输出可读的字段摘要与负载预览。HEADERS / PUSH_PROMISE 的 HPACK 压缩块仅标识长度与偏移，不做解压。用于 h2 抓包的帧级排错；明确限定为帧头与帧结构解析，保持 S 级复杂度。

## 设计内容（进入 Claimed 前补全）

功能范围：单页工具。① 十六进制输入框（容忍空格、换行、`0x` 前缀，可省略连接前导 PRI * HTTP/2.0 魔数）。② 逐帧解析 9 字节定长帧头（24 位 Length、8 位 Type、8 位 Flags、1 位保留 R、31 位 Stream Identifier），输出偏移、类型名、标志位名、流标识与载荷摘要；覆盖 SETTINGS / WINDOW_UPDATE / PING / GOAWAY / RST_STREAM 等类型的可读摘要，HEADERS / DATA / CONTINUATION 仅标识长度与偏移，不做 HPACK（RFC 7541）解压。③ 规则校验：保留位 R 必须为 0、连接级帧（SETTINGS / PING / GOAWAY / 连接级 WINDOW_UPDATE）流标识必须为 0、SETTINGS 载荷长度为 6 的倍数、载荷长度超 16384（默认 MAX_FRAME_PAYLOAD_SIZE）告警、输入截断与残余字节检测。④ 帧类型速查表（RFC 7540 §4/§11）。

核心交互：内置三帧样例（SETTINGS + WINDOW_UPDATE + PING）一键载入、清空、复制输入；错误与告警以 Alert / 行内 Tag 展示；结果表格展示帧序列与告警计数。

输入输出：输入为十六进制文本；输出为帧序列表、载荷摘要、告警与错误信息。

边界情况：奇数个十六进制字符 / 非十六进制字符明确报错；不足 9 字节帧头或声明长度超出剩余字节报截断；空输入给出占位提示；全部解析为确定性纯函数，零依赖。
