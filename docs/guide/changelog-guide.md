# 变更日志填写指南（apps/web/CHANGELOG.md）

> 本文档是 `apps/web/CHANGELOG.md` 的填写指南，定义其条目格式与填写规范。变更日志文件本身只保留实际条目，说明统一维护在本文档。

## 条目格式

每个变更批次一个条目，置于 CHANGELOG「日志」章节顶部：

```markdown
## <YYYY-MM-DD> ：【Agent自主迭代】<变更内容简述>
## <YYYY-MM-DD> ：【人工迭代】<变更内容简述>

- **新增**：<工具中文名>（<slug>）— <一句话功能>
- **修改**：<工具中文名>（<slug>）— <变更说明>
- **移除**：<工具中文名>（<slug>）— <移除原因>
- **备注**：<非工具类的重要变更或背景说明>（可选）
```

## 填写规范

- **记录范围**：apps/web 模块的变更内容（新增 / 修改 / 移除等）；无论来源——Agent 自主迭代与人工迭代均在 CHANGELOG 登记。
- **条目标题**：日期 + 来源标签（【Agent自主迭代】/【人工迭代】）+ 变更内容简述。
- **排序**：条目按时间倒序排列，最新在最上。
- **一日一条**：同一日期只对应一个条目；当日再次发生变更时，**追加或整合**进当日已有条目（同步更新标题简述与明细行），不新建条目。
- **有变更才记录**：无变更的类别整行省略；无任何变更的批次不产生条目（轮次运行情况记录在 `docs/sop/autonomous-iteration/backlog.md` 的运行记录中）。
- **变更对象**：以 apps/web 的工具为主；非工具类的重要变更（如 i18n、主题系统、依赖调整）以 **备注** 行记录。
