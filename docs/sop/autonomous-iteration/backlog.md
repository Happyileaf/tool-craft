- **状态**：候选 ｜ 已选中 ｜ 实现中 ｜ 已实现 ｜ 已否决 ｜ 待人工决策
- **状态日期**：YYYY-MM-DD
- **结果/原因**：（已实现填写 PR 编号与 URL；已否决填写具体原因；待人工决策填写问题、背景与建议；其他状态填写当前进展）
- **备注**：

状态使用要求：

- `已实现` 必须填写真实 PR 编号和 URL。
- `已否决` 必须填写至少一个未通过的评估维度和具体原因。
- `待人工决策` 必须填写待决策问题、背景与建议。
- 评估通过但因本轮实现数量上限未入选的 Idea，状态保持 `候选`，并在“备注”中明确记录原因。
