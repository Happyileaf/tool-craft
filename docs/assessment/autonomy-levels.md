# 自迭代自治等级

> **文档定位**：评估模块，工具-Craft 自治能力等级框架对照表（静态定义）。
>
> 用法：评估时对照本框架，评估结果记录在评估文档，不存储状态于此。

## 1. 评估轴

自治等级衡量一条完整迭代链路中，由 Agent 与自动化设施覆盖、无需人工介入的环节比例：

```
选题 → 实现 → 验证 → 提 PR → 合并 → 部署
```

定级只看两点：链路中哪些环节已自动化；人工介入点收缩到了哪个环节。

## 2. 等级定义

| 等级 | 名称 | 链路覆盖 | 人工介入点 |
| --- | --- | --- | --- |
| L1 | 人工执行 | 无自动化，人写每一步 | 全部环节 |
| L2 | 人机协作 | Agent 辅助编码 | 逐步确认每次改动 |
| L3 | 半自治闭环 | 选题 → 实现 → 验证 → 提 PR 全部由 Agent 完成 | review 与 merge |
| L4 | 完全无人值守 | L3 基础上 CI 全绿即 auto-merge、自动部署 | 仅异常时介入 |
| L5 | 自我进化 | L4 基础上 Agent 自行修订流程规则、自定目标 | 无 |

关于 L5：L5 是被有意排除的安全边界，不是演进目标——流程与规则类文档的修订权保留在人工；任何将流程修订权交给 Agent 的变化都应视为越权，不计为升级。

## 3. 降级告警触发器

当评估判定自治等级发生降级后，**必须触发告警通知开发者**：

- 通知方式：需要在会话中主动告知；如果有集成告警渠道（Issue / 邮件 / IM）需要一并发送。
- 必告内容：当前等级变化、降级原因、需要开发者介入处理的事项。

## 4. 对照用法

- **时机**：项目结构发生重大变更后；CI / 基础设施变更后；版本发布前的例行评估；触发重新评估任一情形。
- **方法**：对照本表逐一核对，满足哪个等级即定到哪个等级。
- **记录**：评估结果单独记录，本文件作为框架对照表，不存储状态。

快速自查命令示例：

```bash
# 本地验证链是否正常
pnpm lint && pnpm typecheck && pnpm test && pnpm build
# gh 认证与远程是否可用
gh auth status && git remote -v
# main 分支是否已配置保护（返回 404 即未配置）
gh api repos/Happyileaf/tool-craft/branches/main/protection
```
